## 刷题铁律（来自 `Algorithms/README.md`）
1. 想 30~40 分钟没思路就看题解，看完**关掉题解重写**
2. 看题解才做出的题记入 `笔记/redo-list.md`，一周后重做，AC 才算完成
3. 每场 rated 赛后 48 小时内完成 upsolve
4. 每做完一题问自己：为什么想到这个算法？为什么自己没想到？复杂度为什么对？
