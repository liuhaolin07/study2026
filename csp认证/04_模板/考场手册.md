## 第 2 页：丢分六大原因自查表 ★每次提交前扫一遍

| # | 原因 | 自查动作 |
|---|---|---|
| 1 | **long long 溢出** | 所有求和/乘积/计数是不是 `ll`？`1 << i` 是不是该写 `1LL << i`？ |
| 2 | **题意理解偏差** | 题面读 3 遍了吗？「同时」「不超过」「恰好」「保证」都圈了吗？ |
| 3 | **边界没处理** | n=1？n=0？空集？最大值？全相同？负数？重复元素？ |
| 4 | **输出格式错** | 空格还是换行？结尾要换行吗？大小写对吗？逐字符比样例 |
| 5 | **TLE** | `ios::sync_with_stdio(false)` 加了吗？用 `'\n'` 不是 `endl`？复杂度对吗？ |
| 6 | **`sort` 比较器写 `<=`** | 最后一级必须是 `<`！写 `<=` 会 RE，整题 0 分 |

### 其他高频坑

- `priority_queue` **默认是大根堆**；小根堆要 `priority_queue<int, vector<int>, greater<int>>`
- `priority_queue` 的比较器语义和 `sort` **相反**（返回 true 的优先级更低）
- 线段树数组开 **`4 * n`**，开小了 RE
- 树状数组下标**从 1 开始**，数组开 `n + 2`
- `v.size() - 1` 当 `v` 为空时是**巨大正数**（无符号溢出）
- `map` 的 `operator[]` 会**插入默认值**，只读判断用 `find` / `count`
- `cin >> n` 后接 `getline` 必须 `cin.ignore()`
- 多组数据时**全局数组要在每组开头重置**
- 递归深度 > 1e4 会**栈溢出**，改迭代
- DP 数组初始化：求最大且"必须装满"→ `-INF`；求最小 → `INF`
- 01 背包容量**倒序**，完全背包容量**正序**
- 区间 DP **先枚举长度，再枚举起点**
- `unordered_map` 在 CSP 上**可能被卡哈希**，`n ≤ 1e5` 时优先用 `map`
- 浮点数**不要用 `==`**，用 `fabs(a-b) < 1e-9`；能用整数就别用浮点
- Dijkstra **不能处理负权边**
- 局部数组**不清零**（`int a[N]` 在函数里是随机值），全局数组自动清零

| n | 可行复杂度 | 想到什么 |
|---|---|---|
| ≤ 10 | `O(n!)` | 全排列 |
| ≤ 20 | `O(2^n · n)` | **状压 / 子集枚举**（出题人在明示） |
| ≤ 100 | `O(n³)` | **Floyd / 区间 DP** |
| ≤ 1000 | `O(n²)` | 二维 DP、双重循环 |
| ≤ 1e5 | `O(n log n)` | **排序 / 堆 / 树状数组 / 线段树 / 二分 / map** |

## 第 5 页：前缀和 / 差分 / 二分

### 一维前缀和（下标从 1 开始，避免边界）

```cpp
for(int i=1;i<=n;i++) s[i] = s[i-1] + a[i];
// 区间 [l,r] 的和 = s[r] - s[l-1]
```

### 二维前缀和

```cpp
for(int i=1;i<=n;i++) for(int j=1;j<=m;j++)
    s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j];
// 子矩阵 (x1,y1)-(x2,y2) = s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]
```

### 差分（区间加，最后一次性还原）

```cpp
d[l] += v; d[r+1] -= v;
for(int i=1;i<=n;i++) a[i] = a[i-1] + d[i];
```

### 二分答案（两种模式，别搞反）

```cpp
// 求"最大的满足 check 的 x"（最大化最小值）
int l = lo, r = hi, ans = lo;
while(l <= r){ int mid = l + (r-l)/2; if(check(mid)){ ans = mid; l = mid+1; } else r = mid-1; }

// 求"最小的满足 check 的 x"（最小化最大值）
int l = lo, r = hi, ans = hi;
while(l <= r){ int mid = l + (r-l)/2; if(check(mid)){ ans = mid; r = mid-1; } else l = mid+1; }
```

⚠️ `mid = l + (r-l)/2` 防溢出；`l <= r` 和 `l = mid+1 / r = mid-1` 必须配套

## 第 6 页：数据结构

### 并查集

```cpp
int fa[N];
void init(int n){ for(int i=1;i<=n;i++) fa[i]=i; }
int find(int x){ return fa[x]==x ? x : fa[x]=find(fa[x]); }   // 路径压缩
bool unite(int a,int b){ a=find(a); b=find(b); if(a==b) return false; fa[a]=b; return true; }
```

### 树状数组（单点改 + 区间查）

```cpp
ll c[N]; int n;
int lowbit(int x){ return x & (-x); }
void add(int i, ll v){ for(; i<=n; i+=lowbit(i)) c[i]+=v; }
ll sum(int i){ ll r=0; for(; i>0; i-=lowbit(i)) r+=c[i]; return r; }
ll range(int l,int r_){ return sum(r_) - sum(l-1); }
```

区间改 + 单点查：对差分数组建树状数组，`add(l,v); add(r+1,-v);` 查询即 `sum(i)`

### 线段树（单点改 + 区间查，无懒标记）

```cpp
ll t[4*N];                                    // ⚠️ 必须 4*N
void build(int p,int l,int r){
    if(l==r){ t[p]=a[l]; return; }
    int m=(l+r)/2; build(p*2,l,m); build(p*2+1,m+1,r);
    t[p]=t[p*2]+t[p*2+1];
}
void upd(int p,int l,int r,int x,ll v){
    if(l==r){ t[p]+=v; return; }
    int m=(l+r)/2;
    if(x<=m) upd(p*2,l,m,x,v); else upd(p*2+1,m+1,r,x,v);
    t[p]=t[p*2]+t[p*2+1];
}
ll qry(int p,int l,int r,int L,int R){
    if(L<=l && r<=R) return t[p];
    int m=(l+r)/2; ll s=0;
    if(L<=m) s+=qry(p*2,l,m,L,R);
    if(R>m)  s+=qry(p*2+1,m+1,r,L,R);
    return s;
}
```

## 第 7 页：图论

### 建图（n ≤ 1e5 用 vector，别用邻接矩阵）

```cpp
vector<pii> g[N];                    // g[u] = {(v, w), ...}
g[u].pb({v,w}); g[v].pb({u,w});      // 无向图两边都加
```

### BFS 最短路（无权图 / 网格）

```cpp
vector<int> d(n+1, -1); queue<int> q;
d[s]=0; q.push(s);
while(!q.empty()){
    int u=q.front(); q.pop();
    for(auto [v,w] : g[u]) if(d[v]==-1){ d[v]=d[u]+w; q.push(v); }
}
```

**多源 BFS**：把所有起点**一次性全 push 进队列**，不是循环 n 次 BFS
**网格四方向**：`int dx[4]={0,0,1,-1}, dy[4]={1,-1,0,0};` 记得判越界 + 判 visited

### Dijkstra 堆优化 `O(m log n)`

```cpp
vector<ll> d(n+1, LINF);
priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<>> pq;   // 小根堆
d[s]=0; pq.push({0,s});
while(!pq.empty()){
    auto [du,u] = pq.top(); pq.pop();
    if(du > d[u]) continue;                       // ⚠️ 过期节点跳过，这句不能省
    for(auto [v,w] : g[u])
        if(d[u]+w < d[v]){ d[v]=d[u]+w; pq.push({d[v],v}); }
}
```

⚠️ **有负权边不能用 Dijkstra**，改用 SPFA / Bellman-Ford

### Floyd `O(n³)`（n ≤ 400）

```cpp
for(int k=1;k<=n;k++)          // ⚠️ k 必须在最外层
  for(int i=1;i<=n;i++)
    for(int j=1;j<=n;j++)
      if(d[i][k]<INF && d[k][j]<INF) d[i][j]=min(d[i][j], d[i][k]+d[k][j]);
```

### 拓扑排序（Kahn，兼判环）

```cpp
vector<int> indeg(n+1,0), order;
queue<int> q;
for(int i=1;i<=n;i++) if(indeg[i]==0) q.push(i);
while(!q.empty()){
    int u=q.front(); q.pop(); order.pb(u);
    for(int v : g[u]) if(--indeg[v]==0) q.push(v);
}
bool has_cycle = ((int)order.size() != n);
```

### Kruskal 最小生成树

```cpp
sort(edges.begin(), edges.end());        // 按权值升序
```

## 第 8 页：DP

### 背包四件套

```cpp
// 01 背包：容量倒序
for(int i=0;i<n;i++) for(int j=V;j>=w[i];j--) f[j]=max(f[j], f[j-w[i]]+v[i]);

// 完全背包：容量正序
for(int i=0;i<n;i++) for(int j=w[i];j<=V;j++) f[j]=max(f[j], f[j-w[i]]+v[i]);

// 多重背包：二进制拆分成 01 背包
for(int i=0;i<n;i++){
    for(int k=1; k<=s[i]; s[i]-=k, k<<=1)
        for(int j=V;j>=k*w[i];j--) f[j]=max(f[j], f[j-k*w[i]]+k*v[i]);
    if(s[i]>0)
        for(int j=V;j>=s[i]*w[i];j--) f[j]=max(f[j], f[j-s[i]*w[i]]+s[i]*v[i]);
}

// 分组背包：每组至多选一件，组内循环在最里层
for(int i=0;i<ng;i++) for(int j=V;j>=0;j--)
    for(auto& it : group[i]) if(j>=it.w) f[j]=max(f[j], f[j-it.w]+it.v);
```

⚠️ **正序/倒序是第一大坑**：01 倒序（防重复使用），完全正序（允许重复）
⚠️ 初始化：求最大且必须装满 → `f[0]=0`，其余 `-INF`；求最小 → `INF`

### LIS `O(n log n)`

```cpp
vector<int> g;                             // g[i] = 长度 i+1 的上升子序列的最小结尾
for(int x : a){

}

```

## 第 10 页：大模拟检查清单 + 暴力速查

### 大模拟四步法

```
第1步 拆规则：题面读3遍，规则编号 R1/R2/…，圈所有限定词
              ⚠️ 重点找"同时发生的事件怎么排序"
第2步 定状态：先写 struct 列出所有状态量，再选容器
第3步 排顺序：多关键字 sort，比较器最后一级用 <
第4步 分阶段：每实现一条规则就用样例验证，不要全写完再跑
```

### 容器选型

| 需求 | 选择 |
|---|---|
| 按 key 查 + **需要有序遍历** | `map` / `set` |
| 按 key 查 + 不需顺序 | `unordered_map`（**可能被卡哈希**，n≤1e5 优先 map） |
| 动态取最值 | `priority_queue`（**默认大根堆**） |
| 顺序处理 + 头部弹出 | `queue` / `deque` |
| 需要撤销回退 | `stack` 或 `vector` 存历史 |
| 区间查改 | 树状数组 / 线段树 |

### 提交前 10 项自查

```
[ ] 1.  题面读了 3 遍，限定词都圈了？
[ ] 2.  规则编号列全了？
[ ] 3.  "同时发生"的顺序规则找到了？
[ ] 4.  struct 状态量都声明了，初始值对了？
[ ] 5.  比较器最后一级是 < 不是 <= ？
[ ] 6.  每实现一条规则都验证过样例？
[ ] 7.  极端样例测了？（n=1 / 全相同 / 空 / 最大值）
[ ] 8.  求和、乘积、计数都是 long long ？
[ ] 9.  输出格式逐字符对照样例了？
[ ] 10. 能跑的代码已经提交了？
```

### 10 分钟暴力速查

| 题目形态 | 暴力写法 | 预期分 |
|---|---|---|
| 选或不选，n ≤ 20 | 二进制枚举子集 | 20~40 |
| 求顺序，n ≤ 10 | `next_permutation` | 20~40 |
| 区间改 + 区间查 | 直接扫，`O(n·q)` | 30~50 |
| 图上多组询问，n ≤ 400 | Floyd `O(n³)` | 30~50 |
| 数方案 | DFS 直接数 | 20~40 |
| 字符串 | `O(n²)` 枚举所有子串 | 30~50 |
| 完全没思路 | 特判 n=1/n=2，或过样例即可 | 5~15 |

### 分层派发写法

```cpp
if(n <= 20)        solve_brute();       // 稳拿小数据分
else if(n <= 2000) solve_quadratic();   // O(n^2)
else               solve_optimal();     // 正解
```

**正解写不完就只留暴力分支交上去**——这是正确决策，不是失败。
