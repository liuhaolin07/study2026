> 规则会随届次调整，**每次认证务必以当次官网公告为准**。

## 一、这是什么考试

CCF CSP 认证 = **CCF 计算机软件能力认证**（Certified Software Professional），由中国计算机学会统一命题、统一评测。

注意区分两个同名缩写：

| | CCF CSP 认证 | CSP-J / CSP-S |
|---|---|---|
| 面向 | 大学生、IT 从业者 | 中小学生（信息学奥赛体系） |
| 形式 | **上机编程**，5 题 | 第一轮笔试 + 第二轮上机 4 题 |
| 满分 | **500 分** | 第二轮 400 分 |
| 时长 | 240 分钟 | J 组 3.5h / S 组 4h |

**本仓库针对的是前者**（5 题 500 分，目标 350+）。

## 二、基本盘（必须背下来的数字）

| 项目 | 内容 |
|---|---|
| 题量 | **5 道编程题**，难度依次递增 |

| 时长 | **240 分钟（4 小时）** |

| 举办频次 | 每年 **3、6、9、12 月各一次**（2022 年起每年 4 场） |

| 成绩查询 | 考后 1~2 周，官网自行下载电子成绩单（彩打后 CCF 公章有效） |

## 三、评测环境（决定你本地怎么练）

| 项目 | 考场配置 |
|---|---|
| 操作系统 | **Ubuntu 24.04 64 位** |
| C++ | **g++ 13.2.0**，编译选项 `-O2 -DONLINE_JUDGE -std=c++17/23/14/98` |
| C | gcc 13.2.0，`-O2 -DONLINE_JUDGE -std=c17/11/99` |
| Java | OpenJDK 21.0.5 |
| Python | 3.12.3，**不含 numpy 等第三方库** |
| 时空限制 | **以题面标示为准，所有语言时间限制完全一致**（Python 不额外加时） |

### 本地练习必须对齐考场

本机 `g++ 16.1.0` 默认标准比考场新，**直接用默认参数练会写出考场编译不过的代码**。统一用下面这条命令编译：

```powershell
g++ -O2 -std=c++17 -DONLINE_JUDGE -Wall solution.cpp -o solution
```

- `-std=c++17`：考场支持的最高稳定档，**不要用 C++20/23 特性**（concepts、ranges、`std::format` 等考场可能不给选）
- `-DONLINE_JUDGE`：配合 `#ifndef ONLINE_JUDGE` 做本地文件重定向调试，交上去自动失效
- `-Wall`：本地把警告全开，考场没有这层保护

> ⚠️ Python 选手注意：考场没有 numpy/pandas。这也是本计划选 **C++** 的直接原因之一。

## 四、提交规则（这几条直接决定战术）

来自官方答疑页原文：

| 问题 | 官方答复 |
|---|---|
| 实时提交多久出结果？ | **数秒至数分钟**；临近结束时服务器易拥堵，可能考后才出结果 |
| 多次提交怎么算分？罚分吗？ | **取最高一次，无罚分** |
| 提交次数有限制吗？ | **有，每题 32 次** |
| 能看到排名吗？ | 只能看到**自己的当前成绩**，排名固定显示为 1 |
| 同分怎么排名？ | **最先得到该分数的选手排名靠前** |

### 这四条推出的战术结论

1. **「取最高一次、无罚分」→ 一有能跑的代码就立刻提交。**
   不存在"改坏了会掉分"的风险。写完 30 分暴力马上交，锁定分数再去想正解。这是白送的分，很多人因为老 OI 赛制的惯性思维白白丢掉。
2. **「实时能看到自己得分」→ 提交就是最强的调试手段。**
   样例过了但不知道大数据对不对？交一次看分数变化，比盯着代码猜快得多。
3. **「每题 32 次」→ 够用但不能浪费。**
   不要提交完全相同的代码；每次提交前先想清楚"这次我改了什么、期望分数怎么变"。
4. **「同分先达成者靠前」→ 前半程抢分比后半程逆袭划算。**
   同样的 350 分，第 2 小时拿到比第 4 小时拿到排名更高。前 3 题要快。
5. **「临近结束服务器拥堵」→ 最后 10 分钟不要指望提交。**
   所有有把握的代码在 **230 分钟前**交完。

## 五、考场纪律（红线）

### 可以带

- 身份证 + 准考证
- **纸质材料：书籍、打印材料、手写材料都可以带**
- 笔、饮用水、食品、未拆封纸巾

> 这条极其重要：**可以带自制模板手册进考场**。所以 `04_模板/考场手册.md` 要认真做，考前打印出来。

### 绝对不能

- 任何通讯工具、存储设备（U 盘、移动硬盘）；手机**关机后置于考场外**
- 联网查资料、获取他人帮助
- **使用 AI 工具答题或辅助答题**

### AI 违纪条款（近年新增，务必看清）

> 考试期间不得使用 AI 工具答题或辅助答题，包括但不限于第三方大语言模型，包括通过对话交互、利用 AI 生成全部或部分代码。
> 每次认证结束后，CCF CSP 技术委员会对提交程序做**合规性分析**。存在答案雷同、AI 生成等问题且无法证实独立完成的，判定该次成绩 **0 分**，公示一周；申诉不成立者纳入 **CSP 黑名单，取消认证资格 1 年**。

对本计划的约束：**平时训练可以查题解、看视频、用 AI 帮你理解概念，但代码必须自己从零敲一遍**。养成"看完题解关掉再重写"的习惯，既是 `Algorithms/README.md` 的铁律，也是考场合规的底线。

## 七、350 分是什么水平

CSP 认证**不设通过线、不发证书**，只给带各题得分和排名的成绩单。业内的粗略刻度：

| 分数 | 含义 |
|---|---|
| 65 | 常被引用的"及格线" |
| 200 | 多数高校/企业的**门槛线**；CCSP 竞赛报名资格线 |
| **300** | "合格程序员"；**清华大学保研/考研机试线**（未达 300 原则上不予录取）；多所高校 300 分可**免复试机试** |
| **350** | ← **本计划目标**。稳超 300 门槛线，接近优秀档 |
| 400 | "优秀程序员"；多校免机试后上机成绩按满分计 |

一个真实换算例（中国地质大学计算机学院 2025 年通知）：

- CSP ≥ 400 → 上机成绩按 **100 分**计
- CSP 300~400 → 上机成绩 = **(CSP 分数 − 300) × 0.20 + 80**

按这个公式，**350 分 → 上机 90 分**；再往上每 5 分只换 1 分，边际收益递减。所以 350 是性价比很高的目标点：够到绝大多数学校的认可线，又不需要卷到 400+ 的算法深度。

其他认可方式：华为/百度/阿里等对高分得主免笔试直面；同济、湖南大学、哈工大、西电、南理工、深大把 CSP 成绩作为保研资格条件之一；湖南大学、燕山大学计入学分。
