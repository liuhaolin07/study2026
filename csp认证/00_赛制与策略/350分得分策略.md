# 350 分得分策略

> 前置阅读：[`CSP认证速览.md`](CSP认证速览.md)。本文所有战术都建立在四条官方规则上：
> **取最高分 / 无罚分 / 每题 32 次提交 / 实时可见自己得分**。

---

## 一、先想清楚：350 分从哪来

500 分满分，5 题各 100 分。350 分不需要"会做难题"，需要的是**前三题不丢分 + 后两题稳定薅到部分分**。

### 三档方案

| 方案 | T1 | T2 | T3 | T4 | T5 | 合计 | 适用人群 |
|---|---|---|---|---|---|---|---|
| **A 大模拟型**（主推） | 100 | 100 | **100** | 30 | 20 | **350** | 工程实现稳，算法一般 |
| **B 均衡型** | 100 | 100 | 70 | 50 | 30 | **350** | T3 读题慢，但算法有底子 |
| **C 算法型** | 100 | 100 | 80 | **100** | 0 | **380** | 算法强，但大模拟容易漏细节 |

**本计划按方案 A 训练**，理由：

- T1、T2 是纯送分题，只要不犯低级错误就是 200 分，**这部分没有区分度，但丢了就是致命的**。
- T3 是 CSP 的招牌「大模拟」：题面长、规则多、没有巧妙算法，**考的是工程能力而非智商**。这类题投入产出比最高——练 20 道就能从 40 分稳定到 90+ 分，而同样的时间投在 T5 上可能只涨 10 分。
- T4、T5 有明确的**数据范围分层**，出题人就是留了部分分给你的。写对暴力 = 白拿 30~50 分。

### 一句话总结

> **300 分靠稳，50 分靠暴力。** 前三题练"不犯错"，后两题练"快速写出能跑的暴力"。

## 二、五道题的画像

历年真题的稳定规律（难度总体递增，但**不保证严格递增**，偶尔 T2 比 T3 难）：

| 题号 | 典型考点 | 满分难度 | 目标分 | 建议用时 |
|---|---|---|---|---|
| **T1** | 简单模拟、基础数学、字符串处理、进制/日期换算 | ★ | **100** | ≤ 25 min |
| **T2** | 中等模拟、排序、前缀和/差分、哈希统计、简单贪心 | ★★ | **100** | ≤ 45 min |
| **T3** | **大模拟**：长题面 + 多规则 + 状态维护（如命令行解析、权限系统、卡牌游戏、文本编辑器、竞价撮合） | ★★★★ | **≥ 80，冲 100** | 70~90 min |
| **T4** | 算法题：最短路 / 并查集 / DP / 线段树 / 二分，**数据范围明显分层** | ★★★★ | **≥ 40** | 40~50 min |
| **T5** | 高难算法：网络流 / 复杂 DP / 计算几何 / 数论，**部分分靠 n≤20 暴力或特殊性质** | ★★★★★ | **≥ 20** | 30 min |

### T3 大模拟为什么是关键

CSP 的 T3 几乎从不考"高级算法"，考的是：

1. **读长题面并准确抽取规则**（题面常有 500~1500 字 + 多个约束条件）
2. **状态建模**：用什么 struct，用什么容器，怎么表示"当前状态"
3. **事件顺序**：多个事件同时发生时谁先谁后（CSP 最爱在这里埋坑）
4. **实现不出错**：300~500 行代码一次写对

这四项**全部可以通过刻意练习提升**，且提升速度快于图论/DP。历史上大量考生 T3 只拿 20~40 分（样例分），意味着 **T3 拿满 100 分就能直接甩开一大片人**。

## 三、4 小时时间分配表（考场执行版）

```
00:00 - 00:15  通读 5 题题面，做标记（见下）
00:15 - 00:40  T1  →  写完立即提交，确认 100 分
00:40 - 01:25  T2  →  写完立即提交，确认 100 分
01:25 - 02:55  T3  →  先交样例暴力保底，再逐规则实现，反复提交
02:55 - 03:40  T4  →  先交暴力（30~50 分保底），有余力再上正解
03:40 - 04:00  T5  →  只写暴力 / 特殊性质，交上去拿 20 分
最后 10 min     确认 5 题都有提交记录；不再改任何代码
```

### 前 15 分钟读题要标记什么

拿草稿纸画一张表，5 行，每行填：

| 题 | 一句话题意 | n 的范围 | 我能想到的最暴力解法 | 预估分 |
|---|---|---|---|---|
| T1 | | | | 100 |
| T2 | | | | 100 |
| T3 | | | | ? |
| T4 | | | | ? |
| T5 | | | | ? |

**只看数据范围就能预判 60% 的解法**（详见 [`../02_知识清单/CSP考频知识点清单.md`](../02_知识清单/CSP考频知识点清单.md) 的复杂度反推表）。

如果发现 T2 明显比 T3 难（偶尔发生），**果断交换顺序**，不要死磕。

## 四、核心战术：三步提交法

这是 CSP 新赛制下最重要、也最容易被忽视的技巧。

### 第 1 步：暴力保底（读完题 10 分钟内）

不管会不会正解，**先写一个"直白到不可能写错"的暴力**，提交，锁定分数。

```
读完 T4 → 发现 n ≤ 1e5，正解要线段树
        → 先写 O(n^2) 双重循环（n ≤ 1000 的数据能过）
        → 提交 → 拿到 30 分 → 心态稳了，再想正解
```

暴力的标准：**能不思考就写出来**。宁可复杂度差，也不要写"稍微优化一下"的半吊子版本——那种最容易写错。

### 第 2 步：正解替换（想到就写）

写出正解后提交。**取最高分，所以暴力那 30 分不会丢。**

### 第 3 步：用提交做调试

因为**实时能看到自己的分数**，提交本身就是最好的调试工具：

- 交一次，从 30 → 60：说明思路对了，是边界/细节问题
- 交一次，从 30 → 30：说明正解思路本身错了，回去重想
- 交一次，从 100 → 100（样例分）：说明大数据没过，查复杂度和溢出

每次提交前问自己：**"这次我改了什么？我期望分数变成多少？"** 如果答不上来，就别浪费这次提交（32 次上限）。

## 五、部分分薅取清单

CSP 每题通常有 10~20 个测试点，**按点给分**。后两题的部分分来源非常固定：

| 部分分来源 | 怎么做 | 典型收益 |
|---|---|---|
| **样例数据** | 只要程序能跑、格式对，样例点就过了 | 5~15 分（白送） |
| **小数据暴力** | 题面常写"其中 30% 的数据满足 n ≤ 100"→ 写 O(n²)/O(n³) | 20~40 分 |
| **特殊性质数据** | "保证图是一棵树" / "保证所有数互不相同" / "k = 1" → 针对特判 | 10~30 分 |
| **退化情形** | n = 1、n = 0、全相等、答案恒为 0 的特判 | 5~10 分 |
| **输出格式分** | 有些题只要求输出一个数（如"最大值"），暴力枚举即可 | 10~20 分 |

### 分层写法的标准姿势

```cpp
if (n <= 20) {
    solve_brute();      // 状压 / 全排列暴力，稳拿小数据分
} else if (n <= 2000) {
    solve_quadratic();  // O(n^2) DP
} else {
    solve_optimal();    // 正解
}
```

**即使正解写不完，前两档也能交上去拿分。** 考场上如果发现正解来不及，就只保留暴力分支提交——这是完全正确的决策，不是失败。

## 六、丢分的六大真实原因（按频率排序）

来自历年考生复盘，**350 分以下的失分几乎全部来自这些，而不是"不会算法"**：

| # | 原因 | 症状 | 对策 |
|---|---|---|---|
| 1 | **long long 溢出** | 样例对，大数据全错 | 只要涉及求和/乘积/计数，**默认全用 `long long`**。CSP 特别爱考这个 |
| 2 | **题意理解偏差** | T3 拿到样例分就上不去 | 题面读 **3 遍**，圈出所有"若"「则」「同时」「不超过」「恰好」等限定词 |
| 3 | **边界没处理** | 差 10~20 分 | 主动造极端样例：n=1、n=0、空集、最大值、全相同、负数 |
| 4 | **输出格式错** | 0 分 | 空格/换行/大小写/是否要换行结尾，逐字符对照样例 |
| 5 | **TLE** | 大数据超时 | `ios::sync_with_stdio(false); cin.tie(nullptr);` + 别用 `endl`（用 `'\n'`）+ 别在循环里 `cin` 字符串 |
| 6 | **`sort` 比较器写成 `<=`** | 运行错误（RE），整题 0 分 | 比较器必须**严格弱序**，相等时必须返回 `false` |

> 第 6 条值得单独强调：`sort` 的比较器如果写成 `return a.x <= b.x;`，在数据量大时会触发未定义行为直接 RE，**整题 0 分**。这是 CSP 考场上最惨烈的翻车方式。必须写成 `<`。

## 七、考场 SOP（照着做，不用现场想）

### 考前一天

- [ ] 打印 [`../04_模板/考场手册.md`](../04_模板/考场手册.md)（A4 双面，官方允许带纸质材料）
- [ ] 下载/打印准考证，确认考点地址（**考前多登录几次系统，考点信息可能更新**）
- [ ] 身份证、准考证、手册、笔、水、未拆封纸巾装好
- [ ] 手机确认能关机；提前查好路线，**至少提前 30~60 分钟到场**
- [ ] 22:30 前睡，不做新题

### 进场后 5 分钟

- [ ] 登录系统：用户名 + **证件号码后 6 位**
- [ ] 打开 C++ 题，确认编译器选 **g++ 开头**的选项
- [ ] 建好 5 个源文件（`t1.cpp` ~ `t5.cpp`），每个先粘上 `contest.cpp` 骨架
- [ ] 确认本地能编译运行一次（写个 `cout << "ok"`）

### 交卷前 10 分钟

- [ ] 逐题确认**有提交记录**（没提交 = 0 分，这是最亏的）
- [ ] 确认提交的**题目和代码对应**（张冠李戴是真实发生过的事故）
- [ ] 停止一切修改。此时服务器可能拥堵，改了也来不及评测

## 八、与 `Algorithms/` 训练的关系

你已经有一套完整的 12 个月 ACM 训练计划（`Algorithms/学习路径.md`），目标 2027 ICPC 银牌。**CSP 350+ 比那个目标低得多**，所以：

| | ACM 训练（Algorithms/） | CSP 训练（本目录） |
|---|---|---|
| 目标 | 想出正解、追求最优复杂度 | **实现正确 + 部分分最大化** |
| 赛制 | ACM 罚时，WA 有代价 | **取最高分、无罚分**，鼓励多交 |
| 短板 | 难题思维 | 大模拟工程能力、读长题面 |
| 时间压力 | 5h 三题，可讨论 | 4h 五题，独立完成 |

### 两条线怎么合并（每天 2~3 小时）

- **CSP 专项占 60%**（约 1.5h）：大模拟、真题、部分分训练 → 本目录题单
- **ACM 主线占 40%**（约 1h）：继续推 `Algorithms/题单/` 的当前专题 → 02-basics / 03-search / 04-data-structure
- **CF Div2 照打**：CSP T4/T5 的难度约等于 CF Div2 的 C/D 题，打 CF 是有效的 CSP 训练
- **周日复盘合并做**：一份周报，同时更新 `Algorithms/笔记/redo-list.md` 和 `05_模考与复盘/`

好处：CSP 训练会显著强化你的**实现能力**，这正是 ACM 三人一机里"一机"最缺的东西。两条线不冲突，互相加成。

## 九、三个月的分数目标曲线

用模考分数追踪进度，每次模考记在 [`../05_模考与复盘/模考记录模板.md`](../05_模考与复盘/模考记录模板.md)：

| 时间点 | 模考目标分 | 关键能力 |
|---|---|---|
| W1（摸底） | 不限，测真实水平 | 熟悉赛制，知道自己现在几分 |
| W4（第 1 月末） | **≥ 220** | T1+T2 稳定满分，T3 拿到样例分以上 |
| W8（第 2 月末） | **≥ 300** | T3 稳定 70+，T4 暴力稳定 30+ |
| W11 | **≥ 340** | T3 稳定 90+，T4/T5 部分分稳定 |
| W12（考前） | **≥ 350** | 连续两次模考达标即可上场 |

**不达标怎么办**：不要加量，先定位是哪一题丢的分。
- 丢在 T1/T2 → 低级错误问题，去 `Algorithms/笔记/易错点与调试.md` 过一遍，练"写完必自测"
- 丢在 T3 → 大模拟专项加练，每天 1 道，见 [`../03_真题题单/历年真题题单.md`](../03_真题题单/历年真题题单.md)
- 丢在 T4/T5 → 部分分技巧没到位，练"10 分钟内写出并提交暴力"
