### 必须搞清的坑

- **并查集**：`find` 必须写路径压缩，否则退化成链；`n` 要开到题目上限
- **树状数组**：下标**从 1 开始**（`lowbit(0)=0` 会死循环），数组开 `n+2`
- **线段树**：数组要开 **`4 * n`**，开小了会 RE（最常见的翻车）
- **线段树懒标记**：递归下去前**必须 `push_down`**；`lazy` 累加时 `t` 也要同步加 `v * 区间长度`
- **`priority_queue`**：默认是**大根堆**！小根堆要 `greater<>`
- **自定义比较器**：`priority_queue` 的比较器和 `sort` 的**语义相反**（返回 true 的优先级更低）
- **`map` vs `unordered_map`**：需要有序遍历只能 `map`；`unordered_map` 可能被卡哈希
- **`map` 的 `operator[]` 会插入默认值**，只读判断用 `find`/`count`
- **`v.size() - 1` 当 v 为空是巨大正数**（无符号溢出）
- **单调队列存下标不存值**，否则无法判断是否出窗

### 建图选型（按数据范围）

| 点数 n | 边数 m | 建图方式 | 最短路算法 |
|---|---|---|---|
| n ≤ 500 | 稠密 | 邻接矩阵 | Floyd `O(n³)` 或朴素 Dijkstra `O(n²)` |
| n ≤ 10⁵ | m ≤ 2×10⁵ | `vector<pair<int,int>> g[]` | 堆优化 Dijkstra `O(m log n)` |
| n ≤ 10⁵ | 有负权 | 同上 | SPFA（**可能被卡**，能用 Dijkstra 就别用） |
| 有负权 + **限制边数 ≤ k** | — | 边数组 | **Bellman-Ford（k 轮 + backup）** |
| 边权只有 0 和 1 | — | 同上 | **0-1 BFS（deque）** |
| 网格图 | n×m ≤ 10⁶ | 直接二维数组，不建图 | BFS，四方向数组 `dx[4]/dy[4]` |

### 必须搞清的坑

- **Dijkstra 不能处理负权边**；堆优化版 `if (du > d[u]) continue;` **不能省**（否则退化 O(m²)）
- **必须用小根堆**（`greater<>`），写反全错
- **Floyd 的 k 必须在最外层**，放最里层结果是错的
- **Bellman-Ford 限边数场景必须用 backup 数组**，防止本轮结果串用
- **多源 BFS**：把所有起点**一次性全 push 进队列**，不是循环 n 次 BFS
- **网格题记得判越界 + 判 visited**，漏一个就死循环
- **n 是 10⁵ 级别时别用邻接矩阵**（直接 MLE）
- **递归 DFS 在链状图上会栈溢出**，n > 10⁴ 时改迭代版（**入栈就标记 vis**）
- **拓扑排序判环**：结果数量 < n → 有环

### 背包四件套（必背）

```cpp
// 01 背包：每件物品只能用一次 → 容量倒序
for (int i = 0; i < n; i++)
    for (int j = V; j >= w[i]; j--)
        f[j] = max(f[j], f[j - w[i]] + v[i]);

// 完全背包：每件物品无限用 → 容量正序
for (int i = 0; i < n; i++)
    for (int j = w[i]; j <= V; j++)
        f[j] = max(f[j], f[j - w[i]] + v[i]);

// 多重背包：第 i 件有 s[i] 个 → 二进制拆分成 01 背包
// 分组背包：每组至多选一件 → 组外循环，容量倒序，组内循环在最里层
```

> ⚠️ **正序/倒序是背包第一大坑**。01 背包倒序（防止一件物品被用多次），完全背包正序（允许重复使用）。写反了样例可能还是对的，大数据全错。

### 必须搞清的坑

- **DP 数组初始化**：求最大值且"必须恰好装满"时，除 `f[0]=0` 外全初始化为 `-INF`；求最小值时全 `INF`。**初始化错了会算出根本不可达的状态**
- **区间 DP 枚举顺序**：必须**先枚举长度，再枚举起点**，否则转移时子区间还没算
- **环形区间 DP**：数组复制一份接在后面（长度 2n），对每个起点算 `f[i][i+n-1]`
- **`ll`**：DP 求方案数几乎必然溢出，看题目是否要取模；取模时**减法要 `+MOD`**
- **状压 DP 的 `1 << i`**：`i ≥ 31` 时必须写 `1LL << i`，否则溢出
- **LIS 严格上升用 `lower_bound`，非降用 `upper_bound`**
- **树形 DP 别漏父亲那侧的连通块**（求重心时）
