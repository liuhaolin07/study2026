# 第 3 月：真题模考冲刺（W9 ~ W13，2026-11-16 ~ 考试日）

> 月末目标：模考 **≥ 350 分**，连续两次达标即可上场。
> 本月**不再学新知识点**（唯一例外：W11 的**模拟退火**，它是 T5 骗分利器，必须练熟），只做三件事：**模考、补弱项、固化考场流程**。
> 弱项回炉时查 [`../02_知识清单/`](../02_知识清单/)（索引见 [`README.md`](../02_知识清单/README.md)，考频分级见其第二节）。

---

## 一、本月的核心转变

前两个月在"学"，这个月在"演"。区别：

| 前两个月 | 第 3 个月 |
|---|---|
| 按专题刷，可以查资料 | **4 小时全真，除自制手册外不查任何东西** |
| 做完对答案、看题解 | **严格计时，到点必须切题** |
| 追求"这题我会了" | 追求"这套卷我能拿 350" |
| 单题思维 | **全局时间分配思维** |

**这个月最重要的不是分数，是节奏。** 很多人知识点都懂，考场上因为时间分配崩盘只拿 250。

## 二、六次模考安排

| 模考 | 日期 | 用什么卷子 | 重点检验 |
|---|---|---|---|
| ③ | W9 周六 11-21 | AcWing 真题（较早年份） | T3 能否稳定 80+ |
| ④ | W10 周六 11-28 | AcWing 真题（近年） | T4 暴力是否 10 min 内交出 |
| ⑤ | W11 周六 12-05 | AcWing 真题（最近 3 次之一） | 整体节奏，目标 ≥ 340 |
| ⑥ | W12 周六 12-12 | **官方模拟系统兑换码** | 全真环境（Ubuntu + 官方评测），目标 ≥ 350 |

> **官方兑换码只有 1 个，务必留到 W12。** 它的价值在于环境完全一致：同样的 Ubuntu、同样的 g++ 13.2、同样的提交界面、同样的实时分数显示。提前用掉就浪费了这个适应机会。
> 如果 W11 模考⑤ 已经 ≥ 350，可以考虑把兑换码提前到 W11 用，W12 改用 AcWing。

### 模考日的完整流程（每次都照做）

```
13:00  准备好：计时器、草稿纸、打印版考场手册、水
13:15  打开卷子，先不看题，把 5 个 .cpp 文件建好，各粘一份 contest.cpp
13:30  开考。严格执行时间分配表：
         00:00-00:15  通读 5 题 + 填标记表
         00:15-00:40  T1
         00:40-01:25  T2
         01:25-02:55  T3
         02:55-03:40  T4
         03:40-04:00  T5
17:30  收工。不管做没做完，停手。
17:30-18:00  立刻记录：每题得分、每题用时、每次提交的分数变化
次日      复盘 2h（见下）
```

### 模考复盘 2h 怎么花

1. **30 min**：把没做出/没满分的题**关掉题解重做**（这是唯一真正涨分的动作）
2. **30 min**：对着 [`../00_赛制与策略/350分得分策略.md`](../00_赛制与策略/350分得分策略.md) 的"丢分六大原因"逐条自查，把命中的记进错题本
3. **30 min**：分析**时间分配**——哪题超时了？超时是因为慢还是因为不肯放弃？
4. **30 min**：更新考场手册，把这次卡住的模板/套路补进去

> 复盘时问自己一个关键问题：**「这次丢的分里，有多少是'不会'，有多少是'会但没拿到'？」**
> 如果"会但没拿到"超过一半，说明问题在流程和心态，不在知识——那就别加练算法，加练限时和检查清单。

**原则：不做新题，不学新东西，不熬夜。**

| 事项 | 说明 |
|---|---|
| 每天 1 道 T1 或 T2 | **只为保持手感**，限时 25 min，做完就停 |
| 每天过一遍考场手册 | 30 min，重点看"丢分六大原因"和常用模板 |
| 每天过一遍错题本 | 只看**自己写错的原因**，不重做 |
| 每天过一遍三级清单 | [`../02_知识清单/CSP考频知识点清单.md`](../02_知识清单/CSP考频知识点清单.md) 第四节，只看★★★级，确认全部能打勾 |

## 四、考前检查清单（考前一天 + 当天早上各走一遍）

### 物品

- [ ] 身份证（**原件**，其他证件多数无效）
- [ ] 准考证（打印版，**考前多登录几次系统确认考点没变**）
- [ ] 考场手册（A4 双面打印，官方明确允许带纸质材料）
- [ ] 黑色水笔 × 2、草稿纸（考点可能提供，自带更稳）
- [ ] 饮用水、食品（4 小时很长，中途会饿）、未拆封纸巾
- [ ] 手机（**进场前关机，放考场外**）

### 技术

- [ ] 报名语言 = **C++**，且考场提交时选 **g++ 开头**的编译器
- [ ] 记住登录方式：用户名 + **证件号码后 6 位**
- [ ] 记住自己的模板骨架能默写出来（开场 5 分钟就能建好 5 个文件）

### 战术

- [ ] 前 15 分钟通读 5 题，填标记表
- [ ] **每题一有能跑的代码就提交**（取最高分、无罚分）
- [ ] T3 到 90 min 必须切走
- [ ] T4/T5 先暴力后正解
- [ ] 230 min 前交完所有代码（服务器临近结束会拥堵）
- [ ] 最后 10 min 只确认"5 题都有提交记录"，不改代码

## 五、临场应急处理

| 情况 | 处理 |
|---|---|
| **T1/T2 卡住超过预期时间** | 立刻切下一题。前面卡住往往说明这次卷子 T2 偏难，**不要死磕**，先把 T3 的分拿到再回来 |
| **T3 完全读不懂题** | 先把样例的输入输出抄下来，**写一个能过样例的程序交上去**（至少拿样例分），再回头慢慢读题 |
| **T4/T5 完全没思路** | 写暴力：枚举所有可能 + 直接判断。10 分钟内必须交出去 |
| **代码怎么调都过不了样例** | **保存当前版本，从头重写一遍**。重写往往比调试快，尤其在大模拟里 |
| **时间只剩 30 min 还有题没交** | 停止思考正解，把所有没交的题都写上暴力交掉。**0 分和 10 分的差距就在这 30 分钟** |
| **提交后服务器迟迟不出结果** | 不要重复提交（浪费 32 次额度），继续做下一题，回头再看 |
| **心态崩了** | 去趟洗手间，喝口水，做 3 次深呼吸。回来看一眼当前得分——**大概率你已经过 300 了** |

## 六、考完之后

- 成绩考后 1~2 周出，官网自行下载电子成绩单
- 如果对成绩有异议，**复议窗口很短**（历年约 7 天），需要缴费并提交申请表，别错过
- 无论多少分，**把这次的经验写进 [`../05_模考与复盘/`](../05_模考与复盘/)**，下次（3 月场）可以直接接着练
- 成绩 ≥ 200 就可以报名 **CCF CCSP 竞赛**（大学生计算机系统与程序设计竞赛），是个不错的后续目标
- CSP 训练攒下的实现能力，直接接回 `Algorithms/` 的 ICPC 主线（你原本的第 4~6 月计划：搜索 + DP + 最短路）
