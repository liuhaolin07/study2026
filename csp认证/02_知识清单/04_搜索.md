## 4.1 DFS 与连通块 ★★★★★

### 基础模板

```cpp
bool vis[N];
void dfs(int u) {
    vis[u] = true;
    // 处理 u
    for (int v : g[u])
        if (!vis[v]) dfs(v);
}

// 求连通块数量
int cnt = 0;
for (int i = 1; i <= n; i++)
    if (!vis[i]) { dfs(i); cnt++; }
```

### 网格 DFS（flood fill）

```cpp
int dx[4] = {0, 0, 1, -1}, dy[4] = {1, -1, 0, 0};   // 四方向
// 八方向：dx = {-1,-1,-1,0,0,1,1,1}, dy = {-1,0,1,-1,1,-1,0,1}

bool in_grid(int x, int y) { return x >= 0 && x < n && y >= 0 && y < m; }

void dfs(int x, int y) {
    vis[x][y] = true;
    for (int d = 0; d < 4; d++) {
        int nx = x + dx[d], ny = y + dy[d];
        if (in_grid(nx, ny) && !vis[nx][ny] && can_pass(nx, ny))
            dfs(nx, ny);
    }
}
```

⚠️ **三个必查**：越界、已访问、可通行。漏任何一个都会死循环或 WA。

### DFS → 迭代（防栈溢出）

```cpp
// 递归版在链状图 n > 1e4 时会栈溢出（考场栈约 8MB，不一定能改）
void dfs_iter(int start) {
    stack<int> st;
    st.push(start); vis[start] = true;
    while (!st.empty()) {
        int u = st.top(); st.pop();
        // 处理 u
        for (int v : g[u])
            if (!vis[v]) { vis[v] = true; st.push(v); }   // ⚠️ 入栈时就标记，不是出栈时
    }
}
```

⚠️ **入栈时就标记 `vis`**，如果出栈时才标记，同一个点会被重复入栈，最坏退化成指数级。

|---|---|---|

| 求细胞数量 | 洛谷 P1451 | 网格连通块计数，四方向 DFS/BFS |

## 4.2 BFS 与最短路 ★★★★★

### 基础 BFS（无权图最短路）

```cpp
int d[N];                                  // 距离，-1 表示未访问
int bfs(int s) {
    memset(d, -1, sizeof d);
    queue<int> q;
    d[s] = 0; q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u])
            if (d[v] == -1) { d[v] = d[u] + 1; q.push(v); }
    }
    return d[target];
}
```

⚠️ BFS 求最短路**只对无权图（或所有边权相等）成立**。有权图要用 Dijkstra。

### 多源 BFS

```cpp
// 所有源点同时入队，求每个点到【最近源点】的距离
queue<pii> q;
for (每个源点 p) { d[p] = 0; q.push(p); }      // ⚠️ 一次性全部入队，不是循环 n 次 BFS
while (!q.empty()) { /* 正常 BFS */ }
```

### 0-1 BFS（边权只有 0 和 1）

```cpp
// 用 deque 代替 queue，O(V+E)，比 Dijkstra 快
deque<int> dq;
vector<int> d(n + 1, INF);
d[s] = 0; dq.push_front(s);
while (!dq.empty()) {
    int u = dq.front(); dq.pop_front();
    for (auto [v, w] : g[u]) {
        if (d[u] + w < d[v]) {
            d[v] = d[u] + w;
            if (w == 0) dq.push_front(v);      // 0 边加到队首
            else        dq.push_back(v);       // 1 边加到队尾
        }
    }
}
```

### 网格 BFS 求路径

```cpp
// 需要输出路径时，记录前驱
pii pre[N][N];
// BFS 中：pre[nx][ny] = {x, y};
// 最后从终点倒着回溯到起点，再 reverse
```

| 无线网络 | CSP 第 1 次 T4 | **分层 BFS**：状态是 `(点, 已用中转次数)`，超过 k 次的边不能走。求最少新增路由器数 |

| 靶形数独 | 洛谷 P1074 | DFS + **强剪枝**：每次选"候选数最少"的空格填（而不是按顺序），配合行/列/宫的位运算标记 |

## 4.3 回溯与全排列 ★★★★

### 全排列

```cpp
vector<int> path; bool used[N];
void dfs(int u, int n) {
    if (u == n) { /* path 是一个完整排列，记录 */ return; }
    for (int i = 0; i < n; i++) {
        if (used[i]) continue;
        // ⚠️ 去重：有重复元素时，跳过"同层相同且前一个未使用"的
        // if (i > 0 && a[i] == a[i-1] && !used[i-1]) continue;
        used[i] = true; path.push_back(a[i]);
        dfs(u + 1, n);
        path.pop_back(); used[i] = false;      // ⚠️ 撤销！忘了就是错的
    }
}
```

### 组合 / 子集枚举

```cpp
// 从 n 个数中选 k 个（组合，不计顺序）
void dfs(int u, int chosen) {
    if (chosen == k) { /* 记录 */ return; }
    if (u > n) return;
    if (n - u + 1 < k - chosen) return;        // ⚠️ 剪枝：剩下的不够选
    path.push_back(u); dfs(u + 1, chosen + 1); path.pop_back();   // 选 u
    dfs(u + 1, chosen);                                            // 不选 u
}
```

### n 皇后

```cpp
bool col[N], dg[2*N], udg[2*N];                // 列、主对角线(x+y)、副对角线(x-y+n)
void dfs(int x, int n) {
    if (x == n) { ans++; return; }
    for (int y = 0; y < n; y++) {
        if (col[y] || dg[x+y] || udg[x-y+n]) continue;
        col[y] = dg[x+y] = udg[x-y+n] = true;
        dfs(x + 1, n);
        col[y] = dg[x+y] = udg[x-y+n] = false;   // ⚠️ 撤销
    }
}
```

⚠️ **对角线的编码**：主对角线上 `x - y` 为常数（加 n 防负），副对角线上 `x + y` 为常数。这是最容易记错的地方。

| 八皇后 | 洛谷 P1219 | 同上，需要输出前 3 个解和总数 |

## 4.4 剪枝 ★★★★

### 六种剪枝手段（**CSP T5 的核心技巧**）

| # | 手段 | 说明 | 典型题 |
|---|---|---|---|
| 1 | **可行性剪枝** | 当前状态已经不可能达到目标（剩余体积不够、时间超了） | 生日蛋糕、小猫爬山 |
| 2 | **最优性剪枝** | 当前代价已经 ≥ 已找到的最优解，直接返回 | 小木棍、任何求最优的搜索 |
| 3 | **搜索顺序优化** | 先搜分支少的 / 先搜"更容易失败"的，让剪枝尽早生效 | 数独（选候选最少的格子）、小木棍（从长到短） |
| 4 | **去重剪枝** | 相同状态不重复搜（排序后跳过相同值、记忆化） | 组合枚举、有重复元素的全排列 |
| 5 | **记忆化** | 存下已算过的状态，直接返回 | 滑雪、Function |
| 6 | **对称性剪枝** | 利用问题对称性砍掉一半搜索空间 | n 皇后（第一行只搜一半再乘 2） |

### 剪枝的通用套路

```cpp
void dfs(State s) {
    if (is_solution(s)) { update_answer(); return; }
    if (!feasible(s)) return;                    // ① 可行性剪枝
    if (lower_bound(s) >= best) return;          // ② 最优性剪枝（估界）
    for (auto nxt : candidates_sorted(s)) {      // ③ 好的搜索顺序
        if (duplicate(nxt)) continue;            // ④ 去重
        if (memo.count(nxt)) { use(memo[nxt]); continue; }   // ⑤ 记忆化
        apply(nxt);
        dfs(next_state(s, nxt));
        undo(nxt);                               // ⚠️ 回溯
    }
}
```

### 估界函数（最关键的剪枝）

**下界**：从当前状态到目标，**至少**还要花多少代价？
- 生日蛋糕：剩余层的最小体积（预处理 `min_v[i]` = 前 i 层的最小体积）
- 小猫爬山：至少还要 `ceil(总重量 / 每车限重)` 辆车
- TSP：剩余点的最小出边之和

**上界**：先用贪心跑一个可行解作为初始 `best`，让最优性剪枝从一开始就生效。
⚠️ **这一步极其重要**：`best` 初始化为 `INF` 时，最优性剪枝几乎不起作用；先用贪心填一个较好的 `best`，剪枝效率能提升一个数量级。

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 小猫爬山 | AcWing 165 | 车数超过当前最优就返回；**按重量降序排**（先放重的，分支更少）；先用贪心给 best 一个初值 |
| 生日蛋糕 | AcWing 168 | 从大到小枚举每层半径/高度；预处理 `min_v[i]`、`min_s[i]`；用"剩余体积"和"剩余面积"双重剪枝 |
| 数独 | AcWing 166 | **位运算优化**：用三个 512 位掩码表示行/列/宫的可用数字，`lowbit` 枚举候选；每次选候选最少的格子 |
| 木棒 | AcWing 167 | 上面提到的四类剪枝全用；**总长从大到小枚举**，第一个能拼成的就是答案 |
| 靶形数独 | 洛谷 P1074 | 数独 + 加权得分，同样用"候选最少优先" |
| 送礼物 | AcWing 169 | n=45 直接搜会爆 → 用 Meet in the Middle（见 4.10） |

## 4.5 记忆化搜索 ★★★★

### 什么时候能用记忆化

**状态必须无后效性**：`f(状态)` 的值只由状态本身决定，与"怎么走到这个状态"无关。

⚠️ 如果路径会影响结果（如"已经用过哪些边"），就不能简单记忆化，要把额外信息编进状态里。

### 模板

```cpp
ll f[N]; bool vis[N];
ll dfs(int x) {
    if (base_case(x)) return base_value(x);
    if (vis[x]) return f[x];
    vis[x] = true;
    ll res = INIT;
    for (每个转移 y) res = max(res, trans(dfs(y), x));
    return f[x] = res;
}
```

### 记忆化 vs 递推 DP

| | 记忆化搜索 | 递推 DP |
|---|---|---|
| 方向 | 自顶向下 | 自底向上 |
| 状态稀疏时 | **优**（只算访问到的） | 差（全部算一遍） |
| 状态稠密时 | 稍慢（递归开销） | **优** |
| 转移顺序复杂 | **优**（不用想顺序） | 差 |
| 空间 | 需要额外的 `vis` 数组 | 可以滚动数组优化 |
| 栈溢出风险 | **有** | 无 |

**考场决策**：想不清递推顺序 → 写记忆化；状态是"一层一层"的（如背包、线性 DP）→ 写递推（能滚动数组省空间）。

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 滑雪 | AcWing 901 | 网格记忆化：`f[i][j]` = 从 (i,j) 出发的最长路径，向四个更低邻居转移 |
| Function | 洛谷 P1464 | 三维记忆化 + `>20` 时归一到 (20,20,20) 的剪枝 |
| 引水入城 | 洛谷 P1514 | 记忆化搜索：每个蓄水厂能覆盖的**连续区间**（关键结论：覆盖区间一定连续，若不连续则无解）。用 `l[i], r[i]` 记录左右端点 |
| 吃奶酪 | 洛谷 P1433 | 状压记忆化：`f[S][i]` = 已吃集合 S、当前在 i 的最短路 |
| 最大子树和 | 洛谷 P1122 | 树形记忆化：`f[u] = val[u] + sum(max(0, f[v]))` |

## 4.6 状态空间搜索 ★★★★

### 核心：把"局面"编码成一个可哈希的对象

CSP 的 T4/T5 常考这类题：**状态不是图上的点，而是整个局面**。

```cpp
// 八数码：3×3 棋盘 -> string（9 个字符）
string encode(const vector<vector<int>>& b) {
    string s;
    for (int i = 0; i < 3; i++) for (int j = 0; j < 3; j++)
        s += (b[i][j] == 0 ? 'x' : char('0' + b[i][j]));
    return s;
}

// BFS
unordered_map<string, int> dist;
queue<string> q;
dist[start] = 0; q.push(start);
while (!q.empty()) {
    string s = q.front(); q.pop();
    if (s == target) return dist[s];
    for (string nxt : expand(s))                 // 把 'x' 与相邻位置交换
        if (!dist.count(nxt)) { dist[nxt] = dist[s] + 1; q.push(nxt); }
}
return -1;
```

### 常见编码方式

| 状态类型 | 编码 |
|---|---|
| 棋盘 | `string` 拼接 |
| 每个位置有 k 种取值 | k 进制数（`val = sum(a[i] * k^i)`） |
| 集合 | 位掩码 `int` / `ll` |
| 多个变量 | `tuple<int,int,int>` 或手写 `struct + hash`，或 `(a * M + b) * M + c` |
| 排列 | **康托展开**（排名 0 ~ n!-1） |

### 康托展开（排列 → 唯一整数）

```cpp
ll cantor(const vector<int>& a) {           // a 是 0..n-1 的排列
    ll res = 0;
    for (size_t i = 0; i < a.size(); i++) {
        int cnt = 0;
        for (size_t j = i + 1; j < a.size(); j++) if (a[j] < a[i]) cnt++;
        res += cnt * fact[a.size() - 1 - i];
    }
    return res;                              // 0-based 排名
}
```

用途：n ≤ 9 时把排列状态压成 `int`，用数组代替 `map`，快很多。

### 状态数的估算（**决定能不能搜**）

| 状态规模 | 能否 BFS |
|---|---|
| ≤ 10⁵ | 轻松 |
| ≤ 10⁶ | 可以，注意内存（`unordered_map` 每个条目约 50 字节 → 50 MB） |
| ≤ 10⁷ | 勉强，必须用数组而不是 map |
| > 10⁸ | **不能全搜**，要剪枝 / 双向 / 启发式 |

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 八数码 | AcWing 845 / 洛谷 P1379 | 上面的模板。状态数 9! = 362880，可以全搜 |
| 字串变换 | 洛谷 P1032 | 状态是字符串，规则是子串替换。**双向 BFS** 才够快 |
| 立体推箱子 | AcWing 172 | 状态是 `(x, y, 姿态)`，姿态有 3 种（立着 / 横躺 / 竖躺），滚动规则不同 |
| 树形地铁系统 | AcWing 157 | 判断两棵树是否同构：DFS 求子树的"最小表示"字符串，排序后比较 |
| 卡牌游戏 | CSP 第 9 次 T5 | 博弈型状态搜索，小数据可 DFS 打表找规律 |

## 4.7 双向 BFS ★★★

### 什么时候用

- 起始状态和目标状态**都已知**
- 状态空间大，单向 BFS 会爆（分支因子 b，深度 d → 单向 b^d，双向 2·b^(d/2)）

### 模板

```cpp
int bidirectional_bfs(State start, State target) {
    if (start == target) return 0;
    unordered_map<State, int> da, db;         // 两个方向的距离
    queue<State> qa, qb;
    da[start] = 0; qa.push(start);
    db[target] = 0; qb.push(target);

    while (!qa.empty() && !qb.empty()) {
        int res = -1;
        // ⚠️ 每次扩展【较小】的那一侧，这样分支最少
        if (qa.size() <= qb.size()) res = expand(qa, da, db);
        else                        res = expand(qb, db, da);
        if (res != -1) return res;            // 相遇了
    }
    return -1;                                // 不可达
}
// expand：把队列 q 的当前层全部扩展一步，若新状态在另一侧的 dist 里出现过，
//         返回 da[s] + db[s] + 1
```

⚠️ **按层扩展**，不是一次弹一个。而且每次选**队列更小的一侧**扩展，效率最高。

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 字串变换 | 洛谷 P1032 | 双向 BFS 经典题。注意步数 > 10 输出 `NO ANSWER!` |
| 八数码（加强版） | 洛谷 P1379 | 单向 BFS 也能过，双向更快；多组询问时**预先打表**所有状态的距离 |
| 魔板类问题 | 各平台 | 双向 BFS + 康托展开压缩状态 |

## 4.8 迭代加深（IDDFS） ★★★

### 什么时候用

- 答案的**深度较小**（≤ 20）但分支因子大
- 需要用 DFS 的省内存特性，又要 BFS 的最短性

### 模板

```cpp
int depth_limit;
bool dfs(int u, int depth) {
    if (depth == depth_limit) return is_goal(u);
    if (estimate(u) + depth > depth_limit) return false;    // 剪枝
    for (auto nxt : expand(u))
        if (dfs(nxt, depth + 1)) return true;
    return false;
}

int iddfs(State start) {
    for (depth_limit = 0; ; depth_limit++) {
        if (dfs(start, 0)) return depth_limit;
        if (depth_limit > MAX_DEPTH) return -1;
    }
}
```

**复杂度**：看起来重复搜了很多次，但因为分支因子 b > 1，总代价约为最后一层的 `b^d / (b-1)`，只比单次 BFS 多一个常数倍。

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 加成序列 | AcWing 170 | **迭代加深**：深度从 1 开始递增，每层枚举"两个已有序列元素之和"作为下一个数。**按降序枚举 + 去重**是关键剪枝 |
| 字串变换 | 洛谷 P1032 | 也可用迭代加深（限制步数 ≤ 10） |
| 埃及分数 | 各平台 | 迭代加深 + 分数分解，按分母从小到大枚举 |

## 4.9 A\* 与 IDA\* ★★

### A\*：BFS + 启发函数

```cpp
// 优先队列按 f = g + h 排序
//   g = 从起点到当前状态的实际代价
//   h = 从当前状态到终点的【估计】代价（启发函数）
// ⚠️ h 必须【不高估】（admissible），否则 A* 不保证最优
priority_queue<Node, vector<Node>, greater<>> pq;   // 按 f 升序
```

### 常见启发函数

| 问题 | 启发函数 |
|---|---|
| 网格最短路（四方向） | 曼哈顿距离 `|dx| + |dy|` |
| 网格最短路（八方向） | 切比雪夫距离 `max(|dx|, |dy|)` |
| 欧几里得空间 | 直线距离 |
| 八数码 | **不在位的数字个数**（弱）或 **各数字曼哈顿距离之和**（强，推荐） |
| 一般图 | 预处理反向图最短路作为 h（此时 A* 退化为双向 Dijkstra） |

### IDA\*

迭代加深 + 启发函数：`if (g + h > limit) return;`。**内存 O(depth)**，适合状态空间极大的题。

⚠️ **CSP 上 A\* 的性价比不高**：写起来复杂、启发函数不好设计，而 CSP 的题往往用 Dijkstra + 分层图就够了。**优先掌握 Dijkstra，A\* 了解即可。**

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 八数码（求最少步数） | 洛谷 P1379 | 用曼哈顿距离之和作 h 的 A\*，或双向 BFS |
| 第 k 短路 | 洛谷 P2449 | A\* 经典应用：反向图跑 Dijkstra 得到每个点到终点的最短路作为 h，然后 A\* 第 k 次弹出终点就是答案 |
| 最优贸易 | AcWing 341 | **分层图**：三层（未买 / 已买 / 已卖），层间边权为 ±价格，跑 SPFA/Dijkstra |

## 4.10 Meet in the Middle（双向搜索） ★★

### 适用

`n` 在 **25~45** 之间：`2^n` 会爆（10¹³），但 `2^(n/2)` 只有 10⁷ 级别。

### 模板

```cpp
// 例：从 n 个数中选若干，使和最接近 W 且不超过 W（n <= 45）
int m = n / 2;
vector<ll> A, B;
// ① 枚举前一半的所有子集和
for (ll S = 0; S < (1LL << m); S++) A.push_back(subset_sum(S, 0, m));
// ② 枚举后一半
for (ll S = 0; S < (1LL << (n - m)); S++) B.push_back(subset_sum(S, m, n));
// ③ 排序 + 去重 + 二分合并
sort(all(B)); B.erase(unique(all(B)), B.end());
ll best = 0;
for (ll x : A) {
    auto it = upper_bound(all(B), W - x);
    if (it != B.begin()) best = max(best, x + *prev(it));
}
```

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 送礼物 | AcWing 169 | n ≤ 45，重量和 ≤ 2³¹。拆半枚举 + 排序去重 + 二分。**注意去重能大幅减少二分次数** |
| 选数（加强版） | 洛谷 P1036 变种 | n 更大时用 meet in the middle |

## 4.11 搜索与 DP 的边界 ★★★★★

### 决策表

| 题目特征 | 用什么 |
|---|---|
| 求**方案数** / **最优值**，状态有明确定义 | **DP**（递推或记忆化） |
| 求**具体方案**（要输出路径/排列） | 搜索（记录路径）或 DP + 回溯 |
| 状态数 ≤ 10⁶ 且转移清晰 | DP |
| 状态数极大但答案深度小（≤ 20） | 迭代加深 / 双向 BFS |
| 状态是"整个局面" | 状态空间 BFS + 哈希 |
| 图上最短路（有权） | Dijkstra / SPFA，**不是 DFS** |
| 图上最短路（无权） | BFS |
| 求所有解 / 判断可行性 | DFS + 剪枝 |
| n ≤ 20 且"选或不选" | 状压 DP 或 子集枚举 |
| n ≤ 10 且"求顺序" | 全排列搜索 |

### 一个重要的转换

**很多"搜索题"其实是 DP，很多"DP 题"可以写成记忆化搜索。**

```cpp
// 这两个是等价的：
// ① 递推 DP
for (int i = 1; i <= n; i++) f[i] = max(f[i-1] + a[i], a[i]);
// ② 记忆化搜索
ll dfs(int i) {
    if (i == 0) return a[0];
    if (vis[i]) return f[i];
    vis[i] = true;
    return f[i] = max(dfs(i-1) + a[i], (ll)a[i]);
}
```

**考场上想不清递推顺序就写记忆化搜索**，正确性一样，代码更直观。

### CSP 考场决策流程

```
读完题
  ↓
n 的范围是多少？
  ├─ n ≤ 20 且"选或不选" → 状压 DP（或子集枚举暴力）
  ├─ n ≤ 10 且"求顺序"   → 全排列搜索
  ├─ 网格 / 图上最短路   → BFS（无权）或 Dijkstra（有权）
  ├─ 状态是"整个局面"    → 状态空间 BFS + 哈希编码
  ├─ 有明显阶段/区间结构 → DP（线性 / 区间 / 树形）
  └─ 完全看不出来        → 【先写暴力 DFS 交上去拿分】，再慢慢想
```

**最后一条最重要**：想不出来时，**朴素 DFS 暴力几乎总能拿到 20~40 分**。CSP 的评分机制（按测试点给分）就是为这种"部分正确"设计的。
