## 3.1 排序 ★★★★★

### 各种排序的复杂度

| 排序 | 平均 | 最坏 | 空间 | 稳定 | 备注 |
|---|---|---|---|---|---|
| 冒泡 | O(n²) | O(n²) | O(1) | ✅ | 只在 n ≤ 10³ 时用 |
| 选择 | O(n²) | O(n²) | O(1) | ❌ | |
| 插入 | O(n²) | O(n²) | O(1) | ✅ | **基本有序时接近 O(n)** |

| 堆排 | O(n log n) | O(n log n) | O(1) | ❌ | |

### 计数排序 / 桶排序（CSP T2 高频）

```cpp
// 值域小（如 0~100）时用计数排序，O(n + k)，比 sort 快得多
int cnt[105] = {0};
for (int i = 0; i < n; i++) cnt[a[i]]++;
// 按频次排序、按值排序都很方便
```

### 自定义排序

```cpp
// 多关键字排序：先按 x 升序，x 相同按 y 降序
sort(all(v), [](const P& a, const P& b) {
    if (a.x != b.x) return a.x < b.x;
    return a.y > b.y;
});
// ⚠️ 最后一级必须是 < 或 >，绝不能是 <= 或 >=（严格弱序要求）
```

### 归并排序求逆序对

```cpp
ll merge_sort(int l, int r) {
    if (l >= r) return 0;
    int m = (l + r) / 2;
    ll cnt = merge_sort(l, m) + merge_sort(m + 1, r);
    int i = l, j = m + 1, k = 0;
    while (i <= m && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else { tmp[k++] = a[j++]; cnt += m - i + 1; }   // ⚠️ 关键：左边剩下的都比 a[j] 大
    }
    while (i <= m) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (int p = 0; p < k; p++) a[l + p] = tmp[p];
    return cnt;
}
```

⚠️ 逆序对数量可达 `n(n-1)/2`，n=10⁵ 时约 5×10⁹，**必须用 `ll`**。

## 3.2 查找 ★★★★★

### 二分查找的四种写法（**必须分清**）

```cpp
// 前提：a 已升序，下标 0..n-1

// ① lower_bound 语义：第一个 >= x 的位置（找不到返回 n）
int lb = lower_bound(a, a + n, x) - a;

// ② upper_bound 语义：第一个 > x 的位置（找不到返回 n）
int ub = upper_bound(a, a + n, x) - a;

// ③ x 的出现次数
int cnt = ub - lb;

// ④ 手写版本（左闭右闭，最不容易写错）
int lower_bound_manual(int l, int r, int x) {   // 在 [l, r] 内找第一个 >= x
    int ans = r + 1;
    while (l <= r) {
        int m = l + (r - l) / 2;                // ⚠️ 防溢出
        if (a[m] >= x) { ans = m; r = m - 1; }
        else l = m + 1;
    }
    return ans;
}
```

⚠️ **二分三大坑**：
1. `m = (l + r) / 2` 当 `l + r` 溢出 int 时出错 → 写 `l + (r - l) / 2`
2. 循环条件 `l < r` 配 `r = m`，`l <= r` 配 `r = m - 1`，**混用会死循环或漏答案**
3. `m = (l + r + 1) / 2` 用于"收缩到左边"的场景（防止 `l = m` 死循环）

## 3.3 枚举 ★★★★★

### 枚举的三个优化方向

```cpp
// ① 缩小枚举范围
//    例：找 a+b+c = n 且 a<b<c，只枚举 a ∈ [1, n/3]，b ∈ [a+1, (n-a)/2]，c 直接算
for (int a = 1; a * 3 < n; a++)
    for (int b = a + 1; b * 2 < n - a; b++) {
        int c = n - a - b;
        if (c > b) { /* 找到一组 */ }
    }

// ② 改变枚举对象
//    例：枚举"所有子集"太慢，改成枚举"分割点"或"最后一步"
//    例：n 个数选 k 个使和最大 → 排序后直接取前 k 个，不用枚举组合

// ③ 预处理 + 空间换时间
//    例：枚举所有区间和 → 先算前缀和，O(1) 得到任意区间和
//    例：枚举两点间距离 → 先 Floyd 预处理全源最短路
```

### 常见枚举模式

```cpp
// 枚举子集（n ≤ 20）
for (int S = 0; S < (1 << n); S++) { ... }

// 枚举 S 的所有子集
for (int sub = S; sub; sub = (sub - 1) & S) { ... }

// 枚举全排列（n ≤ 10）
sort(all(p));
do { ... } while (next_permutation(all(p)));

// 枚举组合 C(n,k)：DFS 或 Gosper's hack
void dfs(int u, int chosen) {
    if (chosen == k) { /* 记录 */ return; }
    if (u > n || n - u + 1 < k - chosen) return;   // 剪枝：剩余不够选
    choose(u); dfs(u + 1, chosen + 1);
    unchoose(u); dfs(u + 1, chosen);
}

// 枚举质因数
for (int i = 2; 1LL * i * i <= n; i++)
    while (n % i == 0) { /* 记录 i */ n /= i; }
if (n > 1) { /* 剩下的是质数 */ }

// 枚举约数
for (int i = 1; 1LL * i * i <= n; i++)
    if (n % i == 0) { divs.push_back(i); if (i != n / i) divs.push_back(n / i); }
```

## 3.4 二分答案 ★★★★

### 什么时候能二分答案

**答案具有单调性**：如果 `check(x)` 成立，那么所有 `x' < x`（或 `> x`）也成立。
典型信号：题目问"**最大化最小值**"或"**最小化最大值**"。

### 两种模式（**别搞反**）

```cpp
// 模式 A：求【最大】的满足 check 的 x
// 例：砍树 —— 切割高度越高，木材越少；求能拿到 >= M 木材的最高高度
int l = lo, r = hi, ans = lo - 1;
while (l <= r) {
    int m = l + (r - l) / 2;
    if (check(m)) { ans = m; l = m + 1; }      // m 可行，试更大的
    else r = m - 1;
}

// 模式 B：求【最小】的满足 check 的 x
// 例：地铁修建 —— 边长上限越大越容易连通；求能连通的最小上限
int l = lo, r = hi, ans = hi + 1;
while (l <= r) {
    int m = l + (r - l) / 2;
    if (check(m)) { ans = m; r = m - 1; }      // m 可行，试更小的
    else l = m + 1;
}
```

### 实数二分

```cpp
double l = lo, r = hi;
for (int i = 0; i < 100; i++) {          // 固定迭代 100 次，最稳
    double m = (l + r) / 2;
    if (check(m)) l = m; else r = m;     // 按单调性方向选
}
cout << fixed << setprecision(6) << l << '\n';
// 或者：while (r - l > 1e-8)  —— ⚠️ 精度要求比 1e-8 更严时会出问题，固定次数更安全
```

## 3.5 三分法 ★★

**适用**：单峰函数求极值（先增后减求最大，先减后增求最小）。

```cpp
// 求 f 在 [l, r] 上的最大值（f 是单峰凸函数）
while (r - l > 1e-9) {
    double m1 = l + (r - l) / 3;
    double m2 = r - (r - l) / 3;
    if (f(m1) < f(m2)) l = m1;      // 峰在右半段
    else r = m2;                    // 峰在左半段
}
```

⚠️ 三分只能用于**严格单峰**的函数。有多个峰时会陷入局部最优。
整数三分：`while (r - l > 2)` 然后枚举剩下的几个点。

## 3.6 前缀和与差分 ★★★★★

### 一维前缀和

```cpp
ll s[N];
for (int i = 1; i <= n; i++) s[i] = s[i-1] + a[i];      // ⚠️ 下标从 1 开始，s[0]=0
ll range_sum(int l, int r) { return s[r] - s[l-1]; }
```

### 二维前缀和

```cpp
ll s[N][N];
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j];

ll rect_sum(int x1, int y1, int x2, int y2) {
    return s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1];
}
```

⚠️ **容斥的符号**：减两个、加一个。画个图确认，别靠记。

### 一维差分（前缀和的逆运算）

```cpp
ll d[N];
void range_add(int l, int r, ll v) { d[l] += v; d[r+1] -= v; }
// 全部操作完后，对 d 求前缀和就得到最终数组
for (int i = 1; i <= n; i++) a[i] = a[i-1] + d[i];      // 这里 a[i-1] 其实是 d 的前缀和
```

### 二维差分

```cpp
void rect_add(int x1, int y1, int x2, int y2, ll v) {
    d[x1][y1]     += v;
    d[x1][y2+1]   -= v;
    d[x2+1][y1]   -= v;
    d[x2+1][y2+1] += v;
}
// 最后对 d 做二维前缀和
```

### 前缀和的高级用法

```cpp
// ① 求"和为 k 的子数组个数"：哈希表存前缀和出现次数
map<ll, int> cnt; cnt[0] = 1;                            // ⚠️ 必须初始化 cnt[0]=1
ll res = 0, s = 0;
for (int i = 0; i < n; i++) {
    s += a[i];
    res += cnt[s - k];                                   // 存在 j 使 s[i]-s[j]=k
    cnt[s]++;
}

// ② 求"和被 m 整除的子数组个数"：统计前缀和 mod m 的余数，同余数两两配对
int cnt[M] = {0}; cnt[0] = 1;
ll s = 0, res = 0;
for (int i = 0; i < n; i++) {
    s = ((s + a[i]) % m + m) % m;                        // ⚠️ 负数取模修正
    res += cnt[s];
    cnt[s]++;
}

// ③ 最大子段和：s[i] - min(s[0..i-1])
ll mn = 0, s = 0, best = -LINF;
for (int i = 0; i < n; i++) {
    s += a[i];
    best = max(best, s - mn);
    mn = min(mn, s);
}
```

## 3.7 双指针 ★★★★

### 同向双指针（滑动窗口）

```cpp
// 求最长的【不含重复元素】的连续子序列
int cnt[N] = {0}, res = 0;
for (int i = 0, j = 0; i < n; i++) {
    cnt[a[i]]++;
    while (cnt[a[i]] > 1) { cnt[a[j]]--; j++; }          // 出现重复就收缩左端
    res = max(res, i - j + 1);
}
```

### 相向双指针

```cpp
// 两个有序数组，找 a[i] + b[j] == target
int i = 0, j = m - 1;
while (i < n && j >= 0) {
    int s = a[i] + b[j];
    if (s == target) { /* 找到 */ i++; j--; }
    else if (s < target) i++;                            // 和太小，左指针右移变大
    else j--;                                            // 和太大，右指针左移变小
}
```

### 双指针的本质

**单调性**：当右指针右移时，左指针**不需要回退**。这样两个指针各走 n 步，总 O(n)。
如果没有单调性（左指针可能需要回退），就不能用双指针，得用其他方法。

## 3.8 离散化 ★★★★

### 什么时候需要

**下标/值域很大（10⁹）但实际出现的值很少（10⁵）**。典型：坐标压缩、区间和问题。

### 标准模板

```cpp
// a 是原数组，b 是离散化后的值域（1-based）
vector<int> alls;                       // 收集所有需要离散化的值
for (int x : a) alls.push_back(x);
for (auto q : queries) { alls.push_back(q.l); alls.push_back(q.r); }   // ⚠️ 查询端点也要收

sort(all(alls));
alls.erase(unique(all(alls)), alls.end());

int find_(int x) {                      // 返回 x 的离散化下标（1-based）
    return lower_bound(all(alls), x) - alls.begin() + 1;
}
```

⚠️ **三个坑**：
1. **查询用到的所有值都要收集**（不只是数组元素，还有查询的左右端点）
2. 离散化会**丢失"间隔"信息**——如果题目关心"两个值之间差多少"，不能直接离散化
3. `+1` 是为了配合树状数组（下标从 1 开始）

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 区间和 | AcWing 802 | 离散化 + 前缀和。**必须把查询端点也收进来** |
| 楼兰图腾 | AcWing 241 | 值域离散化 + 树状数组统计左右两侧比它大/小的个数 |
| 谜一样的牛 | AcWing 244 | 离散化 + 树状数组求第 k 个空位 |
| 亚特兰蒂斯 | AcWing 247 | **y 坐标离散化** + 扫描线线段树 |

## 3.9 贪心 ★★★★★

### 贪心的核心：必须能证明

**贪心不是"看起来对就行"。** 要么能证明，要么能举出反例。证明方法：

1. **交换论证**：假设最优解和我的解不同，把最优解中的一步换成我的选择，证明不会变差
2. **归纳法**：证明每一步的局部最优能推出全局最优
3. **反证法**：假设贪心错，推出矛盾

**考场上没时间严格证明怎么办**：
- 手造 3~5 个小反例试着推翻自己的贪心
- 如果推翻不了，就用**暴力对拍**（小数据随机测试，比对贪心和暴力）
- 实在不确定，就写 DP（DP 一般是对的，只是慢）

### 常见贪心模型

#### ① 区间调度（选最多不重叠区间）

```cpp
sort(all(segs), [](const Seg& a, const Seg& b) { return a.r < b.r; });   // ⚠️ 按右端点排
int cnt = 0, last_r = -INF;
for (auto& s : segs)
    if (s.l > last_r) { cnt++; last_r = s.r; }        // 严格 > 还是 >= 看题目"是否允许端点重合"
```

#### ② 区间覆盖（用最少区间覆盖 [0, M]）

```cpp
sort(all(segs), [](const Seg& a, const Seg& b) { return a.l < b.l; });   // ⚠️ 按左端点排
int cnt = 0, cur = 0;
while (cur < M) {
    int best = cur;
    for (auto& s : segs) if (s.l <= cur) best = max(best, s.r);
    if (best == cur) { cnt = -1; break; }             // ⚠️ 无法推进 = 无解
    cnt++; cur = best;
}
```

#### ③ 区间选点（最少点覆盖所有区间）

```cpp
sort(all(segs), [](const Seg& a, const Seg& b) { return a.r < b.r; });   // 按右端点
int cnt = 0, pos = -INF;
for (auto& s : segs)
    if (s.l > pos) { cnt++; pos = s.r; }              // 在右端点放一个点
```

#### ④ 哈夫曼 / 合并果子

```cpp
priority_queue<int, vector<int>, greater<>> pq;       // 小根堆
ll res = 0;
while (pq.size() > 1) {
    int a = pq.top(); pq.pop();
    int b = pq.top(); pq.pop();
    res += a + b; pq.push(a + b);
}
```

#### ⑤ 排队打水（最小化总等待）

**短作业优先**：按时间升序排，总等待 = `sum(t[i] * (n - i))`。

#### ⑥ 货仓选址（最小化绝对差之和）

选**中位数**。证明：把点往中位数方向移动一定不会变差。

#### ⑦ 反悔贪心（种树、种花类）

选了 x 之后，把 `左 + 右 - x` 作为新权值放回去，允许"反悔"之前的选择。用**双向链表 + 堆**实现。

#### ⑧ 0/1 分数规划

求 `max(sum(a_i) / sum(b_i))`：**二分答案 r**，check `sum(a_i - r * b_i) >= 0`。

## 3.10 分治 ★★★

### 分治三步

1. **分**：把问题分成若干规模更小的子问题
2. **治**：递归解决子问题
3. **合**：把子问题的解合并成原问题的解

### 经典分治

```cpp
// ① 归并排序：见 3.1
// ② 快速幂：a^b = (a^(b/2))^2 * (b 为奇数时再乘 a)
// ③ 快速选择：只递归 pivot 所在的一侧，O(n)
// ④ 平面最近点对
```

### 平面最近点对（分治经典）

```cpp
// 1. 按 x 排序
// 2. 分左右两半递归求各自最近距离 d
// 3. 取 d = min(d_left, d_right)
// 4. 考虑跨中线的点对：只有 |x - mid_x| < d 的点才可能，按 y 排序后
//    每个点只需检查后面【最多 6 个】点（几何性质保证）
// 总复杂度 O(n log n)
```

### 整体二分

把"二分答案"和"分治"结合，一次处理多个询问。CSP 极少考，了解即可。

## 3.11 递推与递归 ★★★★

### 找递推式的通用思路

1. **定义状态**：`f[i]` 表示什么？（这是最关键也最容易错的一步）
2. **考虑最后一步**：最后一步有哪些选择？每种选择对应哪个子问题？
3. **写转移方程**
4. **确定边界**：`f[0]`、`f[1]` 是什么？
5. **确定顺序**：从小到大还是从大到小？

### 经典递推

```cpp
// 斐波那契：f[i] = f[i-1] + f[i-2]
// 卡特兰数：C[n] = C[2n][n] / (n+1)，或 C[n] = sum(C[i]*C[n-1-i])
//   应用：合法括号序列数、n 个节点的不同 BST 数、凸多边形三角剖分数、不出界的路径数
// 错位排列：D[n] = (n-1) * (D[n-1] + D[n-2])
// 斯特林数、贝尔数：见 07_数学.md
```

### 记忆化递归（自顶向下 DP）

```cpp
ll f[N]; bool vis[N];
ll dfs(int x) {
    if (base_case) return base_value;
    if (vis[x]) return f[x];
    vis[x] = true;
    return f[x] = /* 由 dfs(子状态) 转移 */;
}
```

**什么时候用记忆化而不是递推**：
- 状态空间稀疏（大部分状态不会被访问）
- 转移关系复杂，递推顺序难以确定
- 状态是多维的且有些维度值域大

⚠️ 记忆化递归的**栈深度**受限，状态数 > 10⁴ 且形成链状依赖时会栈溢出。

## 3.13 构造与思维 ★★★

CSP 的 T4/T5 偶尔考构造题。**没有固定套路，但有常见的思考方向**：

| 方向 | 说明 | 例子 |
|---|---|---|
| **找不变量** | 操作过程中什么量不变？（奇偶性、模某数的余数、异或和、总和） | 判断能否把全 0 变成目标：看异或和是否匹配 |
| **极端化** | 先考虑最大/最小/最长的情况，再推广 | 排序后从两端向中间构造 |
| **退一步想** | 先解决 n-1 的情况，再插入第 n 个 | 归纳构造 |
| **对称/配对** | 把元素两两配对处理 | 相遇问题、配对消除 |
| **反证/必要性** | 先证明答案必须满足什么条件，再构造出满足条件的解 | 奇偶性论证 |
| **小数据打表找规律** | n=1,2,3,4 手算，猜公式，再证明 | CSP 的"数学题"常这样 |

⚠️ **构造题的部分分很好拿**：`n=1`、`n=2` 的情况直接硬编码输出，往往就有 10~20 分。
