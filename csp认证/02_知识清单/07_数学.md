## 7.1 快速幂与逆元 ★★★★★

### 快速幂

```cpp
ll qpow(ll a, ll b, ll p) {
    ll res = 1 % p;                        // ⚠️ p 可能为 1，此时答案是 0
    a %= p;                                // ⚠️ a 可能 >= p
    while (b > 0) {
        if (b & 1) res = res * a % p;
        a = a * a % p;
        b >>= 1;
    }
    return res;
}
```

⚠️ `res` 和 `a` 必须是 `ll`，否则 `a * a` 在乘法那一步就溢出了（即使最终结果要取模）。

### 乘法逆元

**费马小定理**：若 p 是质数且 `gcd(a,p)=1`，则 `a^(p-2) ≡ a^(-1) (mod p)`

```cpp
ll inv(ll a, ll p) { return qpow(a, p - 2, p); }
```

**批量求逆元（O(n)）**：

```cpp
inv[1] = 1;
for (int i = 2; i < N; i++)
    inv[i] = (MOD - MOD / i) * inv[MOD % i] % MOD;
```

**扩展欧几里得求逆元**（p 不必是质数，只要 `gcd(a,p)=1`）：见 7.4。

## 7.2 质数与筛法 ★★★★

### 试除法判质数 O(√n)

```cpp
bool is_prime(ll n) {
    if (n < 2) return false;
    for (ll i = 2; i * i <= n; i++)          // ⚠️ i*i 可能溢出，用 ll 或 i <= n/i
        if (n % i == 0) return false;
    return true;
}
```

### 埃氏筛 O(n log log n)

```cpp
bool not_prime[N];
vector<int> primes;
void sieve_eratosthenes(int n) {
    for (int i = 2; i <= n; i++) {
        if (not_prime[i]) continue;
        primes.push_back(i);
        for (int j = i + i; j <= n; j += i) not_prime[j] = true;
    }
}
```

### 线性筛（欧拉筛）O(n)

```cpp
int primes[N], cnt; bool st[N];
void sieve_linear(int n) {
    for (int i = 2; i <= n; i++) {
        if (!st[i]) primes[cnt++] = i;
        for (int j = 0; primes[j] <= n / i; j++) {      // ⚠️ 用除法避免 i*primes[j] 溢出
            st[primes[j] * i] = true;
            if (i % primes[j] == 0) break;              // ⚠️ 关键：保证每个合数只被最小质因子筛掉
        }
    }
}
```

⚠️ **线性筛的 `break` 是核心**：`i % primes[j] == 0` 说明 `primes[j]` 是 i 的最小质因子，那么 `i * primes[j+1]` 的最小质因子仍是 `primes[j]`，应该留到后面由 `i' = i/primes[j]*primes[j+1]` 时筛，所以此处必须 break。

### 选型

| n 范围 | 方法 |
|---|---|
| 单个数 ≤ 10¹² | 试除法 O(√n) = 10⁶ |
| 区间内所有数 ≤ 10⁷ | 线性筛 |
| 大区间 [L, R]，R−L ≤ 10⁶ 但 R ≤ 10¹² | **区间筛**：先筛 √R 内的质数，再用它们去筛 [L,R] |

## 7.3 约数与因数分解 ★★★★

### 试除法求所有约数 O(√n)

```cpp
vector<ll> get_divisors(ll n) {
    vector<ll> res;
    for (ll i = 1; i * i <= n; i++) {
        if (n % i == 0) {
            res.push_back(i);
            if (i != n / i) res.push_back(n / i);      // ⚠️ 完全平方数会重复
        }
    }
    sort(all(res));
    return res;
}
```

### 约数个数与约数之和

若 `n = p1^a1 · p2^a2 · … · pk^ak`：

```
约数个数 = (a1+1)(a2+1)…(ak+1)
约数之和 = (p1^0+p1^1+…+p1^a1) · (p2^0+…+p2^a2) · …
```

```cpp
// 约数个数（分解质因数后累乘）
ll cnt = 1;
for (auto& [p, a] : factor) cnt *= (a + 1);

// 约数之和（用等比数列求和，注意取模）
ll sum = 1;
for (auto& [p, a] : factor) {
    ll t = 1, pw = 1;
    for (int i = 0; i < a; i++) { pw = pw * p % MOD; t = (t + pw) % MOD; }
    sum = sum * t % MOD;
}
```

### 最大公约数与最小公倍数

```cpp
ll gcd(ll a, ll b) { return b ? gcd(b, a % b) : a; }
ll lcm(ll a, ll b) { return a / gcd(a, b) * b; }        // ⚠️ 先除后乘防溢出
// g++ 内置：__gcd(a, b)；C++17: std::gcd, std::lcm
```

## 7.4 GCD / LCM / 扩展欧几里得 ★★★★

### 裴蜀定理（Bézout）

`ax + by = gcd(a,b)` 有整数解。推广：`ax + by = c` 有解 ⟺ `gcd(a,b) | c`。

### 扩展欧几里得

```cpp
// 求 ax + by = gcd(a,b) 的一组解
ll exgcd(ll a, ll b, ll& x, ll& y) {
    if (b == 0) { x = 1; y = 0; return a; }
    ll d = exgcd(b, a % b, y, x);          // ⚠️ 注意 x, y 交换
    y -= a / b * x;
    return d;
}
```

### 解线性同余方程 `ax ≡ b (mod m)`

```cpp
// 等价于 ax + my = b
ll x, y;
ll d = exgcd(a, m, x, y);
if (b % d != 0) { /* 无解 */ }
else {
    x = x * (b / d) % m;                   // 一组特解
    x = (x % (m / d) + m / d) % (m / d);   // 最小非负解，周期是 m/d
}
```

### 乘法逆元（exgcd 版）

`a` 在模 `m` 下的逆元 = 解 `ax ≡ 1 (mod m)`，要求 `gcd(a,m) = 1`。

## 7.5 欧拉函数 ★★★

### 定义

`φ(n)` = 1~n 中与 n **互质**的数的个数。

若 `n = p1^a1 · p2^a2 · … · pk^ak`，则

```
φ(n) = n · (1 - 1/p1) · (1 - 1/p2) · … · (1 - 1/pk)
```

### 单个求（试除分解）

```cpp
int phi(int n) {
    int res = n;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            res = res / i * (i - 1);              // ⚠️ 先除后乘，避免溢出和不整除
            while (n % i == 0) n /= i;
        }
    }
    if (n > 1) res = res / n * (n - 1);
    return res;
}
```

### 筛法求 1~n 所有欧拉函数

```cpp
int phi[N], primes[N], cnt; bool st[N];
void sieve_phi(int n) {
    phi[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (!st[i]) { primes[cnt++] = i; phi[i] = i - 1; }
        for (int j = 0; primes[j] <= n / i; j++) {
            st[primes[j] * i] = true;
            if (i % primes[j] == 0) {
                phi[primes[j] * i] = phi[i] * primes[j];       // p | i
                break;
            }
            phi[primes[j] * i] = phi[i] * (primes[j] - 1);     // p 不整除 i
        }
    }
}
```

### 欧拉定理

若 `gcd(a, m) = 1`，则 `a^φ(m) ≡ 1 (mod m)`。
推论（费马小定理）：m 是质数时 `a^(m-1) ≡ 1 (mod m)`。

**扩展欧拉定理**（a 与 m 不互质时）：

```
a^b ≡ a^(b mod φ(m) + φ(m))  (mod m)，当 b >= φ(m)
```

## 7.6 同余与中国剩余定理 ★★

### 中国剩余定理（CRT）

求解方程组 `x ≡ a_i (mod m_i)`，其中 `m_i` **两两互质**：

```cpp
ll crt(int n, ll* a, ll* m) {
    ll M = 1, res = 0;
    for (int i = 0; i < n; i++) M *= m[i];
    for (int i = 0; i < n; i++) {
        ll Mi = M / m[i], x, y;
        exgcd(Mi, m[i], x, y);                   // 求 Mi 在模 m[i] 下的逆元
        res = (res + a[i] % M * Mi % M * (x % M)) % M;
    }
    return (res % M + M) % M;                    // ⚠️ 修正为最小非负
}
```

### 扩展 CRT（m_i 不互质）

两两合并：`x ≡ a1 (mod m1)` 和 `x ≡ a2 (mod m2)` →
解 `m1·t ≡ a2 - a1 (mod m2)`，得 `t`，则 `x = a1 + m1·t`，新模数为 `lcm(m1,m2)`。

### 其他常用结论

```
(a + b) % m = ((a % m) + (b % m)) % m
(a * b) % m = ((a % m) * (b % m)) % m
(a - b) % m = ((a - b) % m + m) % m          // ⚠️ 减法必须 +m
a^b % m：b 很大时用快速幂；若 a 与 m 互质可先用 b % φ(m) 降幂
```

⚠️ **`a % m` 在 C++ 中当 a 为负时结果是负的**，必须 `(a % m + m) % m`。

## 7.7 组合数学 ★★★★

### 阶乘 + 逆元预处理（最常用）

```cpp
ll fac[N], ifac[N];
void init(int n) {
    fac[0] = 1;
    for (int i = 1; i <= n; i++) fac[i] = fac[i-1] * i % MOD;
    ifac[n] = qpow(fac[n], MOD - 2, MOD);
    for (int i = n - 1; i >= 0; i--) ifac[i] = ifac[i+1] * (i+1) % MOD;
}
ll C(int n, int k) {
    if (k < 0 || k > n) return 0;              // ⚠️ 越界必须返回 0，否则算出垃圾值
    return fac[n] * ifac[k] % MOD * ifac[n-k] % MOD;
}
ll A(int n, int k) { return fac[n] * ifac[n-k] % MOD; }
```

### 杨辉三角（n 小时更简单）

```cpp
C[0][0] = 1;
for (int i = 1; i <= n; i++) {
    C[i][0] = 1;
    for (int j = 1; j <= i; j++) C[i][j] = (C[i-1][j-1] + C[i-1][j]) % MOD;
}
```

n ≤ 2000 用这个，比阶乘逆元好写且不会错。

### 卢卡斯定理（n 很大，p 较小）

```
C(n, m) mod p = C(n mod p, m mod p) · C(n/p, m/p) mod p
```

```cpp
ll lucas(ll n, ll m, ll p) {
    if (m == 0) return 1;
    return C(n % p, m % p, p) * lucas(n / p, m / p, p) % p;
}
```

### 常用计数结论（**背下来**）

| 问题 | 答案 |
|---|---|
| n 个不同元素排成一列 | `n!` |
| n 个中选 k 个（无序） | `C(n,k)` |
| n 个中选 k 个（有序） | `A(n,k) = n!/(n-k)!` |
| **可重排列**（n 个元素有重复，第 i 类有 a_i 个） | `n! / (a1!·a2!·…)` |
| **隔板法**：n 个相同物品分给 k 个人，每人至少 1 个 | `C(n-1, k-1)` |
| **隔板法**：n 个相同物品分给 k 个人，可以为 0 | `C(n+k-1, k-1)` |
| **卡特兰数** | `Cat(n) = C(2n,n)/(n+1) = C(2n,n) - C(2n,n-1)` |
| **错位排列** | `D(n) = (n-1)·(D(n-1)+D(n-2))`，`D(1)=0, D(2)=1` |
| **第二类斯特林数**（n 个元素分成 k 个非空集合） | `S(n,k) = k·S(n-1,k) + S(n-1,k-1)` |
| **圆排列**（n 个围成一圈） | `(n-1)!` |
| **n 个点 labeled 树的个数** | `n^(n-2)`（Cayley 公式） |

## 7.8 容斥原理 ★★★

### 基本形式

```
|A1 ∪ A2 ∪ … ∪ An| = Σ|Ai| - Σ|Ai ∩ Aj| + Σ|Ai ∩ Aj ∩ Ak| - …
```

### 二进制枚举实现

```cpp
// 求 1~n 中能被 p1..pk 中至少一个整除的数的个数
ll res = 0;
for (int S = 1; S < (1 << k); S++) {
    ll lcm_val = 1; int bits = 0;
    bool overflow = false;
    for (int i = 0; i < k; i++) {
        if (S >> i & 1) {
            bits++;
            lcm_val = lcm_val / gcd(lcm_val, p[i]) * p[i];
            if (lcm_val > n) { overflow = true; break; }   // ⚠️ 提前退出防溢出
        }
    }
    if (overflow) continue;
    ll cnt = n / lcm_val;
    if (bits % 2 == 1) res += cnt;                          // 奇数个加
    else               res -= cnt;                          // 偶数个减
}
```

### 常见容斥模型

| 问题 | 容斥方式 |
|---|---|
| 1~n 中与 m 互质的数的个数 | 分解 m 的质因子，容斥减去能被每个质因子整除的 |
| 至少满足一个条件的方案数 | 直接容斥 |
| **恰好**满足 k 个条件的方案数 | 二项式反演：`恰好k = Σ(-1)^(i-k)·C(i,k)·至少i` |
| 错排 | `D(n) = Σ(-1)^i · C(n,i) · (n-i)!` |
| 染色 / 集合划分 | 斯特林数反演 |

## 7.9 矩阵与线性代数 ★★★

### 矩阵快速幂（线性递推的加速）

```cpp
struct Mat {
    ll a[SZ][SZ];
    Mat() { memset(a, 0, sizeof a); }
};
Mat mul(const Mat& x, const Mat& y, int n, ll p) {
    Mat r;
    for (int i = 0; i < n; i++)
        for (int k = 0; k < n; k++) {                 // ⚠️ k 在中间层，缓存友好，快很多
            if (!x.a[i][k]) continue;
            for (int j = 0; j < n; j++)
                r.a[i][j] = (r.a[i][j] + x.a[i][k] * y.a[k][j]) % p;
        }
    return r;
}
Mat qpow_mat(Mat base, ll b, int n, ll p) {
    Mat res; for (int i = 0; i < n; i++) res.a[i][i] = 1;
    while (b) {
        if (b & 1) res = mul(res, base, n, p);
        base = mul(base, base, n, p);
        b >>= 1;
    }
    return res;
}
```

**典型应用**：斐波那契 `F(n) = F(n-1) + F(n-2)` 写成矩阵形式：

```
| F(n)   |   | 1 1 |^(n-1)   | F(1) |
| F(n-1) | = | 1 0 |        · | F(0) |
```

⚠️ **三重循环的顺序 `i-k-j` 比 `i-j-k` 快好几倍**（缓存局部性）。n 大时这是能不能过的关键。

### 高斯消元（解线性方程组）

```cpp
// 解 n 元一次方程组，返回 0=唯一解, 1=无穷多解, 2=无解
int gauss(int n, vector<vector<double>>& a, vector<double>& x) {
    int r = 0;
    for (int c = 0; c < n; c++) {
        int t = r;
        for (int i = r + 1; i < n; i++) if (fabs(a[i][c]) > fabs(a[t][c])) t = i;
        if (fabs(a[t][c]) < EPS) continue;                   // 这一列全 0，跳过
        swap(a[r], a[t]);
        for (int i = n; i >= c; i--) a[r][i] /= a[r][c];     // 主元归一
        for (int i = r + 1; i < n; i++)
            if (fabs(a[i][c]) > EPS)
                for (int j = n; j >= c; j--) a[i][j] -= a[r][j] * a[i][c];
        r++;
    }
    if (r < n) {
        for (int i = r; i < n; i++) if (fabs(a[i][n]) > EPS) return 2;   // 0 = 非零 → 无解
        return 1;                                                          // 无穷多解
    }
    for (int i = n - 1; i >= 0; i--) {                       // 回代
        x[i] = a[i][n];
        for (int j = i + 1; j < n; j++) x[i] -= a[i][j] * x[j];
    }
    return 0;
}
```

**异或方程组**：把加/减换成异或，主元归一换成"找 1"，n 可达上千。

## 7.10 线性基 ★

**用途**：求一组数能异或出的最大值 / 第 k 小值 / 能否异或出某个数。

```cpp
ll basis[63];
void insert_(ll x) {
    for (int i = 62; i >= 0; i--) {
        if (!(x >> i & 1)) continue;
        if (!basis[i]) { basis[i] = x; return; }
        x ^= basis[i];
    }
}
ll query_max() {
    ll res = 0;
    for (int i = 62; i >= 0; i--) if ((res ^ basis[i]) > res) res ^= basis[i];
    return res;
}
```

⚠️ **CSP 极少考**。用 01-Trie 也能解决最大异或对，且更好写。**了解即可。**

## 7.12 博弈论 ★★

见 `05_动态规划.md` 5.10。核心结论：

| 游戏 | 先手必胜条件 |
|---|---|
| **巴什博弈**（一堆 n，每次取 1~m） | `n % (m+1) != 0` |
| **Nim**（n 堆，每次任取一堆若干） | 各堆数量**异或和 ≠ 0** |
| **威佐夫博弈**（两堆，取一堆或两堆同数） | 不是奇异局势 `(⌊kφ⌋, ⌊kφ⌋+k)` |
| **SG 定理**（多个独立游戏并行） | 总 SG = 各游戏 SG 异或，≠0 先手必胜 |

### SG 函数求法

```cpp
int sg(int x) {
    if (memo[x] != -1) return memo[x];
    set<int> s;
    for (每个从 x 能到达的状态 y) s.insert(sg(y));
    int res = 0;
    while (s.count(res)) res++;                 // mex
    return memo[x] = res;
}
```

## 7.13 莫比乌斯反演与杜教筛 ★

### 莫比乌斯函数

```
μ(n) = 1              若 n = 1
     = (-1)^k         若 n 是 k 个不同质数的乘积
     = 0              若 n 含平方因子
```

### 莫比乌斯反演

```
若 F(n) = Σ_{d|n} f(d)，则 f(n) = Σ_{d|n} μ(d) · F(n/d)
```

### 杜教筛

用于求 `Σ μ(i)` 或 `Σ φ(i)` 在 n ≤ 10¹⁰ 时的前缀和，复杂度 `O(n^(2/3))`。

## 7.14 随机算法 ★★

> **官方大纲明确列出「随机算法」**，虽然 CSP 很少正面考，但随机化是**考场上救命的手段**。

### ① 随机化快排（防止被卡）

```cpp
void qsort(int l, int r) {
    if (l >= r) return;
    int p = a[l + rand() % (r - l + 1)];        // ⚠️ 随机选 pivot，防止有序数据退化
    int i = l - 1, j = r + 1;
    while (i < j) {
        do i++; while (a[i] < p);
        do j--; while (a[j] > p);
        if (i < j) swap(a[i], a[j]);
    }
    qsort(l, j); qsort(j + 1, r);
}
```

## 7.15 近似算法与模拟退火 ★★

> **官方大纲明确列出「近似算法」**。这是 CSP T5 **最实用的骗分手段**。

### 模拟退火（Simulated Annealing）

```cpp
mt19937 rng(chrono::steady_clock::now().time_since_epoch().count());
double rand_double(double l, double r) {
    uniform_real_distribution<double> u(l, r);
    return u(rng);
}

double best_ans = 1e18;
void simulated_anneal() {
    // ① 随机一个初始解
    State cur = random_state();
    double cur_val = evaluate(cur);

    // ② 温度从高到低
    for (double T = 1e5; T > 1e-6; T *= 0.995) {
        // ③ 在邻域内随机扰动
        State nxt = cur;
        perturb(nxt, T);                         // 扰动幅度与 T 成正比
        double nxt_val = evaluate(nxt);

        double delta = nxt_val - cur_val;        // 求最小值时
        // ④ 变好就接受；变差以概率 exp(-delta/T) 接受
        if (delta < 0 || exp(-delta / T) > rand_double(0, 1)) {
            cur = nxt; cur_val = nxt_val;
        }
        best_ans = min(best_ans, cur_val);
    }
}

// ⑤ 多次重启（时间允许就跑几十次，取最优）
while (clock() < TIME_LIMIT) simulated_anneal();
```

### 关键参数

| 参数 | 常用值 | 说明 |
|---|---|---|
| 初始温度 | 1e4 ~ 1e6 | 让初期几乎什么解都接受 |
| 终止温度 | 1e-6 ~ 1e-8 | |
| 降温系数 | 0.99 ~ 0.999 | 越大搜得越细，但越慢 |
| 扰动幅度 | 与 T 成正比 | `x += (rand_double(-1,1)) * T` |
| 时间限制 | 题目时限的 70% | `clock() / CLOCKS_PER_SEC` 判断 |

### 贪心近似（更简单，收益也高）

很多 T5 是 NP 难问题，但**贪心能得到 1/2 或 1-1/e 近似比**：

| 问题 | 贪心近似 | 近似比 |
|---|---|---|
| 区间调度（最多不重叠） | 按右端点排序贪心 | **最优** |
| 集合覆盖 | 每次选覆盖最多未覆盖元素的集合 | ln(n) |
| 背包 | 按性价比排序（分数背包最优，01 背包 1/2 近似） | 1/2 |
| 旅行商（满足三角不等式） | 最近邻贪心 / MST×2 | 2 |
| 最大割 | 随机分配 | 1/2 |

### ⚠️ 考场使用建议

1. **先把暴力交上去拿 30 分**，再考虑模拟退火
2. 模拟退火代码 30~40 行，**必须提前练熟**，考场上现写来不及
3. **一定要设时间限制**（`clock()`），否则 TLE 得 0 分反而不如暴力
4. 用 `srand(time(0))` 或 `mt19937` + 时钟种子，**每次运行结果不同**，所以要多跑几次取最优
5. CSP 评测**取最高分**，所以模拟退火可以多提交几次，选运气好的那次 ← **这是取最高分规则的最佳应用场景**

## 7.16 数值计算与精度 ★★★

### 浮点数的真相

| 类型 | 有效数字 | 能精确表示的最大整数 |
|---|---|---|
| `float` | 6~7 位 | 2²⁴ ≈ 1.6×10⁷ |
| `double` | 15~16 位 | 2⁵³ ≈ 9×10¹⁵ |
| `long double` | 18~19 位 | 2⁶⁴ |

⚠️ **能用整数就别用浮点。** CSP 大量题目可以通过"把小数乘以 10^k 变成整数"来彻底避免精度问题。

### 浮点比较

```cpp
const double EPS = 1e-9;
bool eq(double a, double b)  { return fabs(a - b) < EPS; }
bool lt(double a, double b)  { return a < b - EPS; }
bool le(double a, double b)  { return a < b + EPS; }
```

⚠️ **绝不要用 `==` 比较浮点数。**

### 二分精度

```cpp
// 方法一（推荐）：固定迭代次数
for (int i = 0; i < 100; i++) {
    double m = (l + r) / 2;
    if (check(m)) l = m; else r = m;
}
// 100 次后区间缩小 2^100 倍，远超任何精度要求

// 方法二：按精度停
while (r - l > 1e-8) { ... }
// ⚠️ 若题目要求输出 1e-9 精度，用 1e-8 会不够；留 2~3 位余量
```

### 取整

```cpp
floor(x)  // 向下取整（≤ x 的最大整数）
ceil(x)   // 向上取整（≥ x 的最小整数）
round(x)  // 四舍五入（⚠️ -0.5 的行为可能不符预期）
(int)x    // 直接截断（向零取整）
// ⚠️ (int)(2.9999999999) == 2 —— 浮点误差导致截断错误！
//    安全做法：(int)(x + 1e-9) 或 (ll)(x + 0.5)（仅对正数）
```

### 输出精度

```cpp
cout << fixed << setprecision(6) << x << '\n';      // 固定 6 位小数
printf("%.6f\n", x);
// ⚠️ 输出 -0.00 的问题：if (fabs(x) < EPS) x = 0;
```
