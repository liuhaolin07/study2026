## 8.1 字符串处理（非算法） ★★★★★

**这是 CSP 字符串题的真正主战场。** T1/T2/T3 里出现的字符串操作，90% 是下面这些。

### 必备函数清单

```cpp
// ---------- 分割 ----------
vector<string> split_str(const string& s, char delim) {
    vector<string> res;
    size_t start = 0, pos;
    while ((pos = s.find(delim, start)) != string::npos) {
        res.push_back(s.substr(start, pos - start));
        start = pos + 1;
    }
    res.push_back(s.substr(start));          // ⚠️ 最后一段必须单独补
    return res;
}
// ⚠️ 连续分隔符会产生空串（"a,,b" -> ["a","","b"]），按题意决定是否跳过

// 按多个分隔符分割
vector<string> split_multi(const string& s, const string& delims) {
    vector<string> res; size_t start = 0;
    while (start <= s.size()) {
        size_t pos = s.find_first_of(delims, start);
        if (pos == string::npos) { res.push_back(s.substr(start)); break; }
        if (pos > start) res.push_back(s.substr(start, pos - start));
        start = pos + 1;
    }
    return res;
}

// ---------- 大小写 ----------
transform(all(s), s.begin(), ::tolower);
transform(all(s), s.begin(), ::toupper);
char to_lower(char c) { return isupper(c) ? c - 'A' + 'a' : c; }
// ⚠️ ::tolower 传入 char 时若为负值是未定义行为，稳妥写 (unsigned char)c

// ---------- 去空格 ----------
string trim(const string& s) {
    size_t b = s.find_first_not_of(" \t\n\r");
    if (b == string::npos) return "";
    size_t e = s.find_last_not_of(" \t\n\r");
    return s.substr(b, e - b + 1);
}
// 去掉所有空格
s.erase(remove_if(all(s), [](char c){ return isspace((unsigned char)c); }), s.end());

// ---------- 数字 <-> 字符串 ----------
to_string(123);  to_string(-1.5);
stoi("123");  stol("123");  stoll("123");  stod("1.5");  stoul("123");
// ⚠️ stoi 遇到非数字会停下，超范围会抛 out_of_range 异常
// ⚠️ 手动解析（题目可能有 '+'、前导零、非法字符）：
ll parse_num(const string& s) {
    ll res = 0; bool neg = false; size_t i = 0;
    if (s[0] == '-') { neg = true; i = 1; }
    else if (s[0] == '+') i = 1;
    for (; i < s.size() && isdigit((unsigned char)s[i]); i++)
        res = res * 10 + (s[i] - '0');
    return neg ? -res : res;
}

// ---------- 查找 ----------
s.find(t);            // 返回 size_t，找不到是 string::npos
s.find(t, pos);       // 从 pos 开始找
s.rfind(t);           // 从后往前找（返回的是最左匹配位置）
s.find_first_of(cs);  s.find_last_of(cs);
s.find_first_not_of(cs);  s.find_last_not_of(cs);
s.substr(start, len);       // ⚠️ len 超长会自动截断，但 start 超范围会抛异常
s.compare(t);               // 0 = 相等
// ⚠️ s.find(t) 最坏 O(n·m)，大量匹配要上 KMP 或哈希

// ---------- 修改 ----------
s.push_back(c);  s.pop_back();
s.insert(pos, t);
s.erase(pos, len);  s.erase(pos);
s.replace(pos, len, t);
s.resize(n);  s.resize(n, '0');
s.clear();
reverse(all(s));
sort(all(s));                          // 字符排序（判异位词常用）

// ---------- 判断 ----------
s.empty();  s.size() == s.length();
s == t;  s < t;                        // 字典序比较
// 前缀判断
s.rfind(t, 0) == 0                     // t 是 s 的前缀（比 s.compare(0,t.size(),t)==0 简洁）
s.compare(0, t.size(), t) == 0         // 等价写法
// 后缀判断
s.size() >= t.size() && s.compare(s.size()-t.size(), t.size(), t) == 0
```

### 常见字符串题型的解法套路

| 题型 | 解法 |
|---|---|
| 判断两个词是否互为异位词 | 分别 `sort` 后比较，或用 26 长度计数数组 |
| 统计每个单词出现次数 | `map<string,int>` |
| 判断是否回文 | 双指针从两端向中间 |
| 最长回文子串 | Manacher（见 8.5）或中心扩展 O(n²) |
| 字符串压缩/展开 | 用栈，见 CSP「压缩编码」 |
| 格式合法性校验 | **逐字符状态机**，把规则编号写全 |
| IP / 日期 / 编号解析 | `split` 后逐段校验（位数、前导零、范围） |
| 路径规范化 | `split('/')` + 栈处理 `..` 和 `.` |
| 大小写不敏感匹配 | 全部转小写后再比较 |
| 全词匹配（不是子串） | 找到位置后**检查前后字符是否为字母** |

```cpp
// ❌ O(n²)：频繁 substr

// ❌ 按值传参导致拷贝

```

## 8.2 字符串哈希 ★★★★

### 单哈希

```cpp
using ull = unsigned long long;
const ull B = 131;                       // 基数，常用 131 / 13331 / 233
ull h[N], pw[N];

void build(const string& s) {            // s 是 0-based
    int n = s.size();
    h[0] = 0; pw[0] = 1;
    for (int i = 1; i <= n; i++) {
        h[i] = h[i-1] * B + (s[i-1] - 'a' + 1);      // ⚠️ +1 避免 'a' 映射到 0
        pw[i] = pw[i-1] * B;
    }
}
// 子串 s[l..r]（0-based，闭区间）的哈希
ull get_hash(int l, int r) {
    return h[r+1] - h[l] * pw[r - l + 1];            // ull 自动溢出取模，不用判负
}
```

⚠️ **三个坑**：
1. 字符映射**不能从 0 开始**（`'a' - 'a' = 0`），否则 "a" 和 "aa" 哈希相同。要 `+1`
2. `ull` 自然溢出等价于模 `2⁶⁴`，**减法不用取模修正**（无符号自动回绕）
3. 用 `ll` + 质数模时，减法要 `((x % MOD) + MOD) % MOD`

### 双哈希（防冲突，**推荐**）

```cpp
// 用两组不同的 (B, MOD)，只有两个哈希都相等才认为字符串相等
// MOD1 = 1e9+7, MOD2 = 1e9+9，B1 = 131, B2 = 13331
// 冲突概率从 1/1e9 降到 1/1e18
```

### 应用场景

| 应用 | 做法 |
|---|---|
| 判断两个子串是否相等 | `get_hash(l1,r1) == get_hash(l2,r2)`，O(1) |
| 求不同子串个数 | 把所有子串哈希放进 `set`（O(n² log n)，n ≤ 5000） |
| 最长公共前缀 | 二分长度 + 哈希比较 |
| 判断回文子串 | 正串哈希 == 反串哈希 |
| 字符串去重 | 哈希值放 `set` |
| 二维哈希 | 先行后列两次哈希 |

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 字符串哈希 | AcWing 841 | 单哈希 + `ull` 自然溢出，回答区间比较询问 |
| 回文子串 / 最长回文 | 洛谷 P1435 | s 与 reverse(s) 求 LCS，答案 `n - LCS`；或用哈希 + 二分 |
| 兔子与兔子 / 子串计数类 | 洛谷 P1467 类 | 哈希 + map 计数 |
| 不同子串个数 | 洛谷 P2408 | 后缀数组正解 `n(n+1)/2 - sum(height)`；n 小时可哈希 + set |
| 最佳文章 | CSP 第 5 次 T5 | 多模式匹配 → AC 自动机；**小数据先用 O(n²) DP 或暴力拿分** |

## 8.3 KMP ★★★★

### 核心：next 数组（最长相等前后缀）

```cpp
// next[i] = p[0..i-1] 的最长相等真前后缀长度
vector<int> build_next(const string& p) {
    int m = p.size();
    vector<int> nxt(m + 1, 0);
    for (int i = 2, j = 0; i <= m; i++) {
        while (j && p[i-1] != p[j]) j = nxt[j];        // ⚠️ 失配时回退到 j 的 next
        if (p[i-1] == p[j]) j++;
        nxt[i] = j;
    }
    return nxt;
}
```

### 匹配

```cpp
vector<int> kmp(const string& s, const string& p) {
    vector<int> res;
    auto nxt = build_next(p);
    int n = s.size(), m = p.size();
    for (int i = 1, j = 0; i <= n; i++) {
        while (j && s[i-1] != p[j]) j = nxt[j];
        if (s[i-1] == p[j]) j++;
        if (j == m) {
            res.push_back(i - m);          // 匹配起始位置（0-based）
            j = nxt[j];                    // ⚠️ 继续找下一个（允许重叠）
                                           //    若不允许重叠，改成 j = 0
        }
    }
    return res;
}
```

### KMP 的复杂度

- 建 next：O(m)
- 匹配：O(n)
- 总 O(n + m)

⚠️ **为什么 `while (j && ...) j = nxt[j]` 是 O(n) 而不是 O(nm)**：`j` 每次匹配成功最多 +1（总共 +n 次），每次回退至少 −1，所以回退总次数 ≤ n。这是**摊还分析**的经典例子。

### next 数组的其他用途

| 用途 | 做法 |
|---|---|
| **最小循环节** | 若 `n % (n - next[n]) == 0`，则最小周期是 `n - next[n]` |
| 求所有 border（相等前后缀） | 从 `next[n]` 开始不断跳 `next` |
| 求每个前缀出现的次数 | 统计 next 数组的出现次数，再倒序累加 |

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| KMP 字符串 | AcWing 831 | 模板，输出所有匹配起始位置（1-based 要 +1） |
| 【模板】KMP | 洛谷 P3375 | 输出 next 数组（**注意题目定义的 next 是 1-based 还是 0-based**） |
| 剪花布条 / 不重叠匹配数 | 洛谷 P1826 类 | 匹配成功后 `j = 0` 而不是 `j = nxt[j]` |
| 周期 / 循环节类 | 洛谷 P4391 | `n - next[n]` 求最小循环节 |
| 压缩编码 | CSP 第 9 次 T4 | **区间 DP + KMP 判周期**：判断区间 [i,j] 是否能由一个更短的子串重复若干次构成（用 KMP 的循环节结论），能则编码更短 |
| 最佳文章 | CSP 第 5 次 T5 | 多模式串 → AC 自动机；小数据可暴力 |

## 8.4 Z 函数（扩展 KMP） ★★

### 定义

`z[i]` = `s` 与 `s[i..]` 的最长公共前缀长度（`z[0]` 通常定义为 0 或 n）。

```cpp
vector<int> z_function(const string& s) {
    int n = s.size();
    vector<int> z(n, 0);
    for (int i = 1, l = 0, r = 0; i < n; i++) {
        if (i <= r) z[i] = min(r - i + 1, z[i - l]);      // 利用已算过的信息
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) z[i]++;
        if (i + z[i] - 1 > r) { l = i; r = i + z[i] - 1; }
    }
    return z;
}
```

### 用途

- **扩展 KMP**：求 `s` 的每个后缀与模式串 `p` 的 LCP → 对 `p + '#' + s` 求 Z 函数
- 求字符串的所有周期
- 字符串匹配（比 KMP 更好写）

⚠️ **CSP 极少单独考 Z 函数**，KMP + 哈希已经覆盖绝大部分场景。**会用即可，不必深练。**

## 8.5 Manacher（最长回文子串） ★★

### 算法

```cpp
// 返回以每个位置为中心的最长回文半径
vector<int> manacher(const string& s) {
    // ① 插入分隔符，统一奇偶长度
    string t = "^#";
    for (char c : s) { t += c; t += '#'; }
    t += "$";
    int n = t.size();
    vector<int> p(n, 0);
    int center = 0, right = 0;
    for (int i = 1; i < n - 1; i++) {
        int mirror = 2 * center - i;
        if (i < right) p[i] = min(right - i, p[mirror]);      // 利用对称性
        while (t[i + p[i] + 1] == t[i - p[i] - 1]) p[i]++;   // 中心扩展
        if (i + p[i] > right) { center = i; right = i + p[i]; }
    }
    return p;                       // p[i] 就是原串中以 i 为中心的回文长度
}
// 最长回文子串长度 = max(p[i])
```

### 更简单的替代：中心扩展 O(n²)

```cpp
int expand(const string& s, int l, int r) {
    while (l >= 0 && r < (int)s.size() && s[l] == s[r]) { l--; r++; }
    return r - l - 1;
}
int longest_palindrome(const string& s) {
    int res = 0;
    for (int i = 0; i < (int)s.size(); i++) {
        res = max(res, expand(s, i, i));        // 奇数长度
        res = max(res, expand(s, i, i + 1));    // 偶数长度
    }
    return res;
}
```

⚠️ **n ≤ 5000 时中心扩展就够了**（2.5×10⁷，1 秒能过）。**只有 n ≥ 10⁵ 才需要 Manacher。** 考场上先写中心扩展交上去拿分，再考虑要不要上 Manacher。

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 【模板】Manacher | 洛谷 P3805 | 模板题，n ≤ 1.1×10⁷，**必须 Manacher + 快读** |
| 回文子串 | 洛谷 P1435 | 转化为 LCS，答案 `n - LCS` |
| 最长回文子串（n ≤ 5000） | 各平台 | 中心扩展 |
| 回文子串计数 | 洛谷 P2470 类 | Manacher 后统计，或哈希 + 二分 |

## 8.6 Trie 与 AC 自动机 ★★★

### Trie

见 `02_数据结构.md` 2.6。核心：把字符串集合组织成一棵树，公共前缀共享节点。

### AC 自动机（多模式串匹配）

**问题**：给 n 个模式串和一个文本串，求每个模式串在文本中出现的次数（或所有匹配位置）。

**做法**：Trie + KMP 的 fail 指针。

```cpp
int son[N][26], fail[N], cnt[N], idx;

void insert_(const string& s, int id) {
    int u = 0;
    for (char c : s) {
        int t = c - 'a';
        if (!son[u][t]) son[u][t] = ++idx;
        u = son[u][t];
    }
    cnt[u] = id;                            // 或 cnt[u]++ 表示以此为结尾的模式串数
}

void build() {                              // BFS 建 fail 指针
    queue<int> q;
    for (int c = 0; c < 26; c++)
        if (son[0][c]) { fail[son[0][c]] = 0; q.push(son[0][c]); }
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int c = 0; c < 26; c++) {
            int v = son[u][c];
            if (v) { fail[v] = son[fail[u]][c]; q.push(v); }
            else   { son[u][c] = son[fail[u]][c]; }   // ⚠️ 关键：把空孩子指向 fail 的孩子
        }                                              //    这样匹配时就不用 while 回退了
    }
}

void query(const string& s) {
    int u = 0;
    for (char c : s) {
        u = son[u][c - 'a'];
        for (int j = u; j && cnt[j] != -1; j = fail[j]) {   // 沿 fail 链统计所有匹配
            res[cnt[j]]++;
            cnt[j] = -1;                                    // ⚠️ 标记已统计，避免重复（否则会 O(nm)）
        }
    }
}
```

⚠️ **AC 自动机两大坑**：
1. `build()` 里把空孩子指向 `son[fail[u]][c]`，这样 `query` 时不需要 while 回退，保证 O(n)
2. `query` 里沿 fail 链统计时要**标记已访问**（`cnt[j] = -1`），否则最坏 O(n·m)

### 配套练习

## 8.7 后缀数组 ★★

### 三个核心数组

```
sa[i]  = 排名第 i 的后缀的起始位置
rk[i]  = 起始位置为 i 的后缀的排名        （sa 和 rk 互逆）
height[i] = sa[i] 与 sa[i-1] 的最长公共前缀长度
```

### 关键性质

```
① 任意两个后缀的 LCP = min(height[rk[i]+1 .. rk[j]])（设 rk[i] < rk[j]）
② 不同子串个数 = n(n+1)/2 - sum(height[i])
③ 最长重复子串 = max(height[i])
④ 可用 ST 表 / 线段树回答 LCP 询问
```

### 倍增法构造（O(n log n)）

```cpp
// 考场建议直接抄模板，不要现场推
// 核心：按前 2^k 个字符排序 -> 用 (rk[i], rk[i+2^(k-1)]) 作为二元组做基数排序 -> 得到新的 rk
```

⚠️ **CSP 上后缀数组的性价比极低**：代码 60+ 行、容易写错、而它能解决的问题**用后缀自动机或哈希往往更简单**。**会用模板即可，重点练 `height` 数组的三个应用。**

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 【模板】后缀排序 | 洛谷 P3809 | 输出 sa 数组，倍增 + 基数排序 |
| 不同子串个数 | 洛谷 P2408 | `n(n+1)/2 - sum(height)`，**用 ll** |
| 最长重复子串 | 各平台 | `max(height)` |
| 两个串的最长公共子串 | 洛谷 P4248 类 | 拼接（中间加分隔符）后求 `max(height)`，且要求两个后缀来自不同串 |

## 8.10 字符串算法选型 ★★★★

### 按需求选

| 需求 | n 范围 | 首选 |
|---|---|---|
| 单纯处理（分割/大小写/解析） | 任意 | `string` 基本操作（8.1） |
| 判断两个子串是否相等 | ≤ 10⁶ | **字符串哈希**（O(1) 查询） |
| 单模式串匹配 | ≤ 10⁶ | **KMP** 或 哈希 + 滑动窗口 |
| 单模式串匹配 | ≤ 5000 | `s.find(t)` 直接暴力 |
| 多模式串匹配 | ≤ 10⁵ | **AC 自动机** |
| 多模式串匹配 | ≤ 2000 | 对每个模式串跑一次 `find` |
| 最长回文子串 | ≤ 5000 | **中心扩展 O(n²)** |
| 最长回文子串 | ≥ 10⁵ | **Manacher** |
| 不同子串个数 | ≤ 5000 | 哈希 + `set` |
| 不同子串个数 | ≥ 10⁵ | 后缀数组 / 后缀自动机 |
| 最小循环节 | 任意 | **KMP 的 `n - next[n]`** |
| 前缀集合 / 最大异或对 | 任意 | **Trie / 01-Trie** |

### CSP 考场的实际决策

```
看到字符串题
  ↓
题面要求的是"解析/校验/格式化"吗？
  ├─ 是 → 【大模拟 + 字符串处理】，见 8.1 和 10_其他与应试.md 的大模拟四步法
  │        ⚠️ 这类题占 CSP 字符串题的 80%
  └─ 否 → 需要匹配/统计子串吗？
           ├─ 单模式 → KMP（或 n 小时直接 find）
           ├─ 多模式 → AC 自动机（或 n 小时暴力）
           └─ 子串性质 → 哈希（先写，最好用）
```

> **重要判断**：CSP 的 T3 大模拟里，字符串往往是"**载体**"而不是"**难点**"。
> 比如「网络连接」的难点是**校验规则的完备性**（前导零、段数、范围、分隔符位置），不是匹配算法。
> **先把规则编号写全，再动手写 `find` 和 `substr`，比一上来就想"要用什么高级算法"重要得多。**
