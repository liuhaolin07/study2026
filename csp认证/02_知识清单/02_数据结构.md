## 2.1 数组与链表 ★★★★

### 数组 vs 链表

| | 数组 `vector` | 链表 `list` / 手写 |
|---|---|---|
| 随机访问 | O(1) | O(n) |
| 头部插入 | O(n) | O(1) |
| 中间插入（已知位置） | O(n) | O(1) |
| 缓存友好 | **极好** | 差 |
| 竞赛中 | **默认选择** | 极少用 STL list |

⚠️ **竞赛里几乎不用 `std::list`**——常数大、缓存不友好。需要"频繁中间插入删除"时，用**手写双向链表 + 数组存节点**，或者用 `set` 维护有序下标。

### 手写双向链表（AcWing 826/827 标准写法）

```cpp
// 用数组模拟链表，e[i]=节点值，l[i]/r[i]=左右邻居，0 和 1 是哨兵头尾
int e[N], l[N], r[N], idx;

void init() {
    r[0] = 1; l[1] = 0;          // 0 是左哨兵，1 是右哨兵
    idx = 2;
}
// 在下标 k 的节点右边插入 x
void insert_right(int k, int x) {
    e[idx] = x;
    r[idx] = r[k]; l[idx] = k;
    l[r[k]] = idx; r[k] = idx;
    idx++;
}
void remove(int k) {
    r[l[k]] = r[k];
    l[r[k]] = l[k];
}
// 遍历
for (int i = r[0]; i != 1; i = r[i]) cout << e[i] << ' ';
```

⚠️ **`insert_right` 里四句赋值的顺序不能乱**：必须先存 `r[k]` 再用它，否则链就断了。

|---|---|---|

## 2.2 栈与队列 ★★★★★

### 单调栈：求"左/右边第一个更大/更小元素"

```cpp
// 求每个位置左边第一个比它【小】的数
stack<int> st;                        // 存下标，栈内对应值【递增】
for (int i = 0; i < n; i++) {
    while (!st.empty() && a[st.top()] >= a[i]) st.pop();   // 弹出所有不优的
    left[i] = st.empty() ? -1 : st.top();
    st.push(i);
}
```

**四种变体只需改两处**：
- 找更大 → 弹 `<=`；找更小 → 弹 `>=`
- 找左边 → 正向扫；找右边 → 反向扫

**单调栈的本质**：每个元素进栈一次出栈一次，总 O(n)。它维护的是"**当前还有可能成为后续答案的候选集合**"。

### 单调队列：滑动窗口最值

```cpp
deque<int> dq;                        // 存下标，对应值【递增】，队首是最小
for (int i = 0; i < n; i++) {
    while (!dq.empty() && a[dq.back()] >= a[i]) dq.pop_back();   // 队尾淘汰
    dq.push_back(i);
    while (dq.front() <= i - k) dq.pop_front();                  // 队首出窗
    if (i >= k - 1) ans.push_back(a[dq.front()]);
}
```

⚠️ 存**下标**而不是值，才能判断是否出窗。

### 其他经典栈应用

```cpp
// 括号匹配
stack<char> st;
for (char c : s) {
    if (c=='(' || c=='[' || c=='{') st.push(c);
    else {
        if (st.empty() || !match(st.top(), c)) return false;
        st.pop();
    }
}
return st.empty();                     // ⚠️ 最后必须判空

// 表达式求值：两个栈（数字栈 + 运算符栈），遇到优先级 <= 栈顶就先算
// 逆波兰（后缀）表达式：一个栈就够
```

## 2.3 堆 ★★★★★

### `priority_queue` 三种用法

```cpp
priority_queue<int> mx;                                        // 大根堆（默认）
priority_queue<int, vector<int>, greater<int>> mn;             // 小根堆

struct Node { ll d; int u; };
// ⚠️ pq 的比较器语义和 sort 【相反】：返回 true 表示优先级更低
priority_queue<Node, vector<Node>,
    function<bool(const Node&, const Node&)>> pq(
        [](const Node& a, const Node& b) { return a.d > b.d; });   // d 小的优先
// 更好写的做法：直接用 pair
priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<>> pq2;  // 按 first 小的优先
```

### 手写堆（了解原理，考场一般不用）

```cpp
int heap[N], sz;
void up(int u)   { while (u > 1 && heap[u] < heap[u/2]) { swap(heap[u], heap[u/2]); u /= 2; } }
void down(int u) {
    while (u * 2 <= sz) {
        int t = u * 2;
        if (t + 1 <= sz && heap[t+1] < heap[t]) t++;
        if (heap[t] >= heap[u]) break;
        swap(heap[t], heap[u]); u = t;
    }
}
void push_(int x) { heap[++sz] = x; up(sz); }
int  top_()       { return heap[1]; }
void pop_()       { heap[1] = heap[sz--]; down(1); }
// O(n) 建堆：从最后一个非叶节点开始倒着 down
for (int i = n / 2; i >= 1; i--) down(i);
```

### 对顶堆：动态维护中位数

```cpp
priority_queue<int> lo;                                    // 大根堆，存较小的一半
priority_queue<int, vector<int>, greater<int>> hi;         // 小根堆，存较大的一半
// 维护不变式：lo.size() == hi.size() 或 lo.size() == hi.size() + 1
void insert_(int x) {
    if (lo.empty() || x <= lo.top()) lo.push(x); else hi.push(x);
    if (lo.size() > hi.size() + 1) { hi.push(lo.top()); lo.pop(); }
    if (hi.size() > lo.size())     { lo.push(hi.top()); hi.pop(); }
}
int median() { return lo.top(); }
```

## 2.4 哈希表 ★★★★

### STL 的选择

| | `map` | `unordered_map` |
|---|---|---|
| 底层 | 红黑树 | 哈希表 |
| 单次操作 | O(log n) 稳定 | O(1) 均摊，**最坏 O(n)** |
| 有序遍历 | ✅ 按 key 升序 | ❌ 无序 |
| 被卡风险 | 无 | **有**（出题人可以构造哈希冲突数据） |
| CSP 上怎么选 | **n ≤ 10⁵ 且需要有序 → map** | n 很大且不需有序 → unordered_map，**但要自定义哈希防卡** |

```cpp
// 防卡哈希：自定义随机化哈希函数
struct CustomHash {
    static uint64_t splitmix64(uint64_t x) {
        x += 0x9e3779b97f4a7c15;
        x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9;
        x = (x ^ (x >> 27)) * 0x94d049bb133111eb;
        return x ^ (x >> 31);
    }
    size_t operator()(uint64_t x) const {
        static const uint64_t FIXED_RANDOM =
            chrono::steady_clock::now().time_since_epoch().count();
        return splitmix64(x + FIXED_RANDOM);
    }
};
unordered_map<ll, int, CustomHash> mp;
// 还可以预留桶 + 设置负载因子：
mp.reserve(1 << 20);
mp.max_load_factor(0.25);
```

### 手写哈希（拉链法）

```cpp
const int MOD = 199999;                // 取质数
int h[MOD], e[N], ne[N], idx;          // h 是桶头，ne 是链表 next
void insert_(int x) {
    int k = ((x % MOD) + MOD) % MOD;   // ⚠️ 负数取模必须修正
    e[idx] = x; ne[idx] = h[k]; h[k] = idx++;
}
bool find_(int x) {
    int k = ((x % MOD) + MOD) % MOD;
    for (int i = h[k]; i != -1; i = ne[i]) if (e[i] == x) return true;
    return false;
}
```

## 2.5 并查集 ★★★★★

### 基础模板

```cpp
int fa[N], sz[N];                      // sz 用于按大小合并（也可用 rank）

void init(int n) { for (int i = 1; i <= n; i++) { fa[i] = i; sz[i] = 1; } }

int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }   // 路径压缩

bool unite(int a, int b) {
    a = find(a); b = find(b);
    if (a == b) return false;
    if (sz[a] < sz[b]) swap(a, b);     // 小树挂到大树上，控制树高
    fa[b] = a; sz[a] += sz[b];
    return true;
}
bool same(int a, int b) { return find(a) == find(b); }
int size_of(int x) { return sz[find(x)]; }
```

⚠️ 只写路径压缩不写按秩合并也能过大部分题（近似 O(α(n))），但**两个都写更稳**。

### 带权并查集（维护节点到根的相对关系）

```cpp
int fa[N]; ll d[N];                    // d[x] = x 到 fa[x] 的权值

int find(int x) {
    if (fa[x] != x) {
        int root = find(fa[x]);
        d[x] += d[fa[x]];              // ⚠️ 必须在 fa[x] 被改之前累加
        fa[x] = root;
    }
    return fa[x];
}
// 合并时按题意计算新的 d[b]
```

### 扩展域并查集（处理"敌友"类关系）

```cpp
// 三种关系（A 吃 B、B 吃 C、C 吃 A）→ 开 3n 个节点
// x 的同类：x，x 吃的：x+n，x 被吃的：x+2n
// 判断语句真假时，检查是否与已合并的关系矛盾
```

## 2.6 Trie（字典树） ★★★

### 基础模板（字符串前缀统计）

```cpp
int son[N][26], cnt[N], idx;           // son[u][c] = u 的 c 孩子，cnt[u] = 以 u 结尾的串数

void insert_(const string& s) {
    int u = 0;
    for (char c : s) {
        int t = c - 'a';
        if (!son[u][t]) son[u][t] = ++idx;
        u = son[u][t];
    }
    cnt[u]++;
}
int query(const string& s) {
    int u = 0;
    for (char c : s) {
        int t = c - 'a';
        if (!son[u][t]) return 0;
        u = son[u][t];
    }
    return cnt[u];
}
```

⚠️ `son[N][26]` 空间是 `N × 26 × 4` 字节，N=10⁵ 就是 10 MB。**字符集大时（如小写+大写+数字=62）要用 `map` 存孩子，或者改用哈希**。

### 01-Trie：求最大异或对

```cpp
int son[N * 31][2], idx;
void insert_num(int x) {
    int u = 0;
    for (int k = 30; k >= 0; k--) {          // ⚠️ 从高位往低位插
        int b = (x >> k) & 1;
        if (!son[u][b]) son[u][b] = ++idx;
        u = son[u][b];
    }
}
int query_max_xor(int x) {
    int u = 0, res = 0;
    for (int k = 30; k >= 0; k--) {
        int b = (x >> k) & 1;
        if (son[u][!b]) { u = son[u][!b]; res += (1 << k); }   // 贪心：优先走相反的位
        else u = son[u][b];
    }
    return res;
}
```

## 2.7 树状数组（BIT） ★★★★

### 单点修改 + 区间查询

```cpp
ll c[N]; int n;
inline int lowbit(int x) { return x & (-x); }

void add(int i, ll v) { for (; i <= n; i += lowbit(i)) c[i] += v; }
ll sum(int i)          { ll r = 0; for (; i > 0; i -= lowbit(i)) r += c[i]; return r; }
ll range_sum(int l, int r) { return sum(r) - sum(l - 1); }
```

⚠️ **下标必须从 1 开始**（`lowbit(0) = 0` 会死循环），数组开 `n + 2`。

### 区间修改 + 单点查询

对**差分数组**建树状数组：

```cpp
void range_add(int l, int r, ll v) { add(l, v); add(r + 1, -v); }
ll point_query(int i) { return sum(i); }
```

### 区间修改 + 区间查询（两个树状数组）

```cpp
ll c1[N], c2[N];
void add2(ll* c, int i, ll v) { for (; i <= n; i += lowbit(i)) c[i] += v; }
ll sum2(ll* c, int i) { ll r = 0; for (; i > 0; i -= lowbit(i)) r += c[i]; return r; }

void range_add(int l, int r, ll v) {
    add2(c1, l, v);     add2(c1, r + 1, -v);
    add2(c2, l, v*(l-1)); add2(c2, r + 1, -v*r);
}
ll prefix_sum(int i) { return sum2(c1, i) * i - sum2(c2, i); }
ll range_sum(int l, int r) { return prefix_sum(r) - prefix_sum(l - 1); }
```

### 经典应用

```cpp
// ① 求逆序对：从后往前扫，query(a[i]-1) 累加，再 add(a[i], 1)
// ② 求第 k 小：树上倍增（需要值域是 1~n）
int kth(int k) {
    int pos = 0;
    for (int i = 20; i >= 0; i--)            // 2^20 > n
        if (pos + (1 << i) <= n && c[pos + (1 << i)] < k) {
            pos += 1 << i;
            k -= c[pos];
        }
    return pos + 1;
}
// ③ 二维树状数组：双重循环 i += lowbit(i), j += lowbit(j)
```

## 2.8 线段树 ★★★★

### 单点修改 + 区间查询

```cpp
ll t[4 * N];                           // ⚠️ 必须开 4N，开小了 RE

void push_up(int p) { t[p] = t[p*2] + t[p*2+1]; }

void build(int p, int l, int r) {
    if (l == r) { t[p] = a[l]; return; }
    int m = (l + r) / 2;
    build(p*2, l, m); build(p*2+1, m+1, r);
    push_up(p);
}
void update(int p, int l, int r, int x, ll v) {   // a[x] += v
    if (l == r) { t[p] += v; return; }
    int m = (l + r) / 2;
    if (x <= m) update(p*2, l, m, x, v);
    else        update(p*2+1, m+1, r, x, v);
    push_up(p);
}
ll query(int p, int l, int r, int L, int R) {
    if (L <= l && r <= R) return t[p];
    int m = (l + r) / 2; ll s = 0;
    if (L <= m) s += query(p*2, l, m, L, R);
    if (R > m)  s += query(p*2+1, m+1, r, L, R);
    return s;
}
```

### 懒标记（区间修改 + 区间查询）

```cpp
ll t[4*N], lazy[4*N];

void push_down(int p, int l, int r) {
    if (!lazy[p]) return;
    int m = (l + r) / 2;
    int lc = p*2, rc = p*2+1;
    t[lc] += lazy[p] * (m - l + 1);  lazy[lc] += lazy[p];
    t[rc] += lazy[p] * (r - m);      lazy[rc] += lazy[p];
    lazy[p] = 0;
}
void range_update(int p, int l, int r, int L, int R, ll v) {
    if (L <= l && r <= R) { t[p] += v * (r - l + 1); lazy[p] += v; return; }
    push_down(p, l, r);                          // ⚠️ 下传前必须先 push_down
    int m = (l + r) / 2;
    if (L <= m) range_update(p*2, l, m, L, R, v);
    if (R > m)  range_update(p*2+1, m+1, r, L, R, v);
    push_up(p);
}
ll range_query(int p, int l, int r, int L, int R) {
    if (L <= l && r <= R) return t[p];
    push_down(p, l, r);
    int m = (l + r) / 2; ll s = 0;
    if (L <= m) s += range_query(p*2, l, m, L, R);
    if (R > m)  s += range_query(p*2+1, m+1, r, L, R);
    return s;
}
```

⚠️ **懒标记三大坑**：
1. 递归下去之前**必须 `push_down`**，否则子节点的 `t` 是过期的
2. `lazy` 累加时 `t` 也要同步加上 `v * 区间长度`
3. "区间乘 + 区间加"混合时，**先乘后加**：`push_down` 里要先处理乘标记，`mul` 和 `add` 两个数组，且 `(t*mul + add*len)`，标记合并规则 `mul' = mul*mul_new`, `add' = add*mul_new + add_new`

### 线段树维护"区间信息"（不只是和）

```cpp
// 维护最大子段和（GSS1）
struct Node { ll sum, lmax, rmax, tmax; };
Node merge_(const Node& a, const Node& b) {
    Node c;
    c.sum  = a.sum + b.sum;
    c.lmax = max(a.lmax, a.sum + b.lmax);
    c.rmax = max(a.rmax, b.sum + a.rmax);
    c.tmax = max({a.tmax, b.tmax, a.rmax + b.lmax});
    return c;
}
```

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 【模板】线段树 1 | 洛谷 P3372 | 区间加 + 区间和，懒标记 |
| 【模板】线段树 2 | 洛谷 P3373 | **区间乘 + 区间加 + 取模**，双标记，注意先乘后加和取模位置 |

## 2.9 ST 表（Sparse Table） ★★★

**适用**：静态区间最值（**不可修改**），O(n log n) 预处理，O(1) 查询。

```cpp
int lg[N], f[21][N];                   // f[k][i] = [i, i+2^k-1] 的最大值

void build(int n) {
    lg[0] = -1;
    for (int i = 1; i <= n; i++) { lg[i] = lg[i/2] + 1; f[0][i] = a[i]; }
    for (int k = 1; k <= lg[n]; k++)
        for (int i = 1; i + (1 << k) - 1 <= n; i++)
            f[k][i] = max(f[k-1][i], f[k-1][i + (1 << (k-1))]);
}
int query(int l, int r) {
    int k = lg[r - l + 1];
    return max(f[k][l], f[k][r - (1 << k) + 1]);   // ⚠️ 只适用于【可重复贡献】的运算（max/min/gcd）
}
```

⚠️ ST 表**只能用于可重复贡献的操作**（max、min、gcd、or、and）。**求和不行**（会重复计算），求和用前缀和或线段树。

### 配套练习

|---|---|---|
| 【模板】ST 表 | 洛谷 P3865 | 区间最大值，直接套模板 |
| 静态区间最值类 | 各平台 | 若可修改 → 线段树/树状数组；不可修改且要 O(1) → ST 表 |
| 蒲公英 | AcWing 249 | 分块 + 预处理块间众数 |

## 2.10 分块 / 莫队 ★

**CSP 极少考，了解思想即可。**

### 分块思想

把长度 n 的序列分成 `√n` 块，每块 `√n` 个元素。
- 整块操作：打标记，O(1) 每块
- 散块操作：暴力，O(√n)
- 总复杂度 `O(n√n)`

适用场景：操作太复杂，线段树维护不了（如区间众数、区间第 k 小带修改）。

### 莫队

离线处理区间询问：把询问按 `(左端点所在块, 右端点)` 排序，然后**移动左右指针**增量维护答案。复杂度 `O(n√n)`。

**CSP 上基本用不到，跳过。** 需要时用 `Algorithms/题单/04-data-structure` 里的分块专题。

## 2.11 平衡树（BST） ★★

### 竞赛中的实际做法

| 需求 | 用什么 |
|---|---|
| 有序集合 + 插入删除查询 | `std::set` / `std::multiset` |
| 有序映射 | `std::map` / `std::multimap` |
| 求第 k 小 | `set` + `distance`（O(n)）不行 → 用**树状数组 + 值域离散化**（O(log n)） |
| 求前驱后继 | `set::lower_bound` / `upper_bound`，然后 `--it` |

```cpp
set<int> s;
s.insert(x); s.erase(x); s.count(x);
auto it = s.lower_bound(x);            // 第一个 >= x
// 前驱（< x 的最大值）：
if (it != s.begin()) { auto prev_it = std::prev(it); /* *prev_it 是前驱 */ }
// 后继（> x 的最小值）：
auto it2 = s.upper_bound(x);           // 第一个 > x
```

⚠️ `unordered_set` **没有 `lower_bound`**，需要前驱后继必须用 `set`。

### 手写 Treap（了解，考场一般不用）

CSP 上如果需要"求第 k 小 + 插入删除"，**优先用树状数组 + 离散化**，比手写 Treap 稳得多。

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 【模板】普通平衡树 | 洛谷 P3369 | 可用 `multiset` + 树状数组组合通过；正解是 Treap/Splay/权值线段树 |
| 普通平衡树（求第k小） | 洛谷 P3834 | **主席树（可持久化线段树）**模板；离线可用整体二分 |
| 黑盒子 | AcWing 162 | 对顶堆：维护"当前第 i 小"，随 ADD 和 GET 操作动态调整 |
| 营业额统计 | 各平台常见 | `set` 求前驱后继，取与当前值差的最小者 |

## 2.12 笛卡尔树 / 其他 ★

- **笛卡尔树**：由序列建成的堆序 + 中序遍历等于原序列的二叉树。与"最大矩形""区间最值"有关。CSP 基本不考。
- **左偏树**（可并堆）：支持 O(log n) 合并两个堆。CSP 极少考。
- **树套树**：CSP 不考。

**结论**：这三类**看懂思想即可，不投入练习时间**。

## 2.13 数据结构选型速查 ★★★★★

### 按需求选

| 需求 | 首选 | 备选 |
|---|---|---|
| 顺序存储 + 随机访问 | `vector` | 裸数组 |
| 先进先出 | `queue` | `deque` |
| 后进先出 | `stack` | `vector` |
| 动态取最值 | `priority_queue` | `multiset`（还需删除任意元素时） |
| 左/右第一个更大/更小 | **单调栈** | — |
| 滑动窗口最值 | **单调队列** | 线段树（慢） |
| 快速查找存在性（不需有序） | `unordered_set`（防卡哈希） | 手写哈希 |
| 快速查找 + **需要有序遍历** | `set` / `map` | — |
| 前驱后继 | `set` + `lower_bound` | — |
| 动态连通性 / 合并集合 | **并查集** | — |
| 前缀静态区间和 | **前缀和** | — |
| 单点改 + 区间查 | **树状数组**（更短） | 线段树 |
| 区间改 + 区间查 | **线段树（懒标记）** | 树状数组（双数组） |
| 静态区间最值 O(1) | **ST 表** | — |
| 字符串前缀集合 | **Trie** | 哈希 |
| 求最大异或对 | **01-Trie** | — |
| 求第 k 小（动态插入） | **树状数组 + 离散化** | 主席树 |
| 矩形面积并 | **扫描线 + 线段树** | — |

### 按数据范围选

| n | 能用的 | 不能用的 |
|---|---|---|
| ≤ 10³ | 一切，包括 O(n²) 暴力 | — |
| ≤ 10⁴ | O(n√n)、O(n log²n) | O(n²) 勉强 |
| ≤ 10⁵ | O(n log n)：树状数组、线段树、set/map、排序 | O(n²) ❌ |
| ≤ 10⁶ | O(n)：前缀和、单调栈、线性筛、计数数组 | O(n log n) 勉强，map ❌（常数大） |
| ≥ 10⁷ | O(n) 且空间受限，或 **O(log n) 数学解** | 任何 O(n) 存数组都可能 MLE |

### 一个重要的反直觉

> **CSP 的 T2/T3 往往 n 很小（≤ 10³），用 `vector` 直接模拟就是最优解。**
>
> 不要因为"学了线段树"就到处套线段树。**先看清 n 的范围**，n ≤ 10³ 时 O(n²) 完全够，写起来还不容易错。
> CSP 第 10 次 T2「学生排队」就是典型：n ≤ 10³，`vector` 模拟 30 行搞定，写线段树反而容易崩。
