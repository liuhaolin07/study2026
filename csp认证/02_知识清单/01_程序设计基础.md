## 1.1 数据类型与溢出 ★★★★★

### 核心知识

| 类型 | 字节 | 范围 | 什么时候用 |
|---|---|---|---|
| `int` | 4 | ±2.1×10⁹ | 下标、计数（确定不超 2e9） |
| `long long` | 8 | ±9.2×10¹⁸ | **默认选择**：求和、乘积、金额、大 n |
| `unsigned long long` | 8 | 0 ~ 1.8×10¹⁹ | 字符串哈希自然溢出 |
| `double` | 8 | ~15-16 位有效数字 | 浮点运算，**不要用来判等** |
| `long double` | 16 | ~18-19 位 | 精度要求极高的几何/数学题 |
| `char` | 1 | ±127 | 字符；**注意可能有符号** |
| `bool` | 1 | true/false | 标记 |
| `__int128` | 16 | ±1.7×10³⁸ | g++ 扩展，`cin/cout` 不支持，需手写读写 |

### 溢出的四种典型场景

```cpp
// ① 两个 int 相乘，结果赋给 ll —— 乘法在 int 范围内就已经溢出了
int a = 1e5, b = 1e5;
ll c = a * b;              // 错！c 是错的
ll c = 1LL * a * b;        // 对：先把其中一个提升为 ll

// ② 移位溢出
1 << 31                    // 未定义行为
1LL << 31                  // 对

// ③ 求和溢出：n 个 1e9 相加
ll sum = 0;                // 必须是 ll，int 会溢出

// ④ 中间步骤溢出：先乘后除
ll x = a * b / c;          // a*b 可能已经溢出
// 若确定能整除，可改写；否则用 __int128 或改变运算顺序
```

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| A+B Problem | 洛谷 P1001 | 热身，确认编译环境正常。注意用 `ll` |
| A*B Problem（高精度） | 洛谷 P1832 | 乘法结果可达 10⁴⁰⁰，必须上高精度；或用 Python 验证思路 |
| 三连击 | 洛谷 P1008 | 枚举 1~9 全排列，拆成三个三位数判断 1:2:3 比例。**注意比例判断要用乘法避免浮点** |
| 计数问题 | 洛谷 P1980 | 枚举 1~n 每个数的每一位，统计 x 出现次数。`n ≤ 10⁶` 直接模拟 |

## 1.2 位运算 ★★★

### 核心技巧

```cpp
x & 1            // 判奇偶，比 x % 2 快（负数时结果不同！-3 & 1 == 1，-3 % 2 == -1）
x & (x - 1)      // 消掉最低位的 1
x & (-x)         // 取最低位的 1（lowbit，树状数组的核心）
x >> i & 1       // 取第 i 位
x |= (1 << i)    // 把第 i 位置 1
x &= ~(1 << i)   // 把第 i 位置 0
x ^ (1 << i)     // 翻转第 i 位
__builtin_popcount(x)     // x 的二进制中 1 的个数
__builtin_clz(x)          // 前导零个数
__builtin_ctz(x)          // 后缀零个数（= lowbit 的位置）
```

### 常用性质

- `a ^ a = 0`，`a ^ 0 = a` → **异或可用于"成对抵消"**（找唯一出现奇数次的数）
- 异或满足结合律交换律 → 可用前缀异或和求区间异或
- `a + b = (a ^ b) + 2 * (a & b)` → 加法分解
- 子集枚举：`for (int sub = S; sub; sub = (sub - 1) & S)` 枚举 S 的所有非空子集

### 易错点

- ⚠️ `1 << i` 当 `i ≥ 31` 溢出 → 写 `1LL << i`
- ⚠️ 运算符优先级：`&` `|` `^` **低于** `==`，所以 `x & 1 == 0` 会被解析成 `x & (1 == 0)`，**必须加括号** `(x & 1) == 0`
- ⚠️ 负数取模和位与的结果不同

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 二进制中 1 的个数 | AcWing 801 | `while(x) { x -= x & -x; cnt++; }`，lowbit 逐个消 |
| 让我们异或吧 | 洛谷 P2420 | 树上路径异或：记 `d[u]` = 根到 u 的异或和，则 u→v 路径异或 = `d[u] ^ d[v]`（LCA 都不用求，因为路径上重复部分自己抵消） |
| 最短 Hamilton 路径 | AcWing 91 | 状压 DP：`f[S][i]` = 走过集合 S 且当前在 i 的最短路，转移 `f[S|1<<j][j] = min(f[S][j] + w[i][j])` |

## 1.3 输入输出 ★★★★★

### 四种读法，按题目格式选

```cpp
// ① 已知个数：直接循环
int n; cin >> n;
for (int i = 0; i < n; i++) cin >> a[i];

// ② 读到 EOF（题目没给个数，或明确说"多组数据直到文件结束"）
while (cin >> x) { ... }                    // 推荐
while (scanf("%d", &x) != EOF) { ... }      // C 风格

// ③ 读到终止标记（如 0 结束）
while (cin >> n && n != 0) { ... }

// ④ 一行内不定个数的整数
string line;
getline(cin, line);
stringstream ss(line);
int x;
while (ss >> x) { ... }
```

### 一整行的读法

```cpp
getline(cin, s);              // 读整行（不含换行符）
cin >> s;                     // 只读到空白符为止
```

⚠️ **`cin >>` 之后接 `getline` 会读到空行**，因为 `>>` 把换行符留在缓冲区：

```cpp
cin >> n;
cin.ignore();                 // 必须吃掉那个换行
getline(cin, s);
```

### IO 加速

```cpp
ios::sync_with_stdio(false);  // 关掉与 C stdio 的同步
cin.tie(nullptr);             // 解绑 cin/cout，取消每次读前的 flush
// ⚠️ 之后绝对不能再混用 scanf / printf
// ⚠️ 输出换行用 '\n'，不要用 endl（endl 每次都 flush）
```

数据量 ≥ 10⁶ 时，用 `getchar` 手写快读（见 `../04_模板/contest.cpp` 的 `read()`）。
⚠️ 快读和 `sync_with_stdio(false)` **二选一**，混用会乱序。

### 输出格式的三个坑

```cpp
// ① 保留小数位数
cout << fixed << setprecision(2) << x << '\n';     // 需要 #include <iomanip>
printf("%.2f\n", x);
// ⚠️ 四舍五入方式：printf/setprecision 是"银行家舍入"的边缘情况极少，
//    但"保留两位"和"乘以100取整"是两回事，看清题目要求

// ② 空格分隔，行末不能有多余空格
for (int i = 0; i < n; i++) {
    if (i) cout << ' ';
    cout << a[i];
}
cout << '\n';

// ③ 大量输出：攒到 string 里一次性 cout，或用 '\n' 而非 endl
```

## 1.4 STL 容器全览 ★★★★★

### 选型速查表

| 容器 | 底层 | 插入/删除 | 查找 | 有序性 | 什么时候用 |
|---|---|---|---|---|---|
| `vector` | 动态数组 | 尾 O(1) 摊还，中间 O(n) | O(n) | 保持插入序 | **默认选择** |
| `deque` | 分段数组 | 头尾 O(1)，中间 O(n) | O(n) | 保持插入序 | 需要头部弹出的队列 |
| `list` | 双向链表 | 任意位置 O(1)（已知迭代器） | O(n) | 保持插入序 | 极少用，vector 几乎总是更好 |
| `array` | 静态数组 | 不支持 | O(n) | 保持 | 固定大小，替代裸数组 |
| `stack` | 适配器 | O(1) | O(1) 顶部 | LIFO | 括号匹配、单调栈、表达式求值 |
| `queue` | 适配器 | O(1) | O(1) 队首 | FIFO | BFS |
| `priority_queue` | 二叉堆 | O(log n) | O(1) 顶部 | 按优先级 | 动态取最值、Dijkstra、贪心 |
| `set` / `multiset` | 红黑树 | O(log n) | O(log n) | **按 key 升序** | 需要有序 + 去重/计数 |
| `map` / `multimap` | 红黑树 | O(log n) | O(log n) | **按 key 升序** | 键值映射且需要有序遍历 |
| `unordered_set/map` | 哈希表 | O(1) 均摊 | O(1) 均摊 | **无序** | 只需查找不需顺序，且 n 大 |
| `bitset` | 位压缩 | O(1) | O(1) | 按下标 | 布尔数组省 32 倍空间，位运算加速 |

### 必须记住的细节

```cpp
// priority_queue 默认是【大根堆】
priority_queue<int> mx;                                            // 大根堆
priority_queue<int, vector<int>, greater<int>> mn;                 // 小根堆
// C++14 起可以省略容器类型：
priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<>> pq;  // 小根堆

// ⚠️ priority_queue 的比较器语义和 sort 【相反】
//    sort 里 cmp(a,b)==true 表示 a 排前面
//    pq   里 cmp(a,b)==true 表示 a 优先级【更低】（在堆底）
//    所以"小根堆"要用 greater

// map 的 operator[] 会【插入】默认值
map<string,int> m;
if (m[key] > 0) { ... }        // ⚠️ 即使 key 不存在，这一行也会插入 m[key]=0
if (m.count(key) && m[key] > 0) { ... }   // 对
auto it = m.find(key); if (it != m.end() && it->second > 0) { ... }  // 对，且更快

// set/map 遍历天然有序
for (auto& [k, v] : m) { ... }            // C++17 结构化绑定，按 k 升序

// erase 迭代器后必须用返回值
for (auto it = v.begin(); it != v.end(); ) {
    if (need_delete(*it)) it = v.erase(it);    // vector: erase 返回下一个有效迭代器
    else ++it;
}
// ⚠️ 对 set/map，erase 也返回下一个迭代器（C++11 起）

// ⚠️ v.size() - 1 当 v 为空时是巨大正数（size() 返回无符号）
for (size_t i = 0; i + 1 < v.size(); i++)      // 对：把 -1 移到左边
for (size_t i = 0; i < v.size() - 1; i++)      // 错：v 为空时死循环/越界

// vector<bool> 不是真容器：不能取元素地址，代理对象导致性能差
// 需要"布尔数组 + 位压缩"时用 bitset；需要能取地址时用 vector<int>

// bitset 常用操作
bitset<1000> b;
b.set(); b.reset(); b.flip();
b.count();               // 1 的个数
b.any(); b.none(); b.all();
b & b2, b | b2, b ^ b2   // 位运算，比循环快 32/64 倍
b.to_string(); b.to_ulong();
```

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 合并果子 | 洛谷 P1090 / AcWing 148 | **小根堆**经典。每次取两个最小的合并，把和 push 回去，累加代价。`O(n log n)` |
| 队列安排 | AcWing 830（单调栈） | 求每个数左边第一个比它小的数。维护一个**从栈底到栈顶递增**的栈 |
| 滑动窗口 | AcWing 154 | 单调队列求窗口最大/最小值。队尾淘汰不优的，队首淘汰出窗的 |
| 食物链 | AcWing 240 | **带权并查集**或**扩展域并查集**（开 3n 个节点表示 A 吃 B、B 吃 C、C 吃 A 三种关系） |
| 模拟散列表 | AcWing 840 | 手写哈希：拉链法（`vector<int> h[N]`）或开放寻址法。**注意负数取模要 `((x%N)+N)%N`** |

## 1.5 `<algorithm>` 全览 ★★★★★

### 必须闭卷写对的

```cpp
sort(a, a + n);                              // 数组
sort(all(v));                                // vector（用宏 all(x) = (x).begin(),(x).end()）
sort(all(v), greater<int>());                // 降序
stable_sort(all(v), cmp);                    // 稳定排序，相等元素保持原序

// 自定义比较：三种写法
struct Node { int x, y; };
bool cmp1(const Node& a, const Node& b) {    // ① 普通函数
    if (a.x != b.x) return a.x < b.x;        //    第一关键字升序
    return a.y > b.y;                        //    第二关键字降序
}                                            // ⚠️ 最后一级必须是 <，不能是 <=
sort(all(v), cmp1);

sort(all(v), [](const Node& a, const Node& b){ return a.x < b.x; });   // ② lambda

struct Cmp3 { bool operator()(const Node& a, const Node& b) const { return a.x < b.x; } };
sort(all(v), Cmp3());                        // ③ 仿函数

// 二分查找（要求已排序）
lower_bound(all(v), x)   // 第一个 >= x 的位置
upper_bound(all(v), x)   // 第一个 >  x 的位置
binary_search(all(v), x) // 是否存在
int pos = lower_bound(all(v), x) - v.begin();          // 0-based 下标
int pos = lower_bound(all(v), x) - v.begin() + 1;      // 1-based 下标
int cnt = upper_bound(all(v), x) - lower_bound(all(v), x);   // x 的个数

// 其他
nth_element(a, a + k, a + n);                // 第 k 小的元素放到 a[k]，O(n)
partial_sort(all(v), v.begin() + k);         // 前 k 个有序，O(n log k)
reverse(all(v));
unique(all(v));                              // 去重【相邻】重复元素，返回新逻辑末尾，必须先 sort
v.erase(unique(all(v)), v.end());            // 真正的"排序去重"
max_element(all(v)); min_element(all(v));    // 返回迭代器，要解引用
accumulate(all(v), 0LL);                     // 求和，⚠️ 初值写 0LL 否则用 int 累加会溢出
count(all(v), x);                            // 计数
find(all(v), x);                             // 线性查找
swap(a, b);
fill(a, a + n, INF);                         // 填充
memcpy(b, a, sizeof a);                      // 拷贝
next_permutation(all(v)); prev_permutation(all(v));
__gcd(a, b);                                 // g++ 内置；C++17 有 std::gcd
```

### 易错点

- ⚠️ **比较器必须满足严格弱序**。相等时返回 `true` 会导致未定义行为，数据量大时**直接 RE，整题 0 分**
- ⚠️ `unique` 只去**相邻**重复，用前必须 `sort`
- ⚠️ `accumulate` 第三个参数决定累加类型，`accumulate(all(v), 0)` 是 int 累加，会溢出
- ⚠️ `next_permutation` 前必须 `sort`，否则只生成字典序更大的部分
- ⚠️ `sort` 对 `list` 不可用（随机访问迭代器要求），用 `list::sort()`

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 【模板】排序 | 洛谷 P1177 | 直接 `sort`。注意 n 可达 10⁵，别用冒泡 |
| 求第 k 小的数 | 洛谷 P1923 | `nth_element` O(n)，或 sort O(n log n)，或快速选择 |
| 数字排序 | CSP 第 4 次 T2 | 按"出现次数降序、数值升序"排。**用计数数组统计频次后排序**，比 map 快 |
| 中间数 | CSP 第 9 次 T1 | 排序后枚举每个数，统计比它大和比它小的个数是否相等 |
| 区间合并 | AcWing 803 | 按左端点排序，然后线性扫描：若当前区间左端点 ≤ 上一个的右端点则合并（取右端点最大值），否则新开一段 |

## 1.6 字符串操作 ★★★★★

### 必备手写函数

```cpp
// 分割：CSP 字符串题几乎必用
vector<string> split_str(const string& s, char delim) {
    vector<string> res;
    size_t start = 0, pos;
    while ((pos = s.find(delim, start)) != string::npos) {
        res.push_back(s.substr(start, pos - start));
        start = pos + 1;
    }
    res.push_back(s.substr(start));          // ⚠️ 最后一段必须单独补
    return res;
}
// ⚠️ 连续两个分隔符之间会产生空串，按题意决定是否跳过

// 大小写转换
transform(all(s), s.begin(), ::tolower);
transform(all(s), s.begin(), ::toupper);

// 去首尾空格
string trim(const string& s) {
    size_t b = s.find_first_not_of(" \t\n\r");
    if (b == string::npos) return "";
    size_t e = s.find_last_not_of(" \t\n\r");
    return s.substr(b, e - b + 1);
}

// 数字 <-> 字符串
to_string(123);            // int -> string
stoi("123");               // string -> int（越界抛异常）
stoll("123");              // string -> long long
stod("1.5");               // string -> double
// C 风格：atoi(s.c_str()), sprintf(buf, "%d", x)

// 反转
reverse(all(s));

// 判断回文
bool is_palindrome(const string& s) {
    for (size_t i = 0, j = s.size() - 1; i < j; i++, j--)
        if (s[i] != s[j]) return false;
    return true;
}
// ⚠️ s.size() 是无符号，空串时 s.size()-1 会溢出。上面的循环 i<j 保证了安全

// 字符分类（<cctype>）
isdigit(c) isalpha(c) isalnum(c) isupper(c) islower(c) isspace(c)
// ⚠️ 传入 char 时若为负数（char 有符号）是未定义行为，稳妥写法 isdigit((unsigned char)c)
```

### `string` 的复杂度陷阱

```cpp
// ⚠️ s + c 在循环里是 O(n) 每次，总 O(n²)
string res;
for (char c : s) res = c + res;        // O(n²)！每次都要整体拷贝
// 应该：
for (auto it = s.rbegin(); it != s.rend(); ++it) res += *it;   // O(n)

// ⚠️ s.substr(i, len) 会创建新字符串，O(len)。频繁 substr 要考虑用下标区间代替
// ⚠️ s.find(t) 最坏 O(n*m)。大量匹配要上 KMP 或字符串哈希
```

## 1.7 复杂度分析 ★★★★★

### 数据范围 → 复杂度（背下来）

| n | 可行复杂度 | 算法 |
|---|---|---|
| ≤ 10 | `O(n!)` | 全排列 |
| ≤ 20 | `O(2ⁿ·n)` | 状压 / 子集枚举 |
| ≤ 100 | `O(n³)` | Floyd / 区间 DP |
| ≤ 1000 | `O(n²)` | 二维 DP |
| ≤ 10⁵ | `O(n log n)` | 排序 / 树状数组 / 线段树 / 二分 |
| ≤ 10⁶ | `O(n)` | 线性筛 / 单调栈 / 双指针 / 前缀和 |
| ≤ 10⁹ | `O(log n)` `O(√n)` | 快速幂 / 二分答案 / 质因数分解 |

安全线：**≤ 3×10⁷ 稳，≤ 10⁸ 勉强（1s）**。`map`/`set` 常数是数组的 5~10 倍。

### 常见复杂度对照

| 写法 | 复杂度 | 备注 |
|---|---|---|
| 双重循环 n=10⁴ | 10⁸ | 危险，1s 可能过不了 |
| `sort` n=10⁶ | 2×10⁷ | 安全 |
| `map` 插入 10⁵ 次 | 1.7×10⁶ × 常数 | 约等于 10⁷，安全但别再多 |
| 递归 DFS 2ⁿ，n=25 | 3×10⁷ | 勉强，需要剪枝 |
| Floyd n=500 | 1.25×10⁸ | 危险，需卡常或换算法 |

### 空间估算

- 1 MB = 10⁶ 字节
- `int a[1000005]` = 4 MB
- `ll a[1000005]` = 8 MB
- 二维 `int a[1005][1005]` = 4 MB
- 二维 `int a[5005][5005]` = 100 MB ⚠️ 可能 MLE
- 线段树 `ll t[4*N]`，N=10⁵ → 3.2 MB

⚠️ **CSP 空间限制常见 512 MB，但个别题是 256 MB**，看题面。

## 1.8 高精度 ★★

### 什么时候需要

题目数据范围里出现"数字不超过 100 位""结果可能非常大"且**没有要求取模**时。

### 核心模板（vector 存位，低位在前）

```cpp
// 加法
vector<int> add(const vector<int>& A, const vector<int>& B) {
    if (A.size() < B.size()) return add(B, A);
    vector<int> C; int t = 0;
    for (size_t i = 0; i < A.size(); i++) {
        t += A[i];
        if (i < B.size()) t += B[i];
        C.push_back(t % 10);
        t /= 10;
    }
    if (t) C.push_back(t);
    return C;
}

// 减法（保证 A >= B）
vector<int> sub(const vector<int>& A, const vector<int>& B) {
    vector<int> C; int t = 0;
    for (size_t i = 0; i < A.size(); i++) {
        t = A[i] - t;
        if (i < B.size()) t -= B[i];
        C.push_back((t + 10) % 10);          // ⚠️ 借位处理
        t = (t < 0) ? 1 : 0;
    }
    while (C.size() > 1 && C.back() == 0) C.pop_back();   // ⚠️ 去前导零
    return C;
}

// 高精度 × 低精度
vector<int> mul(const vector<int>& A, int b) {
    vector<int> C; int t = 0;
    for (size_t i = 0; i < A.size() || t; i++) {
        if (i < A.size()) t += A[i] * b;
        C.push_back(t % 10);
        t /= 10;
    }
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}

// 高精度 ÷ 低精度，返回商，r 为余数
vector<int> divi(const vector<int>& A, int b, int& r) {
    vector<int> C; r = 0;
    for (int i = (int)A.size() - 1; i >= 0; i--) {   // ⚠️ 除法从高位往低位
        r = r * 10 + A[i];
        C.push_back(r / b);
        r %= b;
    }
    reverse(all(C));                                  // ⚠️ 结果要反转回来
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}

// 输出
void print(const vector<int>& A) {
    for (int i = (int)A.size() - 1; i >= 0; i--) cout << A[i];
}
```

### 压位优化（把每位存 10⁴ 或 10⁸ 而不是 10）

数据量极大时（如 10⁵ 位），逐位存储会慢。用 `vector<ll>` 每位存 `1e4`，乘法时注意进位上限：`1e4 × 1e4 × 位数` 不能超 `ll`。

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 高精度加法 | AcWing 791 | 上面的 `add`，注意进位 |
| 高精度减法 | AcWing 792 | 先比较大小决定谁减谁，输出时加负号 |
| 高精度乘法 | AcWing 793 | 高精 × 高精：`C[i+j] += A[i]*B[j]`，最后统一处理进位 |
| 高精度除法 | AcWing 794 | 从高位往低位试商，记得反转结果 |
| A*B Problem | 洛谷 P1832 | 两个 10⁴⁰⁰ 级别的数相乘。朴素 O(n²) 可过；n 更大需 FFT |

## 1.9 日期与时间 ★★★

### 三件套

```cpp
int md[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

bool is_leap(int y) {
    return (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;
}

int days_of(int y, int m) {
    return (m == 2 && is_leap(y)) ? 29 : md[m];
}

// 日期 -> 总天数（用于算日期差、日期加减）
ll date_to_days(int y, int m, int d) {
    ll s = 365LL * y + y / 4 - y / 100 + y / 400;   // 闰年补偿
    for (int i = 1; i < m; i++) s += days_of(y, i);
    return s + d;
}

// 总天数 -> 日期（上面的逆运算）
void days_to_date(ll days, int& y, int& m, int& d) {
    y = int(days / 366);                            // 粗略起点
    while (date_to_days(y + 1, 1, 1) <= days) y++;
    while (date_to_days(y, 1, 1) > days) y--;
    m = 1;
    while (m < 12 && date_to_days(y, m + 1, 1) <= days) m++;
    d = int(days - date_to_days(y, m, 1) + 1);
}
```

### 星期几

**蔡勒公式**（`w=0` 为周日）：

```cpp
int day_of_week(int y, int m, int d) {
    if (m <= 2) { m += 12; y--; }                   // ⚠️ 1、2 月要当作上一年的 13、14 月
    int c = y / 100, yy = y % 100;
    int w = (yy + yy / 4 + c / 4 - 2 * c + 26 * (m + 1) / 10 + d - 1) % 7;
    return (w + 7) % 7;                             // ⚠️ 负数取模要修正
}
```

或者更稳的办法：**选一个已知星期的基准日**（如 2000-01-01 是周六），算日期差再 `% 7`。

### 易错点

- ⚠️ 闰年判断的括号：`(y%4==0 && y%100!=0) || y%400==0`，漏括号结果就错
- ⚠️ 跨月/跨年进位：`d > days_of(y,m)` 时要 `d -= days_of(y,m); m++; if (m>12) {m=1; y++;}`
- ⚠️ "第几个星期几"类题目（如"11 月第 4 个星期四"）：先算 1 号是星期几，再推
- ⚠️ 负数取模：C++ 的 `%` 结果符号跟被除数，要 `(x % 7 + 7) % 7`

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 日期计算 | CSP 第 5 次 T2 | 给年 y 和第 d 天，输出 `yyyy-mm-dd`。**逐月减去天数**即可，注意闰年二月 |
| 节日 | CSP 第 4 次 T2 | 输出某年区间内的多个节日（含"第 n 个星期 x"类）。先算每年 1 月 1 日星期几，再推算 |
| 小鱼的航程 | 洛谷 P1424 | 日期推算 + 跳过周末。把日期转成总天数后 `% 7` 判星期 |
| 小鱼的游泳时间 | 洛谷 P1425 | 时间差计算，注意分钟借位（`if (m1 > m2) { h2--; m2 += 60; }`） |

## 1.10 进制转换 ★★★

```cpp
// 十进制 -> k 进制（k <= 16）
string to_base(ll n, int k) {
    if (n == 0) return "0";
    bool neg = n < 0; if (neg) n = -n;              // ⚠️ LLONG_MIN 取负会溢出
    string s;
    while (n) {
        int d = n % k;
        s += (d < 10) ? char('0' + d) : char('A' + d - 10);
        n /= k;
    }
    if (neg) s += '-';
    reverse(all(s));
    return s;
}

// k 进制 -> 十进制
ll from_base(const string& s, int k) {
    ll n = 0;
    for (char c : s) {
        int d = isdigit(c) ? c - '0' : (toupper(c) - 'A' + 10);
        n = n * k + d;                              // ⚠️ 可能溢出，看题目范围
    }
    return n;
}

// C++ 内置
stoi(s, nullptr, 2);         // 二进制字符串 -> int
bitset<32>(x).to_string();   // int -> 二进制字符串
cout << hex << x << dec << x << oct << x;   // 流格式化输出
```

## 1.11 递归与函数设计 ★★★★

### 递归三要素

```cpp
int f(int n) {
    if (n == 0) return 1;        // ① 边界（必须有，否则无限递归 → 栈溢出）
    return n * f(n - 1);         // ② 递推关系 + ③ 向边界收敛
}
```

### 递归 → 迭代的改写

```cpp
// 递归版 DFS
void dfs(int u) {
    vis[u] = true;
    for (int v : g[u]) if (!vis[v]) dfs(v);
}

// 迭代版（避免 n > 1e4 时栈溢出）
void dfs_iter(int start) {
    stack<int> st; st.push(start); vis[start] = true;
    while (!st.empty()) {
        int u = st.top(); st.pop();
        for (int v : g[u]) if (!vis[v]) { vis[v] = true; st.push(v); }
    }
}
```

⚠️ **考场默认栈约 8 MB**，每个栈帧按 100 字节算约 8 万层。链状图 DFS 10⁵ 个点会栈溢出。CSP 考场（Ubuntu + g++）**不一定能改栈大小**，所以大数据量的 DFS 优先写迭代版，或改用 BFS。

### 函数设计原则（大模拟的关键）

```cpp
// ❌ 反例：一个 300 行的 main，全局变量满天飞，改一处崩三处
// ✅ 正例：状态集中 + 每条规则一个函数
struct State { /* 所有会被修改的量 */ };
State st;

void rule_1_apply(const Op& op) { /* R1 */ }
void rule_2_apply(const Op& op) { /* R2 */ }
bool check_valid(const Op& op)  { /* 合法性校验 */ }

void process(const Op& op) {
    if (!check_valid(op)) return;      // 先校验
    rule_1_apply(op);                  // 再按顺序套用规则
    rule_2_apply(op);
}
```

好处：**每个函数可以单独用样例验证**，出问题时能二分定位。

## 1.12 模拟与代码组织 ★★★★★

### CSP 模拟题的四种类型

| 类型 | 特征 | 代表题 |
|---|---|---|
| **过程模拟** | 按题意一步步做 | 门禁系统、消除类游戏、火车购票 |
| **规则模拟**（大模拟） | 多条规则 + 状态维护 + 事件排序 | 炉石传说、权限查询、集合竞价 |
| **格式模拟** | 主要难在输入解析和输出格式 | 命令行选项、多项式输出、路径解析 |
| **数学模拟** | 找规律 / 推公式 | 折点计数、Z 字形扫描、数位之和 |

### 写模拟题的六条纪律

1. **先读 3 遍题，规则编号写全**（R1、R2…），不要边读边写代码
2. **先设计 struct 再动手**，所有状态量集中声明
3. **分阶段实现**，每实现一条规则就用样例验证
4. **主动造极端样例**：n=1、n=0、空集、最大值、全相同、重复操作、非法输入
5. **默认 `long long`**
6. **卡住 20 分钟就保存当前版本从头重写**（重写常常比调试快）
