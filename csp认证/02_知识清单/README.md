## 五、与 `../../Algorithms/` 的分工

本体系是 **CSP 特化版**：覆盖大纲全部考点，但**优先级按 CSP 考频重排**。

| | 本目录（02_知识清单） | `../../Algorithms/` |
|---|---|---|
| 目标 | 2026-12 CSP 350+ | 2027 ICPC 区域赛银牌 |
| 覆盖 | 大纲全考点，**但按 CSP 考频分三级** | 竞赛全体系，无优先级裁剪 |
| 题单 | 指向 CSP 真题 + 各章「配套练习」 | `题单/` 约 720 题，12 个专题 |
| 模板代码 | 各章内嵌**考场可直接抄**的精简版 | `模板/XCPC_Templates/` 31 个头文件 + 72 项自动化测试 |
| 速查表 | `CSP考频知识点清单.md`（考前打印） | `笔记/速查/` 7 张表 |
| 深度 | 够用即可，✗ 级明确跳过 | 追求完整与严谨 |

**冲突时的优先级**：
- **要练什么题** → 看本目录各章的「配套练习」，或 `../../Algorithms/题单/`
- **要更深入的推导和证明** → 看 `../../Algorithms/笔记/速查/` 和 [OI Wiki](https://oi-wiki.org)
- **要完整的模板代码库** → 看 `../../Algorithms/模板/`

## 六、每个考点的统一格式

所有章节都按同一结构组织，方便查找：

```
### X.Y 考点名  ★考频

【核心知识 / 核心解法】      ← 结论、公式、算法思想
【模板代码】                 ← 考场可直接抄的 C++ 代码
【易错点】                   ← ⚠️ 标记，都是真实翻车点
【选型 / 决策表】            ← 什么时候用这个、什么时候用别的
【配套练习】                 ← 表格：题目 | 来源 | 解法要点
```

「配套练习」的**解法要点**给出的是**思路和关键步骤**，不是完整代码。理由：
- 完整代码看题解更快，抄一遍没有训练价值
- **代码必须自己从零敲一遍**（考场严禁 AI，且"看完题解关掉重写"是 `../../Algorithms/README.md` 的铁律）
- 卡住超过 30~40 分钟再看题解，看完关掉重写

## 七、自查清单怎么用

每个专题文件末尾都有「本章自查清单」，分三级：

- **必会** —— 月末检查点，**必须全部打勾**
- **应会** —— 第 2 月末检查点
