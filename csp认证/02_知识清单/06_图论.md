## 6.1 图的表示与建图 ★★★★★

### 三种方式对比

| 方式 | 空间 | 加边 | 遍历邻居 | 适用 |
|---|---|---|---|---|
| 邻接矩阵 `g[N][N]` | O(n²) | O(1) | O(n) | n ≤ 500，稠密图，Floyd |
| `vector<int> g[N]` | O(n+m) | O(1) 摊还 | O(deg) | **默认选择** |
| 链式前向星 | O(n+m) | O(1) | O(deg) | 需要存边编号 / 网络流 |

```cpp
// ① vector 存图（带权用 pair）
vector<pair<int,int>> g[N];              // g[u] = {(v, w), ...}
g[u].push_back({v, w});
g[v].push_back({u, w});                  // ⚠️ 无向图两边都要加

// ② 链式前向星
int head[N], to[2*N], w[2*M], nxt[2*M], idx;
void add(int u, int v, int ww) {
    to[idx] = v; w[idx] = ww; nxt[idx] = head[u]; head[u] = idx++;
}
for (int i = head[u]; i != -1; i = nxt[i]) { int v = to[i]; /* w[i] */ }
// ⚠️ 用前 memset(head, -1, sizeof head)
```

### 按数据范围选

| n | m | 建图 | 最短路 |
|---|---|---|---|
| ≤ 500 | 稠密 | 邻接矩阵 | Floyd O(n³) 或朴素 Dijkstra O(n²) |
| ≤ 10⁴ | ≤ 10⁵ | vector | 堆优化 Dijkstra |
| ≤ 10⁵ | ≤ 2×10⁵ | vector | 堆优化 Dijkstra O(m log n) |
| 网格 n×m | — | **不建图**，直接二维数组 + 四方向 | BFS |

⚠️ **n = 10⁵ 时用邻接矩阵会 MLE**（`10⁵ × 10⁵ × 4 字节 = 40 GB`）。

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 图中点的层次 | AcWing 847 | BFS，vector 建图 |
| 有向图的拓扑序列 | AcWing 848 | Kahn，用 vector 存出边 + 入度数组 |

### 二分图染色判定

```cpp
int color[N];                            // 0 = 未染色，1/2 = 两种颜色
bool dfs(int u, int c) {
    color[u] = c;
    for (int v : g[u]) {
        if (color[v] == c) return false;              // 冲突
        if (color[v] == 0 && !dfs(v, 3 - c)) return false;
    }
    return true;
}
```

## 6.3 最短路 ★★★★★

### 五种算法选型表（**背下来**）

| 场景 | 算法 | 复杂度 |
|---|---|---|
| 无权图 / 所有边权相等 | **BFS** | O(V+E) |
| 边权只有 0 和 1 | **0-1 BFS**（deque） | O(V+E) |
| 非负权，单源，稀疏图 | **堆优化 Dijkstra** | O(m log n) |
| 非负权，单源，稠密图（n ≤ 500） | **朴素 Dijkstra** | O(n²) |
| **有负权**，单源 | **SPFA / Bellman-Ford** | 平均 O(kE)，最坏 O(VE) |
| 有负权，**限制边数 ≤ k** | **Bellman-Ford（k 轮松弛）** | O(kE) |
| 全源最短路，n ≤ 400 | **Floyd** | O(n³) |
| DAG 上的最短路 | **拓扑序 + 松弛** | O(V+E) |

### ① BFS（无权图）

```cpp
int d[N];
int bfs(int s, int t) {
    memset(d, -1, sizeof d);
    queue<int> q; d[s] = 0; q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        if (u == t) return d[u];
        for (int v : g[u]) if (d[v] == -1) { d[v] = d[u] + 1; q.push(v); }
    }
    return -1;
}
```

### ② 朴素 Dijkstra（稠密图，n ≤ 500）

```cpp
int d[N]; bool vis[N];
void dijkstra_naive(int s) {
    memset(d, 0x3f, sizeof d); d[s] = 0;
    for (int it = 0; it < n; it++) {
        int u = -1;
        for (int i = 1; i <= n; i++)
            if (!vis[i] && (u == -1 || d[i] < d[u])) u = i;      // 找未确定的最小 d
        if (u == -1) break;
        vis[u] = true;
        for (auto [v, w] : g[u]) d[v] = min(d[v], d[u] + w);
    }
}
```

### ③ 堆优化 Dijkstra（**默认选择**）

```cpp
void dijkstra(int s) {
    fill(d, d + n + 1, LINF); d[s] = 0;
    priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<>> pq;
    pq.push({0, s});
    while (!pq.empty()) {
        auto [du, u] = pq.top(); pq.pop();
        if (du > d[u]) continue;                     // ⚠️ 过期节点跳过，这句不能省
        for (auto [v, w] : g[u])
            if (d[u] + w < d[v]) { d[v] = d[u] + w; pq.push({d[v], v}); }
    }
}
```

⚠️ **三个坑**：
1. 必须用**小根堆**（`greater<>`），写反了就全错
2. `if (du > d[u]) continue;` 这句是性能关键，不写会退化成 O(m²)
3. **Dijkstra 不能处理负权边**——负权会让"已确定"的点被再次更新，破坏贪心的前提

### ④ SPFA（队列优化 Bellman-Ford）

```cpp
bool inq[N];
void spfa(int s) {
    fill(d, d + n + 1, LINF); d[s] = 0;
    queue<int> q; q.push(s); inq[s] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop(); inq[u] = false;
        for (auto [v, w] : g[u])
            if (d[u] + w < d[v]) {
                d[v] = d[u] + w;
                if (!inq[v]) { q.push(v); inq[v] = true; }
            }
    }
}
```

⚠️ **SPFA 会被出题人卡**（构造网格图让它退化成 O(VE)）。**能用 Dijkstra 就别用 SPFA。** 只在有负权时才用。

### ⑤ Bellman-Ford（限制边数）

```cpp
// 求"最多经过 k 条边"的最短路 —— SPFA 做不到，必须用这个
memcpy(backup, d, sizeof d);
for (int it = 0; it < k; it++) {
    memcpy(backup, d, sizeof d);                     // ⚠️ 必须备份，防止本轮结果串用
    for (每条边 u->v 权 w)
        d[v] = min(d[v], backup[u] + w);
}
```

⚠️ **"限制边数"是 Bellman-Ford 唯一不可替代的场景**（CSP 第 10 次 T5「引水入城」类题可能用到）。

### ⑥ Floyd（全源，n ≤ 400）

```cpp
for (int k = 1; k <= n; k++)                 // ⚠️ k 必须在最外层
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            if (d[i][k] < INF && d[k][j] < INF)
                d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
```

⚠️ **k 放最里层结果是错的**——这是 Floyd 唯一但致命的坑。原理：`k` 是"允许经过的中间点集合"的上界，必须从小到大逐步放开。
⚠️ 判断 `INF` 相加溢出，先检查再相加。

### ⑦ 判负环

```cpp
// SPFA + 记录每个点入队次数，某点入队 >= n 次则有负环
// 或 Bellman-Ford 跑 n 轮，第 n 轮还能松弛则有负环
```

## 6.4 最小生成树 ★★★

### Kruskal（**默认选择**，O(m log m)）

```cpp
struct Edge { int u, v, w; };
vector<Edge> edges;
sort(edges.begin(), edges.end(), [](const Edge& a, const Edge& b){ return a.w < b.w; });
init(n);
ll tot = 0; int cnt = 0;
for (auto& e : edges) {
    if (unite(e.u, e.v)) {
        tot += e.w;
        if (++cnt == n - 1) break;
    }
}
if (cnt < n - 1) { /* 图不连通，无生成树 */ }
```

### Prim（稠密图，O(n²)）

```cpp
int d[N]; bool vis[N];
ll prim() {
    memset(d, 0x3f, sizeof d); d[1] = 0;
    ll res = 0;
    for (int it = 0; it < n; it++) {
        int u = -1;
        for (int i = 1; i <= n; i++) if (!vis[i] && (u == -1 || d[i] < d[u])) u = i;
        if (d[u] == INF) return -1;              // 不连通
        vis[u] = true; res += d[u];
        for (auto [v, w] : g[u]) if (!vis[v]) d[v] = min(d[v], w);
    }
    return res;
}
```

### 选型

| 场景 | 算法 |
|---|---|
| 稀疏图（m ≈ n） | Kruskal |
| 稠密图（m ≈ n²） | Prim O(n²) |
| 需要"边排序"的后续操作 | Kruskal（天然有序） |
| 求瓶颈路（两点间路径最大边最小） | **Kruskal 重构树** 或 二分 + 并查集 |

### 配套练习

| Kruskal 算法求最小生成树 | AcWing 859 | 稀疏图模板 |

| 树（最小生成树计数） | AcWing 349 | MST 计数：按权值分组，每组内用矩阵树定理或枚举 |

## 6.5 LCA 与树上路径 ★★★

### 倍增法求 LCA（**默认选择**）

```cpp
int fa[21][N], dep[N];
void dfs(int u, int f) {
    fa[0][u] = f; dep[u] = dep[f] + 1;
    for (int v : g[u]) if (v != f) dfs(v, u);
}
void build() {
    dfs(root, 0);
    for (int k = 1; k <= 20; k++)
        for (int i = 1; i <= n; i++)
            fa[k][i] = fa[k-1][ fa[k-1][i] ];      // 2^k 级祖先 = 两个 2^(k-1) 级
}
int lca(int a, int b) {
    if (dep[a] < dep[b]) swap(a, b);
    for (int k = 20; k >= 0; k--)                  // ① 把 a 提到和 b 同深度
        if (dep[fa[k][a]] >= dep[b]) a = fa[k][a];
    if (a == b) return a;
    for (int k = 20; k >= 0; k--)                  // ② 一起往上跳，跳到 LCA 的孩子
        if (fa[k][a] != fa[k][b]) { a = fa[k][a]; b = fa[k][b]; }
    return fa[0][a];
}
```

⚠️ 第二步的条件是 `fa[k][a] != fa[k][b]`（**不等才跳**），跳完后 `fa[0][a]` 就是 LCA。写成 `==` 会跳过头。

### 树上路径

```cpp
// u 到 v 的路径长度（带边权）= dist[u] + dist[v] - 2 * dist[lca]
//   其中 dist[x] = 根到 x 的距离
// 路径上的点数 = dep[u] + dep[v] - 2 * dep[lca] + 1
```

### 树上差分

```cpp
// 给 u 到 v 的路径上所有边 +1：
int p = lca(u, v);
d[u]++; d[v]++; d[p] -= 2;
// 最后自底向上累加：d[u] += sum(d[子节点])，则 d[u] 就是 u 到其父节点那条边的值

// 点权版本（给路径上所有点 +1）：
d[u]++; d[v]++; d[p]--; d[fa[0][p]]--;
```

### Tarjan 离线 LCA

把所有询问离线，DFS 时用并查集合并已访问的子树，O(n + q·α)。CSP 上倍增够用，了解即可。

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 【模板】最近公共祖先 | 洛谷 P3379 | 倍增 LCA |
| 让我们异或吧 | 洛谷 P2420 | 前缀异或：`d[u] ^ d[v]`（路径上重复部分自抵消，**连 LCA 都不用求**） |
| 距离 / 树上路径长度类 | AcWing 117 | 前缀距离 + LCA |

| 货车运输（最大瓶颈路） | 洛谷 P1967 | **最大生成树 + 树上路径最小边**（LCA 时同时维护最小值），或 Kruskal 重构树 |

## 6.6 拓扑排序 ★★★★

### Kahn 算法（BFS 版）

```cpp
vector<int> indeg(n + 1, 0), order;
for (每条边 u->v) indeg[v]++;
queue<int> q;
for (int i = 1; i <= n; i++) if (indeg[i] == 0) q.push(i);
while (!q.empty()) {
    int u = q.front(); q.pop();
    order.push_back(u);
    for (int v : g[u]) if (--indeg[v] == 0) q.push(v);
}
bool has_cycle = ((int)order.size() != n);         // ⚠️ 排序结果数量 < n 说明有环
```

### 字典序最小的拓扑序

把 `queue` 换成 **`priority_queue`（小根堆）** 即可。

### 判有向图是否有环

- Kahn：拓扑序长度 < n → 有环
- DFS：三色标记（白/灰/黑），遇到**灰色**节点 → 有环

### DAG 上的 DP

```cpp
// 拓扑序保证了转移时依赖的状态已算过，所以 DAG DP 不需要记忆化
for (int u : order)
    for (int v : g[u])
        f[v] = max(f[v], f[u] + w);
```

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 有向图的拓扑序列 | AcWing 848 | Kahn，无解输出 -1 |
| 家谱 / 排序问题 | AcWing 343 | **边读入边判**：每加一条边就跑一次拓扑，判断"是否有环"和"是否已能确定全序"（拓扑序唯一 ⟺ 每一步队列里只有 1 个元素） |
| 任务调度 | CSP 第 1 次 T5 | 拓扑排序 + 分层求最长路（关键路径）。`f[v] = max(f[u] + dur[v])`，答案是 `max(f[i])` |
| 可达性统计 | AcWing 164 | 拓扑逆序 + **bitset 传递闭包**：`reach[u] |= reach[v]`，n ≤ 30000 用 bitset 才够快 |
| 最短路计数 | 洛谷 P1144 | Dijkstra 建出最短路 DAG，再按拓扑序累加方案数 |
| 绿豆蛙的归宿 | 洛谷 P4316 | DAG 上期望倒推（拓扑逆序） |

## 6.7 连通性（Tarjan） ★★★

### 割点（割顶）

```cpp
int dfn[N], low[N], tim;
bool is_cut[N];
void tarjan(int u, int root) {
    dfn[u] = low[u] = ++tim;
    int child = 0;
    for (int v : g[u]) {
        if (!dfn[v]) {
            tarjan(v, root);
            low[u] = min(low[u], low[v]);
            if (u != root && low[v] >= dfn[u]) is_cut[u] = true;
            if (u == root) child++;
        } else low[u] = min(low[u], dfn[v]);
    }
    if (u == root && child >= 2) is_cut[u] = true;   // ⚠️ 根要单独判：至少两个孩子
}
```

### 桥（割边）

与割点类似，条件是 `low[v] > dfn[u]`（**严格大于**），且要记录父边编号防止走回头边（不是防父节点，因为有重边）。

### 强连通分量（SCC）

```cpp
int dfn[N], low[N], stk[N], top, tim, scc_cnt, id[N];
bool in_stk[N];
void tarjan(int u) {
    dfn[u] = low[u] = ++tim; stk[++top] = u; in_stk[u] = true;
    for (int v : g[u]) {
        if (!dfn[v]) { tarjan(v); low[u] = min(low[u], low[v]); }
        else if (in_stk[v]) low[u] = min(low[u], dfn[v]);
    }
    if (dfn[u] == low[u]) {                          // u 是这个 SCC 的根
        scc_cnt++;
        while (true) {
            int v = stk[top--]; in_stk[v] = false;
            id[v] = scc_cnt;
            if (v == u) break;
        }
    }
}
// 之后可以"缩点"：把每个 SCC 缩成一个点，得到 DAG，再做拓扑 DP
```

### 边双连通分量（e-DCC）

删掉所有桥后的连通块。**同一边双内任意两点之间有至少两条边不相交的路径。**

### 点双连通分量（v-DCC）

删掉任意一个点后仍连通的极大子图。**割点属于多个点双。**

## 6.8 二分图 ★★★

### 染色判定（是否是二分图）

见 6.2。**一个图是二分图 ⟺ 不含奇环。**

### 匈牙利算法（最大匹配）

```cpp
int match[N];                          // match[v] = 右部点 v 匹配的左部点
bool vis[N];
bool find(int u) {
    for (int v : g[u]) {
        if (vis[v]) continue;
        vis[v] = true;
        if (match[v] == 0 || find(match[v])) {      // v 空闲，或 v 的原配能找到别的
            match[v] = u; return true;
        }
    }
    return false;
}
int hungarian() {
    int res = 0;
    for (int u = 1; u <= n1; u++) {
        memset(vis, 0, sizeof vis);                 // ⚠️ 每个左部点都要清空 vis
        if (find(u)) res++;
    }
    return res;
}
```

### 四个重要等式（** König 定理系列**）

| 结论 | 公式 |
|---|---|
| 最大匹配数 | = 匈牙利算法结果 |
| **最小点覆盖数** | **= 最大匹配数**（König 定理） |
| 最大独立集 | = 总点数 − 最小点覆盖 = n − 最大匹配 |
| 最小路径覆盖（DAG，点不相交） | = n − 拆点后二分图的最大匹配 |

### 二分图最大权匹配

KM 算法，O(n³)。**CSP 基本不考**，需要时用最小费用最大流代替。

## 6.9 欧拉路与欧拉回路 ★★

### 判定

| 图类型 | 欧拉回路（经过每条边一次且回到起点） | 欧拉路（经过每条边一次，起终点可不同） |
|---|---|---|
| 无向图 | 连通 且 **所有点度数为偶** | 连通 且 **恰好 0 或 2 个奇度点**（2 个时它们分别是起点终点） |
| 有向图 | 弱连通 且 **所有点入度=出度** | 弱连通 且 **恰好一个点出度−入度=1（起点）、一个点入度−出度=1（终点）**，其余相等 |

### 构造（Hierholzer 算法）

```cpp
vector<int> path;
void dfs(int u) {
    while (head[u] != -1) {                        // ⚠️ 用 while 不是 if，且要删除已用边
        int i = head[u]; head[u] = nxt[i];         // 删边（防止重复走）
        int v = to[i];
        dfs(v);
    }
    path.push_back(u);                             // ⚠️ 后序加入，最后 reverse
}
// 从起点调用 dfs(start)，然后 reverse(path)
```

⚠️ **必须删边**，否则每条边会被重复遍历，指数爆炸。

|---|---|---|
| 送货 | CSP 第 6 次 T4 | **欧拉路径**判定 + 构造。注意：① 奇度点必须是 0 或 2，且若为 2 则起点必须是最小的那个（题目要求字典序最小）② 图必须连通（只考虑有边的点）③ 用 `set` 或排序保证字典序 |
| 一笔画问题 | 洛谷 P1127 | 欧拉路判定 + 构造，要求字典序最小 → 邻接表排序后 Hierholzer |
| 单词接龙（欧拉路版） | 洛谷 P1019 类 | 把每个单词看成"首字母 → 尾字母"的边，问是否存在欧拉路 |

## 6.10 差分约束 ★★

### 转化规则

| 约束形式 | 转化 |
|---|---|
| `x_i - x_j ≤ c` | 加边 `j → i`，权 `c`（求**最短路**） |
| `x_i - x_j ≥ c` | 加边 `j → i`，权 `c`（求**最长路**），或改写为 `x_j - x_i ≤ -c` |
| `x_i = x_j` | 双向边权 0 |
| `x_i ≤ c` | 加虚拟源点 0，边 `0 → i` 权 `c` |

- **求最大值** → 建最短路图，跑最短路（`d[i]` 就是 `x_i` 的最大值）
- **求最小值** → 建最长路图，跑最长路
- **有解 ⟺ 图中无负环**（最短路情形）

### 模板

```cpp
// 加一个虚拟源点 0，向所有点连边权 0（或题目给的上界）
for (int i = 1; i <= n; i++) add(0, i, 0);
// 跑 SPFA 判负环；无负环则 d[i] 就是一组解
```

|---|---|---|
| 区间约束类 | 洛谷 P1993（小 K 的农场） | 三种约束转成边，SPFA 判负环，无解输出 NO |
| 排队布局 | 洛谷 P1613 类 | 差分约束 + 判负环 + 求最短路 |
| 布局 / Layout | 洛谷 P4878 | 差分约束，注意"不连通"的情况 |

## 6.11 网络流 ★★

> **CSP 考得很少，但一旦出现就是 T5。** 要求：能看懂、能套模板、能拿到部分分。

### 最大流（Dinic 算法）

```cpp
struct Edge { int to, cap, nxt; } e[2*M];
int head[N], idx;
void add(int u, int v, int cap) {                  // ⚠️ 正向边 + 反向边成对加
    e[idx] = {v, cap, head[u]}; head[u] = idx++;
    e[idx] = {u, 0,   head[v]}; head[v] = idx++;
}

int dep[N], cur[N];
bool bfs(int s, int t) {                           // 分层
    memset(dep, 0, sizeof dep);
    queue<int> q; dep[s] = 1; q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int i = head[u]; i != -1; i = e[i].nxt) {
            int v = e[i].to;
            if (!dep[v] && e[i].cap > 0) { dep[v] = dep[u] + 1; q.push(v); }
        }
    }
    return dep[t];
}
int dfs(int u, int t, int flow) {                  // 多路增广
    if (u == t) return flow;
    int used = 0;
    for (int& i = cur[u]; i != -1; i = e[i].nxt) { // ⚠️ cur 是引用，实现当前弧优化
        int v = e[i].to;
        if (dep[v] == dep[u] + 1 && e[i].cap > 0) {
            int d = dfs(v, t, min(flow - used, e[i].cap));
            e[i].cap -= d; e[i ^ 1].cap += d;      // ⚠️ i^1 是反向边（因为成对加）
            used += d;
            if (used == flow) break;
        }
    }
    if (!used) dep[u] = -2;                        // 炸点优化
    return used;
}
int dinic(int s, int t) {
    int res = 0;
    while (bfs(s, t)) { memcpy(cur, head, sizeof head); res += dfs(s, t, INF); }
    return res;
}
```

### 最小割

**最大流最小割定理**：最大流 = 最小割。
"最少删除多少条边使 s 和 t 不连通" = 最大流。

### 常见转化

| 问题 | 转化为 |
|---|---|
| 二分图最大匹配 | 源点连所有左部（容量 1），右部连汇点（容量 1），原边容量 1 |
| 最小点覆盖（二分图） | = 最大匹配（König） |
| 最大独立集（二分图） | = n − 最大匹配 |
| 最小路径覆盖（DAG） | = n − 拆点后最大匹配 |
| 最大权闭合子图 | 正权点连源（容量=权值），负权点连汇（容量=|权值|），原边容量 INF；答案 = 正权和 − 最大流 |
| 项目选择 / 依赖约束 | 最大权闭合子图模型 |

### 最小费用最大流

在 Dinic 的 `bfs` 换成 **SPFA 求最短路（按费用）**，每次沿最短路增广。用于"流量固定时费用最小"或"费用固定时流量最大"。

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 【模板】网络最大流 | 洛谷 P3376 | Dinic 模板 |
| 【模板】最小费用最大流 | 洛谷 P3381 | SPFA + 增广 |
| 修车 | 洛谷 P2053 | **拆点建模**：每个工人的每个时间段拆成一个点，费用 = 等待时间贡献 |
| 餐巾计划 | 洛谷 P2674 | 上下界费用流，拆成"干净/脏"两类点 |
| 货物调度 | CSP 第 3 次 T5 | 小数据状压/搜索，大数据可能需要费用流（**先写小数据暴力拿分**） |
| 最优贸易类 | — | 通常不需要网络流，用分层图最短路 |

## 6.12 分层图 ★★★

### 什么是分层图

当状态不只是"在哪个点"，还包含额外信息（"已用几次免费额度""当前是否持有物品""已经过多少个中转"）时，把图**复制成 k 层**，层内是原图的边，层间是"状态转换"的边。

```cpp
// 状态 (u, j) -> 节点编号 u + j * n
// 层内边：(u, j) -> (v, j)，权 w
// 层间边：(u, j) -> (v, j+1)，权 w'（按题意）
int id(int u, int j) { return u + j * n; }
```

### 常见模型

| 模型 | 层数 | 层间边 |
|---|---|---|
| 最多免费 k 条边 | k+1 | 免费边：`(u,j)→(v,j+1)` 权 0；不免费：层内正常权 |
| 买一次卖一次 | 3 | 层 0→1（买，权 −价格），层 1→2（卖，权 +价格） |
| 最多经过 k 个中转 | k+1 | 每经过一个中转 +1 层 |
| 可以"跳过" k 个点 | k+1 | 跳过的边权 0 |

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 无线网络 | CSP 第 1 次 T4 | 分层 BFS：状态 `(点, 已用中转次数)`，超过 k 次中转的边不能走 |
| 通信线路 | AcWing 340 | 分层图 + 二分答案：二分"免费额度 L"，边权 > L 的记为 1，其余 0，求最短路是否 ≤ k |
| 最优贸易 | AcWing 341 | 三层：未买 / 已买 / 已卖。层间边权为 −价格 / +价格。**有负权 → 用 SPFA** |
| 飞行路线 / 免费 k 条边 | 洛谷 P4822 | 分层图 + Dijkstra，k+1 层 |

## 6.13 图的建模技巧 ★★★★★

**CSP 图论题的真正难点是建模，不是算法。** 常见的转化套路：

### ① 网格 → 图

```
每个格子是一个点，相邻可通行格子之间连边（权 1）
→ BFS 求最短步数
特殊格子（起点多个）→ 多源 BFS
有"传送门"→ 传送门两端连边权 0
```

### ② "限制条件" → 拆点 / 分层

```
"最多用 k 次技能" → k+1 层分层图
"必须先拿钥匙才能开门" → 状态含"钥匙集合" → 状压 + 分层
"每个点只能访问一次" → 拆点，入点和出点之间连容量 1 的边
```

### ③ "区间约束" → 前缀和点

```
约束"区间 [l,r] 内至少选 k 个" →
  设 s[i] = 前 i 个中选了多少个，则 s[r] - s[l-1] >= k
  → 差分约束：s[l-1] → s[r] 权 k，s[i] → s[i-1] 权 0，s[i-1] → s[i] 权 1
```

### ④ "配对 / 匹配" → 二分图

```
"每个人做一个任务，每人每任务只能一次" → 二分图最大匹配
"最少选多少个点覆盖所有边" → 二分图最小点覆盖 = 最大匹配
```

### ⑤ "流量 / 容量" → 网络流

```
"最多能运多少货" → 最大流
"最少切断多少条路使两地不通" → 最小割 = 最大流
"带费用的运输" → 最小费用最大流
```

### ⑥ "时间 / 顺序" → DAG + 拓扑

```
"A 必须在 B 之前完成" → A → B 连边，拓扑排序
"求最早完成时间" → DAG 上最长路（关键路径）
"求最晚开始时间" → 反向 DAG 上最长路
```

### ⑦ "状态是局面" → 状态空间图

```
棋盘状态 → 把每个局面编码成点，操作是边 → BFS/A*
见 04_搜索.md 4.6
```

### 建模自查

写完模型后问自己：
1. 点数是多少？边数是多少？在复杂度限制内吗？
2. 边权是什么？有没有负权？（有负权就不能用 Dijkstra）
3. 求的是最短路、最长路、还是连通性？
4. 答案怎么从图论量还原回原题的答案？
