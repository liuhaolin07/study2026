## 5.1 DP 三要素与解题流程 ★★★★★

### 三要素

1. **状态**：`f[i][j][k]` 表示什么？（**这是最关键也最容易错的一步**）
2. **转移**：从哪些状态来？到哪些状态去？
3. **边界与答案**：初始值是什么？最终答案是哪个（或哪些的 max/min）？

### 解题七步流程

```
① 判断是不是 DP：求最优值/方案数？有重叠子问题？无后效性？
② 定状态：先想"最后一步是什么"，最后一步的选择就是状态的一部分
③ 写转移：枚举最后一步的所有可能
④ 定边界：最小子问题的答案
⑤ 定顺序：保证转移时依赖的状态已经算过
⑥ 定类型：所有值用 ll？要取模吗？求 max 初始化 -INF，求 min 初始化 INF
⑦ 验证：手算样例，一步一步对着转移走
```

### 状态定义的四种常见套路

| 套路 | 形式 | 例子 |
|---|---|---|
| **前缀型** | `f[i]` = 前 i 个的答案 | LIS、最大子段和、背包 |
| **区间型** | `f[i][j]` = 区间 [i,j] 的答案 | 石子合并、区间染色 |
| **位置型** | `f[i][j]` = 走到 (i,j) 的答案 | 网格路径、滑雪 |
| **集合型** | `f[S][i]` = 已选集合 S、当前在 i | 状压 TSP |

### ⚠️ 无后效性检查

**"未来的决策不受过去决策的影响，只受当前状态影响"**。
如果你的转移需要知道"是怎么走到这个状态的"，说明状态定义不完整，**要加维度**。

例子：
- "股票买卖"必须加一维表示"当前是否持股"
- "最多用 k 次机会"必须加一维表示"已用几次"
- "不能选相邻的"必须在状态里体现最后一个是否被选

## 5.2 线性 DP ★★★★★

### 最长上升子序列（LIS）

```cpp
// O(n²) 版
vector<int> f(n, 1);
for (int i = 0; i < n; i++)
    for (int j = 0; j < i; j++)
        if (a[j] < a[i]) f[i] = max(f[i], f[j] + 1);
int lis = *max_element(all(f));

// O(n log n) 版：贪心 + 二分
vector<int> g;                            // g[k] = 长度 k+1 的上升子序列的最小结尾
for (int x : a) {
    auto it = lower_bound(all(g), x);       // ⚠️ 严格上升用 lower_bound
    if (it == g.end()) g.push_back(x);
    else *it = x;
}
int lis = g.size();
```

⚠️ **严格上升 vs 非降**：严格上升用 `lower_bound`，非降（允许相等）用 `upper_bound`。
⚠️ `g` **不是** LIS 本身，只是长度正确。要还原方案需额外记录。

### 最长公共子序列（LCS）

```cpp
vector<vector<int>> f(n + 1, vector<int>(m + 1, 0));
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        f[i][j] = (a[i-1] == b[j-1]) ? f[i-1][j-1] + 1
                                     : max(f[i-1][j], f[i][j-1]);
```

### 编辑距离

```cpp
for (int i = 0; i <= n; i++) f[i][0] = i;        // a 前 i 个变成空串：删 i 次
for (int j = 0; j <= m; j++) f[0][j] = j;        // 空串变成 b 前 j 个：插 j 次
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++) {
        if (a[i-1] == b[j-1]) f[i][j] = f[i-1][j-1];
        else f[i][j] = 1 + min({f[i-1][j],        // 删除
                                f[i][j-1],        // 插入
                                f[i-1][j-1]});    // 替换
    }
```

### 最大子段和

```cpp
ll cur = 0, best = -LINF;
for (int i = 0; i < n; i++) {
    cur = max((ll)a[i], cur + a[i]);        // 要么新开一段，要么接上
    best = max(best, cur);
}
```

### 合唱队形（双向 LIS）

```cpp
// 求 f[i] = 以 i 结尾的 LIS，g[i] = 以 i 开头的 LDS（从右往左做 LIS）
// 答案 = n - max(f[i] + g[i] - 1)
```

## 5.3 背包全家族 ★★★★★

### ① 01 背包

```cpp
// 二维写法（好理解）
for (int i = 1; i <= n; i++)
    for (int j = 0; j <= V; j++) {
        f[i][j] = f[i-1][j];                        // 不选 i
        if (j >= v[i]) f[i][j] = max(f[i][j], f[i-1][j-v[i]] + w[i]);
    }

// 一维滚动（考场用这个）
for (int i = 0; i < n; i++)
    for (int j = V; j >= v[i]; j--)                 // ⚠️ 容量【倒序】
        f[j] = max(f[j], f[j - v[i]] + w[i]);
```

**为什么倒序**：一维数组里 `f[j-v[i]]` 必须是**上一轮**（不含第 i 件物品）的值。倒序遍历时 `j-v[i] < j` 还没被本轮更新，所以是对的。正序会用同一件物品多次。

### ② 完全背包

```cpp
for (int i = 0; i < n; i++)
    for (int j = v[i]; j <= V; j++)                 // ⚠️ 容量【正序】
        f[j] = max(f[j], f[j - v[i]] + w[i]);
```

**为什么正序**：完全背包允许同一物品用多次，`f[j-v[i]]` 就应该是**本轮已更新**的值（可能已经包含了物品 i）。

### ③ 多重背包（每件物品有 s 个）

```cpp
// 朴素版 O(n·V·s)：拆成 s 个 01 背包
for (int i = 0; i < n; i++)
    for (int j = V; j >= 0; j--)
        for (int k = 1; k <= s[i] && k * v[i] <= j; k++)
            f[j] = max(f[j], f[j - k*v[i]] + k*w[i]);

// 二进制拆分 O(n·V·log s)：把 s 拆成 1,2,4,...,2^k, 剩余
for (int i = 0; i < n; i++) {
    int k = 1;
    while (k <= s[i]) {
        for (int j = V; j >= k*v[i]; j--)
            f[j] = max(f[j], f[j - k*v[i]] + k*w[i]);
        s[i] -= k; k *= 2;
    }
    if (s[i] > 0)
        for (int j = V; j >= s[i]*v[i]; j--)
            f[j] = max(f[j], f[j - s[i]*v[i]] + s[i]*w[i]);
}
// ⚠️ 拆分原理：1+2+4+...+2^k + 剩余 能组合出 0~s 的任意整数
```

### ④ 分组背包（每组至多选一件）

```cpp
for (int i = 0; i < ng; i++)                        // 枚举组
    for (int j = V; j >= 0; j--)                    // 枚举容量【倒序】
        for (auto& it : group[i])                   // 枚举组内物品
            if (j >= it.v) f[j] = max(f[j], f[j - it.v] + it.w);
// ⚠️ 组内循环必须在【最里层】，否则同一组会选多件
```

### ⑤ 混合背包（三种混合）

按物品类型分别处理：01 倒序、完全正序、多重先二进制拆分成 01。

### ⑥ 二维费用背包

```cpp
for (int i = 0; i < n; i++)
    for (int j = V1; j >= a[i]; j--)
        for (int k = V2; k >= b[i]; k--)
            f[j][k] = max(f[j][k], f[j-a[i]][k-b[i]] + w[i]);
```

### ⑦ 有依赖的背包（选 i 必须先选它的父节点）

```cpp
// 树形依赖：对每个节点做"分组背包"，组 = 它的子树们
void dfs(int u) {
    f[u][0] = 0;
    for (int v : son[u]) {
        dfs(v);
        for (int j = V; j >= 0; j--)                // 倒序
            for (int k = 0; k <= j; k++)
                f[u][j] = max(f[u][j], f[u][j-k] + f[v][k]);
    }
    for (int j = V; j >= cost[u]; j--) f[u][j] = f[u][j-cost[u]] + val[u];   // 最后加自己
}
```

### ⑧ 求方案数

```cpp
// 把 max 换成 +，初始 f[0] = 1
f[0] = 1;
for (int i = 0; i < n; i++)
    for (int j = V; j >= v[i]; j--)
        f[j] = (f[j] + f[j - v[i]]) % MOD;
// ⚠️ 方案数几乎必然溢出，看题目是否要取模
```

### ⑨ 求具体方案

```cpp
// 先把 f 数组算出来，然后倒着推
for (int i = n - 1; i >= 0; i--)
    if (f[j] == f[j - v[i]] + w[i]) {               // 说明选了 i
        cout << i << ' ';
        j -= v[i];
    }
// 若要求字典序最小，先把物品【倒序】编号再算
```

### 初始化规则（**最容易错的地方**）

| 题目要求 | 初始化 |
|---|---|
| 求最大值，**可以不满** | `f[0..V] = 0` |
| 求最大值，**必须恰好装满** | `f[0] = 0`，其余 `-INF` |
| 求最小值，**必须恰好装满** | `f[0] = 0`，其余 `INF` |
| 求方案数，**必须恰好装满** | `f[0] = 1`，其余 `0` |

⚠️ 初始化错了会算出**根本不可达的状态**，样例可能还是对的，大数据全错。

## 5.4 区间 DP ★★★★

### 通用形式

```cpp
// f[i][j] = 区间 [i,j] 的最优值
for (int len = 2; len <= n; len++) {               // ⚠️ 先枚举【长度】
    for (int i = 1; i + len - 1 <= n; i++) {       // 再枚举【起点】
        int j = i + len - 1;                       // 终点由 len 和 i 决定
        f[i][j] = INF;                             // 求 min 要初始化
        for (int k = i; k < j; k++)                // 枚举【分割点】
            f[i][j] = min(f[i][j], f[i][k] + f[k+1][j] + cost(i, j));
    }
}
```

⚠️ **枚举顺序是区间 DP 唯一的坑**：必须**先长度后起点**。如果先枚举 i 再枚举 j，转移时子区间可能还没算。

### 三种典型模型

```cpp
// ① 合并型（石子合并）：f[i][j] = min(f[i][k] + f[k+1][j] + sum(i,j))
// ② 消除型（消消乐）：f[i][j] = max(f[i][k] + f[k+1][j] + bonus)
// ③ 区间染色型（涂色）：根据两端是否相同分类讨论
//    若 s[i] == s[j]：f[i][j] = f[i][j-1]（或 f[i+1][j]）
//    否则：f[i][j] = min(f[i][k] + f[k+1][j])
```

### 环形区间 DP

把数组**复制一份接在后面**（长度 2n），然后对每个起点 `i` 算 `f[i][i+n-1]`，取最优。

| 合唱队 | 洛谷 P3205 | 区间 DP，按插入规则转移 |

## 5.5 树形 DP ★★★

### 基本形式（在树上做 DP）

```cpp
void dfs(int u, int fa) {
    f[u] = init_value(u);                          // 叶子节点的初值
    for (int v : g[u]) {
        if (v == fa) continue;                     // ⚠️ 不能走回父亲
        dfs(v, u);
        f[u] = combine(f[u], f[v]);                // 合并子树信息
    }
}
```

### 经典模型

#### ① 最大独立集（没有上司的舞会）

```cpp
// f[u][0] = u 不选时子树最大值；f[u][1] = u 选时
f[u][1] = val[u]; f[u][0] = 0;
for (int v : son[u]) {
    f[u][0] += max(f[v][0], f[v][1]);              // u 不选，v 可选可不选
    f[u][1] += f[v][0];                            // u 选了，v 必须不选
}
```

#### ② 树的重心

```cpp
void dfs(int u, int fa) {
    sz[u] = 1; int mx = 0;
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs(v, u); sz[u] += sz[v];
        mx = max(mx, sz[v]);
    }
    mx = max(mx, n - sz[u]);                       // ⚠️ 别忘了父亲那侧的连通块
    if (mx < best) { best = mx; centroid = u; }
}
```

#### ③ 树的直径

```cpp
// 方法一：两次 BFS/DFS（从任意点出发找最远点，再从它出发找最远）
// 方法二：树形 DP
f[u] = 最长链长;
// 在 u 处，取子树中最长和次长的两条链相加，更新全局答案
```

#### ④ 换根 DP（二次扫描）

```cpp
// 第一遍：以 1 为根，算出 f[u]（只考虑 u 的子树）
// 第二遍：从根往下，算 g[u]（考虑整棵树，即把根换到 u）
//   g[v] = 由 g[u] 和 f[u]、f[v] 组合推出
```

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 没有上司的舞会 | AcWing 285 / 洛谷 P1352 | 模型①，**先找根**（入度为 0 的点） |
| 树的重心 | AcWing 846 | 模型② |

## 5.6 状压 DP ★★★★

### 适用信号

**`n ≤ 20`**（或"一行有 m ≤ 20 列"），且状态是"一个集合"。

### 经典模型

#### ① 旅行商（TSP）

```cpp
// f[S][i] = 已访问集合 S，当前在 i 的最短路
memset(f, 0x3f, sizeof f);
f[1][0] = 0;
for (int S = 0; S < (1 << n); S++)
    for (int i = 0; i < n; i++) {
        if (!(S >> i & 1)) continue;               // i 必须在 S 里
        for (int j = 0; j < n; j++) {
            if (S >> j & 1) continue;              // j 必须不在 S 里
            f[S | 1 << j][j] = min(f[S | 1 << j][j], f[S][i] + w[i][j]);
        }
    }
int ans = min over i of f[(1<<n)-1][i];
```

⚠️ `1 << n` 当 n ≥ 31 溢出 → 写 `1LL << n`。

#### ② 逐行状压（网格放置类）

```cpp
// 预处理：所有合法的"单行状态"（不含相邻 1 等约束）
vector<int> valid;
for (int S = 0; S < (1 << m); S++) if (check_row(S)) valid.push_back(S);

// f[i][j] = 第 i 行用第 j 个合法状态的方案数
// 转移：检查与上一行状态是否冲突（如 f[i-1][k] & valid[j] == 0）
```

#### ③ 集合划分类

```cpp
// f[S] = 集合 S 的最小代价划分
for (int S = 0; S < (1 << n); S++)
    for (int sub = S; sub; sub = (sub - 1) & S)    // 枚举 S 的所有子集
        f[S] = min(f[S], f[S ^ sub] + cost(sub));
// ⚠️ 复杂度 O(3^n)，n <= 15 才可行
```

### 常用位运算

```cpp
S >> i & 1              // 第 i 位是否为 1
S | (1 << i)            // 置 1
S & ~(1 << i)           // 置 0
S ^ (1 << i)            // 翻转
S & (S - 1)             // 去掉最低位的 1
__builtin_popcount(S)   // 1 的个数
for (int sub = S; sub; sub = (sub-1) & S)   // 枚举非空子集
```

## 5.7 数位 DP ★★

### 适用信号

求"区间 [1, n] 内满足某数位性质的数的个数"，n 可达 10¹⁸。

### 记忆化搜索写法（最好写）

```cpp
int digit[20], len;
ll f[20][STATE];                     // 状态维按题目定

// pos: 当前处理到第几位（从高到低）
// state: 题目相关的状态
// limit: 前面的位是否都取到了上限（若是，当前位最大只能到 digit[pos]）
// lead: 是否还在前导零阶段
ll dfs(int pos, int state, bool limit, bool lead) {
    if (pos == 0) return is_valid(state);
    if (!limit && !lead && f[pos][state] != -1) return f[pos][state];   // ⚠️ 只有无限制无前导零时才能用记忆化
    int up = limit ? digit[pos] : 9;
    ll res = 0;
    for (int d = 0; d <= up; d++) {
        // 根据 d 更新 state
        res += dfs(pos - 1, new_state, limit && (d == up), lead && (d == 0));
    }
    if (!limit && !lead) f[pos][state] = res;
    return res;
}

ll solve(ll n) {
    len = 0;
    while (n) { digit[++len] = n % 10; n /= 10; }
    memset(f, -1, sizeof f);
    return dfs(len, 0, true, true);
}
// 区间 [L, R] 的答案 = solve(R) - solve(L - 1)
```

⚠️ **三个坑**：
1. `limit == true` 时**不能记忆化**（因为可选数字受上限约束，状态不完整）
2. `lead == true`（前导零）时通常也不能记忆化，或需要把 lead 加进状态
3. 每次 `solve` 前要 `memset(f, -1, ...)`

## 5.8 计数 DP ★★★★

### 核心：加法原理与乘法原理

```cpp
// 加法：完成一件事有 n 类方法，第 i 类有 m_i 种 → 总 sum(m_i)
// 乘法：完成一件事有 n 个步骤，第 i 步有 m_i 种 → 总 prod(m_i)
```

### 取模规则

```cpp
const ll MOD = 1e9 + 7;               // ⚠️ 题目给什么就用什么，常见 1e9+7 / 998244353
(a + b) % MOD
(a * b) % MOD
((a - b) % MOD + MOD) % MOD           // ⚠️ 减法必须 +MOD
// 除法 → 乘逆元：a / b ≡ a * qpow(b, MOD-2) % MOD（MOD 是质数时）
```

### 常见计数模型

| 模型 | 公式 | 应用 |
|---|---|---|
| 排列 | `A(n,k) = n! / (n-k)!` | 有序选择 |
| 组合 | `C(n,k) = n! / (k!(n-k)!)` | 无序选择 |
| 卡特兰数 | `Cat(n) = C(2n,n)/(n+1)` | 合法括号序列、BST 个数、凸多边形剖分、不过对角线的路径 |
| 错位排列 | `D(n) = (n-1)(D(n-1)+D(n-2))` | 每封信都装错 |
| 斯特林数（第二类） | `S(n,k) = k*S(n-1,k) + S(n-1,k-1)` | n 个元素分成 k 个非空集合 |
| 容斥原理 | `|A∪B∪C| = Σ|A| - Σ|A∩B| + |A∩B∩C|` | 至少/恰好类计数 |

## 5.9 概率与期望 DP ★★

### 期望的线性性

`E[X + Y] = E[X] + E[Y]`（**不要求独立**）—— 这是最常用的性质。

### 两种方向

```cpp
// ① 概率 DP（正推）：f[i] = 到达状态 i 的概率
f[start] = 1;
for (转移) f[to] += f[from] * p;

// ② 期望 DP（倒推）：f[i] = 从状态 i 到终点的期望步数
f[end] = 0;
f[i] = 1 + sum(p_ij * f[j]);           // ⚠️ 从后往前推
// 若有自环：f[i] = (1 + sum(p_ij * f[j], j != i)) / (1 - p_ii)
```

## 5.10 博弈 DP ★★

### 胜负态递推

```cpp
// f[状态] = true 表示【当前要行动的人】必胜
// 边界：无法行动的状态为必败（false）
// 转移：f[s] = OR( !f[next(s)] for all next(s) )
//      即：只要存在一步能走到对方的必败态，当前就是必胜态
```

### SG 函数（公平组合游戏）

```cpp
// SG(终态) = 0
// SG(x) = mex{ SG(y) : x 可以一步到 y }    mex = 最小的不在集合里的非负整数
// 多个独立游戏并行：总 SG = 各游戏 SG 的【异或】
// 先手必胜 ⟺ 总 SG != 0
```

### 经典结论（直接背）

| 游戏 | 结论 |
|---|---|
| **Nim**（n 堆石子，每次任取若干） | 先手必胜 ⟺ 各堆数量**异或和 ≠ 0** |
| **台阶 Nim** | 只算**奇数台阶**的异或和 |
| **集合 Nim**（每次只能取集合 S 中的数量） | 记忆化求每堆的 SG，再异或 |
| **威佐夫博弈**（两堆，可取一堆或两堆同数） | 奇异局势 `(a_k, b_k)`，`a_k = k * φ`，`b_k = a_k + k`，φ = 1.618… |
| **巴什博弈**（一堆 n 个，每次取 1~m） | 先手必胜 ⟺ `n % (m+1) != 0` |

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| Nim 游戏 | AcWing 891 | 异或和判胜负 |
| 台阶-Nim 游戏 | AcWing 892 | 只异或奇数台阶 |
| 集合-Nim 游戏 | AcWing 893 | 记忆化求 SG + 异或 |

## 5.11 DP 优化：单调队列 ★★

### 适用形式

```
f[i] = max/min{ f[j] + g(i, j) }  其中 j 在一个【滑动窗口】内（i - k <= j < i）
```

把 `g(i,j)` 拆成 `a(i) + b(j)` 形式后，`b(j)` 部分可以用单调队列维护最值。

### 多重背包的单调队列优化（O(nV)）

```cpp
// 对每个物品 i，按 j mod v[i] 的余数分组，每组内是一个滑动窗口
for (int i = 0; i < n; i++) {
    memcpy(g, f, sizeof f);                       // 备份上一轮
    for (int r = 0; r < v[i]; r++) {              // 枚举余数
        deque<int> dq;                            // 存 j，对应值单调递减
        for (int k = 0; r + k * v[i] <= V; k++) {
            int j = r + k * v[i];
            // 队尾淘汰：价值不如新来的
            while (!dq.empty() && val(dq.back(), i) <= val(j, i)) dq.pop_back();
            dq.push_back(j);
            // 队首过期：超出 s[i] 个物品的限制
            if (dq.front() < j - s[i] * v[i]) dq.pop_front();
            f[j] = val(dq.front(), i);
        }
    }
}
// val(x, i) = g[x] - x / v[i] * w[i]   （把 k 的贡献剥离出来）
```

⚠️ 这个优化**代码量大、容易写错**。CSP 上多重背包用**二进制拆分**（O(nV log s)）几乎总是够用，**优先用二进制拆分**。

### 配套练习

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 多重背包问题 III | AcWing 6 | 单调队列优化，V 和 s 都到 2 万 |
| 跳跃游戏类 | 各平台 | `f[i] = max(f[j]) + a[i]`，`i - k <= j < i` → 单调队列 |
| 理想的正方形 | 洛谷 P2216 | 二维滑动窗口最值（不是 DP，但同技巧） |

## 5.14 状态设计技巧 ★★★★★

DP 做不出来，99% 是**状态定义不对**。四种常用调整手段：

### ① 加维度（消除后效性）

```
问题：股票买卖，最多交易 k 次
❌ f[i] = 前 i 天的最大利润        → 不知道当前是否持股，也不知道用了几次
✅ f[i][j][0/1] = 第 i 天、已交易 j 次、当前是否持股
```

### ② 缩维度（发现冗余）

```
问题：01 背包
f[i][j] → 发现第 i 层只依赖第 i-1 层 → 滚动成一维 f[j]（倒序遍历）
```

### ③ 换主体（换个角度定义状态）

```
问题：求"和为 k 的子数组个数"
❌ f[i][j] = 前 i 个中和为 j 的子数组个数        → j 可能到 1e14，开不下
✅ 用哈希表存前缀和出现次数，O(n) 扫一遍
```

```
问题：把 n 个数分成两组使差最小
❌ 枚举所有分法 2^n
✅ 转化为背包：容量 n*sum/2，求能否凑出
```

### ④ 倒过来定义（从终点往回推）

```
问题：期望步数
❌ f[i] = 从起点到 i 的期望       → 不好推（分母是概率总和）
✅ f[i] = 从 i 到终点的期望       → f[i] = 1 + sum(p * f[j])，倒推清晰
```

### 状态定义的自查方法

写完状态定义后，问自己三个问题：

1. **这个状态能唯一确定后续的答案吗？**（无后效性）
2. **状态总数是多少？在时间和内存限制内吗？**
3. **我能写出转移方程吗？转移时依赖的状态都算过了吗？**

三个问题有一个答不上来，就回去改状态定义。

### 配套练习（专练状态设计）

| 题目 | 来源 | 解法要点 |
|---|---|---|
| 尼克的任务 | 洛谷 P1280 | **倒推**：`f[i]` = 从时刻 i 到 n 的最大空闲时间。有任务时跳到任务结束时刻，无任务时 `f[i] = f[i+1] + 1` |
| 乌龟棋 | 洛谷 P1541 | 状态是"四种卡片各用了几张"而不是"走到第几格"——**格子位置可以由卡片数算出来**，所以不需要那一维 |
| 飞扬的小鸟 | 洛谷 P1941 | 上升是完全背包（正序）、下降是 01 背包（倒序），**同一题里两种背包混用**。还要处理撞管道时的状态不可达 |
| 加分二叉树 | 洛谷 P1040 | 中序遍历的性质 → 区间 DP，根把区间分成左右子树 |
| 方格取数 | 洛谷 P1004 | **两条路径同时走**：用步数 k 作为第一维，避免"走了两遍同一格"的重复计数 |
| 种树 | 洛谷 P1484 | 贪心 + 反悔，或状压 DP |
| 炮兵阵地 | 洛谷 P2704 | 需要**两行**状态（因为影响范围是 2 格） |
