### 怎么按"次"刷

一次认证 = 一套 5 题的完整卷子。**两种用法，别搞混**：

1. **拆开来练**（W1~W8）：只做某次认证的 T1+T2，或只做 T3，配限时。用于专项突破。
2. **整套模考**（W4、W8、W9~W12）：5 题连做，4 小时全真。用于检验节奏。

**同一次认证的卷子不要既拆开练又整套模考**——拆开练过之后整套模考就失真了。所以：

- **W1~W8 拆开练**：用第 1~20 次（老题，题型经典）
- **W9~W12 整套模考**：用第 30 次以后（近年题，命题风格更接近现在）

## 四、T3 大模拟题单 ★★★本计划核心

> **这是 350 分的关键。** T3 满分率从 40% 提到 90%，直接就是 +50 分。
> 每道限时 **90 分钟**，按 [`../02_知识清单/10_其他与应试.md`](../02_知识清单/10_其他与应试.md) §10.1 的**大模拟四步法**走完整流程
> （第 1 月的 [`../01_三个月计划/第1月_地基与大模拟.md`](../01_三个月计划/第1月_地基与大模拟.md) W3 是它的入门版，两处内容一致，以 §10.1 为准）。

| 次 | 题目 | 类型 | 难点 |
|---|---|---|---|
| 第 1 次 | 命令行选项 | **字符串解析 + 规则匹配** | 选项格式合法性、大小写、带参数选项 |
| 第 2 次 | 字符串匹配 | 字符串处理 | 多规则、优先级 |
| 第 3 次 | 集合竞价 | **状态机 + 事件排序** | 同时刻事件的优先级（CSP 经典坑） |
| 第 4 次 | 节日 | 日期计算 | 闰年 + "第几个星期几" |
| 第 5 次 | 模板生成系统 | **字符串替换 + 变量作用域** | 嵌套块、变量遮蔽 |
| 第 6 次 | 画图 | 二维字符画 | 边界、覆盖顺序 |
| 第 7 次 | 路径解析 | **字符串分割 + 状态维护** | `..` `.` 的处理、多斜杠、空段 |
| 第 8 次 | 炉石传说 | **多规则模拟** | 随从死亡结算顺序、攻击力/生命值同步更新 |
| 第 9 次 | 权限查询 | **层级权限 + 缓存** | 权限继承、类别权限、优先级 |
| 第 10 次 | 文本处理 | 编辑器模拟 | 光标位置、插入/删除/撤销 |
| 2021-09 | 网络连接 | **字符串合法性 + 状态机** | IP/端口格式校验的多重规则 |

### W3 ~ W4 建议顺序

按"规则数量从少到多"排：

```
W3: 画图(6) → 节日(4) → 字符串匹配(2)
W4: 路径解析(7) → 集合竞价(3) → 命令行选项(1)
W5+: 模板生成系统(5) → 文本处理(10) → 权限查询(9) → 炉石传说(8) → 网络连接(2021-09)
```

### 每道 T3 做完必答

1. 我漏了哪条规则？为什么会漏？（读题不仔细 / 没意识到 / 题面藏得深）
2. 我在哪个边界上丢了分？
3. 我用了多少分钟？其中读题/建模/编码/调试各占多少？
4. 如果重写一遍，`struct` 会怎么设计得更清楚？
5. **这道题里"同时发生的事件"是怎么排序的？我一开始理解对了吗？**

> 第 5 个问题是 CSP T3 的最大坑。第 3 次「集合竞价」、第 8 次「炉石传说」都在这个点上大量失分。

## 五、T4 题单（练"先暴力后正解"，每道 ≤ 50 min）

| 次 | 题目 | 常见解法 |
|---|---|---|
| 第 1 次 | 无线网络 | BFS / 分层图最短路 |
| 第 2 次 | 最优配餐 | 多源 BFS |
| 第 3 次 | 最优灌溉 | 最小生成树（Kruskal） |
| 第 4 次 | 网络延迟 | 最短路（Floyd / Dijkstra） |
| 第 5 次 | 高速公路 | 并查集 / 连通分量 |
| 第 6 次 | 送货 | 欧拉路径 + 连通性判定 |
| 第 7 次 | 游戏 | 约瑟夫环 / 模拟 |
| 第 8 次 | 交通规则 | 最短路 + 状态扩展 |
| 第 9 次 | 压缩编码 | 区间 DP |
| 第 10 次 | 地铁修建 | 二分答案 + 并查集 |

**练法（这是本阶段最重要的训练）**：

配套知识点：[`../02_知识清单/06_图论.md`](../02_知识清单/06_图论.md) §6.13「图的七种建模技巧」——**CSP 图论题的真正难点是建模，不是算法**。

```
每道 T4 严格执行：
  Step 1  读题，10 min 内写出暴力 → 提交 → 记录拿了多少分
  Step 2  想正解，20 min 内想出思路（想不出直接看题解）
  Step 3  写正解 → 提交 → 记录分数变化
  Step 4  复盘：暴力拿了几分？正解几分？如果考场上正解写不出来，
          我能不能靠暴力稳住 30~40 分？
```

## 六、T5 题单（只练"薅部分分"，每道 ≤ 30 min）

> **T5 不追求做出来。** 目标只有一个：**30 分钟内写出能拿 20 分的暴力并提交**。
> 如果你 T5 能满分，说明你已经不需要这份计划了。

| 次 | 题目 | 部分分思路 |
|---|---|---|
| 第 1 次 | 任务调度 | 小数据用 DFS 枚举；大数据拓扑排序 |
| 第 2 次 | 拼图 | n 小时全排列 / 状压暴力 |
| 第 3 次 | 货物调度 | 状压 DP（n ≤ 20 的数据） |
| 第 4 次 | 最小花费 | 小数据 Floyd / 暴力枚举路径 |
| 第 5 次 | 最佳文章 | 小数据 O(n²) DP |
| 第 6 次 | 矩阵 | 找规律 + 特判小数据 |
| 第 7 次 | 网络连接 | 先写"判断合法性"部分（往往独立给分） |
| 第 8 次 | 祭坛 | 二分答案 + BFS（小数据直接枚举） |
| 第 9 次 | 卡牌游戏 | 小数据博弈 DFS |
| 第 10 次 | 引水入城 | 记忆化搜索（小数据直接 DFS） |

**练法**：`10 分钟暴力挑战`，详见 [`../02_知识清单/10_其他与应试.md`](../02_知识清单/10_其他与应试.md) §10.3 和 [`../01_三个月计划/第2月_专题突破.md`](../01_三个月计划/第2月_专题突破.md) W8。
**10 分钟内没交出去就算失败**，直接看题解学"这题的暴力应该怎么写"。

> 补充：`../02_知识清单/07_数学.md` §7.15 的**模拟退火**是 T5 的另一件骗分利器。
> 对优化类 T5（旅行商、布局、调度），模拟退火 + 多次提交（**CSP 取最高分**）往往能拿 50~80 分。
> W11 专门安排一天练它。
