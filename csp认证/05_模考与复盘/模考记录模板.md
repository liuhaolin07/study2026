## 丢分归因 ★决定下周练什么

把丢的分按原因分类统计：

| 原因 | 丢了多少分 | 占比 |
|---|---|---|
| **不会**（知识点缺失） | | |
| **会但没写对**（实现错误） | | |
| **会但没时间**（速度问题） | | |
| **没交暴力**（战术问题） | | |
| **低级错误**（溢出/边界/格式） | | |
| 合计 | | 100% |

### 关键判断

> **「不会」占比高** → 补知识点，去 [`../02_知识清单/CSP考频知识点清单.md`](../02_知识清单/CSP考频知识点清单.md) 找对应专题
>
> **「会但没写对 / 低级错误」占比高** → **不要加练算法**，练"写完必自查"，每次提交前走一遍考场手册第 2 页的检查表
>
> **「会但没时间」占比高** → 练限时，T1/T2/T3 严格卡表
>
> **「没交暴力」占比高** → 战术没内化，做 W8 的"10 分钟暴力挑战"

**大多数人的问题不是"不会"，而是后三类。** 这也是为什么本计划把大模拟和部分分放在比算法更靠前的位置。
