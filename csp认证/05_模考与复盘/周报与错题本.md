# 周报与错题本

> 每周日花 1 小时填周报，错题本随手记。
> 规矩继承 `Algorithms/笔记/redo-list.md`：**看题解才做出的题记入错题本，一周后重做，AC 才划掉。**
> 连挂两次的题 → 回对应专题加练 3 题。

# 第二部分：错题本

## 记录格式

每条错题按下面格式记，**记完立刻标"重做日期"（+7 天）**：

```
### [编号] 题目名 / 题号

- 记录日期：2026-__-__
- 重做日期：2026-__-__（+7 天）
- 来源：CSP 第 __ 次 T__ / 洛谷 P____ / AcWing ____ / CF ____
- 当时得分：___ / 100

**卡在哪：**
（不是"不会做"，要具体：读不懂题意 / 想到了暴力但写错 / 完全没思路 / 想到了正解但实现不出来）

**正确思路：**
（看完题解后，用自己的话写。不要抄题解原文——抄了等于没记）

**为什么我没想到：**
（这是最关键的一栏。答案通常是：数据范围没看清 / 没见过这个套路 / 联想链断了）

**关联知识点：**
（去 ../02_知识清单/CSP考频知识点清单.md 找对应条目，不熟的标记出来）

**重做记录：**
- 第 1 次重做（2026-__-__）：AC / 未 AC，用时 ___ min
- 第 2 次重做（2026-__-__）：AC / 未 AC，用时 ___ min

**状态：** 待重做 / 重做通过（可划掉） / 连挂两次（需加练 3 题）
```

## 与 `Algorithms/笔记/redo-list.md` 的分工

| | 记什么 | 什么时候用 |
|---|---|---|
| `Algorithms/笔记/redo-list.md` | ACM 主线刷题（题单 00~11）里看题解才做出的题 | 周日复盘时统一重做 |
| 本文件错题本 | CSP 专项（真题 T1~T5、大模拟、部分分）的错题 | 周日复盘 + 月末统计 |

两边分开记，避免混在一起看不出"CSP 特有的问题"是什么。周日复盘时**两个本子都要过一遍**。
