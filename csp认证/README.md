# csp认证 — 三个月冲击 CCF CSP 350+

> **目标**：在第 44 次 CCF CSP 认证（预计 2026 年 12 月中旬）拿到 **350+ / 500**。
> **周期**：2026-09-21 ~ 2026-12-20，13 周，每天 2~3 小时。
> **语言**：C++（考场 Ubuntu 24.04 + g++ 13.2.0，`-std=c++17`）。
> **起点**：已掌握 C++ 与 STL，做过贪心/二分/简单 DP；同步在跑 `../Algorithms/` 的 ICPC 12 个月计划。

---

## 一句话看懂这个计划

> **300 分靠稳，50 分靠暴力。**
>
> CSP 五题各 100 分。350 分不需要会做难题，需要的是：
> **T1+T2 满分（200）+ T3 大模拟满分或接近（80~100）+ T4/T5 暴力薅部分分（50~70）。**
>
> 所以本计划把最多的训练量给了两件 ACM 训练里不练的事：**大模拟工程能力** 和 **部分分战术**。
> 同时 `02_知识清单/` 提供了**覆盖官方大纲全部考点**的知识体系，确保遇到冷门考点也不会完全空白。

## 三条最容易被忽略的规则

### 1. 提交取最高分、无罚分 → 一有能跑的代码就交

很多人带着 OI/老 CSP 赛制的惯性思维（"以最后一次提交为准"），死活不敢早交。
**现行官方规则是取最高一次、无罚分、每题 32 次。** 所以：

- 写完 30 分的暴力，**立刻交**，锁定分数
- 想到正解再交一版，**分不会掉**
- 实时能看到自己的得分 → **提交本身就是最好的调试手段**

这一条战术执行到位，直接就是 30~60 分的差距。

### 2. 可以带纸质资料 → 考场手册是真资产

官方明确允许携带书籍、打印材料、手写材料（只禁通讯工具和存储设备）。
所以 [`04_模板/考场手册.md`](04_模板/考场手册.md) 不是摆设——**把它做成你考场上真的会翻的那 10 页纸**，每月更新，W10 定稿打印。

### 3. 严禁使用 AI 工具，赛后做合规性分析

考试期间用 AI 生成任何部分代码 → 判定 **0 分 + 公示一周 + 黑名单 1 年**。

对本计划的约束：**平时可以用 AI 帮你理解概念、解释题解，但代码必须自己从零敲一遍。**
"看完题解关掉重写"既是 `../Algorithms/README.md` 的铁律，也是考场合规的底线。

## 知识体系的三级优先级

`02_知识清单/` 覆盖**官方大纲全部考点**（含大纲明列的随机算法、近似算法、计算几何），但按 CSP 考频分成三级，避免三个月时间被平均摊薄：

| 级别 | 含义 | 数量 | 要求 |
|---|---|---|---|
| **★★★ 必会** | 丢分就是失误 | 约 40 项 | 闭卷独立写对 |
| **★★ 应会** | 能套模板能改 | 约 50 项 | 看懂 + 改对 |
| **★ 了解** | 知道是什么、为什么 CSP 不练 | 约 15 项 | 能说出来即可 |
| **✗ 跳过** | CSP 从未考过（SAM / 半平面交 / FFT / 主席树 / 树剖 等 11 项） | — | 文件里保留说明和跳过理由，考后接回 ICPC 主线再学 |

完整清单见 [`02_知识清单/README.md`](02_知识清单/README.md) 第二节。

**每个考点的统一格式**：核心解法 → 模板代码 → ⚠️ 易错点 → 选型决策表 → **配套练习（题目 + 来源 + 解法要点）**。

## 与 `../Algorithms/` 的关系（重要）

你已经有一套完整的 12 个月 ICPC 训练计划。这个目录**不是替代它，是三个月的专项叠加**。

| | `../Algorithms/` | 本目录 |
|---|---|---|
| 目标 | 2027 ICPC 区域赛银牌 | 2026-12 CSP 350+ |
| 周期 | 12 个月 | 13 周 |
| 侧重 | 想出正解、算法深度 | **实现正确 + 部分分最大化** |
| 赛制 | ACM（罚时，WA 有代价） | 取最高分、无罚分 |
| 知识覆盖 | 竞赛全体系，无优先级裁剪 | **大纲全考点，但按 CSP 考频分三级** |

### 分工原则（避免两处维护同一份东西）

- **通用模板代码库** → `../Algorithms/模板/`（含 `XCPC_Templates/` 31 个头文件 + 72 项自动化测试）
- **通用算法题单** → `../Algorithms/题单/`（12 个专题，约 720 题）
- **深入推导与证明** → `../Algorithms/笔记/速查/`（7 张表）、[OI Wiki](https://oi-wiki.org)、[cp-algorithms](https://cp-algorithms.com)
- **CSP 特有的东西** → 本目录：赛制策略、大模拟方法论、部分分战术、真题题单、考场手册、模考记录，以及**按 CSP 考频重排的全考点知识体系**

### 每天 2~3 小时怎么分

| 时段 | 内容 |
|---|---|
| 1.5 h | **CSP 专项**：大模拟 / 部分分 / 真题（本目录题单 + 知识体系配套练习） |
| 1 h | **ACM 主线**：继续推 `../Algorithms/题单/` 的当前专题 |
| 周六 | CF Div2（W1~W8 优先）**或** CSP 全真模考（W9~W12 优先） |
| 周日 1 h | 复盘：upsolve + 重做错题（**两个错题本都过一遍**）+ 填周报 |

**好处**：CSP 训练强化的正是"实现能力"，而这是 ICPC 三人一机里最容易掉链子的一环。两条线互相加成，不是互相挤占。

**12 月考完之后**：直接接回 `../Algorithms/学习路径.md` 的第 4~6 月计划（搜索 + DP + 最短路），并把这里 ✗ 级跳过的内容（SAM、半平面交、FFT、主席树、树剖等）排进第 7~10 月。进度不会断。
