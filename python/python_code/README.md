## 环境准备

```bash
pip install numpy pandas matplotlib scipy scikit-learn openpyxl
```

Day 1–5 只需标准库；Day 6 起按上表安装。所有绘图脚本已配置 Windows 中文字体。

## 使用方式

1. 进入当天文件夹，先读 `*.md` 笔记；
2. 运行 `python test.py`（或各项目同名主脚本），对照输出理解代码；
3. 完成笔记末尾的「今日任务验收」和练习；
4. 项目文件夹会生成图片/csv，可对照检查自己的运行结果。

## 自学方法（怎么读这个仓库）

1. **先读笔记**：把当天 `*.md` 通读一遍，建立概念；
2. **再逐段看代码**：`test.py` 的分节编号与笔记章节一一对应，行内注释按「做什么 / 为什么 / 易错点」三层展开，看到 ⚠️ 务必停下来读懂；
3. **运行对照**：先猜输出再运行，猜错的地方就是理解缺口；含 `input()` 的脚本（Day1-3）需要键盘交互；
4. **动手练习**：每个脚本末尾有「今日练习」，先自己写，再看文件里的参考实现；
5. **对照产出**：项目文件夹已保存的图片/CSV 是标准结果，可核对自己的运行输出；
6. **草稿对照**：Day1-4 另有 `prac.py`「草稿本」，保留了学习时试错的真实思路，适合和规范写法对比着看。

## 注释规范（后续新增天数时延续）

- 文件头：`# -*- coding: utf-8 -*-` + docstring（Day N：主题 / 前置依赖 / 运行方式 / 产出）；
- 分节用 `# ========== N. 小节名 ==========`，与当日笔记章节对应；
- 行内注释说清做什么、为什么、易错点，重要陷阱用 ⚠️ 标记；
- 每个脚本末尾设「今日练习」：题目 + 提示 + 参考实现。
