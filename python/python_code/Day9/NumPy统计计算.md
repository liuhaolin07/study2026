## 一、常用统计函数一览

| 函数 | 含义 | 备注 |
|------|------|------|
| `a.mean()` | 均值 | 对异常值敏感 |
| `np.median(a)` | 中位数 | 抗异常值，房价数据常用它 |
| `a.std()` | 标准差 | 波动大小；`var()` 是它的平方 |
| `a.min()` / `a.max()` | 最值 | 配 `argmin()/argmax()` 取位置 |
| `np.ptp(a)` | 极差 max−min | peak to peak（NumPy 2.0 起用函数形式） |
| `np.percentile(a, q)` | 分位数 | `q` 可传列表 `[25,50,75]` |

## 二、二维数组必懂：axis

```python
table.sum(axis=1)    # 每行求和 → 得到每名学生的总分
table.mean(axis=0)   # 每列求均值 → 得到每门课的平均分
```

口诀：**axis=0 跨行压扁成一行（按列统计），axis=1 跨列压扁成一列（按行统计）**。
不写 axis 就对全部元素统计。

## 三、标准化 z-score

```python
z = (x - x.mean()) / x.std()
```

变换后均值为 0、标准差为 1。不同量纲的指标（收入元 / 年龄岁）比较或回归前，先标准化。

## 四、相关系数 corrcoef

```python
r = np.corrcoef(x, y)[0, 1]     # 返回 2x2 矩阵，取 [0,1]
```

- r ∈ [−1, 1]：绝对值越大线性关系越强；
- r≈1 正相关，r≈−1 负相关，r≈0 无线性相关；
- **相关 ≠ 因果**，论文里下结论要谨慎。

Day 26 的线性回归就是在这个基础上进一步“拟合直线”。
