## 一、分析流程（数模数据处理的标准模板）

```
① 明确问题 → ② 获取/造数据 → ③ 清洗 → ④ 描述统计 → ⑤ 分组对比 → ⑥ 可视化 → ⑦ 结论建议
```

## 二、本项目的业务问题

| 问题 | 用到的方法 | 对应图表 |
|------|-----------|----------|
| 学生一天的消费节奏？ | 小时直方图（三峰结构） | spend_hourly |
| 各时段消费水平差异？ | groupby + 命名 agg | spend_by_meal |
| 每日流水是否平稳？ | 按日期 sum + 折线 | spend_daily |
| 低消费群体识别？ | 人均分布 + 10% 分位线 | spend_distribution |

第4问是真实应用：不少高校用食堂消费数据辅助贫困生认定（低消费且频次正常 → 隐性补助名单）。

## 三、清洗环节回顾

```python
d = d.dropna(subset=["时段类型"])   # 关键字段缺失 → 删
d = d[d["金额"] > 0]                # 业务非法值（负金额）→ 删
d = d.drop_duplicates()             # 系统重传的重复 → 去重
```

每一步都**有理由**并在报告里说明剔除条数——论文中"数据预处理"章节就写这些。

## 四、值得记住的分析技巧

1. `np.select(条件列表, 取值列表)` 按 meal 类型批量生成不同的金额分布——造模拟数据的利器；
2. `groupby().agg(新名=("列", 函数))` 命名聚合，报表一步到位；
3. `quantile(0.1)` 分位数画参考线，比拍脑袋定阈值科学；
4. 直方图看"三峰"（三餐时间）——多峰分布提示背后存在多个群体。
