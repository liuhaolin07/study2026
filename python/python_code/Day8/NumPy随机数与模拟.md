## 二、常用随机函数

| 函数 | 分布/行为 | 典型用途 |
|------|-----------|----------|
| `np.random.rand(n)` | [0,1) 均匀 | 抛硬币、几何概型 |
| `np.random.randn(n)` | 标准正态 N(0,1) | 加噪声、误差模拟 |
| `np.random.normal(μ, σ, n)` | 一般正态 | 身高、测量误差 |
| `np.random.randint(low, high, size)` | [low, high) 均匀整数 | 掷骰子 |
| `np.random.choice(arr, size, replace)` | 有/无放回抽取 | 抽样调查 |
| `np.random.shuffle(arr)` | 原地打乱 | 随机分组 |

## 三、模拟的通用套路

```python
n = 100000                       # ① 定试验次数（要大！）
trials = np.random.rand(n) < p   # ② 一次向量化生成全部试验结果
freq = trials.mean()             # ③ mean() 统计频率/概率
```

核心技巧：**布尔数组求平均 = 事件发生的频率**（True 按 1、False 按 0）。

大数定律：试验次数越多，频率越接近理论概率。test.py 的抛硬币实验能直观看到这一点。

---

## 四、蒙特卡洛方法（Monte Carlo）

**思想：用大量随机样本的频率估计一个未知量。**

经典应用——估算 π（Day 10–12 项目正式实现）：

1. 单位正方形内均匀撒 N 个点；
2. 数出落在四分之一圆内（x²+y²≤1）的点数 k；
3. 因为面积比 = 点数比：π/4 ≈ k/N，所以 **π ≈ 4k/N**。

误差大约按 $O(1/\sqrt{N})$ 收敛——想要多一位精度，试验量要扩大约 100 倍。
