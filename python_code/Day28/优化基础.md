# Day 28 学习笔记：优化基础 scipy.optimize

> 配套练习：`optimization.py`

## 一、minimize：求函数最小值

```python
from scipy.optimize import minimize
res = minimize(f, x0=[0], method="BFGS")
res.x      # 最优点（数组）
res.fun    # 最小值
```

要点：

1. `x0` 初值很重要——**非凸函数可能收敛到局部最小值**，多换几个初值跑；
2. 目标函数写成接收数组的形式 `f(x): return (x[0]-3)**2 ...`；
3. 最大值问题 = 最小化其相反数。

## 二、linprog：线性规划

标准形式（注意 linprog 只做 **min**）：

```
min  c·x     s.t.  A_ub·x ≤ b_ub,  A_eq·x = b_eq,  lb ≤ x ≤ ub
```

```python
res = linprog(c, A_ub=..., b_ub=..., bounds=[...], method="highs")
```

建模套路（生产计划类）：

1. 定义决策变量（产量、投资额…）；
2. 写目标函数 → 系数向量 c；
3. 每条约束一行进 A_ub/b_ub；max 就把 c 取负；
4. 读 `res.x`（最优方案）与 `-res.fun`（最优值）。

## 三、curve_fit：参数拟合

已知函数形状、未知参数时反推参数：

```python
params, cov = curve_fit(model, xs, ys, p0=[初值1, 初值2])
perr = np.sqrt(np.diag(cov))   # 参数不确定度
```

Day 25 的 Logistic 人口模型就是用它求解的。`p0` 给得离谱会不收敛——先画散点图目测数量级再设初值。

## 四、三类问题的对应关系

| 场景 | 工具 |
|------|------|
| 光滑目标函数求极值 | minimize |
| 线性目标 + 线性约束 | linprog |
| 已知模型形式估参数 | curve_fit |

## 五、常见坑

- 忘了 max→min 转换，得到负的"最大利润"；
- 约束方向写反（A_ub 全部是 ≤）；
- 非凸多峰函数只试一个初值就下结论；
- curve_fit 不给 p0 或 p0 太差导致 OptimizeWarning/发散。
