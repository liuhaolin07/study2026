## 一、模型形式

$$\hat{y} = b_0 + b_1 x_1 + b_2 x_2 + \dots + b_n x_n$$

一元 = 一条直线；多元 = 一个超平面。sklearn 用最小二乘自动解出全部参数。

## 二、sklearn 标准四步（所有模型通用！）

```python
from sklearn.linear_model import LinearRegression
model = LinearRegression()          # ① 建模
model.fit(X_train, y_train)         # ② 训练
y_pred = model.predict(X_test)      # ③ 预测
r2_score(y_test, y_pred)            # ④ 评估
```

记住这个模式，Day 27 换成 KNN/决策树只是第一行类名不同。

## 三、两个必须注意的细节

1. **X 必须二维**：`(样本数, 特征数)`。一列也要 `reshape(-1, 1)`；
2. **训练/测试集要分开**：`train_test_split(X, y, test_size=0.25, random_state=42)`。在训练集上评估会"自己考自己"，虚高。

## 四、评价指标

| 指标 | 含义 | 好坏 |
|------|------|------|
| RMSE | 预测平均偏差（与 y 同单位） | 越小越好 |
| R² | 模型解释了数据变异的比例 | 越接近 1 越好 |

R² 的直觉：R²=0.8 → "80%的分数波动能被学习时长解释"。

## 五、读出模型参数

```python
model.intercept_    # b0 截距
model.coef_         # [b1, b2, ...] 斜率
```

论文里的写法示例：*"回归结果表明，学习时长每增加 1 小时，成绩平均提高约 X 分（p<0.05）"*——系数就是结论。

## 六、线性回归的使用前提（模型检验）

- 线性：散点图先看关系是否大致线性；
- 独立、同方差、残差近似正态——深入可查残差图；
- 多重共线性：自变量之间高度相关时系数不可靠（相关矩阵检查，Day 9 技能）。
