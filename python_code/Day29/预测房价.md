## 二、本项目的三个新知识点

### 1. 类别特征编码 get_dummies
"低层/中层/高层"是文字，模型只认数字：

```python
X = pd.get_dummies(df, columns=["楼层"])
```
每种类别变成一列 0/1（独热编码）。**类别列必须处理，否则 fit 直接报错。**

### 2. 第二个模型：随机森林
很多棵决策树各预测一次再平均——比单棵树稳得多，且自带 `feature_importances_`（哪些变量重要一目了然），数模论文解释性神器。

```python
from sklearn.ensemble import RandomForestRegressor
rf = RandomForestRegressor(n_estimators=200, random_state=42)
```

### 3. 模型对比的规范动作
同一套训练/测试集跑多个模型，用**同一个指标**比较后择优——论文里做成对比表格。

## 三、如何读结果图

- **预测 vs 真实图**：点越贴红色对角线越准；系统性偏离说明模型有偏；
- **特征重要性**：面积通常第一——与常识一致是模型可信度的旁证；
- RMSE 的业务翻译："平均猜偏 X 万元"。

## 四、往真实数据迁移的检查清单

1. 缺失值/异常值清洗（Day 20 流水线）；
2. 偏态严重的价格做 log 变换；
3. 多重共线性检查（面积×房间数高度相关）；
4. 交叉验证代替单次切分（`cross_val_score`）；
5. 残差图检验同方差假设。
