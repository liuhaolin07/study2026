## 二、KNN：近朱者赤

**思想**：新样本离谁最近就像谁——找最近的 k 个邻居投票。

```python
from sklearn.neighbors import KNeighborsClassifier
knn = KNeighborsClassifier(n_neighbors=5)
```

关键点：

| k 取值 | 行为 | 风险 |
|--------|------|------|
| 太小(=1) | 只听最近1票，边界曲折 | 过拟合、对噪声敏感 |
| 太大(≈n) | 几乎全按多数类 | 欠拟合 |

k 用验证/交叉验证来选（常见 3~15）。

## 三、标准化：KNN 的命门

KNN 按**距离**工作 → 特征量纲必须一致。收入（元）和年龄（岁）混在一起时大数值特征会淹没小数值特征。

```python
scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)   # fit 只在训练集
X_test_s  = scaler.transform(X_test)        # 测试集沿用训练集参数
```

⚠️ 不能对全体数据先 fit 再切分——那等于让测试集信息泄漏进训练。

## 四、决策树：一串 if-else

**思想**：自动学出一棵提问树（"花瓣长 > 2.45cm 吗？"），像玩二十个问题。

```python
from sklearn.tree import DecisionTreeClassifier, plot_tree, export_text
tree = DecisionTreeClassifier(max_depth=3)
```

优点：规则完全可读（`export_text` 直接打印）、无需标准化。
缺点：容易过拟合 → 限制 `max_depth` / `min_samples_leaf`。

## 五、分类评估三件套

```python
accuracy_score(y_test, y_pred)     # 总准确率
confusion_matrix(y_test, y_pred)   # 混淆矩阵：哪两类容易搞混
classification_report(y_test, y_pred)   # precision/recall/f1 明细
```

类别不平衡时（99% 正例），准确率会骗人 → 看 recall/F1。数模论文里混淆矩阵几乎是标配图表。

## 六、模型对比结论（本项目实测）

| | KNN | 决策树 |
|---|-----|--------|
| 需要标准化 | 必须 | 不需要 |
| 可解释性 | 弱（黑盒投票） | 强（规则可见） |
| 训练/预测 | 训练快预测慢 | 都快 |
| 主要超参 | k | max_depth |
