## 一、两种乘法，千万别混！

| 写法 | 含义 | 数学名称 |
|------|------|----------|
| `A * B` | **对应元素相乘** | Hadamard 积 |
| `A @ B` 或 `np.dot(A, B)` | **矩阵乘法** | 矩阵乘 |

记忆：想算线性代数里的 AB，就用 `@`。

## 二、向量点积

```python
u = np.array([1, 2, 3]); w = np.array([4, 5, 6])
u @ w      # = 1*4 + 2*5 + 3*6 = 32
```

几何意义：内积为 0 ⟺ 两向量垂直（判断正交常用）。

## 三、转置

```python
A.T          # 行变列
(A @ B).T == B.T @ A.T   # 线代性质，可用代码验证
```

## 四、方阵三件套（np.linalg 子模块）

```python
np.linalg.det(A)     # 行列式 |A|
np.linalg.inv(A)     # 逆矩阵 A⁻¹
np.linalg.norm(v)    # 向量长度（模）
```

- 行列式 = 0 的矩阵（奇异矩阵）没有逆，`inv` 会抛 `LinAlgError`；
- 浮点计算有微小误差，验证 `A @ inv(A) ≈ I` 时用 `np.allclose()` 而不是 `==`。

## 五、解线性方程组 Ax = b —— 数模最常用

$$\begin{cases} 2x + y = 5 \\ x + 3y = 10 \end{cases} \Rightarrow M=\begin{pmatrix}2&1\\1&3\end{pmatrix},\ b=(5,10)$$

```python
x = np.linalg.solve(M, b)   # 不要用 inv(M) @ b！solve 更快更稳
```

> 数模中的平衡问题、投入产出模型、电路方程……最后都归到这里。

## 六、常见坑

1. `*` 当成矩阵乘用了 → 结果形状对但数值错，检查是否该用 `@`；
2. 内积维度不匹配报 `shapes not aligned` → 打印两个 `.shape` 先看清楚；
3. 直接比较浮点矩阵 `==` 几乎总返回 False → 用 `np.allclose(a, b)`。
