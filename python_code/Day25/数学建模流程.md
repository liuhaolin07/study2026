## 一、五步流程（背下来）

| 步骤 | 做什么 | 产出 |
|------|--------|------|
| ① 问题分析 | 要回答什么？关键变量是什么？有哪些假设？ | 问题重述+假设清单 |
| ② 建立模型 | 把现实翻译成数学：公式/方程/规则 | 模型表达式 |
| ③ 数据处理 | 收集、清洗、标准化（Day 19–22 的全部技能） | 干净数据集 |
| ④ 求解 | 解析解 or 数值计算（numpy/sklearn/scipy） | 参数、结果 |
| ⑤ 可视化检验 | 画图对比；误差多大？假设成立吗？ | 图表+结论 |

**循环而非直线**：⑤ 发现偏差 → 回到② 改进模型。

## 二、test.py 示例的两个模型

| | Malthus 指数 | Logistic 阻滞 |
|---|--------------|---------------|
| 假设 | 增速 ∝ 当前数量 | 资源有限，有容量 K |
| 公式 | dN/dt = rN | dN/dt = rN(1−N/K) |
| 适用 | 初期短期 | 中长期 |

核心思想示范：**模型 = 假设的数学化**；假设不同，结果天差地别；检验环节告诉你哪个假设更接近现实。
