## 二、数据是"造"出来的——模拟建模思想

季节温度用正弦波近似：

```
temp = 年均值 + 振幅 × sin((t - 相位) / 365 × 2π) + 噪声
```

降雨用"概率随季节变化的伯努利试验 × 指数分布雨量"。**用简单随机过程模拟现实**，正是数学建模的基本功（蒙特卡洛思想的延续）。固定 `RandomState(2024)` 保证可复现。

注意 `to_csv(..., encoding="utf-8-sig")`：加 BOM 后 Excel 打开中文不乱码。

## 三、代码里值得学的四个技巧

1. **groupby 月度聚合**
   ```python
   df["月份"] = df["日期"].dt.month
   monthly = df.groupby("月份")[["最高温","最低温","降雨量"]].mean()
   ```
   （pandas 正式内容 Day 18 起，这里先用后学）
2. **fill_between 温度区间着色**：高低温之间的面积填充，视觉层次立刻出来；
3. **双 y 轴 twinx**：雨量和雨日数量纲不同，同图展示的标准解法；
4. **fig.autofmt_xdate()**：日期轴标签自动倾斜防重叠。

## 五、思考题提示

- 最热一天：`df.loc[df["最高温"].idxmax()]`
- 最长连续降雨：`(df["降雨量"] > 0).astype(int)` 之后按断点分组求最大组长度（经典 cumsum 技巧，可搜索 "pandas consecutive groupby"）
- 改南方城市：调大年均值与振幅、提高 rain_prob、增大指数分布尺度参数即可
