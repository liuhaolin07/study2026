## 一、原理（三句话）

1. 边长为 1 的正方形面积 = 1；内嵌四分之一圆的面积 = π/4；
2. 往正方形里**均匀**撒 N 个点，落在圆内的点数 k 满足 k/N ≈ 面积比 = π/4；
3. 所以 **π ≈ 4k/N**。

判断点是否在圆内：x² + y² ≤ 1。

## 三、必须理解的三个点

### 1. 为什么向量化快？
循环版在 Python 层执行 N 次解释器指令；向量化把整个循环下沉到 C 层一次完成。百万点的量级下差距是**几十倍**——写数模代码要养成"能不写 for 就不写 for"的习惯。

### 2. 误差如何收敛？
绝对误差 ≈ C/√N：

- N 扩大 **100 倍** → 精度只提高 **1 位数字**；
- 收敛曲线在对数坐标下是一条斜率 −1/2 的直线（图2 中与参考线平行）。

这解释了蒙特卡洛方法"精度换算力"的本质，也说明它适合高维问题（维度不增加收敛难度）。

### 3. seed 与可复现
`np.random.RandomState(seed)` 把随机数发生器绑定到固定种子，保证论文数据可复现。不同 seed 结果会略有波动——这正是随机方法的特性。

## 四、常见问题

- **为什么撒点必须"均匀"？** 用 `rand()`（均匀分布）而不是 `normal()`（正态），否则点集中在中间，比例失真。
- **估计值每次不一样？** 是正常的；想稳定就固定 seed 或加大 N。
- **想更快？** 多跑几组独立实验取平均，或多进程并行——蒙特卡洛天然可并行。
