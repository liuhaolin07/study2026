# P1226 【模板】快速幂

- 专题:`07-math` § 快速幂(倍增思想)
- 难度:普及-

## 题意

求 a^b mod p(0 < a, b, p < 2^31),按 `a^b mod p=c` 的格式输出。

## 思路怎么来的

b 最大 2^31,逐个乘要 20 亿次。把指数按**二进制**拆:

> b = 2^{k1} + 2^{k2} + … ⇒ a^b = a^{2^{k1}} × a^{2^{k2}} × …

而 a^{2^k} 可以由 a^{2^{k-1}} **自乘一次**得到。于是从 a 开始不断平方(预处理出 a^1, a^2, a^4, a^8, …),遇到 b 的二进制位是 1 就把当前平方值乘进答案。整个过程的循环次数 = b 的二进制位数 ≈ 31。

本质是**倍增**:每一步利用"翻倍"把问题规模减半,和归并排序、树上倍增(LCA)同源。这也是它在题单里被归到"倍增思想"小节的原因。

注意全程取模:乘完就 `% p`,否则中间结果天文数字直接溢出。

## 复杂度

O(log b),31 次循环。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll qpow(ll a, ll b, ll p) {
    ll res = 1;
    a %= p;
    while (b > 0) {
        if (b & 1) res = res * a % p;   // 该二进制位为 1,乘进答案
        a = a * a % p;                  // 底数自平方:a^1 -> a^2 -> a^4 ...
        b >>= 1;
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    ll a, b, p;
    cin >> a >> b >> p;
    cout << a << "^" << b << " mod " << p << "=" << qpow(a, b, p) << '\n';
    return 0;
}
```

## 易错点

1. **溢出**:a, p < 2^31 时 `a * a` 接近 2^62,`res * a` 同级,long long 刚好装下;若题目 p 到 10^18 级,要用 __int128 或龟速乘(见 P10446 64 位整数乘法)。
2. `res` 初值是 **1 不是 0**(乘法单位元);b = 0 时答案应为 1 % p(边界 p = 1 时应为 0),`res = 1` + 循环不进 + 忘了最后 % p 会错——稳妥写法是 `res = 1 % p` 或输出前取模。
3. 先 `a %= p` 再进循环,防 a 本身超 p 的乘法溢出。

## 延伸

快速幂是数论模块的地基:P3811 逆元(费马小定理 a^{-1} = a^{p-2})、P3390 矩阵快速幂(把"乘法"换成矩阵乘)、P1962 斐波那契数列(矩阵加速递推)。**"换掉乘法运算、保留二分指数框架"** 是这套模板的推广方式,后面反复会遇到。
