# P1443 马的遍历

- 专题:`03-search` § BFS
- 难度:普及-

## 题意

n×m(n, m ≤ 400)棋盘,马从 (sx, sy) 出发,按中国象棋"日"字走法,求到每个格子的最少步数,到不了输出 -1。输出格式:每个数占 5 格左对齐。

## 思路怎么来的

"最少步数 / 最少操作次数"是 BFS 的招牌信号:BFS 按**层**扩展,先访问距起点近的格子,后访问远的,第一次到达某格时走过的步数就是最短步数(每走一步代价相等,相当于无权图最短路)。

与 DFS 对比:DFS 一条路走到黑,先到的未必是最近的;BFS 一圈圈扩散,天然有序。记住:**问最少几步 → BFS;问有没有/有哪些方案 → DFS**。

实现要点:
1. `dist` 数组初始化为 -1,兼具"访问标记"和"距离"两个职能(-1 即未访问);
2. 起点入队前先标 `dist[sx][sy] = 0`,防止重复入队;
3. 8 个方向写成方向数组,防手打 8 遍出错;
4. 只有 `dist == -1` 的格子才入队,入队时立刻赋值(不是出队时),保证每格只进队一次。

## 复杂度

每个格子入队一次,O(nm) = 160000。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m, sx, sy;
int dist_[405][405];
const int DX[] = {1, 1, -1, -1, 2, 2, -2, -2};
const int DY[] = {2, -2, 2, -2, 1, -1, 1, -1};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m >> sx >> sy;
    memset(dist_, -1, sizeof dist_);
    queue<pair<int, int>> q;
    dist_[sx][sy] = 0;
    q.push({sx, sy});
    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();
        for (int i = 0; i < 8; i++) {
            int nx = x + DX[i], ny = y + DY[i];
            if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
            if (dist_[nx][ny] != -1) continue;    // 已访问
            dist_[nx][ny] = dist_[x][y] + 1;
            q.push({nx, ny});
        }
    }
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            printf("%-5d%c", dist_[i][j], " \n"[j == m]);
    return 0;
}
```

## 易错点

1. **入队时标距离**而不是出队时,否则同一格子会被重复入队,复杂度爆炸。
2. 输出用 `%-5d` 左对齐宽度 5,`printf` 比手写对齐省事;最后一列后也要补空格到宽度 5。
3. 马走"日":横 1 竖 2 或横 2 竖 1,方向数组写错是这题最常见的 WA 原因,写完用 (1,2)、(2,1) 两组值自查。
4. 变量名避免与 `std::dist` 冲突(用了 `using namespace std`),故命名为 `dist_`。
