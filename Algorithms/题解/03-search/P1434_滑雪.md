# P1434 [SHOI2002] 滑雪

- 专题:`03-search` § 记忆化搜索
- 难度:普及+ / 提高-

## 题意

r×c(r, c ≤ 100)网格,每格有高度。从任意格子出发,每步只能滑到**上下左右**且高度**严格更小**的格子。求最长滑行路径的长度(经过格子数)。

## 思路怎么来的

纯 DFS:从每格出发爆搜所有下滑路径,取最大——路径可能很长,总复杂度指数级,超时。

观察重叠子问题:从格子 A 出发的最长路径,只取决于 A 的位置,与"怎么到达 A 的"无关。若从 A 出发的答案已经算过,再次遇到直接返回。这就是**记忆化搜索**:DFS + 结果缓存,等价于动态规划(事实上它就是这道题的 DP 转移方程的递归写法):

> `f[i][j]` = 从 (i, j) 出发的最长路径 = 1 + max(f[相邻更小格]),四邻都不更小则为 1。

另一个隐藏性质:高度严格递减保证了转移无环(不会绕回来),不需要担心环——这也是记忆化合法的前提。答案 = 所有格子的 f 最大值。

与 BFS/DFS 的选择对照:本题问"最长"而非"最少",且边权(格子数)虽均匀但路径要挑最长的,BFS 层序失去意义;记忆化 DFS 是正解。

## 复杂度

每格只算一次,每次 O(4),O(r×c) = 10^4。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int r, c;
int h[105][105], f[105][105];
const int DX[] = {1, -1, 0, 0};
const int DY[] = {0, 0, 1, -1};

int dfs(int x, int y) {
    if (f[x][y]) return f[x][y];        // 已算过,直接返回(记忆化)
    f[x][y] = 1;                         // 至少包含自己
    for (int i = 0; i < 4; i++) {
        int nx = x + DX[i], ny = y + DY[i];
        if (nx < 1 || nx > r || ny < 1 || ny > c) continue;
        if (h[nx][ny] >= h[x][y]) continue;   // 只能滑向严格更低
        f[x][y] = max(f[x][y], dfs(nx, ny) + 1);
    }
    return f[x][y];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> r >> c;
    for (int i = 1; i <= r; i++)
        for (int j = 1; j <= c; j++)
            cin >> h[i][j];
    int ans = 0;
    for (int i = 1; i <= r; i++)
        for (int j = 1; j <= c; j++)
            ans = max(ans, dfs(i, j));
    cout << ans << '\n';
    return 0;
}
```

## 易错点

1. **缓存命中要早返回**:`if (f[x][y]) return f[x][y];` 放在函数第一行,否则记忆化形同虚设。
2. `f[x][y] = 1` 要在递归子之前赋初值,且它同时充当"正在计算"的标记——本题图无环(高度严格递减)所以安全;有环的图记忆化会死循环。
3. 高度**相等不能滑**(严格小于),写成 `<=` 会 WA。
4. 这题用 `f` 非零判断"已计算"足够;若高度可能为 0 导致状态值与标记冲突的题,要用单独的 vis 数组或 `memset -1`。
