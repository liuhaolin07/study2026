# P3372 【模板】线段树 1

- 专题:`04-data-structure` § 线段树(区间修改 + 区间查询)
- 难度:提高-

## 题意

长度 n(n ≤ 10^5)的数组,m(m ≤ 10^5)条操作:区间 [l, r] 每个数加 k;查询区间 [l, r] 的和。

## 思路怎么来的

朴素做法:修改 O(r-l+1),查询同样 O(n),m 次操作最坏 10^10。需要同时把**两种操作**都压到 O(log n)。

线段树把数组切成一棵二叉树:节点管一段区间,存这段的和。修改 [l, r] 时,若某节点区间被 [l, r] **完全覆盖**,它和它所有后代的和其实能"批量"算出(区间长 × k),却不必立刻往下传——把 k 记在节点的**懒标记 lazy** 上,先返回。等将来真的需要访问它的孩子时,再把 lazy 下放一层,补上欠的账。

这就是核心:**修改可以记账,查询才结账**。因为每次操作的路径只经过 O(log n) 个节点,懒标记保证了每层只展开必要的部分。

工程细节约定(记死这套,赛场直接默写):
- 节点 p 管区间,左孩子 2p,右孩子 2p+1;
- `pushup(p)`:sum[p] = sum[2p] + sum[2p+1],由孩子更新父亲;
- `pushdown(p)`:把 lazy[p] 下放给两个孩子(孩子的 lazy 累加、孩子的 sum 加 区间长×lazy[p]),然后清零;
- 修改/查询途中,进入孩子前先 `pushdown`,离开后 `pushup`(修改时)。

## 复杂度

每次操作 O(log n),总计 O((n + m) log n)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int n, m;
ll a[100005];
ll sum[400005], lz[400005];   // 4 倍空间

void build(int p, int l, int r) {
    if (l == r) { sum[p] = a[l]; return; }
    int mid = (l + r) / 2;
    build(2 * p, l, mid);
    build(2 * p + 1, mid + 1, r);
    sum[p] = sum[2 * p] + sum[2 * p + 1];
}

void pushdown(int p, int l, int r) {
    if (!lz[p]) return;
    int mid = (l + r) / 2;
    for (int c : {2 * p, 2 * p + 1}) {
        int cl = (c == 2 * p ? l : mid + 1), cr = (c == 2 * p ? mid : r);
        lz[c] += lz[p];
        sum[c] += (cr - cl + 1) * lz[p];
    }
    lz[p] = 0;
}

void update(int p, int l, int r, int ql, int qr, ll k) {
    if (ql <= l && r <= qr) {           // 完全覆盖:记账不深入
        sum[p] += (ll)(r - l + 1) * k;
        lz[p] += k;
        return;
    }
    pushdown(p, l, r);                  // 要碰孩子了,先还账
    int mid = (l + r) / 2;
    if (ql <= mid) update(2 * p, l, mid, ql, qr, k);
    if (qr > mid) update(2 * p + 1, mid + 1, r, ql, qr, k);
    sum[p] = sum[2 * p] + sum[2 * p + 1];
}

ll query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return sum[p];
    pushdown(p, l, r);
    int mid = (l + r) / 2;
    ll res = 0;
    if (ql <= mid) res += query(2 * p, l, mid, ql, qr);
    if (qr > mid) res += query(2 * p + 1, mid + 1, r, ql, qr);
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i];
    build(1, 1, n);
    while (m--) {
        int op, x, y; ll k;
        cin >> op >> x >> y;
        if (op == 1) { cin >> k; update(1, 1, n, x, y, k); }
        else cout << query(1, 1, n, x, y) << '\n';
    }
    return 0;
}
```

## 易错点

1. **数组开 4 倍**,开 2 倍在 n 接近 10^5 某些形态下越界 RE。
2. `sum` 与 lazy 必须 long long:10^5 个 2^31 级数求和爆 int,这是本题最常见的 WA/RE 来源。
3. 完全覆盖分支**不 pushdown**——正是懒标记省时间的地方;反之,递归进入孩子前**必须 pushdown**,漏掉则孩子 sum 是旧账。
4. 区间打的高度:`if (ql <= mid)` 与 `if (qr > mid)` 不能写 `else`,左右都可能要走。
5. 建议把这份代码手写三遍再收入 `模板/`,线段树是所有进阶数据结构(懒标记变体、扫描线)的地基。
