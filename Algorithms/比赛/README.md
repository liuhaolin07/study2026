# 比赛记录

每场比赛一个文件夹,命名示例:

- `codeforces/CF1980-Div2/` — 文件夹内 `A.cpp` `B.cpp` …
- `atcoder/ABC365/`
- `nowcoder/2026-网络预选赛/`
- `icpc/2024-沈阳/` — 真题 VP(第 6 个月起每周至少一场)

## 约定

1. 每场比赛文件夹里建一个 `upsolve.md`,记录每道没做出的题:
   - 卡在哪(没思路 / 想到思路写不出 / 写挂)
   - 题解的关键一步是什么
2. rated 赛后 **48 小时内**完成 upsolve,否则当周加练一场。
3. 每月月底回看:同样的"卡点"出现两次以上的,回 `专题/` 对应专题补题。
