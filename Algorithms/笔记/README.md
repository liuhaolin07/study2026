## 维护规则

1. **笔记是活的**:每周日复盘时,把本周新踩的坑补进 `易错点与调试.md`,新套路补进对应速查表;速查表只收"赛场会反复用"的结论,不收一次性推导。
2. 速查里的代码片段**以 `模板/` 为准**:模板更新后同步速查,两边不一致以模板为准。
3. 赛前只看三样:`易错点与调试.md`、`比赛策略.md`、`checklist.md`。
4. 与 `redo-list.md` 的分工:错题记录在 redo-list,错题背后**共性的坑**提炼进本目录。

## 单题复盘模板(卡壳题、upsolve 题通用)

```markdown
### 题目:Pxxxx 名称(日期)
- 卡在哪:□ 没读懂题 □ 没想到算法 □ 想到写不出 □ 写挂
- 题解的关键一步:(一句话,比如"把交换操作看成图上的环")
- 为什么自己没想到:缺知识点 / 有知识点没联想到 / 方向错了
- 归类到:速查哪一张表 / 专题哪个知识点
- 重做安排:记入 redo-list,日期 +7 天
```
