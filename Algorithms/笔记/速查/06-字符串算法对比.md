# 速查:字符串算法对比

> 对应专题 `题单/08-string`;模板 `模板/XCPC_Templates/string/`。约定:字符串 0-index,`n = |s|`。

## 一、算法对照总表

| 需求/信号 | 首选 | 复杂度 |
|---|---|---|
| 任意两个子串判等/比较 | 哈希(双模) | O(1) 查,预处理 O(n) |
| 模式串在文本中的所有出现 | KMP / Z 函数 | O(n+m) |
| border / 周期 / 循环节 | KMP 的 fail 数组 | O(n) |
| 最长回文子串 / 回文计数 | Manacher | O(n) |
| 多个模式串一起匹配 / 禁词计数 | AC 自动机 | O(文本长 + Σ模式串长) |
| 前缀查询、异或最值 | Trie / 01-Trie | O(总长 / n·64) |
| 后缀排序、不同子串数、子串出现次数 | 后缀数组(选学) | O(n log n) |

**经验法则**:能哈希糊过去的小数据先糊;单串结构问题找 fail/回文半径;多串上自动机;问"出现次数/字典序"上后缀数组。

## 二、哈希

```cpp
h[i] = h[i-1] * B + s[i];                          // 前缀哈希
hash(l, r) = h[r] - h[l-1] * pw[r-l+1];            // 子串哈希(取模意义下)
```

- 底数 B 取 131/13331;**双模**(1e9+7 与 998244353)或单个 2^61-1,防止被卡/自然溢出冲突。
- 用途:判子串相等、二分长度找两串最长公共子串、正反哈希判回文、字符串 DP 去重。
- 坑:比较前先统一取模;`h[l-1]` 当 l=0 时要写 `0`。

## 三、KMP(fail 数组,一切"前后缀"问题的根)

- 定义:`fail[i]` = s[0..i] 的最长**真**前缀等于后缀的长度(border)。
- **最小周期** `p = n - fail[n-1]`;若 `n % p == 0`,p 是最小循环节,否则不是完整循环(但 border 结构仍有用)。
- 匹配文本:j 指针失配时 `j = fail[j-1]`,总复杂度均摊 O(n+m)。
- 应用:求每个前缀出现次数(沿 fail 树统计子树和)、最短回文拼接(找 s 的最长回文前缀)。
- 配题:P3375 KMP、P4391 无线传输(周期)。

## 四、Z 函数(扩展 KMP)

- 定义:`z[i]` = 后缀 s[i..] 与 s 的最长公共前缀长度;`z[0]` 单独定义。
- 求模式串出现:拼 `s + '#' + t`,凡 `z[i] == |s|` 即在 `i - |s| - 1` 处匹配。
- 与 KMP 可互相推导;求"每个前缀出现次数"时 fail 树更顺手。

## 五、Manacher

- 插入 `#` 统一奇偶回文;`p[i]` = 以 i 为中心的最大回文**半径**(新串上),原串回文长度 = `p[i] - 1`。
- 利用已知回文的镜像信息跳过重复比较,线性;回文中心 i 覆盖的区间即 `[i-p[i]+1, i+p[i]-1]`(新串下标)。
- 用途:最长回文子串、每个位置结尾/开头的回文个数(配合差分)。
- 配题:P3805、P1659 长度为奇数的回文计数。

## 六、Trie 与 01-Trie

- Trie:逐字符建儿子;查询前缀存在性、不同前缀计数;空间 = 总字符数 × 字符集,注意清空复用。
- **01-Trie**(按位从高到低插入):最大异或对(查询时高位尽量走相反分支)、异或前缀和最值;配合可持久化做区间异或最值(选学)。
- 配题:P8306、P10471 最大异或对。

## 七、AC 自动机(KMP 思想推广到 Trie)

- 构建:Trie 上 BFS,`fail` 指向"当前串的最长真后缀对应的节点"。
- 匹配:文本沿 goto 走(儿子不存在则接到 fail 的儿子),每个节点积累"以该位置结尾的模式串数"。
- **上 DP**:把文本/计数问题搬上自动机,禁止词 = 标记危险节点,DP 状态 `(长度, 自动机节点)`;多条 fail 链贡献用 **fail 树子树和**或拓扑累加优化。
- 配题:P3808/P3796、P2444 病毒(危险环判定)。

## 八、后缀数组(选学,第 10 月后)

- 倍增/桶排求 rank;`height[i]` = 排名相邻两后缀的最长公共前缀。
- 不同子串数 = `n(n+1)/2 - Σ height`;出现次数 = 某排名区间的后缀数。
- 一般先试哈希/二分,后缀数组是更精细工具。

## 九、字符串 DP 常见模型

| 模型 | 状态 |
|---|---|
| 编辑距离 | f[i][j]:a 前 i 个变 b 前 j 个的最小代价 |
| 最长回文子序列 | 区间 DP:f[i][j] |
| 回文划分/最少分割 | f[i] = min f[j-1] + 1,j..i 是回文(哈希/Manacher 优化) |
| 循环节拼接 | 枚举周期 + KMP 判定 |

## 十、高频错误

1. 哈希单模被卡:比赛用双模;考场写的哈希被人构造数据卡的题,赛后记录。
2. KMP 的 `fail` 下标 ±1 混淆(有的教材从 1 开始):统一自己的一套写法,贴进 `模板/` 后别再改。
3. Manacher 的"新串/原串"下标换算出错:固定一套换算公式写在注释里。
4. AC 自动机忘接 fail 的儿子(没有 goto 的边),复杂度退化成暴力。
5. 多测清空 Trie:用时间戳/编号代替 memset。
