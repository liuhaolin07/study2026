# 速查:图论选型与建图套路

> 对应专题 `题单/06-graph`;模板 `模板/XCPC_Templates/graph/`;经典题详解在 `题单/06-graph/`。

## 一、算法复杂度与适用总表

| 算法 | 复杂度 | 适用/限制 |
|---|---|---|
| BFS / DFS | O(n+m) | 无权最短路、连通性;DFS 深图防爆栈(BFS 或改迭代) |
| 拓扑排序 | O(n+m) | DAG;判环(排不完有环) |
| Dijkstra + 堆 | O(m log n) | **边权非负**,单源首选 |
| Bellman-Ford / SPFA | O(nm) / 均摊快最坏 O(nm) | 有负权;判负环 |
| Floyd | O(n^3) | 全源,n ≤ 500;传递闭包 |
| Kruskal | O(m log m) | MST;配合并查集 |
| Prim(堆) | O(m log n) | MST,稠密图;朴素 O(n^2) 版适合稠密 |
| Tarjan 缩点/割点/桥 | O(n+m) | 有向图强连通 / 无向图点双、边双 |
| 匈牙利匹配 | O(n·m) | 二分图;小图够用 |
| Dinic | 一般 O(n^2·m),二分图 ≈ O(√n·m) | 最大流,建图是关键 |

**最短路选型**:有负权 → SPFA(小心被卡,准备 Bellman-Ford 兜底);判负环 → SPFA 记录入队次数 ≥ n;全源 → n 小用 Floyd,否则每个点跑一次 Dijkstra。

## 二、树上问题速查

- **LCA**:`dis(u,v) = dep[u] + dep[v] - 2*dep[lca]`;倍增法先 BFS 求深度(防爆栈),再跳 2^k 祖先。模板 P3379。
- **直径**:两遍 DFS(从任一点到最远点 x,再从 x 到最远点 y,x~y 即直径)或树形 DP;注意两遍 DFS 不能用于**负边权**。
- **重心**:删去后最大子树最小的点;性质:所有点到重心的距离和最小、以重心为根每个子树 ≤ n/2。
- **树上差分**:
  - 点差分(路径上点 +1):`d[u]++, d[v]++, d[lca]--, d[fa[lca]--`,最后子树和还原。P3128。
  - 边差分(路径上边 +1):`d[u]++, d[v]++, d[lca] -= 2`,子树和还原。
- **树的子树和/子树最值**:DFS 序 + 区间数据结构,把树上问题转成序列问题。

## 三、建图套路(想到图论之后,卡在建图)

| 场景 | 手法 |
|---|---|
| 每个点/每个位置有"次数限制" | **拆点**:入点→(容量)→出点 |
| 每条边可免费使用 k 次/状态机 | **分层图**:复制 k+1 层,层间连"决策边"。P4568 飞行路线 |
| 多个起点/多个终点 | **超级源/超级汇**,边权 0 |
| "谁到达谁"反过来更简单 | 建反图跑同算法 |
| 一堆不等式 xi - xj ≤ c | **差分约束**:j→i 连边权 c,跑最短路;求 xi - xj 最大用 ≥ 约束跑最长路;有负环/正环即无解。P5960 |
| 依赖先后(DAG) | 拓扑序上 DP(最长路、方案数) |
| 缩点后变简单 | Tarjan 缩点成 DAG 再 DP。P3387 |
| 棋盘上选不相邻/冲突格 | 黑白染色 → 二分图;最小点覆盖 = 最大匹配(König) |
| 环形结构 | 断环成链复制 2n,或固定起点枚举 |
| 边权只有 0/1 | 0-1 BFS(deque)省掉 Dijkstra |
| 只关心可达性 | BFS/DFS/传递闭包,别上最短路 |

## 四、判定类结论(背下来)

- **二分图判定**:无奇环 ⟺ 可二染色(BFS 染色)。P1525 关押罪犯(扩展域并查集亦可)。
- **欧拉回路**:无向图——连通且所有点度数为偶;有向图——连通且每点入度 = 出度。**欧拉路径**:无向图恰有 0 或 2 个奇度点;有向图恰有一点 `出-入=1`、一点 `入-出=1`。
- **Kruskal 重构树**:两生成树上的瓶颈边问题(路径最大边最小化),点权即瓶颈。P1967 货车运输。
- **桥/割点**:桥——去掉后不连通的边(父边重边要特判);割点——至少两个"不可回到祖先"的子树。
- **最小生成树唯一性**:所有边权互不相同时唯一。

## 五、常见错误

1. **无向图数组开 `2*m`**,链式前向星加边两次。
2. Dijkstra 忘了 `if (d[u] != 堆中记录) continue;` 的懒删除判断,复杂度退化。
3. 求最短路时边权溢出:`INF = 0x3f3f3f3f` 相加两次仍安全,但自定义大 INF(1e18)加边权会溢,先判断再相加。
4. 判连通忘记 isolated 点;多测忘清空邻接表表头 `head[]`。
5. 差分约束建图方向搞反:先推导"要求 xi ≤ xj + c"再连 j→i,c 为正负决定跑最短还是最长路。
