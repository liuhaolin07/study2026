# 速查:数论与组合数学

> 对应专题 `题单/07-math`;模板 `模板/XCPC_Templates/math/`;详解在 `题单/07-math/`。

## 一、幂与逆元

| 需求 | 方法 | 条件 |
|---|---|---|
| a^b mod p | 快速幂 O(log b) | 无条件;乘法中途开 long long |
| a·b mod p,b、p 达 1e18 | 龟速乘 / `__int128` | `(__int128)a * b % p` |
| 单个逆元 | 费马:`qpow(a, p-2, p)` | **p 为质数** |
| 批量逆元 1..n | 递推 `inv[1]=1; inv[i] = (p - p/i) * inv[p%i] % p` | p 质数,O(n) |
| 阶乘逆元 | `invf[n]=qpow(f[n],p-2)` 倒推 `invf[i]=invf[i+1]*(i+1)%p` | p 质数 |
| p 非质数求逆 | exgcd:`a·x ≡ 1 (mod p)`,有解 ⟺ gcd(a,p)=1 | — |

- **除法取模 = 乘逆元**;组合数、期望、平均数全靠它。
- 负数取模:`((a - b) % p + p) % p`,封成函数 `sub()`。

## 二、gcd / exgcd / 同余方程

- `gcd(a,b) = gcd(b, a%b)`;`lcm = a / gcd * b`(先除后乘防溢出)。
- exgcd 求解 `ax + by = gcd(a,b)`;通解 `x = x0 + b/d·k`,`y = y0 - a/d·k`(d=gcd)。
- 线性同余方程 `ax ≡ b (mod m)`:有解 ⟺ `gcd(a,m) | b`;解为 `x ≡ x0 (mod m/gcd)`,共 d 个。P1516 青蛙的约会、P5656。
- 注意解回代后先 `% (m/d)` 再 `+m/d` 取正,避免负解。

## 三、筛法与因子

- **欧拉筛** O(n):每个合数只被最小质因子筛一次;顺带可线性筛出 φ、最小质因子、约数个数。
- 单个 n 分解质因数:试除到 √n,O(√n);配合 map 计数。
- 判单个大素数:试除 √n;更大用 Miller-Rabin(选学)。
- φ(n) = n·∏(1 - 1/p);a 与 p 互质时 `a^φ(p) ≡ 1`(欧拉定理,费马是其特例)。

## 四、同余方程组

- **CRT**(模数两两互质):各余数加权合并,权 = M/mi·(M/mi 的逆元)。
- **EXCRT**(任意模数):两条两条合并 `x ≡ r1 (mod m1)`、`x ≡ r2 (mod m2)`:
  1. 化成 `m1·k ≡ r2 - r1 (mod m2)`;
  2. exgcd 判解,无解直接无解;
  3. 合并为 `x ≡ r1 + m1·k0 (mod lcm(m1, m2))`。
  - 合并过程乘法可能爆 long long,用 `__int128`。

## 五、组合数

| n 范围 | 方法 |
|---|---|
| ≤ 5000 | 递推 `C[i][j] = C[i-1][j] + C[i-1][j-1]`(任意模) |
| ≤ 1e7(模质数) | 阶乘 + 阶乘逆元:`C(n,m) = f[n]·invf[m]·invf[n-m]` |
| n,m ≤ 1e18,p < 1e5 质数 | 卢卡斯:`C(n,m) ≡ C(n/p, m/p)·C(n%p, m%p) (mod p)` 递归 |

- 常用恒等式:`C(n,m)·m = C(n-1,m-1)·n`;ΣC(n,k) = 2^n;隔板法:n 个相同球进 m 个不同盒,允许空 `C(n+m-1, m-1)`,不允许空 `C(n-1, m-1)`。
- **容斥**:对"至少满足一个条件"计数,枚举子集符号 (-1)^|S|;配合"枚举 2^k 个条件"使用,n≤20 信号。
- **卡特兰数** `Cn = C(2n,n)/(n+1)`:合法括号串、出栈序列、不越过对角线的路径数。
- **错排** `Dn = (n-1)(D_{n-1} + D_{n-2})`,D1=0、D2=1。
- **整除分块**:Σ⌊n/i⌋ 按 i 分成 O(√n) 块,块内值相同,`r = n/(n/l)`。

## 六、博弈论

- **Bash**:n 个石子每次取 1~m,`n % (m+1) == 0` 则先手必败。
- **Nim**:各堆异或和 ≠ 0 先手必胜(必胜策略:取后使异或和为 0)。
- **SG 定理**:局面 SG = mex(后继 SG);多个独立局面异或。组合博弈先拆成独立子局面对照。

## 七、矩阵与线性代数

- **矩阵快速幂**:线性递推第 n 项(n ≤ 1e18)——构造转移矩阵;"图上走 k 步的方案数"= 邻接矩阵 k 次幂。
- **高斯消元** O(n^3):解方程组、行列式、逆矩阵;**异或方程组**(开关灯问题)按位消元,统计自由变元。
- 常用模数:998244353(NTT 友好,= 119·2^23+1)、1e9+7;**题目给的模不一定是质数**,用逆元前必须确认,否则换 exgcd 或改成加减乘消去除法。

## 八、高频错误

1. `p/i`、`i*p` 溢出 int:涉及乘法的都先转 long long。
2. 快速幂指数没开 long long(b 到 1e18)。
3. Lucas 递归没写 `if (m == 0) return 1` 边界,或对 p=1 特判遗漏。
4. CRT/EXCRT 合并时忘加"解为非负"调整。
5. 组合数预处理上界开小(答案要 C(2n, n),数组开 2n)。
