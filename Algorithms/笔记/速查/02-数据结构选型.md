# 速查:数据结构选型

> 问题:什么需求用什么结构?先看"查询和修改各是什么",再选。模板在 `模板/XCPC_Templates/data_structure/`。

## 一、选型总表

| 需求 | 推荐 | 复杂度 | 模板 |
|---|---|---|---|
| 单点加 + 前缀/区间和;区间加 + 单点查 | 树状数组 | O(log n) | `data_structure/fenwick_tree.hpp` |
| 区间加 + 区间和/最值 | 线段树(懒标记) | O(log n) | `data_structure/segment_tree_lazy.hpp` |
| 静态区间 min/max/gcd | ST 表 | 建 O(n log n),查 O(1) | `data_structure/sparse_table.hpp` |
| 区间最值但带修改 | 线段树 | O(log n) | `data_structure/segment_tree.hpp` |
| 滑动窗口最值 | 单调队列 | O(n) | — |
| 左/右第一个更大(小)元素 | 单调栈 | O(n) | — |
| 合并集合、判连通 | 并查集 | 均摊 O(α) | `data_structure/union_find.hpp` |
| 动态中位数 / 第 k 小(流) | 对顶堆(大根+小根) | O(log n) | — |
| 在线第 k 小 / 区间排名 | 权值线段树 / 主席树(选学) | O(log^2) | — |
| 前驱后继、插入删除 | `set`/`multiset`,或 pb_ds 平衡树 | O(log n) | — |
| 区间开方/取模(和有界) | 势能线段树(选学) | 均摊 O(log n) | — |
| 多串前缀/计数 | Trie | O(总长) | `string/trie.hpp` |

**选型优先原则**:能用树状数组不写线段树(代码短、不易错);静态查询用 ST 表;**先想清楚暴力维护什么信息**,再选结构,不要反向。

## 二、树状数组

- 本质:维护前缀和的高效结构,依赖减法(逆操作);**不支持区间 min**(除非巧妙转化,如预处理 nxt)。
- 常见变体:
  - 区间加+区间和:两个树状数组(维护 d 与 i·d);
  - 求逆序对:值域上单点加,从左往右查询"已插入的比我小的个数"。
- 值域大先离散化。

## 三、线段树要点(银牌分水岭)

1. `pushdown` 永远在用子节点信息**之前**调用。
2. 递归开头:完全不相交 → `return`;叶子 → 直接改;`mid` 拆分左右。
3. 懒标记复合顺序(乘加双标):新标记来时,先对旧标记"乘后加"地合并——`mul = mul*nm % p; add = (add*nm + na) % p;` 下传时同样先乘后加。对应 P3373。
4. 信息可合并性:区间要维护"能由左右拼出来"的量(如区间和、max、以及带左右端点信息的结构体)。
5. 动态开点/权值线段树:下标是值域,空间 `4e7` 量级,注意回收与离散化。

## 四、并查集变体

| 变体 | 信号 | 做法 |
|---|---|---|
| 普通 | 连通性、合并 | 路径压缩 + 按秩/按大小合并 |
| 扩展域 | "敌人的敌人是朋友"等关系传递 | 开 n·k 个点,同类连一起 |
| 带权 | 维护"到根的相对量"(距离/奇偶) | 路径压缩时顺带累加边权 |
| 可撤销 | 需要回溯/离线删边 | **只按秩合并不路径压缩**,栈记录合并历史 |
| 判二分图 | 奇环判断 | 扩展域,或带权并查集维护奇偶 |

- 配题:P3367、P1955(离散化+扩展域)、P2024 食物链、P1196 银河英雄传说。

## 五、单调栈 / 单调队列

- **单调栈**:求每个元素左/右第一个比它大(小)的位置;信号:"贡献只在被弹出的那一刻产生"(直方图最大矩形、发射站)。
- **单调队列**:滑动窗口最值;队头过期弹、队尾破坏单调弹;dp 优化见 `03-DP方法论.md`。
- 两者存下标不存值(方便判断过期)。

## 六、堆

- `priority_queue` 默认大根堆;小根堆 `priority_queue<T, vector<T>, greater<T>>`。
- 对顶堆求动态中位数:大根堆存小的一半,小根堆存大的一半,调整使两堆大小差 ≤1。
- 合并果子、Dijkstra、Kruskal 重构树都靠它;需要"删除任意元素"时用懒删除(计数)或 `multiset`。
