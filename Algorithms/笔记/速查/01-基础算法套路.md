## 一、二分

**适用信号**:最大化最小值 / 最小化最大值 / "最少需要多少次操作";答案具有单调性——"答案 x 可行 ⇒ 比 x 更保守的也可行"。

统一写法(求第一个满足 check 的位置,答案落在 `[L, R]`):

```cpp
int lo = L, hi = R + 1;              // [lo, hi) 左闭右开
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;    // 防溢出写法
    if (check(mid)) hi = mid;
    else lo = mid + 1;
}
// lo 即答案;若 lo == R+1 说明无解
```

- `check` 必须是纯判定函数,别在 check 里顺手改全局。
- 浮点二分:固定迭代 100 次即可,不要用 `fabs(r-l)<eps` 停(可能死循环)。
- STL:`lower_bound`(第一个 ≥ x)、`upper_bound`(第一个 > x),作用在**有序**区间上。
- 常见坑:边界 ±1、`mid` 上溢(int 用 `l+(r-l)/2`)、答案在 R+1(无解)漏判。
- 配题:P1873 砍树、P2440 木材加工、P1163 银行贷款(浮点)。

## 二、双指针 / 滑动窗口

| 形态 | 场景 | 要点 |
|---|---|---|
| 对撞 | 有序数组两数之和、回文判断 | 两端向中间收缩,利用有序性 |
| 同向 | 归并、去重、双序列匹配 | 两指针各扫一遍 O(n) |
| 滑动窗口 | "最长/最短子串(段)满足……" | 右端点扩,不合法时左端点缩;窗口内信息用计数数组/桶维护 |

- 前提:窗口扩大单调变好(或变坏),否则只能二分+前缀和。
- 配题:P1102 A-B 数对、P1638 逛画展、P3143。

## 三、前缀和 / 差分

```cpp
// 一维
pre[i] = pre[i-1] + a[i];          // 区间和 = pre[r] - pre[l-1]
// 差分:区间 [l,r] 加 x
d[l] += x; d[r+1] -= x;            // 还原 = 差分的前缀和
// 二维前缀和
s[i][j] = a[i][j] + s[i-1][j] + s[i][j-1] - s[i-1][j-1];
// 二维差分:矩形 [x1,y1]-[x2,y2] 加 x
d[x1][y1] += x; d[x2+1][y1] -= x; d[x1][y2+1] -= x; d[x2+1][y2+1] += x;
```

- 信号:"区间加、单点查"→差分;"区间和、静态"→前缀和;动态版本分别升级为树状数组/线段树(见 `02-数据结构选型.md`)。
- 树上版本(点差分/边差分)在 `04-图论选型与建图.md`。

## 四、贪心

**证明两板斧**:交换论证(任取两个相邻决策,交换后不更差 ⇒ 全局贪心合法)与反证法。想不出证明时,贪心只敢在"小数据对拍"通过后用。

| 经典模型 | 策略 |
|---|---|
| 区间调度(最多不重叠区间) | 按**右端点**排序,能选就选 |
| 区间覆盖 | 按**左端点**排序,贪心扩展可达最远 |
| 排队接水/平均等待最小 | **耗时小**的先做 |
| 合并果子/哈夫曼 | 每次合并最小的两个(优先队列) |
| 奶牛晒太阳/匹配类 | 双序列各自排序后对应匹配 |

- 配题:P1090 合并果子、P1223 排队接水、P1803 凌乱的yyy/线段覆盖。

## 五、离散化

```cpp
vector<int> v(a, a + n);           // 1. 收集所有出现的值
sort(v.begin(), v.end());          // 2. 排序
v.erase(unique(v.begin(), v.end()), v.end());  // 3. 去重
int id = lower_bound(v.begin(), v.end(), x) - v.begin();  // 4. 查排名
```

- 信号:值域 1e9 但只有 ≤1e6 个关键值;线段树/树状数组/DP 下标装不下时。
- 查询"第 k 大的原值"直接用 `v[k]`。

## 六、位运算

```cpp
x & -x                 // lowbit:取出最低位的 1
x >> i & 1             // 第 i 位是否为 1
x |= 1 << i; x &= ~(1 << i)      // 置 1 / 置 0
for (int s = S; ; s = (s - 1) & S) { /* 枚举 S 的所有子集 */ if (!s) break; }
__builtin_popcount(x)  // 1 的个数
```

- 信号:n ≤ 20 的选取问题;"异或不进位"的拆位讨论(每一位独立);状态压缩。
- `1 << k` 在 k ≥ 31 时未定义,写 `1LL << k`。
- 异或性质:a^a=0、异或满足交换律结合律、"出现奇数次的数"用全体异或。

## 七、倍增思想

- 定义 `f[k][u]` = 从 u 出发走 2^k 步(或跳跃 2^k 层)到达的信息;查询时把任意 k 拆成二进制位逐级合并。
- 应用:快速幂(本质是倍增)、ST 表、倍增 LCA、树上路径第 k 步、瓶颈路查询。
- 关键性质:信息合并满足**结合律**即可倍增。
