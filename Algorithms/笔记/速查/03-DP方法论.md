# 速查:DP 方法论

> 银牌核心模块:区域赛中档题一半以上是 DP。对应专题 `题单/05-dp`;模板 `模板/XCPC_Templates/dp/`;经典题详解在 `题单/05-dp/`。

## 一、设计四步法

1. **状态**:描述"局面"且无后效性——通常包含:处理到哪(i)、已用资源(j:容量/次数/余额)、上一个决策(k:方向/颜色/最后一段)。问自己:"只凭这个状态,后面怎么选与之前怎么来的无关吗?"
2. **转移**:盯住**最后一步**(最后选了什么物品/最后一段是什么),枚举它。
3. **初始化与答案**:`f[0]` 是什么?"恰好/至少/至多"决定初始化(见下);答案可能在 `f[n]`、`max f[i]`、或需要枚举终点。
4. **顺序**:按状态依赖的拓扑序递推;写不出递推就记忆化搜索,等价且更不容易写错顺序。

## 二、"恰好 / 至少 / 至多"的初始化(方案数与最优值通用)

| 语义 | 初始化 | 说明 |
|---|---|---|
| 至多(不超过 j) | f[0..j] 全部合法初值 0 | 无"必须装满"约束 |
| 恰好 j | f[0]=0,其余 = 非法值(最优值用 ±inf,方案数用 0) | 转移时判断来源是否非法 |
| 至少 j | 与"至多"同构,把 j 截断在 max | 部分题对 j > 某界等价 |

- 最优值用 `-INF` 表示"不可达"时,加法转移前判断 `f[pre] > -INF/2`,防止 inf 相加减溢出。

## 三、分类清单(按"信号"认类型)

| 类型 | 信号 | 代表题 |
|---|---|---|

| LIS 优化 | 最长上升 | 贪心+二分 O(n log n):维护"长度 k 的结尾最小值" |

## 四、优化手段对照

| 转移长这样 | 优化为 |
|---|---|
| f[i][j] = min/max f[i-1][j-w..j] | 单调队列 O(n) |
| f[i][j] = Σ f[i-1][k] (k 在区间) | 前缀和/树状数组 |
| f[i][j] = min(a_j·x_i + b_j) 型 | 斜率优化(凸壳,银牌边缘) |
| 多重背包 s 件循环 | 二进制拆分成 O(log s) 件 |
| 线性递推第 n 项,n ≤ 1e18 | 矩阵快速幂 |
| 状态里"集合" | 状压(bitmask) |

## 五、高频错误

1. 01 背包容量**倒序**、完全背包**正序**——写反等于把 01 做成完全。
2. 方案数题忘记取模,或取模后比较大小(取模后不可比!)。
3. 状态值开 int 但理论上有 1e9 量级方案/代价——直接 long long。
4. 区间 DP 长度从 2(或 1)开始枚举,断点区间写错 `len-1` / `i+len-1`。
5. 输出方案:用 pre 数组记前驱,最后倒推;别在 f 里存整个路径(爆内存)。

## 六、思考卡壳时的检查单

- 是不是状态定义少了一维?(把"最后一步"或"剩余资源"显式放进状态)
- 能不能先写出暴力搜索,再改成记忆化?
- 数据范围是不是在暗示状压/数位/折半?(对照 `00-复杂度与数据范围.md`)
- 拆位/拆性质后每一位独立了吗?(异或、进位类)
- 实在不会:**记忆化搜索打暴力 + 部分分**,别空着。
