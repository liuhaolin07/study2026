# 易错点与调试

> 用法:赛前扫一遍"提交前检查清单";WA/TLE 时按"症状 → 病因"表排查;写完想验证就上对拍。新踩的坑当天补进对应小节。

## 一、提交前 10 秒检查清单

- [ ] 输入输出**文件名/流**与题面一致( freopen、多组输入格式 )
- [ ] 多测:**清空**(邻接表 `head[]`、并查集 fa、计数数组、Trie);读清 `∑n` 约定
- [ ] 数组开够:无向图 `2*m`、字符串 `n+1`、差分 `n+2`、组合数按最大 C(2n,n) 开
- [ ] 该 long long 的都 long long(见第三节)
- [ ] 取模:`a-b` 先加 mod;除法已换乘逆元;题目 mod 是否质数确认过
- [ ] 边界:n=0/1、空串、全相同、自环重边、单点图
- [ ] 浮点输出用 `printf("%.Nf")`,负零修成 0
- [ ] 本地过了样例 + 至少一个自造极端样例

## 二、症状 → 病因排查表

| 症状 | 高频病因(按概率排序) |
|---|---|
| WA 大数据、小数据全对 | 溢出;数组越界(忘 ×2 / 忘 n+1);多测没清空;复杂度里漏了 log 导致实际超时但评测机快?→ 改查复杂度 |
| WA 连样例都过不了 | 题意读错(操作顺序/边界含义);初始化错(恰好/至多);循环顺序错(背包);下标 ±1 |
| WA 偶现(交几次不一样) | 未定义行为:数组越界写、`+=` 溢出、迭代器失效、全局与局部重名 |
| TLE | 算法复杂度选错;死循环(二分边界、SPFA 遇负环);卡常(cin、取模过多、map 换数组、递归改迭代);多测没按 ∑n 复杂度算 |
| RE / MLE | 除 0、取模 0;越界;递归爆栈(改 BFS/手写栈);MLE 查 `2*m`、动态开点空间 |
| 输出对但判错 | 行末多余空格/换行;大小写;浮点精度比要求少一位;用了科学计数法 |

## 三、溢出自查三问

1. 三个数相乘/相加的地方?上界各是多少,乘起来超 int(2.1e9)吗?
2. 中间量:前缀和、方案数、距离和,上界是不是 1e9 量级以上?→ 直接全 long long,别省。
3. 位移:`1 << k` 在 k ≥ 31 未定义 → `1LL << k`;`(1<<62)` 直接 UB。

## 四、调试手段(按成本从低到高)

1. **重读题面**的 Input/Output 段和样例解释——一半 WA 在这。
2. 手推一个最小样例,与程序输出逐行对。
3. 打印中间量:循环变量、dp 关键行、图的关键边,加 `#ifdef LOCAL`。
4. `assert` 埋点:断言不变量(有序、非负、度数关系),定位第一个崩坏处。
5. 注释法/二分注释:注释一半逻辑看错误是否消失,二分定位出错代码段。
6. **对拍**(下一节):正确性存疑的唯一终极手段。

## 五、对拍(随机数据 + 暴力验证)

三个文件:`sol.cpp`(提交解)、`brute.cpp`(保证正确的暴力)、`gen.cpp`(数据生成器)。

```cpp
// gen.cpp:小而随机,手动改参数制造边界
#include <bits/stdc++.h>
using namespace std;
mt19937 rnd(chrono::steady_clock::now().time_since_epoch().count());
int main() {
    int n = rnd() % 10 + 1;                    // 想测大数据就放大范围
    cout << n << "\n";
    for (int i = 0; i < n; i++) cout << rnd() % 100 << " \n"[i == n - 1];
}
```

Git Bash 循环(Windows 下编译一次,循环对比):

```bash
g++ -O2 -std=c++17 sol.cpp -o sol
g++ -O2 -std=c++17 brute.cpp -o brute
g++ -O2 -std=c++17 gen.cpp -o gen
while true; do
  ./gen > in.txt
  ./sol   < in.txt > out1.txt
  ./brute < in.txt > out2.txt
  diff -q out1.txt out2.txt > /dev/null || { echo "WA! 数据:"; cat in.txt; break; }
done
```

- 找到 WA 数据后**保存下来**,卡住就手工分析,别急着改代码硬试。
- gen 要**针对性地造数据**:最小 n=1、全相同、极值、链/菊花/完全图/网格、卡贪心的反例(小随机大量跑,贪心错的会很快现形)。
- 交互题/构造题对拍不了,改用"拍构造器":随机生成输入,肉眼验证输出满足所有限制。

## 六、卡常小抄(确认复杂度没问题之后才做)

- `ios::sync_with_stdio(false); cin.tie(nullptr);` 或快读。
- 内层循环减少取模:累加不取模,循环尾一次取模(注意溢出)。
- `map`/`set` 换排序数组或手写哈希;`endl` 换 `"\n"`。
- 递归改迭代、传大结构体改引用、`memset` 只清有用部分。
- 循环内除法/浮点尽量提出循环。
