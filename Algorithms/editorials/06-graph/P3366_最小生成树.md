# P3366 【模板】最小生成树

- 专题:`06-graph` § 最小生成树
- 难度:普及+ / 提高-

## 题意

n(n ≤ 5000)个点、m(m ≤ 2×10^5)条**无向**带权边。求最小生成树的边权总和;图不连通输出 `otz`。

## 思路怎么来的

生成树 = 保留 n-1 条边把所有点连通。要总权最小,kruskal 的贪心:**边按权排序,从小到大依次尝试,两端还不连通就选它**。

为什么贪心对?交换论证:若最优解不含当前最小的合法边 e(两端点分属不同连通块),把 e 加进最优树会形成环,环上必有另一条横跨 e 两端的边 e',w(e') ≥ w(e),换掉它总权不增。所以"每步选能选的最小边"不会输。

"两端是否连通"用并查集 O(α) 判定(见 P3367 详解),选中的边即把两端合并。这正是**并查集最经典的应用场景**:离线、只有合并没有拆分。

对照 prim:kruskal 按"边"思考、实现靠排序 + 并查集,稀疏图(m 小)友好;prim 按"点"扩张、堆优化后适合稠密图。竞赛默认先写 kruskal,代码短、不易错。

不连通的判定:数一下选中的边数,凑不满 n-1 条即无生成树。

## 复杂度

排序 O(m log m) 占大头,并查集近似 O(m),总 O(m log m)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int fa[5005];
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }

struct Edge { int u, v, w; };

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<Edge> e(m);
    for (auto &x : e) cin >> x.u >> x.v >> x.w;
    sort(e.begin(), e.end(), [](const Edge &a, const Edge &b) { return a.w < b.w; });

    for (int i = 1; i <= n; i++) fa[i] = i;
    long long total = 0;
    int picked = 0;
    for (auto [u, v, w] : e) {
        int ru = find(u), rv = find(v);
        if (ru == rv) continue;        // 已连通,选了会成环
        fa[ru] = rv;                   // 选中:合并
        total += w;
        if (++picked == n - 1) break;  // 提前收工
    }
    if (picked == n - 1) cout << total << '\n';
    else cout << "otz" << '\n';
    return 0;
}
```

## 易错点

1. **无向图**:边只存一条即可(kruskal 不区分方向),但注意别和有向最短路题的存图习惯打架。
2. 判连通是**数边数** `picked == n-1`,不是"并查集根的个数"(那样也行但要多扫一遍,容易写错)。
3. 答案总和用 long long(边权 × 2×10^5 条)。
4. 自环(u = v)会被 `ru == rv` 自然过滤,重边也无须特判——排序后小的先选,这就是 kruskal 皮实的地方。
