# P4779 【模板】单源最短路径(标准版)

- 专题:`06-graph` § 单源最短路
- 难度:普及+ / 提高-

## 题意

n(n ≤ 10^5)个点、m(m ≤ 2×10^5)条**有向**边,边权非负。求从点 s 到每个点的最短距离。

## 思路怎么来的

三种最短路算法先摆清楚选型:

| 算法 | 适用 | 复杂度 |
|---|---|---|
| Floyd | 多源、点少(n ≤ 500) | O(n³) |
| SPFA / Bellman-Ford | 允许负权 | 均衡 O(nm),可被卡 |
| **dijkstra + 堆** | 边权非负 | O((n+m) log n) |

本题规模 + 非负权,dijkstra 是标准解。

dijkstra 的核心是一个贪心不变量:**已确定最短距离的点集合 S,每次把"距离最小的未确定点"拉进 S,这个距离就是最终的答案**。它成立的前提正是**边权非负**——路径不可能走着走着变短回来,所以先近后远、每个点只处理一次。

朴素找最小是 O(n) 一轮,堆优化把"取最小"降到 O(log n):

1. `dist[s] = 0`,其余 ∞,(s, 0) 入堆;
2. 弹出 (u, d):若 `d > dist[u]` 说明是过期条目,跳过(**惰性删除**,小根堆不支持 decrease-key 的标准替代法);
3. 否则 u 确定,用它的所有出边 (u→v, w) 松弛:`dist[v] = min(dist[v], d + w)`,更新成功则 (v, dist[v]) 入堆。

图用 vector 邻接表存,`g[u]` 存 (v, w) 列表。

## 复杂度

每条边至多松弛成功一次、入堆一次,O((n + m) log m)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using pii = pair<ll, int>;

int n, m, s;
vector<pii> g[100005];            // g[u]: (邻点, 边权)
ll dist_[100005];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m >> s;
    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        g[u].push_back({v, w});   // 有向图只存单边
    }
    memset(dist_, 0x3f, sizeof dist_);
    dist_[s] = 0;
    priority_queue<pii, vector<pii>, greater<pii>> pq;   // 小根堆:(距离, 点)
    pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist_[u]) continue;         // 过期条目,跳过
        for (auto [v, w] : g[u]) {
            if (dist_[u] + w < dist_[v]) {
                dist_[v] = dist_[u] + w;
                pq.push({dist_[v], v});
            }
        }
    }
    for (int i = 1; i <= n; i++)
        cout << dist_[i] << " \n"[i == n];
    return 0;
}
```

## 易错点

1. **距离开 long long**:边权上限 2^31 级,一条链累加轻松爆 int;∞ 用 0x3f 起步,若担心边权和超 4×10^18 才需要换 __int128(本题不至于)。
2. **过期条目必须跳过**:`if (d > dist_[u]) continue;` 漏写不影响正确性但大幅增加堆操作,严卡常数的题会 TLE;更糟的是有人想"标记访问数组"却忘了判过期,逻辑写乱。
3. 本题是有向图,加反向边就变另一道题(反着读题是图论题第一大坑)。
4. 弱化版 P3371 可以用 SPFA 水过,**标准版会被特殊数据卡**,别拿 SPFA 套一切——dijkstra 才是非负图的正解。
