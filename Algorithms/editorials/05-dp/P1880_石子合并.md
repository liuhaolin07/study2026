# P1880 [NOI1995] 石子合并

- 专题:`05-dp` § 区间 DP(环形)
- 难度:普及+ / 提高-

## 题意

n(n ≤ 100)堆石子**围成一圈**,每次合并相邻两堆,代价为两堆石子数之和。全部合并成一堆,求最小总代价和最大总代价。

## 思路怎么来的

和合并果子(P1090)对比着学:合并果子**任意两堆**可选,贪心(小根堆)即可;本题**只能合并相邻两堆**,贪心失效(局部最优的合并可能把更优的相邻组合拆散),必须区间 DP。

区间 DP 的通用思考:最后一一定有一次合并,把序列切成左半段 [l, k] 和右半段 [k+1, r]——最终那一次的代价是整段和,与切法无关;而左右两段各自怎么合并,是**独立的子问题**。于是:

> `dp[l][r]` = 把 [l, r] 合成一堆的最小代价 = min over k (dp[l][k] + dp[k+1][r]) + sum(l..r)

按**区间长度**从小到大枚举(短的算完才能算长的),区间和用前缀和 O(1) 取。

**环形的处理**(本题与弱化版 P1775 的区别):断环成链,把数组复制一遍接在后面,长 2n。任意环形相邻关系都包含在某条长度 n 的链里。答案 = 所有起点 s ∈ [0, n) 中 `dp[s][s+n-1]` 的最值。这个"破环成链,长度翻倍"的技巧是环形问题的标准起手式。

## 复杂度

状态 O(n²),转移 O(n),总 O(n³) = 10^6(按 2n = 200 算是 8×10^6,依然轻松)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int a[205], pre[205];
int fmin_[205][205], fmax_[205][205];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        a[i + n] = a[i];                      // 破环成链:复制一遍
    }
    int N = 2 * n;
    for (int i = 1; i <= N; i++)
        pre[i] = pre[i - 1] + a[i];
    memset(fmin_, 0x3f, sizeof fmin_);
    for (int i = 1; i <= N; i++)
        fmin_[i][i] = fmax_[i][i] = 0;        // 单堆无需合并

    for (int len = 2; len <= N; len++) {
        for (int l = 1; l + len - 1 <= N; l++) {
            int r = l + len - 1;
            int cost = pre[r] - pre[l - 1];   // 最后一次合并的代价:整段和
            for (int k = l; k < r; k++) {
                fmin_[l][r] = min(fmin_[l][r], fmin_[l][k] + fmin_[k + 1][r] + cost);
                fmax_[l][r] = max(fmax_[l][r], fmax_[l][k] + fmax_[k + 1][r] + cost);
            }
        }
    }
    int ansmin = INT_MAX, ansmax = 0;
    for (int s = 1; s <= n; s++) {            // 枚举环上每个起点
        ansmin = min(ansmin, fmin_[s][s + n - 1]);
        ansmax = max(ansmax, fmax_[s][s + n - 1]);
    }
    cout << ansmin << '\n' << ansmax << '\n';
    return 0;
}
```

## 易错点

1. **不能贪心**:写个堆像合并果子那样交上去,样例都过不了——"相邻"限制改变了问题本质。
2. 枚举顺序:**外层区间长度,内层左端点,最内层分割点 k**,写反顺序会用到还没算出的状态。
3. 单堆 `dp[i][i] = 0` 别忘;fmin 初始化 0x3f,但注意本题代价都是正数,0 会错误地成为最小值候选。
4. 环形答案在"长度恰好为 n 的所有区间"里取最值,不是 `f[1][n]`(那是固定断点的链)。
5. 变量名 `fmin`/`fmax` 与 `std` 里的名字冲突(用了 using namespace std),故加下划线。
