# P1776 宝物筛选(多重背包)

- 专题:`05-dp` § 背包(多重背包)
- 难度:普及+ / 提高-

## 题意

n(n ≤ 100)种宝物,第 i 种有 c_i 件,每件重量 w_i、价值 v_i。背包容量 V(V ≤ 4×10^4),求最大价值。总件数可达 10^7 量级。

## 思路怎么来的

多重背包 = 01 背包 + "同一种有 c 件"。三种思路按代价排:

1. **拆成 c 件做 01 背包**:把第 i 种复制 c_i 遍——O(V·Σc) ≈ 4×10^4 × 10^7,必然超时。
2. **二进制拆分(本题主线)**:任何 ≤ c 的件数 k 都能写成若干个 2 的幂与一个余数之和。把 c 件拆成"1 件、2 件、4 件…… 2^(t-1) 件、余数件"这些**捆绑包**,每包当成一件新的 01 物品(重量 = 件数×w,价值 = 件数×v)。做 01 背包时"选这个包"就等于"这种宝物取这么多件",组合出 0..c 的每种取法。件数从 Σc = 10^7 骤降到 Σ⌈log c⌉ ≈ 100 × 17,总 O(V·Σlog c) ≈ 7×10^6。
3. **单调队列优化**(见延伸):严格 O(nV),多重背包的满分姿势,但代码量和细节都上一档。

二进制拆分的正确性直觉:二进制能表示一切数——1、2、4、… 覆盖所有二进制位,余数补齐高位缺口。这是"拆物品"技巧最常用的形态,务必练到能默写。

## 复杂度

O(V·Σlog c_i),约 7×10^6。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll dp[40005];

int main() {
    int n, V;
    scanf("%d %d", &n, &V);
    while (n--) {
        int v, w, c;                 // 价值、重量、数量(顺序对照题面核对)
        scanf("%d %d %d", &v, &w, &c);
        for (int k = 1; c > 0; k <<= 1) {
            int take = min(k, c);    // 捆绑 take 件当一件新物品
            c -= take;
            for (int j = V; j >= take * w; j--)      // 01 背包:倒序
                dp[j] = max(dp[j], dp[j - take * w] + (ll)take * v);
        }
    }
    printf("%lld\n", dp[V]);
    return 0;
}
```

## 易错点

1. **读入三元组顺序**:价值/重量/数量的顺序各题不一,以题面为准,写反了通常能过样例但错大半数据——提交前默念一遍每个变量的含义。
2. 拆完的每一包**仍按 01 背包倒序**枚举,正序就变成"同一包可重复选"。
3. 余数包的 `take = min(k, c)`,拆出的包件数之和必须恰好等于 c(不多不少),拿 c = 5 手玩一遍:1 + 2 + 2 ✓。
4. 价值总和可达 4×10^8,dp 数组用 long long 保险。

## 延伸

单调队列优化版:固定余数类 j ≡ r (mod w),`dp[j] = max_{0≤k≤c} dp0[j-k·w] + k·v` 是一个长度 c+1 的滑动窗口最大值,单调队列 O(1) 均摊,总 O(nV)——思路与 P1886 滑动窗口同源。另外:P1833 樱花(混合背包 = 01 + 完全 + 多重三合一,按类型分派到不同循环)、P5322 排兵布阵(分组背包)。三种背包循环方向与拆分技巧,合起来就是"背包全家桶"。
