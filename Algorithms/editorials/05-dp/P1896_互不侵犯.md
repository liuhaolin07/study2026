# P1896 [SCOI2005] 互不侵犯

- 专题:`05-dp` § 状压 DP(棋盘放置类)
- 难度:提高-

## 题意

n×n(n ≤ 9)棋盘放 k(k ≤ n²)个国王,国王攻击周围 8 格。求使所有国王互不攻击的放置方案数。

## 思路怎么来的

先看数据范围:**n ≤ 9**——这种"小到反常"的维度就是状态压缩的信号。每行的放置情况可以编码成一个 n 位二进制数(第 i 位为 1 表示这行第 i 列放了国王),一行至多 2^9 = 512 种状态,存得下、枚得动。

DP 按行推进,状态设计:

> `f[i][s][j]` = 前 i 行、第 i 行放置状态为 s、总共放了 j 个国王的方案数。

转移合法要满足两层约束:

1. **行内不冲突**:s 自身不能有相邻的 1(国王左右互攻)。这一条与行号无关,可以**预处理**出所有合法行状态,顺便存下每个状态的 popcount(该行国王数)。
2. **相邻行不冲突**:第 i 行 s 与第 i-1 行 p,逐列看 |c - d| ≤ 1 则冲突,位运算三连判:
   - `s & p` —— 正上/正下;
   - `(s << 1) & p` —— 斜向;
   - `(s >> 1) & p` —— 另一侧斜向。
   三个都为 0 才能转移。

预处理 + 位运算是状压 DP 的两大手脚架:合法性检查全部交给位运算,循环只做累加。转移方程:

> `f[i][s][j] = Σ f[i-1][p][j - cnt[s]]`(p 与 s 兼容)

初始化:第 1 行(或第 0 行视为全空)按 `f[1][s][cnt[s]] = 1`。答案 = 第 n 行所有状态的 `f[n][s][k]` 之和。

## 复杂度

合法状态约 F(n+2) 个(n = 9 时 89 个),转移 (89)² × k × n ≈ 89² × 81 × 9 ≈ 5.8×10^6,瞬间。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    cin >> n >> k;

    // 预处理:一行内的合法状态(无左右相邻)及国王数
    vector<int> states, cnt;
    for (int s = 0; s < (1 << n); s++) {
        if (s & (s << 1)) continue;              // 行内有相邻国王
        states.push_back(s);
        cnt.push_back(__builtin_popcount(s));
    }
    int T = states.size();

    // f[t][j]:当前行取 states[t]、总国王数为 j 的方案数(滚动数组)
    vector<vector<ll>> f(T, vector<ll>(k + 1, 0));
    for (int t = 0; t < T; t++)
        if (cnt[t] <= k) f[t][cnt[t]] = 1;       // 第 1 行

    for (int i = 2; i <= n; i++) {
        vector<vector<ll>> g(T, vector<ll>(k + 1, 0));
        for (int t = 0; t < T; t++) {            // 当前行状态 s
            int s = states[t];
            for (int u = 0; u < T; u++) {        // 上一行状态 p
                int p = states[u];
                if (s & p) continue;             // 上下冲突
                if ((s << 1) & p) continue;      // 对角冲突
                if ((s >> 1) & p) continue;
                for (int j = cnt[t]; j <= k; j++)
                    g[t][j] += f[u][j - cnt[t]];
            }
        }
        f = move(g);
    }

    ll ans = 0;
    for (int t = 0; t < T; t++) ans += f[t][k];
    cout << ans << '\n';
    return 0;
}
```

## 易错点

1. **行内合法性筛的是 `s & (s << 1)`**,跟相邻行冲突判定(`s & p` 等)是两码事,漏筛行内会在 n = 1 就出错。
2. 冲突三件套(上下 + 两个斜向)缺一不可;只有 `s & p` 的话对角攻击没挡住。
3. 方案数可能很大(n = 9、k 适中时已是几十亿级),用 long long。
4. k = 0 是合法输入,答案是 1(全空方案),上面初始化天然覆盖——但如果你把状态 0 从合法表里漏掉,这个边界就错了。
5. `__builtin_popcount` 返回 int,注意它数的是二进制 1 的个数,别和"最低位"混淆。
