# P1352 没有上司的舞会

- 专题:`05-dp` § 树形 DP 入门
- 难度:普及+ / 提高-

## 题意

n(n ≤ 6000)人组成一棵关系树(上下级)。每个人有快乐指数 r_i(可为负)。选一个子集开会,要求**没有人与其直接上司同时出席**。求快乐指数总和的最大值。

## 思路怎么来的

"相邻/父子不能同时选"是树形 DP 的招牌约束。树的结构天然递归:定下节点 u 选或不选,u 的整棵子树的最优值就由各孩子的子树最优值拼出来——子问题按**子树**划分,无后效性来自"孩子内部的决策不依赖父亲"。

状态设计带一维"选择状态":

> `f[u][0]` = u **不出席**时,u 子树能取得的最大快乐和;
> `f[u][1]` = u **出席**时,u 子树能取得的最大快乐和。

转移看约束:"不同时出席直接上下级"——
- u 出席 ⇒ 每个直接下属 v 必须不出席:`f[u][1] = r_u + Σ f[v][0]`;
- u 不出席 ⇒ 下属可来可不来,自由取大:`f[u][0] = Σ max(f[v][0], f[v][1])`。

答案 = `max(f[root][0], f[root][1])`。实现:邻接表存孩子(读入 k 条"v 的上司是 k",即边 k→v),DFS 后序合并;根 = 没有上司的那个人(没有被任何边指向)。

## 复杂度

每个节点、每条边各访问一次,O(n)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, r_[6005], f[6005][2], hasBoss[6005];
vector<int> ch[6005];          // ch[u]: u 的直接下属

void dfs(int u) {
    f[u][0] = 0;
    f[u][1] = r_[u];
    for (int v : ch[u]) {
        dfs(v);                               // 先算完孩子的子树
        f[u][1] += f[v][0];                   // u 来 ⇒ v 不来
        f[u][0] += max(f[v][0], f[v][1]);     // u 不来 ⇒ v 随意
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;
    for (int i = 1; i <= n; i++) cin >> r_[i];
    for (int i = 0; i < n - 1; i++) {
        int l, k;
        cin >> l >> k;                        // l 的上司是 k
        ch[k].push_back(l);
        hasBoss[l] = 1;
    }
    int root = 1;
    while (hasBoss[root]) root++;             // 唯一没有上司的即根
    dfs(root);
    cout << max(f[root][0], f[root][1]) << '\n';
    return 0;
}
```

## 易错点

1. **树的读入方式**:题目给的是 n-1 条 (职员, 上司) 边,方向别接反;找根用"从未当过孩子"的判定。
2. 转移里 `f[u][1] += f[v][0]` 用的是**加法**不是 max——所有孩子的贡献都要拿,不是挑一个。
3. 快乐指数可为负(不去可能更优),`f[u][0]` 初始化 0、`f[u][1]` 初始化 r_u,不要把负数状态错误地 clamp 成 0……准确说:f[u][1] 必须包含 r_u(来都来了),而整棵子树可以全都不来,根处取 max 已保证非负结果。
4. 变量名 `r` 与 `std::ranges` 冲突风险,同样加下划线处理。
