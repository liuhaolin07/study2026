# P5788 【模板】单调栈

- 专题:`04-data-structure` § 单调栈
- 难度:普及+ / 提高-

## 题意

n(n ≤ 3×10^6)个数,对每个 i 输出其**左边第一个**比 a_i 大的元素的下标,不存在输出 0。

## 思路怎么来的

暴力对每个 i 向左扫,O(n²) = 9×10^12,必挂。找规律:

从右往左看,若 j < k 且 a_j ≤ a_k,那么对任何 k 右边的 i,"左边第一个更大"**永远轮不到 j**——k 又更近又更大,把 j 完全挡住了。这种"被彻底挡住、再无出场机会"的元素可以**永久删除**。

于是维护一个栈,保存"还有出场机会"的下标,从栈底到栈顶值严格递减:

- 来了新数 a_i,把栈顶所有 ≤ a_i 的下标弹出(它们被 a_i 挡死);
- 弹完后栈顶(若有)就是左边第一个比 a_i 大的,即答案;
- i 自己入栈,等待被更大的数处理。

每个下标至多入栈、出栈各一次,总代价 O(n)——这就是"单调栈 O(n) 的来历"。

## 复杂度

O(n),但 n = 3×10^6,普通 cin/cout 即使关同步也悬,**必须快读快写**。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

inline int read() {
    int x = 0, f = 1;
    char c = getchar();
    while (c < '0' || c > '9') { if (c == '-') f = -1; c = getchar(); }
    while (c >= '0' && c <= '9') { x = x * 10 + c - '0'; c = getchar(); }
    return x * f;
}

inline void write(int x) {
    if (x == 0) { putchar('0'); putchar('\n'); return; }
    char b[12]; int l = 0;
    while (x) { b[l++] = '0' + x % 10; x /= 10; }
    while (l) putchar(b[--l]);
    putchar('\n');
}

int a[3000005], L[3000005];

int main() {
    int n = read();
    static int st[3000005], top = 0;          // 栈存下标,对应值严格递减
    for (int i = 1; i <= n; i++) {
        a[i] = read();
        while (top && a[st[top]] <= a[i]) top--;   // 被挡死的出栈
        L[i] = top ? st[top] : 0;
        st[++top] = i;
    }
    for (int i = 1; i <= n; i++) write(L[i]);
    return 0;
}
```

## 易错点

1. **输入输出是本题真正的考点**:3×10^6 个数,`scanf/printf` 勉强,`cin/cout` 关同步也常超,手写 getchar 版快读最稳。
2. 栈里存**下标**不是值——答案要输出位置;比较时记得套一层 `a[st[top]]`。
3. 弹栈条件是 `<=` 还是 `<` 取决于题目要"严格更大"还是"大于等于",对照题面逐字确认。
4. 大数组(3×10^6 × 4 个 int ≈ 48MB)开全局静态区,别开在 main 里爆栈。
