# P3367 【模板】并查集

- 专题:`04-data-structure` § 并查集
- 难度:普及-

## 题意

n(n ≤ 10^4)个元素,m(m ≤ 2×10^4)条操作:`1 x y` 把 x 和 y 所在集合合并;`2 x y` 查询 x、y 是否在同一集合,输出 `Y` 或 `N`。

## 思路怎么来的

维护"分组"且支持合并与查组,先想最朴素的:`belong[i]` 记录组号。查询 O(1),但合并要把一整组的 belong 全改一遍,最坏 O(n) 每次——被反复合并卡爆。

并查集的反向思路:**不维护平铺的组号,维护一片森林**。每个集合是一棵树,`fa[i]` 指向父节点,树根就是集合的代表。查询 = 沿父指针爬到根(两根相同即同集合);合并 = 把一棵树的根挂到另一棵树下,O(1)。

两个让它飞起来的优化:

1. **路径压缩**:爬到根之后,把路径上所有点直接挂到根下面。下次查询这些点一步到位。均摊接近 O(1)。
2. **按秩合并**(可选):矮树挂高树下,防止退化成链。只写路径压缩就足够过一切,两者同用是理论上界。

## 复杂度

单次操作均摊 O(α(n)),α 是反阿克曼函数,可视为常数。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int fa[10005];

int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);   // 路径压缩:找到根后顺手挂上去
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) fa[i] = i;        // 初始每个元素自成一集合
    while (m--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (op == 1) {
            fa[find(x)] = find(y);                 // x 的根挂到 y 的根下
        } else {
            cout << (find(x) == find(y) ? 'Y' : 'N') << '\n';
        }
    }
    return 0;
}
```

## 易错点

1. **初始化**:`fa[i] = i`,漏了这步全部查询都是 Y。
2. 合并写的是 `fa[find(x)] = find(y)`(根挂根),写成 `fa[x] = y` 也对但没压缩效果,还可能把已挂好的子树"截断"到错误位置——不,准确说 `fa[x]=y` 本身没错,但绕过了根,会让集合结构混乱,**必须连根**。
3. 递归 find 在数据极大时可能栈深(本题规模无所谓);卡栈场景改写成两遍循环:先找根,再二次扫路径挂根。
