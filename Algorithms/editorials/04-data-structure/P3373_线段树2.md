# P3373 【模板】线段树 2

- 专题:`04-data-structure` § 线段树(乘法 + 加法双懒标记)
- 难度:提高-

## 题意

n(n ≤ 10^5)个数,m(m ≤ 10^5)条操作,答案对 p 取模:区间乘 k;区间加 k;区间求和。

## 思路怎么来的

线段树 1 只有加法标记,本题多一个乘法,难点全部在**两个标记怎么共存**。

给标记一个统一的代数视角:节点上挂的标记表示"这段里每个数 x 都要变成 `m·x + a`"。孩子收到父亲的标记,就是把孩子的 (m', a') 与父亲的 (m, a) **复合**:

> 孩子变换 `x → m'x + a'`,再叠加父亲 `→ m(m'x + a') + a = (m·m')x + (m·a' + a)`

对照着读出复合规则:

- **再来一次乘 M**:孩子的 (m, a) → (m·M, a·M)——注意 **a 也要乘 M**;
- **再来一次加 A**:(m, a) → (m, a + A)。

约定"先乘后加"的书写顺序后,所有操作都归约为对 (m, a) 的一次更新。这就是为什么代码里乘法标记下放时,加法标记必须跟着乘:漏掉这半行,样例都过不了。

其余与线段树 1 完全同构:完全覆盖就记账(同时更新 sum 与标记),要碰孩子先 pushdown,改完孩子 pushup。初始标记是**乘法 1、加法 0**(乘法单位元),不是全 0。

## 复杂度

O((n + m) log n),常数比线段树 1 略大(取模多)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int n, m;
ll MOD, a[100005];

struct Node { ll sum, mul, add; } t[400005];

void build(int p, int l, int r) {
    t[p].mul = 1; t[p].add = 0;                // 乘法单位元初始化!
    if (l == r) { t[p].sum = ((a[l] % MOD) + MOD) % MOD; return; }
    int mid = (l + r) / 2;
    build(2 * p, l, mid); build(2 * p + 1, mid + 1, r);
    t[p].sum = (t[2 * p].sum + t[2 * p + 1].sum) % MOD;
}

void apply_tag(int p, int l, int r, ll mul, ll add) {
    t[p].sum = (t[p].sum * mul + add * (r - l + 1)) % MOD;
    t[p].mul = t[p].mul * mul % MOD;
    t[p].add = (t[p].add * mul + add) % MOD;   // 乘法会把旧 add 一起放大
}

void pushdown(int p, int l, int r) {
    int mid = (l + r) / 2;
    apply_tag(2 * p, l, mid, t[p].mul, t[p].add);
    apply_tag(2 * p + 1, mid + 1, r, t[p].mul, t[p].add);
    t[p].mul = 1; t[p].add = 0;
}

void update(int p, int l, int r, int ql, int qr, ll mul, ll add) {
    if (ql <= l && r <= qr) { apply_tag(p, l, r, mul, add); return; }
    pushdown(p, l, r);
    int mid = (l + r) / 2;
    if (ql <= mid) update(2 * p, l, mid, ql, qr, mul, add);
    if (qr > mid) update(2 * p + 1, mid + 1, r, ql, qr, mul, add);
    t[p].sum = (t[2 * p].sum + t[2 * p + 1].sum) % MOD;
}

ll query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return t[p].sum;
    pushdown(p, l, r);
    int mid = (l + r) / 2;
    ll res = 0;
    if (ql <= mid) res = query(2 * p, l, mid, ql, qr);
    if (qr > mid) res = (res + query(2 * p + 1, mid + 1, r, ql, qr)) % MOD;
    return res;
}

int main() {
    scanf("%d %d %lld", &n, &m, &MOD);
    for (int i = 1; i <= n; i++) scanf("%lld", &a[i]);
    build(1, 1, n);
    while (m--) {
        int op, x, y;
        scanf("%d %d %d", &op, &x, &y);
        if (op == 1) {
            ll k; scanf("%lld", &k);
            update(1, 1, n, x, y, ((k % MOD) + MOD) % MOD, 0);   // 乘
        } else if (op == 2) {
            ll k; scanf("%lld", &k);
            update(1, 1, n, x, y, 1, ((k % MOD) + MOD) % MOD);   // 加
        } else {
            printf("%lld\n", query(1, 1, n, x, y));
        }
    }
    return 0;
}
```

## 易错点

1. **乘法标记初始为 1**,且每个节点都要初始化——memset 成 0 会让所有乘法变 0。
2. **下放乘法时旧加法标记要跟着乘**,这是本题唯一的新知识点,也是 90% WA 的来源。
3. 负数取模:C++ 的 `%` 对负数返回负值,读入后统一 `((x % MOD) + MOD) % MOD`。
4. `add * (r - l + 1)` 与 `t[p].add * mul` 都是 10^9 × 10^9 量级,ll 必须全程。

## 延伸

把复合规则抽象出来后,线段树可以维护任意"可复合的仿射变换":区间赋值(assignment 标记,优先级高于乘加,后到的赋值直接覆盖前面的标记)、P1438 无聊的数列(区间加等差数列,标记 = 首项 + 公差)、矩阵变换(标记换成矩阵)。套路不变:**标记 = 变换,下放 = 复合**。
