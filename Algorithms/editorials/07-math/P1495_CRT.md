# P1495 【模板】中国剩余定理(CRT)/ 曹冲养猪

- 专题:`07-math` § 中国剩余定理
- 难度:提高-

## 题意

n(n ≤ 10)个同余方程 `x ≡ a_i (mod m_i)`,模数**两两互质**,求关于模 M = Πm_i 的最小非负整数解(即 [0, M) 内的唯一解)。

## 思路怎么来的

先看 1600 年前的原版,《孙子算经》"物不知数":x ≡ 2 (mod 3),x ≡ 3 (mod 5),x ≡ 2 (mod 7),答 23。古人给的口诀"三人同行七十稀":**70** 这个数是关键——它 mod 3 = 1、mod 5 = 0、mod 7 = 0。同理 21(mod 5 = 1,其余为 0)、15(mod 7 = 1,其余为 0)。于是:

> 2×70 + 3×21 + 2×15 = 233 ≡ 233 - 2×105 = 23 (mod 105)

每个方程配一个"**只在自己的模数下等于 1、其他模数下等于 0**"的基向量,加权求和就同时满足所有方程。构造方法形式化:

- `M_i = M / m_i`:它整除所有 m_j(j ≠ i),天然满足"其他模数下为 0";
- 再求 `t_i = inv(M_i mod m_i)`,即 M_i 在 mod m_i 下的逆元,`M_i·t_i ≡ 1 (mod m_i)`;
- `e_i = M_i·t_i` 就是那个基向量。

> 答案 `x ≡ Σ a_i·e_i (mod M)`

**逆元必须用 exgcd 求**(P5656),不能用费马小定理快速幂——m_i 只保证互质,不保证是质数。

## 复杂度

O(n log M)(逆元递归深度),可忽略不计。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using i128 = __int128;

ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (!b) { x = 1; y = 0; return a; }
    ll x2, y2;
    ll g = exgcd(b, a % b, x2, y2);
    x = y2;
    y = x2 - (a / b) * y2;
    return g;
}

ll inv(ll a, ll mod) {                  // gcd(a, mod) = 1
    ll x, y;
    exgcd(a, mod, x, y);
    return ((x % mod) + mod) % mod;
}

int main() {
    int n;
    scanf("%d", &n);
    vector<ll> a(n), m(n);
    for (int i = 0; i < n; i++) scanf("%lld %lld", &a[i], &m[i]);

    ll M = 1;
    for (int i = 0; i < n; i++) M *= m[i];

    i128 x = 0;
    for (int i = 0; i < n; i++) {
        ll Mi = M / m[i];
        ll t = inv(Mi % m[i], m[i]);    // M_i·t ≡ 1 (mod m_i)
        x = (x + (i128)a[i] * Mi % M * t) % M;
    }
    printf("%lld\n", (ll)(x % M));      // [0, M) 内的唯一解
    return 0;
}
```

## 易错点

1. **CRT 的适用前提是模数两两互质**——不互质时这套构造直接作废,要用 EXCRT(P4777)逐对方程合并。读题先确认这一点。
2. **溢出**:M 可达 10^18 级,`a_i·Mi`、再乘 `t` 都会爆 long long,中间量升 __int128(或写龟速乘)。
3. 逆元用 exgcd,不要条件反射写快速幂(m_i 非质数时费马小定理不成立)。
4. 输出前把结果归一到 [0, M):解在模 M 下唯一,负数或 ≥ M 都不是"最小非负"。

## 延伸

题单路线:P3868 猜数字(裸 CRT)→ P4777 EXCRT(模数不互质:两条同余方程合并成一条,exgcd 解出合并系数,解模数升为 lcm)→ P4774 屠龙勇士(EXCRT 套在打怪循环里,NOI 级应用)。CRT 的现代视角是"模数互质时,Z_M ≅ Z_m1 × … × Z_mn 的环同构"——大模数运算拆成小模数分别做再拼回来,多项式乘法取模、NTT 里反复用到这个思想。
