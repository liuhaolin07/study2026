# P3383 【模板】线性筛素数

- 专题:`07-math` § 筛法
- 难度:普及+ / 提高-

## 题意

求 1~n(n ≤ 10^8)内的所有素数,q(q ≤ 10^6)次询问,每次给 x(x ≤ n),判断是否质数。

## 思路怎么来的

方法演进(理解"为什么需要线性筛"):

1. **逐个试除**判定:单次 O(√x),q 次最坏 10^6 × 10^4 = 10^10,挂。
2. **埃氏筛**:对每个素数 p,划掉 p², p²+p, p²+2p, …。总代价 Σ n/p ≈ n·ln ln n,已经接近线性。但一个合数(如 30 = 2×3×5)会被它的**每个素因子**各划一遍,存在重复劳动。
3. **线性筛(欧拉筛)**:规定每个合数**只被它的最小素因子**划掉。做法:从小到大枚举 i,对已筛出的素数 primes[j] 划掉 i × primes[j];一旦 `i % primes[j] == 0` 立刻停——因为再往后,i × primes[j'] 的最小素因子是 primes[j] 而非 primes[j'],它应当留给更大的 i 来划。

"break 那一行"就是唯一性与线性的全部秘密:每个合数恰被划一次,总代价 O(n)。

判定查询 O(1):查 `!comp[x] && x >= 2`。

## 复杂度

筛 O(n),查询 O(q)。n = 10^8 时线性筛常数小,1 秒级可过(本题时限宽松)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100000010;
bool comp[N];              // comp[x] = true 表示 x 是合数;约 95MB,开全局
vector<int> primes;

inline int read() {        // 10^6 次询问 + 10^8 规模,统一走快读
    int x = 0;
    char c = getchar();
    while (c < '0' || c > '9') c = getchar();
    while (c >= '0' && c <= '9') { x = x * 10 + c - '0'; c = getchar(); }
    return x;
}

int main() {
    int n = read(), q = read();
    for (int i = 2; i <= n; i++) {
        if (!comp[i]) primes.push_back(i);
        for (int p : primes) {
            if ((ll)i * p > n) break;      // 越界停
            comp[i * p] = true;
            if (i % p == 0) break;         // p 已是 i*p 的最小素因子,后面的留给别人
        }
    }
    while (q--) {
        int x = read();
        puts(x < 2 || comp[x] ? "No" : "Yes");
    }
    return 0;
}
```

## 易错点

1. **内存**:n = 10^8 的 bool 数组约 95MB + 素数表 vector(π(10^8) ≈ 576 万个 int ≈ 23MB),必须开全局静态数组并确认题目空间限制;卡空间时换 `vector<bool>`(位压缩,12.5MB,代价是速度慢些)。
2. **break 的两个条件一个都不能少**:`i * p > n` 防越界(注意 i*p 用 ll 防中间溢出);`i % p == 0` 保证唯一性,删掉它退化成埃氏筛,复杂度没保障。
3. x < 2(0、1)不是素数,`puts` 的判断里要兜住。
4. 10^6 次查询用快读/scanf,别裸 cin。

## 延伸

题单路线:P1835 素数密度(区间筛)、P2043/P10495 质因数分解与阶乘分解、P2158 仪仗队(欧拉函数)。欧拉筛稍加改造(筛的时候顺便累加 φ)就能 O(n) 递推欧拉函数——线性筛的真正威力在"能同时筛出积性函数"。
