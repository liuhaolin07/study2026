# P1873 [COCI2011/2012 #5] EKO / 砍树

- 专题:`02-basics` § 贪心之后、二分答案第一题
- 难度:普及+ / 提高-

## 题意

n(n ≤ 10^6)棵树,第 i 棵高 h_i。伐木机锯片设定高度 x,每棵树得到 max(0, h_i - x) 的木材。要求木材总量**不少于** m,求 x 的最大值。

## 思路怎么来的

直接想:枚举 x 从 0 到 max(h)?x 的范围到 10^9,枚不动。但注意到一个关键的单调性:

> **x 越低,砍到的木材越多;x 越高,木材越少。**

也就是说"木材总量 ≥ m"这个条件随 x 增大**单调由成立变不成立**。函数图像是一条单调下降的阶梯——这正是"二分答案"的标准信号:答案(x)具有单调性,且给定候选答案后验证很容易(O(n) 扫一遍求和)。

于是套用二分答案模板:在 [0, max(h)] 上二分最大 x,使 check(x) = (Σ max(0, h_i - x) ≥ m) 成立。

这是二分答案三要素的教科书案例,以后看到"最大的最小 / 最小的最大 / 至少 / 至多",先想单调性。

## 复杂度

每次 check O(n),共 O(log(max h)) 次,总 O(n log V)。n = 10^6 时约 60 次扫描,轻松通过。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; ll m;
    cin >> n >> m;
    vector<ll> h(n);
    ll lo = 0, hi = 0;
    for (auto &x : h) {
        cin >> x;
        hi = max(hi, x);
    }
    // 找最大 x 使 sum(max(0, h_i - x)) >= m
    while (lo < hi) {
        ll mid = lo + (hi - lo + 1) / 2;   // 上取整防死循环
        ll sum = 0;
        for (ll x : h) if (x > mid) sum += x - mid;
        if (sum >= m) lo = mid;            // mid 可行,尝试更大
        else hi = mid - 1;                 // mid 不可行,必须更小
    }
    cout << lo << '\n';
    return 0;
}
```

## 易错点

1. **二分死循环**:求"最大可行值"时 mid 要上取整(`+1`),否则 lo = mid 分支会在 lo = hi-1 时原地踏步。记忆:求大取大,求小取小。
2. **求和爆 int**:n = 10^6 棵、每棵最高 2×10^9,总和达 2×10^15,必须 long long。
3. n = 10^6 的输入量,cin 记得关同步,或用 scanf。
