# P1102 A-B 数对

- 专题:`02-basics` § 二分查找 / `01-stl` § 哈希表
- 难度:普及-

## 题意

给一个长度为 n(n ≤ 2×10^5)的整数数组和一个数 C,求数对 (a, b) 的个数,使得 a - b = C(数对按位置计,同值不同位置算不同数对)。

## 思路怎么来的

暴力两重循环 O(n²) = 4×10^10,必然超时。把等式**变形**:a - b = C 等价于 a = b + C。于是问题变成:对每个数 b,数组里有多少个值为 b + C 的数?

"查某个值出现多少次"是哈希表(map / unordered_map)的本职:

1. 扫一遍数组,统计每个值出现的次数 `cnt[v]`;
2. 对每个不同的值 v,若 v + C 也在数组里,答案加上 `cnt[v] * cnt[v + C]`(v 作为 b,v+C 作为 a,任意位置组合)。

等价做法:排序 + 二分(对每个 b,在有序数组里二分找 [b+C, b+C] 区间长度),或排序后双指针。哈希写法最短,推荐先掌握。

## 复杂度

哈希:O(n)。排序 + 二分:O(n log n)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; ll c;
    cin >> n >> c;
    unordered_map<ll, int> cnt;
    vector<ll> a(n);
    for (auto &x : a) {
        cin >> x;
        cnt[x]++;
    }
    ll ans = 0;
    // 先把键拷出来再遍历:遍历 map 时不做插入,避免迭代器失效
    vector<pair<ll, int>> items(cnt.begin(), cnt.end());
    for (auto &[v, k] : items) {
        auto it = cnt.find(v + c);
        if (it != cnt.end()) ans += (ll)k * it->second;
    }
    cout << ans << '\n';
    return 0;
}
```

## 易错点

1. **爆 int**:n = 2×10^5,最坏答案约 4×10^10(全部相等且 C = 0 时是 n² 量级),ans 必须开 long long;值域到 ±2^30,v + C 也会溢出 int,统一用 ll。
2. **边遍历边插入**:遍历 unordered_map 的同时用 `[]` 访问不存在的键会触发插入,属于未定义行为。要么先拷贝键列表,要么用 `find`。
3. 统计的是"有序数对"(b 在前 a 在后各数一次),和题目定义一致,不要乘 2 或除 2。
