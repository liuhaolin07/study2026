# P1379 八数码难题

- 专题:`03-search` § BFS(状态空间搜索)
- 难度:提高-

## 题意

3×3 棋盘上放数字 1~8 和一个空格(输入里空格是字母 `x`)。每次移动可以把空格与上下左右相邻的数字交换。给定初始局面,求变到目标局面 `123804765`(即 1 2 3 / 8 x 4 / 7 6 5)的最少移动次数。数据保证有解。

## 思路怎么来的

这题的"图"不是题面画出来的棋盘,而是**所有局面构成的状态空间**:节点 = 一个排列,边 = 一次移动。求最少步数 → 无权最短路 → **BFS**。

三个关键点:

1. **状态怎么表示**:一个局面就是 9 个字符的字符串,直接用 `string` 当状态;空格统一读成 `'0'`(把 `x` 替换掉),目标串写成 `"123804765"`。
2. **判重怎么存**:`map<string,int>` / `unordered_map<string,int>`,值存起点到该状态的步数,兼作访问标记。9! = 362880 个排列,可接受。
3. **转移怎么生成**:找到 `'0'` 的位置 p,换算成坐标 (x, y) = (p/3, p%3),与四个方向的相邻位置交换,得到新字符串。交换的是**字符串里的两个字符**,不是坐标。

优化路线(本题不需要,但要知道):状态可经康托展开压成一个 int 排名,省掉字符串哈希;数据更大时上双向 BFS(从初始和目标同时扩散,相遇即答案,复杂度开根号)或 A*(启发函数取每个数码到目标的曼哈顿距离之和,保证可采纳)。

## 复杂度

状态 ≤ 9!/2 ≈ 1.8×10^5,每个状态 4 条出边,加上哈希开销,毫秒级。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    replace(s.begin(), s.end(), 'x', '0');     // 空格统一当 '0'
    const string target = "123804765";
    if (s == target) { cout << 0 << '\n'; return 0; }

    queue<string> q;
    unordered_map<string, int> dist;           // 步数兼访问标记
    dist[s] = 0;
    q.push(s);
    const int DX[] = {1, -1, 0, 0}, DY[] = {0, 0, 1, -1};

    while (!q.empty()) {
        string u = q.front(); q.pop();
        int d = dist[u];
        int p = u.find('0');
        int x = p / 3, y = p % 3;
        for (int i = 0; i < 4; i++) {
            int nx = x + DX[i], ny = y + DY[i];
            if (nx < 0 || nx > 2 || ny < 0 || ny > 2) continue;
            string v = u;
            swap(v[p], v[nx * 3 + ny]);        // 交换空格与相邻数字
            if (dist.count(v)) continue;
            dist[v] = d + 1;
            if (v == target) { cout << d + 1 << '\n'; return 0; }
            q.push(v);
        }
    }
    cout << -1 << '\n';                        // 题目保证有解,保险兜底
    return 0;
}
```

## 易错点

1. **输入里空格是 `x`,目标是 `0`**:两个表示必须先统一,`find('0')` 才能找到空格——这是本题最经典的 WA 原因。
2. 初始即目标时答案 0,入队前先判,否则输出成 1。
3. 移动的是空格本身(空格走到相邻格),不是"数字滑进空格"之外的其他动作,别脑补成 8 个方向。
4. 把排列逆序数的奇偶性当作可行性判断:3×3 八数码中,初始与目标的逆序数奇偶性不同则无解——题目虽保证有解,输出 -1 的分支换成这个判定可以秒掉某些变种题。
