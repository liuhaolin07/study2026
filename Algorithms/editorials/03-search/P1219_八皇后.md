# P1219 [USACO1.5] 八皇后 Checker Challenge

- 专题:`03-search` § DFS 回溯
- 难度:普及-/普及

## 题意

在 n×n(n ≤ 13)棋盘上放 n 个皇后,任意两个不同行、不同列、不同对角线。输出前 3 种方案的每行皇后列号,以及总方案数。

## 思路怎么来的

n 皇后每行恰好一个皇后(鸽笼:n 个皇后 n 行),所以方案可以表示为"第 1 行放哪列、第 2 行放哪列……"。这就是一棵搜索树:深度 = 行,分支 = 列。

DFS 框架:`dfs(row)` 枚举第 row 行放哪一列,递归到 row > n 时记录方案。关键在**冲突判定怎么做快**:

- 同列冲突:开 `col[c]` 标记该列是否已有皇后;
- 对角线冲突:棋盘上"从左上到右下"方向的对角线,格 (row, c) 满足 **row - c 为定值**;"从右上到左下"方向满足 **row + c 为定值**。开 `d1[row + c]`、`d2[row - c + n]` 两个标记数组(加 n 防止下标为负)。

三个标记数组都是 O(1) 判定,这就是剪枝:不合法的分支在放置瞬间被砍掉,而不是等全放完再检查。

回溯的核心动作:修改标记 → 递归 → **恢复标记**。"恢复现场"是回溯区别于普通递归的标志,漏掉会直接漏解。

## 复杂度

上界 O(n!),剪枝后 n = 13 瞬间跑完。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, cnt = 0;
bool col[30], d1[30], d2[30];   // 列、主对角线(row+c)、副对角线(row-c+n)
int path[30];                   // path[i] = 第 i 行皇后所在列

void dfs(int row) {
    if (row > n) {
        cnt++;
        if (cnt <= 3) {
            for (int i = 1; i <= n; i++)
                cout << path[i] << " \n"[i == n];
        }
        return;
    }
    for (int c = 1; c <= n; c++) {
        if (col[c] || d1[row + c] || d2[row - c + n]) continue;
        col[c] = d1[row + c] = d2[row - c + n] = true;
        path[row] = c;
        dfs(row + 1);
        col[c] = d1[row + c] = d2[row - c + n] = false;   // 回溯:恢复现场
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    dfs(1);
    cout << cnt << '\n';
    return 0;
}
```

## 易错点

1. **忘恢复标记**:递归返回后不清标记,搜索树后面的分支全被判冲突,答案骤减。
2. 对角线下标负数:`row - c + n` 平移到非负区间;数组开 2n 而不是 n(row + c 最大 2n)。
3. 输出格式:前 3 个方案 + 总数,列号之间空格分隔;方案必须按字典序输出——列从小到大枚举天然保证。
4. `cout << x << " \n"[i == n]` 是行尾不空格的常用写法,等价于判断是否该换行。
