## 规则

- 本目录是**课程精学线**（8 阶段 / 24 月，系统化学习，兼顾求职向训练）；竞赛冲刺主线（12 个月）见根目录 `学习路径.md`。两线内容对照、进度独立，对照表见 `学习路径.md` 第一节。
- 空目录不算完成：每阶段只有填入实际学习内容才算启动。
- 进度统一记录在 `PROGRESS.md`，模板的增删改走 `../模板/docs/MAINTENANCE.md`。
- 刷题练习优先放 `../题单/`（比特题单）和 `../比赛/`（比赛记录），这里只放课程配套练习。
