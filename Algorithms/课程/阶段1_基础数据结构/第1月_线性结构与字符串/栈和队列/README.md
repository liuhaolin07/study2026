"# 栈和队列

## 学习目标 

- [ ] 理解栈（Stack）的 LIFO 特性
- [ ] 理解队列（Queue）的 FIFO 特性
- [ ] 掌握栈和队列的数组/链表实现
- [ ] 掌握栈和队列的应用场景    

## 核心概念

### 栈
- 后进先出（LIFO）
- 操作：push, pop, top, empty
- 应用：函数调用、括号匹配、表达式求值

### 队列
- 先进先出（FIFO）
- 操作：push, pop, front, empty
- 应用：BFS、任务调度、缓存

## 代码模板

### 栈
```cpp
stack<int> s;
s.push(1);          // 入栈
int x = s.top();    // 取栈顶
s.pop();            // 出栈
s.empty();          // 判空
s.size();           // 大小
```

### 队列
```cpp
queue<int> q;
q.push(1);          // 入队
int x = q.front();  // 取队首
q.pop();            // 出队
q.empty();          // 判空
q.size();           // 大小
```

## 进阶技巧

### 单调栈
- 找到下一个更大/更小的元素
- 常用于：每日温度、接雨水

### 双端队列
- deque：两端可插入删除
- 常用于：滑动窗口最大值

## 注意事项

1. 栈为空时 pop() 或 top() 会报错，务必先判空
2. 队列 front() 和 pop() 通常成对使用
3. C++ stack 默认基于 deque 实现
