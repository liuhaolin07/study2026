# P2758 编辑距离

- 专题:`05-dp` § 经典线性(双序列)
- 难度:普及/提高-
- 对应速查:`../笔记/速查/03-DP方法论.md` § 三

## 题意

对字符串 A 只允许三种操作:删除一个字符、插入一个字符、把一个字符改成另一个。求把 A 变成 B 的最少操作次数(|A|, |B| ≤ 2000)。

## 思路怎么来的

双序列问题几乎都长一个样:状态同时描述"两个串各处理到哪"。

> `f[i][j]` = A 的前 i 个字符变成 B 的前 j 个字符的最少操作数。

转移盯住"**最后一步**"(A 的第 i 个字符与 B 的第 j 个字符怎么对上):

1. `A[i] == B[j]`:直接匹配,`f[i][j] = f[i-1][j-1]`;
2. 不相等,三选一取 min(各 +1):
   - **改**:`f[i-1][j-1] + 1`(把 A[i] 改成 B[j]);
   - **删**:`f[i-1][j] + 1`(删掉 A[i],A 前进 B 不动);
   - **插**:`f[i][j-1] + 1`(在 A 末尾插入 B[j],B 前进 A 不动)。

边界 `f[i][0] = i`(全删光)、`f[0][j] = j`(全插入)。如果一时写不出递推,先写记忆化搜索——状态和转移一模一样,只是换了个遍历方式。

## 复杂度

状态 O(nm),转移 O(1),总 O(nm) = 4×10^6。

## 参考代码

```cpp
#include <cstdio>
#include <cstring>
#include <algorithm>
using namespace std;
const int N = 2005;
int f[N][N];
char s[N], t[N];

int main() {
    scanf("%s %s", s + 1, t + 1);
    int n = strlen(s + 1), m = strlen(t + 1);
    for (int i = 0; i <= n; i++) f[i][0] = i;   // 全删光
    for (int j = 0; j <= m; j++) f[0][j] = j;   // 从空串全插入
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            if (s[i] == t[j]) f[i][j] = f[i - 1][j - 1];   // 相等免费
            else f[i][j] = min({f[i - 1][j - 1],           // 改
                                f[i - 1][j],               // 删
                                f[i][j - 1]}) + 1;         // 插
        }
    printf("%d\n", f[n][m]);
    return 0;
}
```

## 易错点

1. `s[i] == t[j]` 时**必须**直接取 `f[i-1][j-1]`,不要也 min 三种操作——相等时改/删/插都不可能更优,但混着写容易把边界带歪。
2. 边界是第 0 行/第 0 列,`strlen` 之前下标从 1 读入(`s+1`),两处约定要一致。
3. 删和插的转移下标:`删`是 `f[i-1][j]`(A 缩 B 不动),`插`是 `f[i][j-1]`(B 缩 A 不动)——从"A 变 B"的方向想清楚,别背反。
4. 2000×2000 的 int 数组 16MB,静态全局没问题;空间紧张时可滚动数组(只留两行)。
5. 本题不需要 long long(答案 ≤ n+m),但同型题算方案数时要取模。

## 延伸

- 编辑距离是双序列 DP 的母题:LCS(相等时 +0,不等时 max 两种"跳过")、最长公共上升子序列都在同一个状态框架上变形。
- 带权版本(插入/删除/替换代价不同)只需把三个 +1 换成各自代价,转移结构不变。
- 应用:diff 工具、拼写纠错、DNA 序列比对;考场上出现"最少操作把 X 变成 Y"直接联想本题。
