# P2704 [NOI2001] 炮兵阵地

- 专题:`05-dp` § 状压 DP(棋盘放置类,进阶)
- 难度:提高+/省选-

## 题意

n×m(n ≤ 100,m ≤ 10)棋盘,格子分平原(`P`)和山地(`H`),炮兵只能放平原。炮兵攻击同一行左右各 2 格、同一列上下各 2 格。求互不攻击条件下最多放多少炮兵。

## 思路怎么来的

对照互不侵犯(P1896)逐项升级,理解"什么变了":

1. **m ≤ 10 不变,但行内约束升级**:国王只挡左右 1 格,炮兵要挡左右 2 格。预处理合法状态的筛子从一个变两个:`s & (s<<1)` 和 `s & (s<<2)` 都必须为 0。合法状态数进一步缩到 60 以内。
2. **行间约束反而变简单**:国王斜向也攻击,要查 `s&p` 加两个移位;炮兵的纵向攻击**只打同一列**(上下各 2 格、不斜),所以相邻行只需 `s & p == 0`。别照搬国王的三件套,多加了约束会错。
3. **状态要多记一行**:射程纵向是 2,第 i 行的炮会打到第 i-2 行,转移要同时检查前两行。状态升成 `f[i][s][p]` = 第 i 行状态 s、第 i-1 行状态 p 时的最大炮数,转移枚举第 i-2 行状态 q,要求 `s & p == 0` 且 `s & q == 0`。

再加两个工程要点:**地形约束**(状态与该行山地掩码按位与必须为 0,读入时把每行的 `H` 压成掩码)和**滚动数组**(n ≤ 100 而 T³ ≈ 2×10^5,n·T³ ≈ 2×10^7,三维数组虽然也放得下,但滚动成 T×T 的两层是状压的肌肉记忆)。

## 复杂度

预处理 O(2^m),DP 为 O(n·T³),m = 10 时 T = 60,约 2×10^7。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m, ter[105];          // ter[i]:第 i 行山地掩码,1 = 不能放

int dp[70][70], nd[70][70];  // dp[a][b]:上一行 st[a]、当前行 st[b] 的最大炮数

int main() {
    scanf("%d %d", &n, &m);
    for (int i = 1; i <= n; i++) {
        char row[15];
        scanf("%s", row);
        for (int j = 0; j < m; j++)
            if (row[j] == 'H') ter[i] |= 1 << j;
    }
    // 预处理行内合法状态:左右 2 格内不能有另一个 1
    vector<int> st, sc;
    for (int s = 0; s < (1 << m); s++) {
        if (s & (s << 1)) continue;
        if (s & (s << 2)) continue;
        st.push_back(s);
        sc.push_back(__builtin_popcount(s));
    }
    int T = st.size();
    int z = find(st.begin(), st.end(), 0) - st.begin();   // "空行"状态的下标

    memset(dp, -1, sizeof dp);                            // -1 = 不可达
    for (int b = 0; b < T; b++)                           // 初始化第 1 行
        if (!(st[b] & ter[1])) dp[z][b] = sc[b];

    for (int i = 2; i <= n; i++) {
        memset(nd, -1, sizeof nd);
        for (int b = 0; b < T; b++) {                     // 第 i 行
            if (st[b] & ter[i]) continue;
            for (int a = 0; a < T; a++) {                 // 第 i-1 行
                if (st[b] & st[a]) continue;              // 相邻行同列冲突
                int best = -1;
                for (int q = 0; q < T; q++) {             // 第 i-2 行
                    if (dp[q][a] < 0) continue;
                    if (st[b] & st[q]) continue;          // 隔行同列冲突
                    best = max(best, dp[q][a]);
                }
                if (best >= 0) nd[a][b] = best + sc[b];
            }
        }
        memcpy(dp, nd, sizeof dp);
    }
    int ans = 0;
    for (int a = 0; a < T; a++)
        for (int b = 0; b < T; b++)
            ans = max(ans, dp[a][b]);
    printf("%d\n", ans);
    return 0;
}
```

## 易错点

1. **行内筛两档距离**:`(s<<1)` 与 `(s<<2)` 缺一个,样例过不了。
2. **行间不查斜向**:炮兵纵向只打同列,搬用国王的 `(s<<1)&p` 判定会把合法方案错杀,答案偏小。
3. **地形掩码参与两处判断**:初始化第 1 行时、以及每轮 `st[b] & ter[i]`,漏一处山地就放上炮了。
4. 用 -1 表示"该状态组合不可达",转移时跳过,防止拿垃圾值更新。

## 延伸

本题是"状压 + 滚动"的标准终点,再往后是 P10975 Mondriaan's Dream(轮廓线 DP,把状态压在**列的边界**上滚动)和插头 DP——那是省选/金牌线的内容,银牌阶段掌握到本题即可。
