# P1048 [NOIP2005 普及组] 采药

- 专题:`05-dp` § 01 背包
- 难度:普及-

## 题意

T(T ≤ 1000)单位时间,M(M ≤ 100)株草药,采第 i 株耗 t_i 时间、价值 v_i。求限时内采到的最大总价值。

## 思路怎么来的

这是所有背包问题的原型。暴力:每株药采或不采,2^100 种组合。观察:决策只有"采/不采"两种,且"剩下多少时间、还剩哪些药"确定了后续所有可能——**子问题只由 (剩余时间, 药草区间) 决定**,与之前怎么选的无关。这就是最优子结构,DP 的入场券。

四步走(每道 DP 都按这个顺序想,别跳):

1. **状态**:`dp[j]` = 考虑前 i 种药、恰好用不超过 j 时间能取到的最大价值(i 被 01 背包的滚动技巧隐去了,先看二维 `dp[i][j]`);
2. **转移**:`dp[i][j] = max(dp[i-1][j], dp[i-1][j-t_i] + v_i)`——第 i 株不采,或采(前提 j ≥ t_i);
3. **初始化**:`dp[0][j] = 0`,其余取负无穷?本题求"不超过 j"的最大值,全 0 即可;
4. **答案**:`dp[M][T]`。

空间优化:转移只依赖上一行,且 `dp[i][j]` 用到的 `dp[i-1][j-t_i]` 下标更**小**——把 j **倒序**枚举,一维数组滚动即可,`dp[j] = max(dp[j], dp[j-t_i] + v_i)`。倒序是关键:保证右边的 `dp[j-t_i]` 还是上一行(未选第 i 株)的值;正序则同一物品被重复选取,那就变成完全背包了(P1616)。

## 复杂度

O(T × M) = 10^5。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int dp[1005];   // dp[j]: 限时 j 内的最大价值

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T, m;
    cin >> T >> m;
    for (int i = 0; i < m; i++) {
        int t, v;
        cin >> t >> v;
        for (int j = T; j >= t; j--)          // 倒序!01 背包的灵魂
            dp[j] = max(dp[j], dp[j - t] + v);
    }
    cout << dp[T] << '\n';
    return 0;
}
```

## 易错点

1. **内层循环方向**是 01 背包与完全背包的唯一区别:01 倒序、完全正序。写错后者能把同一株药采无限次。
2. 循环边界 `j >= t`,防止 `j - t` 越界(也可以从 T 往下不判断,但读代码的人会疑惑)。
3. "不超过 T" 的问法初始化全 0;若问"恰好装满",dp[0]=0 其余 -∞,两者含义不同,读题要抠字。

## 延伸

题单路线:P1616 完全背包(改正序)、P1077 摆花(多重)、P1757 分组(每组互斥,多一维决策)、P1833 樱花(混合)。背包是 DP 的第一课,这题的四步分析法要沿用全年。
