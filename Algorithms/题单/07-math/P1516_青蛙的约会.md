# P1516 青蛙的约会

- 专题:`07-math` § exgcd 应用(解线性同余方程)
- 难度:提高-

## 题意

数轴上长度 L 的环(0 ~ L-1)。两只青蛙起点 x、y,每步分别跳 m、n。求最少跳多少步后两者位于同一点,无解输出 `Impossible`。数值范围到 2×10^9 量级。

## 思路怎么来的

设跳了 t 步后相遇,"同一点"在环上就是模 L 同余:

> x + t·m ≡ y + t·n (mod L)

移项整理,把 t 的系数与常数各自归并:

> t·(m − n) ≡ (y − x) (mod L)

这是**一元线性同余方程**。数论题的标准动作:把同余翻译成不定方程——存在整数 k 使得

> t·(m − n) + k·L = y − x

令 a = m − n,b = L,c = y − x,即 `a·t + b·k = c`。这就是 P5656 解过的二元一次不定方程:先 `g = gcd(|a|, |b|)`,g 不整除 c 则无解;有解时 exgcd 给出特解,t 的通解以 `L/g` 为周期,**最小非负 t** 即答案。

两个必须处理的归一化细节(都是本题的坑):

1. **m − n 可为负、可为零**:先 `a = ((m − n) % L + L) % L` 收进 [0, L),同余意义不变;若归一后 a = 0,方程退化为 0 ≡ c:能否相遇取决于两只青蛙起点是否本来就同余(答 0 / Impossible)。
2. **c 同样取模归一**,再判 `c % g`。

溢出防线:L ≤ 2.1×10^9,t 的特解与 `c/g` 各自先 mod `L/g` 再相乘,乘积 ≈ (2.1×10^9)² ≈ 4.4×10^18,恰在 long long 内;不放心就上 __int128。

## 复杂度

一次 exgcd,O(log L)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (!b) { x = 1; y = 0; return a; }
    ll x2, y2;
    ll g = exgcd(b, a % b, x2, y2);
    x = y2;
    y = x2 - (a / b) * y2;
    return g;
}

int main() {
    ll x0, y0, m, n, L;
    cin >> x0 >> y0 >> m >> n >> L;

    ll a = ((m - n) % L + L) % L;     // 系数归一到 [0, L)
    ll c = ((y0 - x0) % L + L) % L;   // 常数项归一

    if (a == 0) {                     // 相对距离每步不变
        puts(c == 0 ? "0" : "Impossible");
        return 0;
    }
    ll x, y;
    ll g = exgcd(a, L, x, y);
    if (c % g) { puts("Impossible"); return 0; }

    ll mo = L / g;                    // t 的解周期
    ll t = (x % mo) * ((c / g) % mo) % mo;
    t = (t % mo + mo) % mo;           // 最小非负
    cout << t << '\n';
    return 0;
}
```

## 易错点

1. **a = m − n 的负数/零**:不归一直接 exgcd,负 gcd、周期为负各种诡异;归一到 [0, L) 后单独分支处理 a = 0。
2. 溢出:特解 x 与 `c/g` 先各自 `% mo` 再乘,直接 `x * (c/g)` 几乎必炸 ll。
3. 无解输出的是 `Impossible`(区分大小写),不是 -1。
4. "相遇"允许 t = 0 吗?起点重合时 c = 0,输出 0 即可,公式天然覆盖。

## 延伸

本题是"同余方程 → 不定方程 → exgcd"三连的标准示范。同链练习:P1082 同余方程(裸的 ax ≡ 1 mod b)、P5656 不定方程模板、本题、P4777 EXCRT。往后所有"什么时候重合/循环几次对齐"类环形问题,第一反应都应该是列同余方程。
