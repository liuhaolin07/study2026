# P4568 飞行路线(分层图)

- 专题:`06-graph` § 分层图
- 难度:提高+/省选-
- 对应速查:`笔记/速查/04-图论选型与建图.md` § 三

## 题意

n(n ≤ 10^4)个城市、m(m ≤ 5×10^4)条双向航线,边权 w ≤ 10^4。可以**免费**乘坐至多 k(k ≤ 10)次航班。求 s 到 t 的最小总花费。

## 思路怎么来的

"至多 k 次免费"让最短路状态多了一个维度:同样在点 u,还剩几次免费,往后的最优决策不同。两步转化:

1. **状态扩展**:把 (点, 已用免费次数 j) 当作一个新节点,0 ≤ j ≤ k。这正是**分层图**——把原图复制 k+1 层,第 j 层表示"已经免费了 j 次"。
2. **连边**:
   - 层内:原图的每条边照搬,权 w(付费);
   - 跨层:u 的第 j 层连到 v 的第 j+1 层,权 0(免费坐这趟),只允许 j → j+1 **单向**升级,不允许降层。

分层图上跑堆优化 dijkstra 即可。实现上不必真把图建出来:状态 (u, j) 直接放堆里,转移时"花 w 停在本层"或"免费升一层"二选一,空间从 (k+1)·m 条边降到 (k+1)·n 个距离值。

答案不是 `dist[k][t]`——免费次数可以**不用完**,要对 j = 0..k 全取 min。

## 复杂度

状态数 (k+1)·n ≤ 11×10^4,边数每状态 2m 条转移,堆优化 dijkstra O(km·log(kn)),轻松通过。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int N = 1e4 + 5, K = 11;
const ll INF = 0x3f3f3f3f3f3f3f3fLL;

int n, m, k, s, t;
ll dist[K][N];                            // dist[j][u]:到达 u、已免费 j 次的最短路
vector<pair<int, int>> g[N];              // (邻点, 边权)

int main() {
    scanf("%d %d %d", &n, &m, &k);
    scanf("%d %d", &s, &t);
    for (int i = 0; i < m; i++) {
        int u, v, w;
        scanf("%d %d %d", &u, &v, &w);
        g[u].push_back({v, w});
        g[v].push_back({u, w});
    }
    memset(dist, 0x3f, sizeof dist);
    priority_queue<tuple<ll, int, int>, vector<tuple<ll, int, int>>, greater<>> pq;
    dist[0][s] = 0;
    pq.push({0, s, 0});
    while (!pq.empty()) {
        auto [d, u, j] = pq.top(); pq.pop();
        if (d > dist[j][u]) continue;     // 懒删除:过期状态直接扔
        for (auto [v, w] : g[u]) {
            if (d + w < dist[j][v]) {     // 决策一:付钱,停在 j 层
                dist[j][v] = d + w;
                pq.push({dist[j][v], v, j});
            }
            if (j < k && d < dist[j + 1][v]) {  // 决策二:这条边免费,升到 j+1 层
                dist[j + 1][v] = d;
                pq.push({d, v, j + 1});
            }
        }
    }
    ll ans = INF;
    for (int j = 0; j <= k; j++) ans = min(ans, dist[j][t]);
    printf("%lld\n", ans);
    return 0;
}
```

## 易错点

1. **答案是所有层取 min**,不是最后一层——免费次数"至多 k"不是"恰好 k"。
2. 免费边只从 j 层连到 j+1 层,写成"双向 0 边"或允许降层都会错(等于无限免费)。
3. 免费转移的边权是 `d` 而不是 `d + 0` 后再比较——直接 `d < dist[j+1][v]`,别画蛇添足。
4. dijkstra 要求边权非负,这里天然满足;若题面改成"免费 = 返还一半钱"之类出现负权,就得换 SPFA/Johnson。
5. 二维 dist 用 `[K][N]` 的布局比 `[N][K]` 对缓存更友好;memset 0x3f 时确认类型是 ll。
6. 显式建分层图的做法等价:总边数约 (k+1)·2m + k·2n,注意数组开够(易错点见速查表 § 五)。

## 延伸

- 分层图是"状态机最短路"的特例:把限制(次数/油量/钥匙/昼夜)编码进节点。P1073 最优贸易(两遍最短路)、P2662/ATC 相关的"剩余油量"题都是同族。
- "恰好/至多"的差异反复出现:**至多 k 次**取全层 min;若改成**恰好 k 次**只看 `dist[k][t]`。
- k 很大(如 1e9)时分层图失效,要转 DP + 凸优化(银牌边缘技巧),先把 ≤10 的小 k 写熟。
