# P8436 【模板】边双连通分量

- 专题:`06-graph` § Tarjan 无向图(边双)
- 难度:提高+/省选-
- 对应速查:`笔记/速查/04-图论选型与建图.md` § 四

## 题意

n、m 达 3×10^5 量级的无向图(可能有重边、自环),把图划分成若干**边双连通分量**——分量内任意两点之间都存在两条(边不相交的)路径,等价定义:删去任意一条边分量仍连通。输出分量个数与每个分量的点集(分量内按编号升序)。

## 思路怎么来的

边双与割点/桥是同一个故事的两个视角:**桥**是删掉后图不连通的边;把所有桥删掉,剩下的每个连通块恰好就是一个边双。这个等价关系直接给出两步算法:

1. **Tarjan 求桥**:树边 (u,v) 是桥 ⟺ `low[v] > dfn[u]`(子树连 u 自己都绕不回去)。**重边必须用边编号区分**:跳过"进来的那条边"(`ine ^ 1`,链式前向星成对存边,异或 1 即反向边),其余到父亲的平行边照常更新 low——两条平行边意味着"删一条还在",那条边一定不是桥。
2. **删桥染色**:对每个未标记点 DFS,**不走桥**,一次可达的全部点就是同一个边双。

比起单遍 Tarjan 弹栈的写法,两遍版更慢一点常数,但每一步都能独立验证、独立讲清楚,适合当第一份实现;单遍版(维护栈,`low[u]==dfn[u]` 时弹出)学有余力再写。

## 复杂度

两遍 DFS,各 O(n + m),总 O(n + m)。m、n 到 3×10^5,递归深度同阶,洛谷默认栈一般可过,保险起见可改显式栈或调大栈。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 3e5 + 5, M = N << 1;       // 无向图边数 ×2
int n, m;
int head[N], nxt[M], to[M], cnt = 1;     // 边从 2 开始成对存:e 与 e^1 互为反向边
int dfn[N], low[N], timer;
bool bridge[M];                          // 桥标记打在两条有向边上
int comp[N];
vector<vector<int>> comps;

void add(int u, int v) { to[++cnt] = v; nxt[cnt] = head[u]; head[u] = cnt; }

void tarjan(int u, int ine) {            // ine:进入 u 的边的编号(防重边)
    dfn[u] = low[u] = ++timer;
    for (int e = head[u]; e; e = nxt[e]) {
        int v = to[e];
        if (!dfn[v]) {
            tarjan(v, e);
            low[u] = min(low[u], low[v]);
            if (low[v] > dfn[u]) bridge[e] = bridge[e ^ 1] = true;  // 树边是桥
        } else if (e != (ine ^ 1)) {     // 只跳过"刚进来的那条边",平行边要更新 low
            low[u] = min(low[u], dfn[v]);
        }
    }
}

void dfs(int u) {                        // 不经过桥,收集当前边双
    comp[u] = comps.size();
    comps.back().push_back(u);
    for (int e = head[u]; e; e = nxt[e]) {
        int v = to[e];
        if (bridge[e] || comp[v]) continue;
        dfs(v);
    }
}

int main() {
    scanf("%d %d", &n, &m);
    for (int i = 0; i < m; i++) {
        int u, v;
        scanf("%d %d", &u, &v);
        add(u, v); add(v, u);
    }
    for (int i = 1; i <= n; i++)
        if (!dfn[i]) tarjan(i, 0);        // 根调用 ine=0,e^1=1 不会撞上真实边
    for (int i = 1; i <= n; i++)
        if (!comp[i]) { comps.emplace_back(); dfs(i); }
    for (auto &c : comps) sort(c.begin(), c.end());   // 分量内按编号升序
    printf("%d\n", (int)comps.size());
    for (auto &c : comps) {
        printf("%d ", (int)c.size());     // 本题判定对分量顺序有 SPJ
        for (int i = 0; i < (int)c.size(); i++)
            printf("%d%c", c[i], " \n"[i + 1 == (int)c.size()]);
    }
    return 0;
}
```

## 易错点

1. **边从 2 开始成对存**(`cnt = 1`),`e ^ 1` 才正好是反向边;从 0 开始存会把 `e^1` 撞到 1 号上出错。
2. 求桥判 `low[v] > dfn[u]`(严格大于);割点判 `low[v] >= dfn[u]`,两个条件只差一个等号,别混。
3. 重边是本题的核心陷阱:必须传**边编号**跳过反向边,而不是跳过父节点——否则两条平行边会被当成"回到父亲"全跳过,把桥误判出来。
4. `bridge` 打在**成对的两侧**(`e` 和 `e^1`),染色时从任一侧看都挡得住。
5. 图可能不连通,两遍都要全点循环;分量内点集排序后再输出。
