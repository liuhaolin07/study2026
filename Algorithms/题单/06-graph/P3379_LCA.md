# P3379 【模板】最近公共祖先(LCA)

- 专题:`06-graph` § 树上倍增
- 难度:提高-

## 题意

n(n ≤ 5×10^5)个点、n-1 条边的树,以 1 为根,q(q ≤ 5×10^5)次询问两点 u, v 的最近公共祖先。

## 思路怎么来的

朴素做法:两点各自一步步往上跳,先跳到同一深度,再手拉手一起往上,相遇即 LCA——每次询问最坏 O(n),链状树直接被卡死。

倍增的思路与快速幂同源:**把"跳一步"改造成"跳 2^k 步"**。预处理 `fa[k][u]` = u 往上跳 2^k 步到达的祖先(fa[0][u] 是父亲,越界记 0),它满足倍增递推:

> `fa[k][u] = fa[k-1][ fa[k-1][u] ]` —— 跳 2^k 步 = 先跳 2^(k-1),再跳 2^(k-1)。

预处理 O(n log n) 后,每次询问分两步,各 O(log n):

1. **对齐深度**:把深的点按深度差的二进制分解往上跳,与浅点同层;
2. **齐步上跳**:k 从大到小试,若 `fa[k][u] != fa[k][v]` 就一起跳——跳过头的风险被"不等才跳"挡住,最终两点停在 LCA 的直接孩子上,答案即 `fa[0][u]`。

工程上最大的坑是**递归 DFS 爆栈**:5×10^5 深的链,递归深度同样 5×10^5,默认栈必炸。改用 **BFS** 求深度和父节点(队列天然按层序,父亲先于孩子出队),空间也省。

## 复杂度

预处理 O(n log n),单次询问 O(log n),总 O((n + q) log n)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int LOG = 20;                     // 2^19 > 5*10^5
int n, q;
vector<int> g[500005];
int dep[500005], fa[LOG][500005];
int Q_[500005];                          // BFS 队列(名字避开 std 冲突)

int main() {
    scanf("%d %d", &n, &q);
    for (int i = 0; i < n - 1; i++) {
        int u, v;
        scanf("%d %d", &u, &v);
        g[u].push_back(v);
        g[v].push_back(u);
    }
    // BFS 求深度与父节点:防链状树递归爆栈
    int head = 0, tail = 0;
    dep[1] = 1;
    Q_[tail++] = 1;
    fa[0][1] = 0;                        // 越过根 = 0
    while (head < tail) {
        int u = Q_[head++];
        for (int v : g[u]) {
            if (v == fa[0][u]) continue;
            fa[0][v] = u;
            dep[v] = dep[u] + 1;
            Q_[tail++] = v;
        }
    }
    for (int k = 1; k < LOG; k++)
        for (int u = 1; u <= n; u++)
            fa[k][u] = fa[k - 1][fa[k - 1][u]];

    while (q--) {
        int a, b;
        scanf("%d %d", &a, &b);
        if (dep[a] < dep[b]) swap(a, b);            // 保证 a 更深
        int d = dep[a] - dep[b];
        for (int k = 0; k < LOG; k++)
            if (d >> k & 1) a = fa[k][a];           // 按二进制跳到同层
        if (a == b) { printf("%d\n", a); continue; } // 本来就是祖先关系
        for (int k = LOG - 1; k >= 0; k--)          // 从大步往小试
            if (fa[k][a] != fa[k][b]) { a = fa[k][a]; b = fa[k][b]; }
        printf("%d\n", fa[0][a]);
    }
    return 0;
}
```

## 易错点

1. **爆栈**:n = 5×10^5 的链上递归 DFS 必炸,BFS 或显式栈是必会写法。
2. 对齐深度后**先判 a == b**(一方本是另一方祖先),漏判会答成父亲。
3. 齐跳阶段 k **从大到小**,从小到大会直接跳过头。
4. `fa[*][0] = 0` 的越界约定要贯穿:跳过根得到 0,0 不参与比较也不越数组。
5. 内存:`fa[20][5×10^5]` 约 40MB,注意题目空间限制;卡内存时换链式前向星存图并精简 LOG。
6. q 到 5×10^5,读入用 scanf/快读。

## 延伸

LCA 是树上一切问题的地基:题单路线 P3398 仓鼠找 sugar → P1967 货车运输(最大生成树 + 倍增跳最小边)→ P3128 Max Flow(树上差分,LCA 处 +2、两端 +1)→ P2680 运输计划(树上差分 + 二分答案,银牌压轴水准)。另有 O(1) 查询的 Euler 序 + ST 表写法,询问极多时再学。
