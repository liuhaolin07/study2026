# P3128 [USACO15DEC] Max Flow P

- 专题:`06-graph` § 树上差分(点差分)
- 难度:提高+ / 省选-

## 题意

n(n ≤ 5×10^4)个点的树,给出 K(K ≤ 10^5)条路径(s_i, t_i),每条路径上的每条边流量 +1。求流量最大的边上的流量。

## 思路怎么来的

暴力:每条路径沿树走一遍,O(nK) ≈ 5×10^9,超时。回忆**数组差分**的做法:区间 [l, r] 整体 +1,只需 `d[l]++, d[r+1]--`,最后前缀和一遍还原——把 O(区间长) 的修改压成 O(1)。

树上的路径怎么套?把路径 s → t 拆成两段**竖直链**:s → lca 与 t → lca。竖直链的本质是"从根往下的前缀"——给从根到 s 这条链整体 +1,在树上等价于在 s 处 +1,求和时它会沿着祖先方向一路累加(子树和);而要"截止"在 lca,就在 lca 处 -1 抵消。于是点差分四连:

> `d[s]++`、`d[t]++`、`d[lca]--`、`d[fa(lca)]--`

最后自底向上做**子树和**(某个点的累加值 = 它子树里所有 d 之和),而 `u 子树和` 恰好等于"边 (u, fa[u]) 被覆盖的次数"——因为 u 子树里的任何 +1 都意味着对应路径穿过了这条父子边。

实现两个工程点:LCA 用倍增(P3379 原样搬来);子树和**不用递归**,利用 BFS 序的性质——父节点一定比孩子先入队,**倒序扫 BFS 队列**,把每个点的值加给父亲,一遍完成自底向上累加。

## 复杂度

预处理 O(n log n),K 次询问 LCA O(K log n),累加 O(n),总 O((n + K) log n)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int LOG = 17;
int n, k;
vector<int> g[50005];
int dep[50005], f[LOG][50005], df[50005], Q_[50005];

int lca(int a, int b) {
    if (dep[a] < dep[b]) swap(a, b);
    int d = dep[a] - dep[b];
    for (int i = 0; i < LOG; i++)
        if (d >> i & 1) a = f[i][a];
    if (a == b) return a;
    for (int i = LOG - 1; i >= 0; i--)
        if (f[i][a] != f[i][b]) { a = f[i][a]; b = f[i][b]; }
    return f[0][a];
}

int main() {
    scanf("%d %d", &n, &k);
    for (int i = 0; i < n - 1; i++) {
        int u, v;
        scanf("%d %d", &u, &v);
        g[u].push_back(v);
        g[v].push_back(u);
    }
    int head = 0, tail = 0;
    dep[1] = 1;
    Q_[tail++] = 1;
    while (head < tail) {
        int u = Q_[head++];
        for (int v : g[u]) {
            if (v == f[0][u]) continue;
            f[0][v] = u;
            dep[v] = dep[u] + 1;
            Q_[tail++] = v;
        }
    }
    for (int i = 1; i < LOG; i++)
        for (int u = 1; u <= n; u++)
            f[i][u] = f[i - 1][f[i - 1][u]];

    for (int i = 0; i < k; i++) {
        int s, t;
        scanf("%d %d", &s, &t);
        int l = lca(s, t);
        df[s]++; df[t]++; df[l]--;
        if (f[0][l]) df[f[0][l]]--;      // lca 的父亲是根(0)时跳过
    }
    for (int i = tail - 1; i >= 1; i--) { // BFS 序倒序 = 先孩子后父亲
        int u = Q_[i];
        df[f[0][u]] += df[u];             // 子树和向父亲汇总
    }
    int ans = 0;
    for (int u = 2; u <= n; u++)          // 每条边对应一个非根点
        ans = max(ans, df[u]);
    printf("%d\n", ans);
    return 0;
}
```

## 易错点

1. **四个修改位置一个不能少**:最容易漏 `df[fa(lca)]--`。少它的话,lca 到根的整条链也被 +1,答案虚高。
2. `f[0][l] == 0`(lca 是根)时没有父亲可减,要跳过。
3. 汇总必须**倒序**扫 BFS 序;正序等于父还没收齐孩子的值就上交了。
4. 答案在**非根节点**的子树和里取(根没有父边),从 2 开始扫是靠"根固定为 1"成立,通用写法是 `u != 根`。
5. 倍增表建一次,K 条路径反复查,别把预处理写进询问循环。

## 延伸

**边差分**是孪生技巧:路径 s→t 的每条边 +1,只需 `d[s]++, d[t]++, d[lca] -= 2`(lca 处的两条竖直链在此汇合终止)。对照记忆:点差分四个点、边差分三个点。题单路线:P3258 松鼠的新家(点差分 + 一点偏移修正)、P10931 闇の連鎖(边差分统计)、终点是 P2680 运输计划(边差分 + 二分答案,银牌压轴题的标配组合)。
