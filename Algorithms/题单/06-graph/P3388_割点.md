# P3388 【模板】割点

- 专题:`06-graph` § Tarjan 无向图(割点/桥)
- 难度:提高
- 对应速查:`笔记/速查/04-图论选型与建图.md` § 四

## 题意

n(n ≤ 2×10^4)个点、m(m ≤ 1×10^5)条边的无向图,求所有**割点**——删去后图连通块个数增加的点。输出割点个数与编号(升序)。

## 思路怎么来的

暴力:删每个点跑一遍连通性,O(n(n+m)) 必炸。需要一次 DFS 把所有割点找出来。

DFS 生成树给了关键结构:一条边要么是**树边**,要么是**返祖边**(连向祖先)。于是定义时间戳:

> `dfn[u]`:u 被 DFS 到的次序;`low[u]`:u 及其子树中,通过返祖边能回到的**最早**时间戳。

- **非根 u 是割点** ⟺ 存在一棵子树 v,`low[v] ≥ dfn[u]`——v 这一整块想出去只能"穿过" u,绕不到 u 的任何祖先。注意是 `≥` 不是 `>`:能回到 u 自己(相等)也不行,因为删的就是 u。
- **根是割点** ⟺ 在 DFS 树上有 ≥ 2 棵子树(根没有"祖先"可比,只能数孩子;根-孩子的重边不算第二棵子树,`child` 只在树边分支累加)。

一次 DFS 全部得出,O(n + m)。

## 复杂度

Tarjan 一遍 O(n + m)。递归深度 = n ≤ 2×10^4,洛谷默认栈可过;图更大时改显式栈(参照 P3379 的教训)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 2e4 + 5, M = 2e5 + 5;      // 无向图边数 ×2
int n, m;
int head[N], nxt[M], to[M], cnt;
int dfn[N], low[N], timer;
bool cut[N];

void add(int u, int v) { to[++cnt] = v; nxt[cnt] = head[u]; head[u] = cnt; }

void tarjan(int u, int fa, int root) {
    dfn[u] = low[u] = ++timer;
    int child = 0;                        // 只统计树边孩子
    for (int e = head[u]; e; e = nxt[e]) {
        int v = to[e];
        if (!dfn[v]) {                    // 树边
            child++;
            tarjan(v, u, root);
            low[u] = min(low[u], low[v]);
            if (u != root && low[v] >= dfn[u]) cut[u] = true;  // 子树绕不过 u
        } else if (v != fa) {             // 返祖边:更新为 dfn[v](不是 low[v])
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (u == root && child >= 2) cut[root] = true;             // 根:两棵独立子树
}

int main() {
    scanf("%d %d", &n, &m);
    for (int i = 0; i < m; i++) {
        int u, v;
        scanf("%d %d", &u, &v);
        add(u, v); add(v, u);
    }
    for (int i = 1; i <= n; i++)
        if (!dfn[i]) tarjan(i, 0, i);     // 图可能不连通
    vector<int> ans;
    for (int i = 1; i <= n; i++) if (cut[i]) ans.push_back(i);
    printf("%d\n", (int)ans.size());
    for (int i = 0; i < (int)ans.size(); i++)
        printf("%d%c", ans[i], " \n"[i + 1 == (int)ans.size()]);
    return 0;
}
```

## 易错点

1. **返祖边更新 low 用 `dfn[v]`**,不要顺手写成 `low[v]`(本题碰巧多数不错,但对桥类问题会错,统一用 dfn 更稳)。
2. 跳过父亲用 `v != fa` 判定即可——割点判定里,重边到父亲不会造成误判(low[v] 最多回到 dfn[u],`≥` 依然成立);**但求桥必须改用边编号**,见 P8436。
3. 根节点的判定走的是另一条分支(数树边孩子),`child` 不要在返祖边分支里累加。
4. 图**可能不连通**,要对每个未访问点各跑一遍 Tarjan。
5. 链式前向星边数组开 `2*m`;输出行末空格用 `" \n"[i+1==size]` 技巧。

## 延伸

- 同族的**桥**(删去后图不连通的边):判定改为 `low[v] > dfn[u]`,且必须用边编号防重边 → P8436 边双连通分量。
- **点双连通分量**:栈辅助 Tarjan,弹出时机在割点判定处;圆方树(选学)是它的进阶应用。
- 应用场景:网络可靠性(关键路由)、P3469 BLO-Blockade(割点删去后各有序对计数,割点判定 + 子树大小)。
