# P1967 [NOIP2013 提高组] 货车运输

- 专题:`06-graph` § 最大生成树 + 倍增 LCA(维护路径最小边)
- 难度:提高+ / 省选-

## 题意

n(n ≤ 10^4)座城市、m(m ≤ 5×10^4)条双向道路,每条有限重 w。一辆车走某条路径,载重不能超过路径上所有边的最小限重。q(q ≤ 3×10^4)次询问:从 x 到 y 最多能运多重的货物;不连通输出 -1。

## 思路怎么来的

先想清楚"最优路径"长在哪:每次询问要的是**瓶颈最大**的路径(最大化路径最小边)。关键结论:

> 全图任意两点间瓶颈最大的路径,一定存在于**最大生成树**上。

原因与 kruskal 本身同构:把边按权从大到小加入,当 x、y 第一次连通时,连通它们的这条路径上全是"前几大"的边,任何其他路径都必须用到更晚加入(更小)的边。于是非树边对答案永远无用,图可以安全缩成最大生成树(n ≤ 10^4 个点、n-1 条边,还是森林——不连通的询问直接用并查集判)。

剩下的问题:**树上路径的最小边**。在倍增 LCA 的骨架上加一维信息——`mn[k][u]` = u 向上跳 2^k 步经过边的最小权,与 `f[k][u]` 一样满足倍增递推:

> `mn[k][u] = min(mn[k-1][u], mn[k-1][ f[k-1][u] ])`

查询时,深度对齐和齐步上跳的每一步都顺手 min 进答案。**"LCA 不止求祖先,还能顺路维护路径信息(最小/最大/和)"**,这是倍增 LCA 真正的用法,后面树上差分、路径统计全靠它。

## 复杂度

排序 O(m log m),建树 O(m α),倍增表 O(n log n),每次询问 O(log n),总 O(m log m + (n + q) log n)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int LOG = 14, INF = 0x3f3f3f3f;
int n, m;

struct Edge { int u, v, w; };
int fa_[10005];
int find(int x) { return fa_[x] == x ? x : fa_[x] = find(fa_[x]); }

int dep[10005], f[LOG][10005], mn[LOG][10005];
vector<pair<int, int>> t[10005];      // 生成树邻接:(邻点, 边权)
int Q_[10005];

int main() {
    scanf("%d %d", &n, &m);
    vector<Edge> e(m);
    for (auto &x : e) scanf("%d %d %d", &x.u, &x.v, &x.w);
    sort(e.begin(), e.end(), [](const Edge &a, const Edge &b) { return a.w > b.w; });

    for (int i = 1; i <= n; i++) fa_[i] = i;
    for (auto &x : e) {                       // kruskal 建最大生成树(森林)
        int ru = find(x.u), rv = find(x.v);
        if (ru == rv) continue;
        fa_[ru] = rv;
        t[x.u].push_back({x.v, x.w});
        t[x.v].push_back({x.u, x.w});
    }
    // 森林 BFS:每个连通块各跑一次,建深度 / 父亲 / 父边权
    memset(mn, 0x3f, sizeof mn);              // mn[*][0] 保持 INF,跳过根不误伤
    int head = 0, tail = 0;
    for (int s = 1; s <= n; s++) {
        if (dep[s]) continue;
        dep[s] = 1;
        Q_[tail++] = s;
        while (head < tail) {
            int u = Q_[head++];
            for (auto [v, w] : t[u]) {
                if (v == f[0][u]) continue;
                f[0][v] = u; mn[0][v] = w; dep[v] = dep[u] + 1;
                Q_[tail++] = v;
            }
        }
    }
    for (int k = 1; k < LOG; k++)
        for (int u = 1; u <= n; u++) {
            f[k][u] = f[k - 1][f[k - 1][u]];
            mn[k][u] = min(mn[k - 1][u], mn[k - 1][f[k - 1][u]]);
        }

    int q;
    scanf("%d", &q);
    while (q--) {
        int a, b;
        scanf("%d %d", &a, &b);
        if (find(a) != find(b)) { puts("-1"); continue; }
        int res = INF;
        if (dep[a] < dep[b]) swap(a, b);
        int d = dep[a] - dep[b];
        for (int k = 0; k < LOG; k++)
            if (d >> k & 1) { res = min(res, mn[k][a]); a = f[k][a]; }
        if (a == b) { printf("%d\n", res); continue; }
        for (int k = LOG - 1; k >= 0; k--)
            if (f[k][a] != f[k][b]) {
                res = min({res, mn[k][a], mn[k][b]});
                a = f[k][a]; b = f[k][b];
            }
        res = min({res, mn[0][a], mn[0][b]});   // 最后各跳一步到 LCA
        printf("%d\n", res);
    }
    return 0;
}
```

## 易错点

1. **排序方向**:最大生成树要**降序**排,习惯性写 `a.w < b.w` 就变成最小生成树,样例直接错。
2. **不连通输出 -1**:判连通用并查集 `find(a) != find(b)`,别在原图的邻接表上判(建完树原边就没用了)。
3. `mn` 数组预填充 INF(`memset 0x3f`),让"跳过根"的哑节点保持 INF,不会把答案拉低。
4. 生成树是**森林**,BFS 要对每个连通块各起一次,否则部分点深度为 0,倍增查询全乱。
5. 齐跳结束后**还要各跳一步**到 LCA 本身,这一步的边权容易漏 min。

## 延伸

同一骨架的变体:P2330 繁忙的都市(最小化最大边)、题单里的 P4180 严格次小生成树(树上倍增维护最大/严格次大边,替换环上最大边)、P2680 运输计划(树上差分 + 二分答案,把本题的"查瓶颈"升级成"删一条边优化瓶颈")。kruskal 重构树则是这一族问题的终极抽象(边权变成点权,LCA 的点权即路径瓶颈)。
