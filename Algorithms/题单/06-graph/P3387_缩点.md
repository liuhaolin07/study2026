# P3387 【模板】缩点

- 专题:`06-graph` § Tarjan 强连通分量 + DAG 上 DP
- 难度:提高+ / 省选-

## 题意

n(n ≤ 10^4)个点、m(m ≤ 10^4)条有向边,点权 a_i。找一条路径(点可重复经过,权只算一次)使路径上点和最大。

## 思路怎么来的

"可反复经过"是题眼:**同一个强连通分量(SCC)里的点彼此可达,进去就能全逛一遍**——所以每个 SCC 可以坍缩成一个"超级点",权 = 成员权之和。缩点后的图是 DAG(有向无环),原题变成:

> DAG 上找一条路径,使经过的超级点权和最大。

DAG 上没有环,最长路 DP 一遍拓扑序即可:`f[u] = w[u] + max(f[v])`(v 为指向 u 的前驱),答案取所有 f 的最大值。整题分三步:

1. **Tarjan 求 SCC**。核心是两个数组:`dfn[u]`(首次访问时间戳)、`low[u]`(u 经子孙回边/横叉边能回到的最早祖先的 dfn)。递归访问,树边用孩子的 low 更新,返祖边/横叉边(指向栈中的点)用对方 dfn 更新;当 `dfn[u] == low[u]`,u 与栈中其后元素构成一个 SCC,弹栈标号。
2. **缩点建新图**:对每条原边 u→v,若 `bel[u] != bel[v]`,连 `bel[u] → bel[v]` 并统计入度(重边无害)。
3. **拓扑序(Kahn)DP**:入度 0 的超级点先入队,出队时它 DP 值已定,去松弛后继。

Tarjan 的 low 数组是全场最难啃的细节,记忆锚点:**树边传 low,回边比 dfn,横叉边只在"对方还在栈里"时比 dfn**。

## 复杂度

Tarjan 与缩点、拓扑均线性,O(n + m)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int n, m, a[10005];
vector<int> g[10005];
int dfn[10005], low[10005], timer_ = 0;
int stk[10005], top_ = 0, sccid = 0, bel[10005];
bool ins[10005];
ll w[10005];
vector<int> G[10005];          // 缩点后的 DAG
int indeg[10005];

void tarjan(int u) {
    dfn[u] = low[u] = ++timer_;
    stk[++top_] = u; ins[u] = true;
    for (int v : g[u]) {
        if (!dfn[v]) {
            tarjan(v);                          // 树边:用孩子的 low
            low[u] = min(low[u], low[v]);
        } else if (ins[v]) {                    // 只认还在栈里的点
            low[u] = min(low[u], dfn[v]);
        }
    }
    if (dfn[u] == low[u]) {                     // u 是所在 SCC 的根
        sccid++;
        while (true) {
            int v = stk[top_--];
            ins[v] = false;
            bel[v] = sccid;
            w[sccid] += a[v];
            if (v == u) break;
        }
    }
}

int main() {
    scanf("%d %d", &n, &m);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
    for (int i = 0; i < m; i++) {
        int u, v;
        scanf("%d %d", &u, &v);
        g[u].push_back(v);
    }
    for (int i = 1; i <= n; i++)
        if (!dfn[i]) tarjan(i);                 // 图可能不连通

    for (int u = 1; u <= n; u++)
        for (int v : g[u])
            if (bel[u] != bel[v]) {
                G[bel[u]].push_back(bel[v]);
                indeg[bel[v]]++;
            }

    queue<int> q;
    vector<ll> f(sccid + 1);
    for (int c = 1; c <= sccid; c++) {
        f[c] = w[c];                            // 路径至少含自己
        if (!indeg[c]) q.push(c);
    }
    ll ans = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        ans = max(ans, f[u]);
        for (int v : G[u]) {
            f[v] = max(f[v], f[u] + w[v]);      // u 的 DP 值已定,松弛后继
            if (--indeg[v] == 0) q.push(v);
        }
    }
    printf("%lld\n", ans);
    return 0;
}
```

## 易错点

1. **横叉边必须判 `ins[v]`**:指向已弹出 SCC 的点不能更新 low,这是 Tarjan 最常见的错。
2. 树边更新用 `low[v]`,非树边用 `dfn[v]`,两者混用直接错——口诀"树边 low,边边 dfn"。
3. 弹 SCC 用 `do-while` 语义:从栈顶弹到 u **本身**为止(u 也要弹出)。
4. 图不连通时要对每个未访问点跑 Tarjan;Kahn DP 的初值 `f[c] = w[c]` 别设 0(路径不能为空)。
5. 名字避开 `stack`、`time` 等 std/保留标识符。

## 延伸

Tarjan 一族:P3388 割点、桥(无向图版本,low 的更新规则要排除"来的那条边")、P8436 边双。应用侧的经典:P2341 [USACO03FALL] 受欢迎的牛(缩点后判出度为 0 的分量是否唯一)、P2746 [USACO5.3] 校园网络(缩点 + 入度/出度统计)。**"有环 → 缩点变 DAG → 拓扑 DP"** 是图论 DP 的标准开局。
