# 题单(比特题单 + 内嵌题解库)

每个专题目录 = **题单**(`README.md`,题目清单)+ **题解**(同目录下的 `P*.md` 经典题详解)。题解与题目在同一目录,做题时顺手可查。

## 题解使用规则(重要)

1. **先做题,再看详解**:独立思考至少 30~40 分钟,实在没思路才打开对应文件。
2. 看懂思路后**关掉文档自己重写**,能独立 AC 才算掌握。
3. 凡是看了解析才做出的题,照例记入 `../笔记/redo-list.md`,一周后重做。
4. 题解结构:题意 → 思路怎么来的 → 复杂度 → 参考代码(已编译验证)→ 易错点 → 延伸。
