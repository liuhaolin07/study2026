# P1886 滑动窗口 /【模板】单调队列

- 专题:`04-data-structure` § 单调队列
- 难度:普及/提高-
- 对应速查:`../笔记/速查/02-数据结构选型.md` § 五

## 题意

n(n ≤ 10^6)个数,窗口长度 k。窗口从最左滑到最右,输出每次窗口内的**最小值**与**最大值**各一行。

## 思路怎么来的

暴力每个窗口 O(k),总 O(nk) = 10^12 必炸。观察:窗口右移时,只有"新进来的数"和"过期的数"影响最值——需要一种结构,既知道当前最值,又能 O(1) 删头、O(1) 加尾。

**单调队列**:队列里存**下标**,值保持单调。以最小值为例,队列从队头到队尾严格递增:

- **加尾**:新数 a[i] 来了,把队尾所有 ≥ a[i] 的都弹掉——它们比 a[i] 老(下标小)又比它大,只要 a[i] 在,它们永远当不上最小值,"未老先衰"直接淘汰;
- **删头**:队头下标滑出窗口(i-k)就丢;
- 队头永远是窗口最小值。

每个元素至多进队一次、出队一次,**均摊 O(1)**,总 O(n)。求最大值把比较方向反过来(递减队列)。

## 复杂度

O(n)。这是"每个元素最多进出队一次"的均摊分析第一次登场,后面 dijkstra 懒删除、KMP 失配跳转都是同一套论证。

## 参考代码

```cpp
#include <cstdio>
const int N = 1e6 + 5;
int n, k, a[N], q[N], h, t;               // q 存下标,有效区间 [h, t)

int main() {
    scanf("%d %d", &n, &k);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
    h = t = 0;
    for (int i = 1; i <= n; i++) {        // 最小值:递增队列
        while (t > h && a[q[t - 1]] >= a[i]) t--;   // 队尾 >= 新数,弹出
        q[t++] = i;
        if (q[h] <= i - k) h++;           // 队头滑出窗口
        if (i >= k) printf("%d%c", a[q[h]], i == n ? '\n' : ' ');
    }
    h = t = 0;
    for (int i = 1; i <= n; i++) {        // 最大值:递减队列
        while (t > h && a[q[t - 1]] <= a[i]) t--;
        q[t++] = i;
        if (q[h] <= i - k) h++;
        if (i >= k) printf("%d%c", a[q[h]], i == n ? '\n' : ' ');
    }
    return 0;
}
```

## 易错点

1. **存下标不存值**:过期判断需要下标,只存值就没了淘汰依据。
2. 弹队尾的等号方向:最小值队列弹 `>=`(相等也弹,队列保持严格递增),不弹等号也能过但队列变长、常数变大。
3. 删头是 `while` 更稳(理论上一次最多过期一个,但写 while 防手滑);判过期用 `q[h] <= i - k`。
4. n = 10^6,两个循环都要等 i ≥ k 才输出;输出 2×10^6 个数,printf 够用,卡常就上快读。
5. 单调队列与单调栈的区别只在于"队头过期删除":窗口问题必须双向,左右第一个更大元素(单调栈)只需一端。

## 延伸

- 单调队列最重的应用是 **DP 优化**:转移形如 `f[i] = min f[j] + w(i-j) 且 j ∈ [i-k, i]` 时 O(n) 化,见 `../笔记/速查/03-DP方法论.md` § 四;经典题 P2627 修剪草坪、P1725 琪露诺。
- 配题:P2251 质量检测(直接套)、P2216 理想的正方形(二维滑动窗口,行内一遍、列上再一遍)。
- 另一种"窗口最值"是稀疏表/线段树,但窗口**单向滑动**时单调队列 O(n) 且常数最小。
