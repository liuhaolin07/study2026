# P4145 上帝造题的七分钟 2 / 花神游历各国(线段树 + 势能剪枝)

- 专题:`04-data-structure` § 线段树(维护非常规信息)
- 难度:提高+/省选-
- 对应速查:`笔记/速查/02-数据结构选型.md` § 三

## 题意

n(n ≤ 10^5)个数(初值 ≤ 10^12),m(m ≤ 10^5)次操作:`0 l r` 把区间每个数**开方下取整**;`1 l r` 输出区间和。

## 思路怎么来的

硬伤一眼可见:开方**没有叠加性**,两个开方懒标记没法合并,"区间改"那套懒标记直接失效,单次区间开方最坏要碰所有叶子,O(nm) 必炸。

救命的观察是**开方的收敛速度**:

> 对任意 x ≤ 10^12,开方约 6 次后变成 1;**0 和 1 开方永远是自己**。

于是每个点真正"被修改"的次数是 O(log log V) 级别的——这就是**势能分析**:修改总代价有上限,只是被摊到很多次操作里。实现上给线段树再维护一个区间 max:递归修改时,

- 区间 `max ≤ 1` → 整段都是 0/1,开方不变,**直接剪掉**;
- 否则递归下去,叶子才真正开方。

这样总修改次数 = Σ(每个元素的开方次数)· log n,总复杂度 O((n + m log log V) log n) 级别,轻松通过。**不开方到 0 的场景 max≤1 剪枝同样成立**(0 ≤ 1)。

## 复杂度

修改均摊 O(log n · log log V),查询 O(log n)。这类"剪枝靠收敛"的线段树也叫**吉司机线段树**的入门形态(区间取 min/max 与本题同源)。

## 参考代码

```cpp
#include <cstdio>
#include <cmath>
#include <algorithm>
using namespace std;
typedef long long ll;
const int N = 1e5 + 5;

int n, m;
ll sum[N << 2], mx[N << 2], a[N];

ll isqrt(ll x) {                          // 开方下取整,防浮点误差
    ll s = (ll)sqrtl((long double)x);
    while (s > 0 && s * s > x) s--;
    while ((s + 1) * (s + 1) <= x) s++;
    return s;
}

void build(int u, int l, int r) {
    if (l == r) { sum[u] = mx[u] = a[l]; return; }
    int mid = (l + r) >> 1;
    build(u << 1, l, mid);
    build(u << 1 | 1, mid + 1, r);
    sum[u] = sum[u << 1] + sum[u << 1 | 1];
    mx[u] = max(mx[u << 1], mx[u << 1 | 1]);
}

void modify(int u, int l, int r, int ql, int qr) {
    if (mx[u] <= 1) return;               // 势能剪枝:整段 0/1,开方无效
    if (l == r) { sum[u] = mx[u] = isqrt(sum[u]); return; }
    int mid = (l + r) >> 1;
    if (ql <= mid) modify(u << 1, l, mid, ql, qr);
    if (qr > mid) modify(u << 1 | 1, mid + 1, r, ql, qr);
    sum[u] = sum[u << 1] + sum[u << 1 | 1];
    mx[u] = max(mx[u << 1], mx[u << 1 | 1]);
}

ll query(int u, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return sum[u];
    int mid = (l + r) >> 1;
    ll s = 0;
    if (ql <= mid) s += query(u << 1, l, mid, ql, qr);
    if (qr > mid) s += query(u << 1 | 1, mid + 1, r, ql, qr);
    return s;
}

int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) scanf("%lld", &a[i]);
    build(1, 1, n);
    scanf("%d", &m);
    while (m--) {
        int op, l, r;
        scanf("%d %d %d", &op, &l, &r);
        if (op == 0) modify(1, 1, n, l, r);
        else printf("%lld\n", query(1, 1, n, l, r));
    }
    return 0;
}
```

## 易错点

1. **没有懒标记不是忘了写**:开方不可叠加,套用"区间加"模板的 pushdown 反而错;修改逻辑只在叶子发生。
2. 势能剪枝的判据是**区间 max ≤ 1**,不是区间和——和很大不代表有可开方的元素。
3. `sqrt` 用 `double` 对 10^12 量级的完全平方数可能差 1,用 `sqrtl` + 校正循环(或对 `s² ≤ x < (s+1)²` 双向修)。
4. 值到 10^12,和更大,全程 long long;输入输出 `%lld`。
5. 部分题面不保证 `l ≤ r`,提交前确认,必要时 swap。
6. 复杂度对"势能"的依赖:**每个元素开方次数有限**是全局上界,单次操作仍可能 O(n log n)(对一段全是 2 的区间开方),别误以为单次修改是 log。

## 延伸

- 同族题:CF438D The Child and Sequence(区间取模 + 区间求和,势能同源)、P6242 【模板】线段树 3(区间取 min/max 的吉司机线段树,选学进阶)。共同点:**操作自身有势能上界**,所以不需要懒标记。
- 先想清楚"操作会不会无界":区间加没上界 → 必须懒标记;区间开方/取模/取 min → 找势能,找得到就不用懒标记。
- 对拍建议:随机小数据 + 暴力(数组直接开方)对拍,势能类题的正确性极适合这么验(流程见 `笔记/易错点与调试.md` § 五)。
