# P8306 【模板】字典树

- 专题:`08-string` § Trie
- 难度:普及/提高-
- 对应速查:`../笔记/速查/06-字符串算法对比.md` § 六

## 题意

T(T ≤ 10^5)组数据。每组给 n(n ≤ 10^5)个字符串(只含大小写字母和数字,共 62 种字符,大小写敏感),回答 q(q ≤ 10^5)个询问:每个询问串 t,输出 n 个串中**以 t 为前缀**的串的个数。所有输入串总长不超过 3×10^6。

## 思路怎么来的

"以 t 为前缀的串数"= 沿着 t 在 Trie 上走到的那个节点上,**挂着的串数**。所以插入时给路径上每个节点的计数 +1(不是只在叶子 +1),查询就是"顺着 t 走,走不动输出 0,走到底输出计数"。

本题的真正考点是**多组数据下的 Trie 工程学**:

1. **字符集 62**:儿子数组开 `ch[节点数][62]`;
2. **总节点数 ≤ 总长 + 1 = 3×10^6 + 1**(Trie 每插入一个字符至多新增一个节点),静态数组 `ch[3e6+5][62]` 约 750MB——本题内存限制就是为此放开的;换到 128MB 场合必须改动态开点或哈希儿子表(见易错点);
3. **多组数据不能整块 memset**:T 组最多 10^5,每组 `memset` 750MB 直接上天。正确做法是每组只把 `tot` 拨回 1,并且**每个新建节点把自己的儿子行清零**——这样脏数据只存在于"本组没走过的节点",查询永远读不到。

## 复杂度

每组:插入 O(Σ|sᵢ|),查询 O(Σ|tⱼ|),全组总长 ≤ 3×10^6,一次线性扫描。清零总代价也是 O(总长 × 62 字节),memset 实测极快。

## 参考代码

```cpp
#include <cstdio>
#include <cstring>
const int CH = 62, N = 3e6 + 5;
int T, n, q;
int ch[N][CH], cnt[N], tot;               // 节点 1 为根;cnt = 经过该节点的串数

int id(char c) {
    if (c >= 'a' && c <= 'z') return c - 'a';
    if (c >= 'A' && c <= 'Z') return 26 + c - 'A';
    return 52 + c - '0';
}

void insertStr(const char *s) {
    int u = 1;
    cnt[u]++;                             // 根被每个串经过
    for (int i = 0; s[i]; i++) {
        int c = id(s[i]);
        if (!ch[u][c]) {                  // 建新节点,当场清零防上一组残留
            ++tot;
            memset(ch[tot], 0, sizeof ch[0]);
            cnt[tot] = 0;
            ch[u][c] = tot;
        }
        u = ch[u][c];
        cnt[u]++;
    }
}

long long query(const char *s) {          // 询问串可能比所有串都长,计数用不到 ll 但统一写
    int u = 1;
    for (int i = 0; s[i]; i++) {
        int c = id(s[i]);
        if (!ch[u][c]) return 0;
        u = ch[u][c];
    }
    return cnt[u];
}

int main() {
    scanf("%d", &T);
    static char buf[N];
    while (T--) {
        scanf("%d %d", &n, &q);
        tot = 1;                          // 只拨指针,不整块清内存
        memset(ch[1], 0, sizeof ch[0]);   // 根节点单独清零
        cnt[1] = 0;
        for (int i = 0; i < n; i++) {
            scanf("%s", buf);
            insertStr(buf);
        }
        for (int i = 0; i < q; i++) {
            scanf("%s", buf);
            printf("%lld\n", query(buf));
        }
    }
    return 0;
}
```

## 易错点

1. **多测残留是本题的隐藏主考点**:忘了"新建节点时清零"会拿到上一组的旧儿子,查询走出幽灵分支;忘了根节点单独清零,第一层就串组。
2. 计数加在**路径上所有节点**(含根),不是只在叶子——查询问的是前缀数量而不是完整串数量。
3. 内存账要会算:节点数 ≤ Σ|s|+1,`62 叉 × 4B × 3e6 ≈ 750MB`。交题前先估内存;128MB 限制下改 `vector<array<int,62>>` 动态开点,或儿子表用 `unordered_map<int,int>`(慢一点但稳)。
4. `tot` 拨回 1 之后,**旧节点行不清**也没关系——只有被重新写入/新建的节点才可能被本组访问到,这是"用时清零"和"整块清零"的本质区别。
5. 62 字符映射函数三种区间的顺序判断别写重;`cnt` 数组类型按最坏情况(全部串共享一条链)开 long long 更稳,本题 int 亦可通过。

## 延伸

- 01-Trie(按位插入 0/1)是另一族:最大异或对(P10471)、异或前缀和;和这里的字符 Trie 共用"路径即信息"的思想。
- 多模式串匹配 = Trie + fail 指针 = AC 自动机(P3808),本目录字符串区后续补。
- 删除/撤销场景用"计数减一"而不是真删节点;卡内存时考虑可持久化(选学)。
