# P3375 【模板】KMP

- 专题:`08-string` § KMP
- 难度:普及/提高-
- 对应速查:`笔记/速查/06-字符串算法对比.md` § 三

## 题意

给文本串 s1 与模式串 s2,输出 s2 在 s1 中**每次出现**的位置(1-based,按顺序每行一个),再输出 s2 的 next(fail)数组:对 s2 的每个前缀,其最长的"相等真前缀与真后缀"的长度。样例:s1 = `ABCABC`,s2 = `AB`,出现位置 1、4;next = `0 0`。

## 思路怎么来的

暴力匹配每次失配都把模式串挪回开头,最坏 O(nm)。KMP 的核心观察:**失配时,模式串已经匹配过的部分是已知的**,它的"最长相等真前后缀"可以直接对接上,文本串指针 i **永远不回退**。

这个"最长相等真前后缀"就是 fail/next 数组:

> `nxt[i]` = s 前 i 个字符中,最长的既是真前缀又是真后缀的长度(≤ i-1)。

求 next 本身就是一次"自己匹配自己":`j` 表示当前已匹配的前缀长度,失配则沿 `nxt` 链回退,均摊 O(m)。匹配文本同理,匹配满就输出,再 `j = nxt[j]` 找下一次出现。

**记忆锚点**:next 数组是"模式串的自我介绍",匹配时失配问 next,不许回头。

## 复杂度

求 next O(m),匹配 O(n)(两个指针各自只增不减,均摊),总 O(n + m)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string t, s;                          // t:文本串 s1;s:模式串 s2(读入顺序别反)
    cin >> t >> s;
    int n = t.size(), m = s.size();
    vector<int> nxt(m + 1, 0);            // nxt[i]:s 前 i 个字符的最长相等真前后缀
    for (int i = 1, j = 0; i < m; i++) {  // 自我匹配求 nxt[2..m]
        while (j && s[i] != s[j]) j = nxt[j];
        if (s[i] == s[j]) j++;
        nxt[i + 1] = j;
    }
    for (int i = 0, j = 0; i < n; i++) {  // 匹配文本串
        while (j && t[i] != s[j]) j = nxt[j];
        if (t[i] == s[j]) j++;
        if (j == m) {                     // 完整出现一次,0-based 起点 i-m+1
            printf("%d\n", i - m + 2);    // 输出 1-based
            j = nxt[j];                   // 缩到最长相等前后缀,继续找下一次
        }
    }
    for (int i = 1; i <= m; i++) printf("%d%c", nxt[i], " \n"[i == m]);
    return 0;
}
```

## 易错点

1. **下标约定要先定死再写**:本代码 `nxt[i]` 按前 i 个字符(1-based 前缀)定义,循环里填的是 `nxt[i+1]`;网上的 0-based `fail[i]` 写法与它差一位,混着抄必然错。定好后贴进 `模板/`,别再改。
2. 读入顺序:洛谷 P3375 **文本串在前、模式串在后**,与"模式串优先"的直觉相反。
3. 匹配成功后 `j = nxt[j]` 不是 `j = 0`:允许重叠出现(如 `AA` 在 `AAAA` 中出现 3 次)。
4. 回退用 `while` 不是 `if`:一次失配可能要沿 next 链连跳多次。
5. 均摊复杂度的前提是"j 每次至多 +1":自己改题面(比如匹配后强制 j=0)会破坏均摊,复杂度仍是对的,但要心里有数。

## 延伸

- **周期/循环节**(next 数组最重要的应用):最小周期 `p = m - nxt[m]`;若 `m % p == 0`,p 是最小循环节。P4391 无线传输直接考这个结论。
- next 数组构成一棵树(fail 树),"每个前缀出现次数"沿树统计子树和。
- 多模式串 = Trie 上跑 KMP,即 AC 自动机(P3808),思路完全同构。
- 匹配还可用 Z 函数(拼 `s2#s1`),两者可互相推导,见速查表 § 四。
