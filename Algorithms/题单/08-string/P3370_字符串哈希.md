# P3370 【模板】字符串哈希

- 专题:`08-string` § 哈希
- 难度:普及/提高-
- 对应速查:`../笔记/速查/06-字符串算法对比.md` § 二

## 题意

N(N ≤ 10^4)个字符串(长度 ≤ 1500,含大小写字母与数字,大小写敏感),求互不相同的字符串个数。

## 思路怎么来的

直接两两比较 O(N²·L) ≈ 1.5×10^11 必炸;排序去重 O(N·L·log N) 也能过,但本题练的是**哈希**——把整个字符串压成一个整数,比较整数代替比较串,单次 O(1)(预处理 O(L)):

> `h = h·B + c`,B 取 131 或 13331。

用 `unsigned long long` **自然溢出**(模 2^64)最省事;判断"不同"只需比较哈希值:排序 + unique 后计数。

**哈希不是永远对的**:两个不同串可能撞出同一个哈希(冲突)。本题 N=10^4,冲突概率约 N²/2^64 ≈ 5×10^-12,足够安全;但 CF 上自然溢出哈希会被**针对性构造**卡掉,赛场双模数才是正装(见易错点)。

## 复杂度

读入 + 哈希 O(总长) ≈ 1.5×10^7,排序 O(N log N)。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef unsigned long long ull;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<ull> hs(n);
    for (auto &h : hs) {
        string s;
        cin >> s;
        ull v = 0;
        for (char c : s) v = v * 131 + (c + 1);   // +1 让"前缀空字符"不产生歧义
        h = v;
    }
    sort(hs.begin(), hs.end());
    cout << (int)(unique(hs.begin(), hs.end()) - hs.begin()) << "\n";
    return 0;
}
```

## 易错点

1. **自然溢出哈希会被卡**:出题人能构造让 131 进制自然溢出冲突的数据(CF 上真实发生)。赛场写双模:`h1 = h1*131+s % 1e9+7`、`h2 = h2*137+s % 998244353`,用 `pair` 排序去重。
2. 每位字符**加 1** 不是多虑:`"a"` 与 `"ab"` 若用 `h*131+c`,前者 = 'a',后者 = 'a'·131+'b',本就不同;但在某些取模方案里前导零(字符 0)会造成串尾歧义,养成 +1 习惯一劳永逸。
3. 大小写敏感:直接按字符值算即天然区分;若题目要"忽略大小写"先统一转小写再哈希。
4. 读入规模 1.5×10^7 字符,`cin` 记得关同步,或 `scanf("%s", buf)`(注意 buf 开 1505)。
5. 哈希回答"是否相等"但不回答"字典序"——要比较大小必须另存原串或用后缀数组。

## 延伸

- 前缀哈希 + 幂次数组,就能 O(1) 取**任意子串**的哈希:`hash(l,r) = h[r] - h[l-1]·B^{r-l+1}`,这是哈希真正的威力(P10468 兔子与兔子、二分+哈希求最长公共子串)。
- 回文判定:正着反着各建一份前缀哈希比较。
- 与 Trie 的分工:离线一次读入、只问相等 → 哈希;在线插入删除、问前缀 → Trie(P8306,本目录)。
