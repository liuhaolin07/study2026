# P1449 后缀表达式

- 专题:`01-stl` § 栈和 stack
- 难度:普及-

## 题意

给一个后缀表达式(逆波兰式)字符串,长度小于 1000,运算对象为不超过 2^31 的整数,数字之间用 `.` 分隔,表达式以 `@` 结束。求表达式的值。

样例:`14.3.20.*@` → 260(即中缀式的 `20 * (14 - 3)` 的后缀写法,计算过程见下)。

## 思路怎么来的

后缀表达式的定义天然适合栈:运算符出现在操作数**之后**,意味着读到运算符时,它的两个操作数**刚刚被读完**。于是:

- 读到数字 → 还不知道它何时被用,先压栈;
- 读到运算符 → 它需要的两个数就是栈顶的两个,弹出、计算、把结果压回去(结果也可能暂时没人用,继续等);
- 读到 `@` → 整个表达式算完,栈里剩下的唯一元素就是答案。

细节:数字以 `.` 结尾,所以逐字符扫描,用 `num = num*10 + c` 累积,遇 `.` 时入栈并清零。减法和除法**有顺序**:先弹出的是右操作数,后弹出的是左操作数,写反样例都过不了。

## 复杂度

每个字符处理一次,O(L),L 为字符串长度。

## 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    string s;
    cin >> s;
    stack<ll> st;
    ll num = 0;
    for (char c : s) {
        if (isdigit(c)) {
            num = num * 10 + (c - '0');
        } else if (c == '.') {
            st.push(num);
            num = 0;
        } else if (c == '@') {
            break;
        } else {
            ll b = st.top(); st.pop();   // 先弹的是右操作数
            ll a = st.top(); st.pop();
            ll r = 0;
            if (c == '+') r = a + b;
            else if (c == '-') r = a - b;
            else if (c == '*') r = a * b;
            else r = a / b;
            st.push(r);
        }
    }
    cout << st.top() << '\n';
    return 0;
}
```

## 易错点

1. **操作数顺序**:先弹的是 b(右),后弹的是 a(左),`a - b`、`a / b` 不能反。
2. 中间结果可能超 int(题目数字上限 2^31,乘法累积),用 long long。
3. 数字分隔符是 `.`,`14.3` 表示两个数 14 和 3,不是小数。
