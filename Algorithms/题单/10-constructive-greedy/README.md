# 构造 & 思维(没有固定模板,靠积累)

这类题没有题单可背,唯一方法是持续喂题:

## 方法

- CF 按 tag `constructive algorithms` + rating 1300~1800,**每天一道**,雷打不动
- 每题在本文件夹建一个 `CF题号_简记.md`,只写一句话:**关键观察是什么**
- 同类套路会反复出现:奇偶性、按位考虑、排序后贪心、交换相邻、鸽巢原理

## 文件格式示例

```
CF1980D_棋子.md:
关键观察:每次操作不改变总和的奇偶性,于是按总和奇偶性分类讨论。
```

## 学完的标准

- 1300~1500 的构造题,15 分钟内有靠谱方向
- 做不出时能快速判断"这是我能做的"还是"该丢给队友"
