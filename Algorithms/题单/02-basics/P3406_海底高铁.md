# P3406 海底高铁(差分统计)

- 专题:`02-basics` § 前缀和与差分(应用)
- 难度:普及/提高-
- 对应速查:`../笔记/速查/01-基础算法套路.md` § 三

## 题意

一条铁路 n(n ≤ 10^5)个站,相邻站 i~i+1 之间有两种付费方式:单程票每次 aᵢ 元;办卡花 bᵢ 元,之后每次 cᵢ 元。有人依次游览 m(m ≤ 10^5)个站(给出行程序列 P),每一段都走铁路最短路(即沿线路直走)。求最小总花费。

## 思路怎么来的

每种付费方式都只和"**这段铁路被经过几次**"有关,与顺序无关。所以先把 m-1 段行程摊到 n-1 条边上,统计每条边的经过次数 cntᵢ,再对每条边独立决策:`min(aᵢ·cntᵢ, bᵢ + cᵢ·cntᵢ)`。

统计次数用**边差分**:行程 p→q(p < q)覆盖边 p..q-1,做 `d[p]++, d[q]--`,前缀和还原即 cnt。若 p > q(反方向走)交换即可——线路是无向的。

两个经典套路叠在一起:**差分求覆盖次数 + 逐项贪心二选一**。

## 复杂度

O(n + m)。答案上界 10^5 × 10^5 × 10^5 = 10^15,**必须 long long**。

## 参考代码

```cpp
#include <cstdio>
#include <algorithm>
using namespace std;
typedef long long ll;
const int N = 1e5 + 5;
int n, m, p[N], d[N], a[N], b[N], c[N];

int main() {
    scanf("%d %d", &n, &m);
    for (int i = 1; i <= m; i++) scanf("%d", &p[i]);
    for (int i = 1; i < n; i++) scanf("%d %d %d", &a[i], &b[i], &c[i]);
    for (int i = 1; i < m; i++) {         // 相邻两站覆盖的边做差分
        int u = p[i], v = p[i + 1];
        if (u > v) swap(u, v);
        d[u]++; d[v]--;                   // 边 u..v-1 各 +1
    }
    ll ans = 0;
    for (int i = 1; i < n; i++) {
        d[i] += d[i - 1];                 // 前缀和还原 = 边 i 的经过次数
        ans += min((ll)a[i] * d[i], (ll)b[i] + (ll)c[i] * d[i]);
    }
    printf("%lld\n", ans);
    return 0;
}
```

## 易错点

1. **方向**:行程可能"往回走",必须 swap 成 u ≤ v 再差分;直接 `d[p[i]]++ d[p[i+1]]--` 在倒退时全错。
2. 差分数组是**对边编号**做的:`d[u]++` 里的 u 既是站点又是边号(边 i 连接 i 与 i+1),别混成点差分。
3. 次数为 0 的边也要参与 min(两项都是 0,无影响但别写除法)。
4. `a[i] * d[i]` 中间量 10^10,乘前转 long long;ans 累加同理。
5. 办卡的 bᵢ 是**一次性**沉没成本,即使 cntᵢ = 1 也可能划算(比较式里已体现),不要写成"次数 ≥ 2 才办卡"的错误贪心。

## 延伸

- 本题是"差分统计 + 独立决策"的范本:先把全局问题摊到每个元素,再逐项最优。同思路:P2367 语文成绩(本目录)、P1719 最大加权矩形。
- 若行程不沿铁路直走而是任意路径,就要先求最短路再数边——"先转化再差分"是常用组合拳。
