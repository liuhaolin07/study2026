# P2367 语文成绩(差分模板)

- 专题:`02-basics` § 前缀和与差分
- 难度:普及-
- 对应速查:`笔记/速查/01-基础算法套路.md` § 三

## 题意

n(n ≤ 5×10^6)个学生的初始成绩,m(m ≤ 5×10^6)次操作:每次把区间 [x, y] 的成绩都加上 z(可为负)。最后 p(p ≤ 5×10^6)次询问:某个学生现在的成绩。

## 思路怎么来的

最朴素的想法:每次操作把 [x, y] 挨个加 z,单次 O(n),m 次共 O(nm) = 2.5×10^13,必死。

矛盾点在"**区间改**"与"**单点查**"方向相反:挨个改贵,但查询便宜。**差分**恰好把这两件事反过来——只在差分数组上改两个端点 O(1),查询时用一次前缀和还原。

> 核心等式:若 `d[i] = a[i] - a[i-1]`,则"区间 [x,y] 整体加 z"等价于 `d[x] += z; d[y+1] -= z`。因为对 i ∈ [x,y],前缀和 Σd 恰好多 z,y 之后恢复如初。

还原时对 d 做一遍前缀和,得到的正是每人最终成绩——所以本题把前缀和**原地**算在 d 上,查询直接 O(1) 读下标。

## 复杂度

建差分 O(n),每次操作 O(1),前缀和 O(n),总 O(n + m + p)。瓶颈在读入:5×10^6 个数,必须快读。

## 参考代码

```cpp
#include <cstdio>
const int N = 5e6 + 5;
int n, m, p, d[N];                       // 差分数组,最终原地前缀和 = 每人最终分数

inline int read() {                      // 负数也要能读(z 可为负)
    int x = 0, f = 1, c = getchar();
    while (c != '-' && (c < '0' || c > '9')) c = getchar();
    if (c == '-') f = -1, c = getchar();
    while (c >= '0' && c <= '9') x = x * 10 + (c - '0'), c = getchar();
    return x * f;
}

int main() {
    n = read(); m = read(); p = read();
    int prev = 0;
    for (int i = 1; i <= n; i++) {       // 读初始分,直接落成差分:d[i] = a[i] - a[i-1]
        int cur = read();
        d[i] = cur - prev;
        prev = cur;
    }
    while (m--) {
        int x = read(), y = read(), z = read();
        d[x] += z;
        d[y + 1] -= z;                   // y+1 ≤ n+1,数组要开 n+5
    }
    for (int i = 1; i <= n; i++) d[i] += d[i - 1];   // 差分还原
    while (p--) {
        int x = read();
        printf("%d\n", d[x]);
    }
    return 0;
}
```

## 易错点

1. **快读是硬要求**:5×10^6 个数用 `cin`/`scanf` 都可能卡过去但有风险,`getchar` 快读最稳;z 可为负,快读要处理负号。
2. `d[y+1]` 越界:y 可以等于 n,数组开 `n+5`,别开 `n+1`。
3. 还原必须**在所有操作做完之后**——中途有人问"现在多少分"这种题就要在线树状数组了。
4. 最终分理论上可能为负,若担心爆 int 把 d 开成 long long(内存翻倍,本题限内可过)。
5. 不要写"循环区间逐个加"的暴力碰运气:O(nm) 在本题数据下必 TLE,验证贪心/数据结构的第一反应应是看操作方向。
