# P2280 激光炸弹(二维前缀和)

- 专题:`02-basics` § 前缀和与差分(二维)
- 难度:普及/提高-
- 对应速查:`../笔记/速查/01-基础算法套路.md` § 三

## 题意

地图上有 n(n ≤ 10^4)个目标,坐标 (xᵢ, yᵢ) ∈ [0, 5000]²,价值 vᵢ。一次爆炸能摧毁一个**边长 m(m ≤ 5000)的正方形**,问一次最多摧毁多少总价值的目标。**关键规则:目标若在正方形的边上,不会被摧毁**(严格内部才算)。

## 思路怎么来的

正方形位置可以连续滑动,枚举位置没法下手;但"某个区域内目标和"是二维前缀和的本行。两个转化:

1. **离散到格点**:把每个目标记到 `s[x+1][y+1]`(整体右移一格,顺便消掉 0 坐标的边界问题),多次命中的价值累加。
2. **把"严格内部"变成整数窗口**:开区间长度 m 内最多含 m 个整数格点(半偏移即可取满),所以"能被炸掉的格点集合"恰是任意 m×m 的连续格子窗口——枚举窗口右下角即可,不用真的处理实数。

于是答案 = 所有 m×m 窗口和的最大值,二维前缀和 O(1) 查询。

## 复杂度

建前缀和 O(5001²),枚举窗口 O(5001²),总 O(地图²) ≈ 2.5×10^7,轻松通过。

## 参考代码

```cpp
#include <cstdio>
#include <algorithm>
using namespace std;
const int N = 5005;
int n, m, s[N][N];                        // 原地做二维前缀和,省一个数组

int main() {
    scanf("%d %d", &n, &m);
    for (int i = 0; i < n; i++) {
        int x, y, v;
        scanf("%d %d %d", &x, &y, &v);
        s[x + 1][y + 1] += v;             // 右移一格:坐标 0 变下标 1
    }
    for (int i = 1; i <= 5001; i++)
        for (int j = 1; j <= 5001; j++)
            s[i][j] += s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1];
    if (m > 5001) m = 5001;               // 边长超过地图 = 炸全图
    int ans = 0;
    for (int i = m; i <= 5001; i++)
        for (int j = m; j <= 5001; j++)
            ans = max(ans, s[i][j] - s[i - m][j] - s[i][j - m] + s[i - m][j - m]);
    printf("%d\n", ans);
    return 0;
}
```

## 易错点

1. **"边上不炸"是这个题的灵魂**:直觉会算成闭正方形(m+1 格窗口),错在把边界目标算进去。正确模型是"开区间能含 m 个格点 → m×m 窗口"。
2. 坐标从 0 开始:直接拿 x 当下标会丢掉第 0 行/列的容斥,统一右移一格。
3. **内存**:5005×5005 的 int 约 100MB,洛谷本题限内可过;若在内存 128MB 的场合抄这个写法MLE,先算好 `数组大小 × 4B` 再交。
4. m > 5000 要截断,否则窗口枚举直接漏掉全图;多重目标同一格点要 `+=` 不是 `=`。
5. 前缀和容斥的符号:`+s[i][j] - s[i-m][j] - s[i][j-m] + s[i-m][j-m]`,减号写漏一个就变成天价答案。

## 延伸

- 二维差分的镜像操作(矩形加、单点查)见速查表;P2004 领地选择是同款"固定尺寸窗口最大和"。
- 坐标范围大到 1e9 时不能开地图数组,先**离散化关键坐标**再前缀和(思路见速查 § 五)。
