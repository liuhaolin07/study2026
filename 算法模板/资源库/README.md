## 🎯 如何使用这个资源库

### 学习新算法
1. 在 OI Wiki 上查看讲解
2. 看相关书籍或视频
3. 记录笔记
4. 从模板库找相关代码
5. 做 10-20 道对应题目

### 参加比赛
1. 提前准备好常用模板
2. 带上题目模板和笔记
3. 比赛后详细填写比赛记录
4. 分析自己的失误

### 定期复习
1. 每月查看模板库，补充新模板
2. 每月回顾比赛记录，找出规律
3. 每季度回顾书籍的重点内容
