"# 线性表和链表

## 学习目标

- [ ] 理解数组（顺序表）的存储结构和特点
- [ ] 理解链表（单链表、双链表、循环链表）的存储结构和特点
- [ ] 掌握数组和链表的基本操作（增删改查）
- [ ] 比较数组和链表的优缺点

## 核心概念

### 数组（顺序表）
- 连续内存空间
- 随机访问 O(1)
- 插入/删除 O(n)
- 适用于：频繁查询、少量修改

### 链表
- 离散内存空间
- 随机访问 O(n)
- 插入/删除 O(1)
- 适用于：频繁修改、少量查询

## 代码模板

### 数组实现
```cpp
// 动态数组
vector<int> arr;
arr.push_back(1);     // 添加
arr.pop_back();       // 删除末尾
arr.size();           // 大小
arr[i];               // 访问 O(1)
```

### 单链表
```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

// 创建节点
ListNode* head = new ListNode(1);
head->next = new ListNode(2);
head->next->next = new ListNode(3);
```

## 学习笔记

### 链表分类
1. **单链表**：每个节点只有一个 next 指针
2. **双链表**：每个节点有 prev 和 next 指针
3. **循环链表**：最后一个节点指向第一个节点

### 时间复杂度比较
| 操作 | 数组 | 链表 |
|------|------|------|
| 访问 | O(1) | O(n) |
| 插入（已知位置） | O(n) | O(1) |
| 删除（已知位置） | O(n) | O(1) |
| 末尾添加 | O(1) | O(1) |"
