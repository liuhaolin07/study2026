# 模板维护指南

## 接口约定

- 使用 C++17，头文件必须自包含，不依赖调用方预先包含 `bits/stdc++.h`。
- 公开下标使用 0-based；区间接口默认闭区间 `[left, right]`。
- 无效参数抛出 `std::invalid_argument`，越界抛出 `std::out_of_range`。
- 无法构造的合法结果优先使用 `std::optional`，例如非连通图的 MST。
- 头文件中的非模板自由函数必须声明为 `inline`，避免多翻译单元重复定义。

## 新增模板

1. 将头文件放到正确分类目录，并写明功能、输入约束和复杂度。
2. 在 `tests/test_templates.cpp` 增加正常、边界和错误输入测试。
3. 如果新增了非模板自由函数，在 `tests/odr_probe.cpp` 中包含对应头文件。
4. 更新 `XCPC_Templates/README.md` 的索引和分类 README。
5. 运行 `tests/run_tests.ps1`，确保零警告并通过全部检查。

## 审查清单

- 空输入、单元素、重复值和最大/最小合法下标是否定义清楚。
- 加法、乘法、距离松弛是否可能溢出。
- 图算法是否区分负边、负环和非连通图。
- 构造函数是否真的使用了输入数据。
- 查询函数能否标记为 `const`。
- README 声明的文件、接口和复杂度是否与代码一致。

## Windows 中文路径

部分 MinGW 链接器不能在中文路径中创建 `.exe`。`tests/run_tests.ps1` 检测到非 ASCII 项目路径时，会把测试可执行文件写到系统临时目录；源代码仍从项目目录读取。
